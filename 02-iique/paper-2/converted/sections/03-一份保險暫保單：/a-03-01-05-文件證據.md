# 第3章 一份保險暫保單： > 3.1.5 文件證據

證明文件有多種形式。提供證明文件可能是被保險人的責任，也可能是保險人的責任（包括支付所需費用）。尤其應該注意以下各項：

( a ) ：這些不可避免地是被保險人的責任，因收集而花的費用也由他承擔。理論上，收據是必需的，然而保險人應該採用實際可行及合理的辦事方法。要求出具收據以證明商業上的損失屬於普遍和合理的做法，不過相對小額的個人保險索償或保險金要求則可作例外。

( b ) ：商業保險（例如火災、盜竊及後果損失）通常要求保留足夠的記錄，作核實損失用途。保險人相當可能會堅持這項要求。

( c ) ：在這類索償中，文件證明十分重要。所需文件包括檢驗報告、保單正本、提貨單，或再加上其他的所有權文件。

( d ) ：提出喪失能力（人身意外）的保險金要求，須出具醫療報告，所需費用由被保險人負責。如果僱主要求受傷的僱員進行體檢，體檢費應由僱主按照《僱員補償條例》支付，但最終是由有關的保險人承擔。

( e ) ：通常由保險人收集。
