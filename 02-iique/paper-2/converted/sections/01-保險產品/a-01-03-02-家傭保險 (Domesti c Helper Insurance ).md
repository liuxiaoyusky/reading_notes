# 第1章 保險產品 > 1.3.2 家傭保險 (Domesti c Helper Insurance )

## (a) 保障範圍

家傭保險可以用獨立的保單或家居保單的自選保障形式提供。它基本上屬於一籃子保障，承保僱主對家傭承擔的 ，及向其提供的 ，包括：

( i ) 醫療開支；

( i i ) 即萬一家傭死亡，或因身體不好而不宜繼續受僱，把家傭或其遺體送返或運返家鄉所花的費用（視屬何情況而定）；

( i i i ) 及

(iv) 即家傭在香港對第三者承擔的法律責任。

保障範圍也可以包括：在家傭住院超過比如 3 天的情況下給受保住戶支付 （一項每日現金補貼），支付因家傭不予通知而離去、變得殘疾或死亡而需 ，及賠付因家傭 而給被保險人帶來的財務損失。

## (b) 限制及除外責任

這些方面與所提供的不同險種的情況是一致的。例如人身意外保障受到人身意外保險的常用除外責任條款所約束（指明運動、自殺、分娩、懷孕等），醫療開支保障載明不保保險生效前已患疾病、整容手術、例行醫療檢查等。

(c) 保費：按每名家傭收取固定保費。
