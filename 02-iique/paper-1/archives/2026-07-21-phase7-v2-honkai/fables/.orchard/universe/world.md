# 保险考试1 · 王者荣耀宇宙 (v2)

## 适用范围

这是《保险考试1》单本书的 Phase 7 寓言世界观 **v2**。它只作用于 v2,作用于 archives/2026-07-21-phase7-v2-honkai/ 下的全部 fab 生成,不跨书复用,不写入跨项目长期记忆区。

v2 不改变任何拆分规则:仍然 **1 H1 = 1 fab,严格 1:1 映射,命名沿用 v1**。v2 只换故事风格、人物谱和情绪底色。

## 世界基调

时间:王者大陆上的"现在时",以稷下纪年记之。三个学院与诸国会盟交错并存,长城与玄雍对峙,云中漠地商旅不绝。

地点(可按章切换):

- 稷下学院(学宫、机关工坊、藏书楼、辩论台)
- 玄雍(朝堂、律法寺、户籍司、赈灾司)
- 云中漠地(沙暴走廊、丝路驿站、商队、骆驼客)
- 长城守卫军(烽火台、戍边营地、校场)
- 大理寺/长安(法庭、缉事铺、官驿)
- 东海/云梦泽(水师、泽国船渡、岛屿港口)
- 魏国/蜀国/吴国古城(任何需要"江湖"或"江湖气"的江湖场景)

时代气质:明君、能臣、忠将、贤士并存,秩序与江湖气、朝廷与学院、长城内外、家国与个人交织。寓言不在复刻王者官方硬史,而是借这一片大陆去承载"风险、责任、承诺、监管、伦理"这些抽象概念。

叙事风格:**现代白话 + 半个游戏梗**,舞台是王者大陆,但人物开口可以像峡谷玩家一样讲话。戏剧冲突靠人物立场和嘴皮子,而不是打技能特效。每篇故事像一段峡谷同行的小传,发生在学院辩论、律法判案、漠地商旅、长城值守、茶馆密议之中。

> 允许的语气:"这波不亏""直接 GG""等我回城再上线""对面开大我就跑"——这些都是合法的语气词,可以让角色"说一句王者圈里才有的俏皮话"。
> 王者 UI 词当正经台词没问题:**技能名(回城/治疗/闪现/护盾/惩戒)、装备名(反甲/魔女/名刀/辉月)、地图词(主宰/暴君/暗影暴君/草丛/河道/小龙)、游戏圈梗(吃口低保/打得好不如躺得好/对面稳得一批)**——都可以由人物自然开口。
> 但请别照搬官方技能描述当台词(比如不要写"诸葛亮释放了时空穿梭穿越到了过去")。最好让 UI 词**滑过口语**,像一个老玩家在聊棋局。

## 一致性硬规则

- 每篇仍然严格 **1 H1 = 1 fab**。
- 全书共享同一个王者大陆观:阵营、地理、人物履历前后要一致。
- 每章有自己专属的"主舞台"(见 chapter-casts/*.json)。
- 主角优先复用章内 cast;可以新增路人,但不要新增核心主角,也不要让核心主角突然改换阵营或履历。
- 故事要落地到具体场景:一个辩论题、一桩纠纷、一次商队被劫、一封请愿、一份账册。
- **王者术语**(技能名、装备名、地图词、玩家圈梗)**可以自然开口**,没有禁用词,见"世界基调 > 叙事风格"那一段。

## 风格软规则

- **保险专业术语全不进正文**。故事段 / 对话段 / 叙述段一律不用"保险""保单""最高诚信""可保利益""近因""代位""分摊""委付""损余""弥偿"等术语。术语 **只放在 "原文定义" 段**,那是引用教材原文,不属于故事。
- 人物开口要说"白纸黑字""出事有人兜底""拿一笔钱以防万一""账目做不得假""谁应得"这类 **带王者古人气的白话**(可以混用半文半白)。
- 也可以用更口语、像峡谷玩家聊天的语气,**王者 UI 梗完全允许**:护盾、回城、治疗、惩戒、草丛、河道、主宰、暴君、GG、吃低保、躺好、对面开大、这波不亏……都可以让角色自然说出来。
- 隐喻要贴王者世界观:承诺可以写"立文书一封",监管可以写"上官派员查账",道德可以写"君子一诺"。
- 感情线服务概念:角色之间的牵挂让他们理解"为什么有人愿意义务为别人承担后果"。
  - 不直接写爱情冲突;用行动表达(替对方挡一刀、多留一封信、夜里替对方守更);每篇只服务一个核心概念,不抢主线。
- 战场和打架只作背景,不写大招效果;**一段对话、一笔账、一封书,胜过一场团战**。但若人物愿意"打一局"来形容风险,也不是不行。

## 全局共享人物(横跨章节的"叙述者骨架")

- **姜子牙**(稷下夫子,常以旁观者身份穿针引线;年迈、慎重、说话不凭喜好而凭典籍。可承担"风险/精算/承诺"的纵深台词。)
- **大乔 / 小乔**(江东乔氏姐妹,温柔、稳重;可承担"家庭责任、受益人、感情"暗线。她们的故事不抢主线,只做底色。)
- **蒙恬**(玄雍将领,守规矩、讲条文;可承担"监管、披露、持牌"等需要"上官派员"台词的章节。)
- **苏烈**(长城守卫军老将,讲义气、重承诺;可承担"保险原则中的近因、损失补偿"等需要"军人视角"的章节。)
- **鬼谷子**(稷下贤者,讲命数与因果,克制冷静;可承担"风险、不确定性"等抽象概念的引子。)

允许这些人物在不同章节以"一闪而过"或"半个字"的方式出现,但只在所属 cast 的章节做实戏。

## 核心场景与适用概念

- **稷下学院辩论台/藏书楼** → 风险、不确定性、风险分类、最高诚信、披露义务
- **玄雍律法寺/赈灾司** → 法律原则、可保利益、合同、代位、监管
- **长城烽火台/戍边营地** → 保险原则、近因、损失补偿、委付、损余、共保
- **云中漠地商队驿站** → 保险公司功能、再保险、协会联保
- **大理寺/长安官驿** → 监管架构、披露要求、持牌、回避、利益冲突
- **茶馆 / 江湖客栈** → 职业道德、防止洗钱、贿赂、保险诈骗
- **江东水域/云梦泽** → 受益人、长期承诺、家庭责任

## 一段示例(只作风格示范,不进任何 fab)

> 墨子把账册摊在辩论台前的青石上,抬头问诸葛亮:"孔明,商队上次走云中,半路遇上沙暴,货全湿了。商主说这是'天意',行商说这是'人算不如天算'。你说,这事儿是定数,还是未定?"
> 诸葛亮喝了一口冷萃:"孔明我跟你说,这不是定数,这叫'对面的埋伏'——你不知道他什么时候开,开了就 GG。"

> 武则天翻着律法寺送来的卷宗,问狄仁杰:"这桩活人与死人之间的承诺,白纸黑字讲得出道理吗?"
> 狄仁杰答:"娘娘,讲得出才讲得清;讲不清时,就像一次团战打完后没结算——先别急着开下一局。"

> 王昭君在藏书楼门口整理暗影暴君的笔记,见墨子从辩论台出来,她叹了口气:"我这波先去读本。"
> 墨子:"去吧,你这是回城——回来再一起开团。"

风格定调:**王者大陆里讲人话,人话里带峡谷味;道理嵌入人物关系,不是照本宣科**。

## 跨章连贯日志

每写完一篇 fab,如果章节发生了变化(人物履历、上次说话的承诺、欠下的一笔账……),在 `universe/continuity-log.jsonl` 里追加一行:

```jsonl
{"chapter":"03-保險原則","section":"近因","event":"苏烈在长城烽火台替守夜的新兵挡了一阵风沙","implies":"今后该新兵若出事,苏烈会认定有'看守'之责"}
```

这是给所有 worker 看的"已发生事件"提示,避免它在另一章里假装从没发生。
