# 保险考试1 共同人物宇宙

## 适用范围

这是《保险考试1》单本书的可选世界观设定。它只作用于当前书的 Phase 7 寓言生成，不跨书复用，不写入跨项目长期记忆区。

本世界观不改变任何拆分规则：每篇仍然严格 `1 H1 = 1 fab`。世界观只约束故事风格、人物连续性和情绪底色。

## 世界基调

时间：1980 年前后的香港。

地点：一个横跨中环、上环、湾仔、尖沙咀、观塘、鸭脷洲、油麻地和维港码头的商业城市。城市里有渡轮、叮叮车、红色小巴、旧式唐楼、码头仓库、制衣厂、茶餐厅、银行大堂、洋行办公室、街坊诊所、律师楼和保险行。

时代气质：香港正在从制造业城市转向金融和服务业城市。街坊仍然重人情、口碑和熟人介绍，商号则越来越依赖合约、账本、银行、保险和制度。许多人一边相信街坊关系，一边开始学会用白纸黑字保护自己和家人。

叙事风格：生活化、有人情味、有真实两难。不要写成教材讲解，也不要写成宏大历史剧。每篇故事都像发生在普通香港街坊、商号、码头、工厂或洋行里的一件具体小事。

## 英国元素

英国元素作为环境和制度背景出现，不喧宾夺主。

可以出现：

- 中环的英资洋行、保险公司、银行经理、英文合约、打字员、秘书和档案柜
- 英式普通法、法院、律师楼、殖民地政府部门、牌照、监管、消防检查
- 英国经理、香港本地买办、双语文书、英文信件、印章和正式通知
- 伦敦来的规章、总公司批文、英镑账目、航运保险传统
- 港督画像、政府公告、皇家警察、海关、码头监管

不要写成：

- 英国人永远正确、本地人永远落后
- 政治说教或殖民史讲解
- 与保险概念无关的大事件背景
- 为了时代感而牺牲保险概念准确性

## 核心场景

### 码头与船运

适合讲风险、货物损失、责任、赔付、共同海损、运输相关概念。

常见场景：台风压港、货柜受潮、船期延误、码头工人受伤、货主和船公司争执。

### 制衣厂与小商号

适合讲财产保障、雇员保障、火灾、机器损坏、现金流压力。

常见场景：观塘制衣厂赶订单、机器突然坏、仓库起火、老板舍不得花钱买保障。

### 茶餐厅与街坊生活

适合讲人寿、医疗、意外、家庭保障、长期承诺。

常见场景：伙计摔伤、老板娘住院、家庭顶梁柱出事、街坊众筹但不够用。

### 洋行与银行

适合讲合同、核保、费率、精算、再保险、诚信披露、文件审查。

常见场景：英文合约少看一行、账房漏报事实、经理要求补文件、总公司不同意承保。

### 旧楼与街区

适合讲火险、责任、共用空间、业主与租客、邻里纠纷。

常见场景：唐楼水管爆裂、招牌掉落、楼上楼下互相追责、业主大会争执。

## 隐晦感情线

本书允许轻微、克制、长期埋伏的感情线。感情线只能作为人物动机和情绪底色，不能抢走保险概念主线。

写法要求：

- 不直接告白，不写狗血爱情冲突。
- 用行动表达关系：多留一把伞、替对方核一遍账、把保单夹进旧信封、台风夜多打一个电话、一杯放凉的奶茶。
- 感情线服务概念：因为在意某个人，所以人物开始理解“保障”“责任”“长期承诺”“风险转移”。
- 每篇故事仍然只讲 1 个核心概念。感情线是暗线，不是主题。
- 情绪像老香港电影里的留白：一句没说出口的话，一个没送出的信封，一个没回头的电车站。

总原则：感情线不是为了制造爱情，而是为了让“保障”背后有一个具体想守住的人。

## 可复用情感暗线

### 梁志明 与 林若兰

梁志明是本地保险行伙计，林若兰是英资洋行的中英打字员。两人常在文件、合约、批文之间打交道。

关系基调：互相欣赏，但都很克制。

表现方式：林若兰会替梁志明指出英文条款里的细节；梁志明会在台风天绕路送她回电车站。

适合承载：合同条款、如实告知、核保、保单解释、长期承诺。

禁忌：不要直接写成恋爱故事。两人的关系永远通过工作细节和日常照顾表现。

### 陈伯 与 旧日未婚妻

陈伯是老账房，年轻时曾有一位未婚妻后来去了英国。她偶尔从伦敦寄来明信片，提醒他世界变了，但陈伯仍守着旧账本。

关系基调：遗憾、克制、旧时代余温。

表现方式：陈伯把明信片夹在账簿里，遇到年轻人犹豫是否买保障时，会想起当年自己没能准备好的事。

适合承载：人寿保障、家庭责任、长期风险、现金价值、受益人安排。

### 何师奶 与 已故丈夫

何师奶经营茶餐厅，丈夫早年因意外去世。她嘴上精打细算，实际很怕伙计和家人重蹈覆辙。

关系基调：失去之后的责任感。

表现方式：她舍不得换旧招牌，却愿意给伙计买意外保障；她不说“我担心你们”，只说“出事唔好连累屋企人”。

适合承载：意外险、医疗险、责任险、家庭保障。

## 固定规则

- 每篇仍然严格 `1 H1 = 1 fab`。
- 全书共享同一个 1980 年前后老香港世界观。
- 每章有自己的小主角团，章内人物、地点、关系要连续。
- 可以有英国经理、律师、政府职员，但核心视角优先放在香港本地人物身上。
- 英国元素只做制度背景，不做政治说教。
- 故事正文尽量不用保险专业术语。专业词只放在“原文定义”和“对应点”里。
- 人物可以讲“保障”“赔钱”“白纸黑字”“出事有人兜底”，不要直接讲“保险利益”“近因原则”“等待期”等术语。
- 不要为了连续性合并多个 H1，也不要为了感情线牺牲概念准确性。
- 不要让人物职业、性格、关系前后矛盾。
- 不要每篇临时新造一个完全无关世界。

## 章内人物谱建议

每章生成 3-6 个核心人物即可。人物谱应包含：

- `setting`：本章主要地点或行业场景
- `cast`：核心人物数组
- `rules`：本章人物使用规则

示例：

```json
{
  "setting": "上环一家替商号安排保障的洋行办公室",
  "cast": [
    {
      "name": "梁志明",
      "role": "本地保险行伙计",
      "trait": "勤快、会讲街坊话，也看得懂英文文件"
    },
    {
      "name": "林若兰",
      "role": "英资洋行中英打字员",
      "trait": "细心、克制，常能发现合约里被忽略的小字"
    },
    {
      "name": "陈伯",
      "role": "老账房",
      "trait": "谨慎，凡事看账本、收据和旧信封"
    },
    {
      "name": "Mr. Thompson",
      "role": "英资洋行经理",
      "trait": "重视文件和规则，但不太懂街坊做生意的习惯"
    }
  ],
  "rules": [
    "本章优先复用这些人物",
    "可以新增路人，但不要新增核心主角",
    "人物不能突然改变职业、性格或关系",
    "隐晦感情线只能作为动机底色，不能成为故事主题"
  ]
}
```
