# 1.1.1 壽 險 的 需 求

## 🍜 寓言故事 —— 《小蔡的账本》

小蔡在老弄堂口开了家小面馆,做了第五个年头,刚攒够钱把隔壁半间铺面也盘下来,打算挂个"蔡记"的招牌,顺带把房子重新刷一遍。老婆阿芳肚子里那一个,再有四个月就要生了。

这天晚上收摊,小蔡把当天的钱往抽屉里一扔,坐到桌前,摊开那本他用了三年的牛皮纸账本。一笔一笔写下去,他的眉头越皱越紧。

第一个,老婆生娃,产检、住院、月子里的花销,少说也得上万。第二个,孩子生下来,奶粉、尿布、看病,一年到头是笔长流水。第三个,孩子再大点要上学,城里的学校光赞助费就把人吓一跳,后面还有补习班、兴趣班,一年攒不下几个钱根本撑不住。第四个,自己爹妈年纪大了,身体一年不如一年,医院里一去就是大几百,要是哪天躺下动不了,那更是要命。第五个,面馆刚刚扩了一间,跟街坊借的钱还没还,每个月光利息就是一笔。第六个,店里那台旧冰柜三天两头出毛病,真要哪天彻底报废,临时拿不出钱进货,生意就得停。第七个,阿芳最怕他说的一句话——"万一我有个闪失"。

小蔡拿笔杆敲着桌子,念叨:"这七件事,哪一件离得开钱?"他转头看阿芳,阿芳正低着头缝小衣服,没接话。

转折发生在半个月后一个清晨。隔壁那家做铝合金门窗的铺子,电焊的火星子引着了堆在后头的废木料,火苗蹿得老高,烧了小蔡面馆的半边屋顶,灶台、冰柜、桌椅全毁了。所幸人没事。可小蔡站在街边,看着那一堆焦黑的木头,两腿发软。

他心里忽然翻出一句话——前阵子发小阿辉劝他买份寿险,被他笑骂了回去:"我年纪轻轻,谈什么身后事,晦气。"那天晚上,小蔡一个人坐在临时搭的棚子里,看着阿芳抱着肚子在里头点蜡烛。他想:要是这火不是烧了铺子,而是烧在自己身上呢?我躺在医院里,谁来还债?谁去给阿芳生孩子、养孩子?谁去给爹妈看病?谁去给面馆重新开张?

他不是怕死。他是怕"自己不在"以后,那些本来压在肩上的事,一股脑全砸在阿芳头上,她一个人扛不住。

第二天一早,小蔡找到阿辉,坐下来认真听他说。听完,他没问"买哪种最划算",也没问"哪家口碑好"。他只问了一句:"能不能有一份合约,真到了那一天,钱会替我继续把该做的事做完?"

阿辉点点头:"能。"

小蔡站起来,把那本账本翻到第一页,指着自己写的那七件事说:"我买的就是这七件。它不是保我的命,它是保这七件事在我不在的时候,还能继续往前走。"

---

**📖 原文定义**

> 人壽保險的種種用途,現代觀點傾向從人壽保險如何滿足各種需求的角度去了解。需求可概括為:
> (a) 個人需求(Personal Needs):(i)受養人的生活開支;(ii)善終(生命完結)開支;(iii)教育經費;(iv)退休收入;(v)償還按揭資金;(vi)應急資金;(vii)殘疾收入。
> (b) 業務需求(Business Needs):(i)關鍵人物;(ii)企業擁有人;(iii)合夥人;(iv)僱員福利。

**💡 对应点**

| 故事元素 | 概念对应 |
|---------|---------|
| 小蔡账本上的七件心事 | 寿险的「个人需求」七项分类 |
| 阿芳、孩子、父母 | 受养人的生活开支 + 退休收入(赡养父母) |
| 产检、住院、月子花销 | 善终(生命完结)开支的延伸——家人因他而产生的支出 |
| 孩子上学、补习 | 教育经费 |
| 面馆扩铺欠下的借款 | 偿还按揭资金 |
| 旧冰柜随时可能报废 | 应急资金(突发开支) |
| 着火那晚,小蔡想「万一我不在了」 | 寿险存在的根本动因——保护身后的家人 |
| 小蔡最后那句话:「不是保命,是保钱还在做事」 | 寿险的本质:用合约把未来的开支提前锁住 |
