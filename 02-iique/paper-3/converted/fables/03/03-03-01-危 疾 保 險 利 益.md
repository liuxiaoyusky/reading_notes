# 3.3.1 危 疾 保 險 利 益 (Critical Illn ess B en efit)

## 🛡️ 寓言故事 —— 《一篮鸡蛋》

老夏在菜市场卖了二十年鸡蛋，从一辆破三轮车做到两间门面。他每天凌晨三点起床，骑着那辆咯吱作响的电动车去批发市场进货，再赶回店里摆好，等着早起的主妇们来挑。日子虽然辛苦，但家里两个孩子都在读书，老夏算过，攒够钱再过五年，就够给儿子付首付了。

有一年春天，老夏开始觉得胸口闷。起初他没当回事，以为是搬货累的。后来连上楼梯都喘，他才在媳妇的催促下去医院检查。医生拿着片子，表情严肃，说他心脏里有根血管堵了大半，得做手术，不然随时可能倒下。

媳妇当场就慌了："手术费要二十万，咱家哪有？"老夏坐在医院走廊的长椅上，也愣住了。他盘算了一下家底——存款只有八万，门面租金马上要交，两个孩子下学期的学费还没凑齐，货车的贷款还欠着银行六万。要凑齐二十万手术费，要么卖门面，要么借高利贷。

回家那天晚上，老夏闷声不响地翻着柜子。媳妇以为他在找存折，却发现他从抽屉底下摸出一份泛黄的纸。纸上是五年前他在一个朋友介绍下签的一份东西——当时每月交几百块，朋友说："你这种顶梁柱，万一哪天得大病躺下了，保险公司会一次性赔你一大笔钱，至少不用卖房卖车。"老夏当时觉得晦气，媳妇也说"别乱花钱"，但他还是咬着牙交了五年。

老夏盯着那张纸看了很久，喃喃自语："五年了，一次都没用上，还以为白扔了。"

第二天，他揣着那份纸和医院诊断书，找到了当初介绍业务的那个朋友。朋友帮他打电话，递了材料，又催着补了一张心脏专科医生的报告。一周后，保险公司那边回话了：符合约定，按合同一次性给付二十万整。

老夏签完字那天，从银行柜台出来时，手都在抖。他没急着打车回家，而是站在路边抽了根烟。阳光照在脸上，他忽然觉得，这五年每月扔出去的几百块，好像从来没"扔"过——它一直在那儿等着，等一个他不愿去想、却可能撞上来的日子。

二十万到账那天，老夏做了手术。媳妇在医院走廊里哭，不是伤心，是松了口气。手术很顺利，老夏醒来第一眼看见媳妇手里攥着缴费单据，上面的"已结清"三个字让她整个人都软了下来。

三个月后，老夏回到菜市场。他没再骑那辆破三轮，换了一辆新的电动车——不是因为旧车坏了，是因为他发现自己以前太拼了，总觉得"病倒了再说"。现在他想明白了，那份每月交几百块的东西，不是晦气，是给这个家留了一条后路——一条不用卖门面、不用借高利贷、不用让孩子辍学的后路。

他跟隔壁卖鱼的老周说这事，老周听完，后悔得直拍大腿："当年那业务员也找过我，我嫌贵没办。"老夏笑笑，没接话，只是把烟掐了，弯腰开始码鸡蛋。

**📖 原文定义**

> 這類附約的基本特點如下：
>
> (a) 含義：受保保單所有人將獲給付死亡保險金的載明部分，條件是：(i) 他被診斷患上指明疾病；(ii) 他被診斷患上終末疾病並只有12個月或更短的壽命；或 (iii) 他有必要接受指明的醫療程序；
>
> (b) 指明疾病：儘管不是所有保險人都是保同一範圍的疾病，一切受保疾病均可分類為：(i) 癌症 (ii) 心臟相關疾病 (iii) 傷殘 (iv) 重要器官相關疾病 (v) 神經系統相關疾病 (vi) 免疫系統相關疾病 (vii) 其他。
>
> (c) 醫學證據：必須有主診醫生發出的報告，以確認患者的健康狀況和（如屬終末疾病）其評估的預期壽命。
>
> (d) 利益的金額：每家保險公司支付的金額不同，並視乎所患疾病的類型而定，全額支付死亡保險金是其中一個可能性。危疾利益總是一次性給付的。
>
> (e) 限制：同樣，並非所有保險人設定的限制都是一樣的，但一般包括下列幾項：(i) 危疾保障僅適用於某歲數（如80歲）或以下的人；(ii) 危疾保障僅適用於標準風險；(iii) 多重疾病和復發性的疾病可能不會獲得給付，某一兩類疾病或屬例外；(iv) 等候期：上面(a)項中所指的診斷須於附約生效了某指明期間（如90天）後作出的。
>
> (f) 豁免保費：有些附約承諾豁免於所界定的喪失工作能力發生了（比如）三個月後到期的所有續保保費。

**💡 对应点**

| 故事元素 | 概念对应 |
|---------|---------|
| 老夏心脏血管堵塞需要手术 | 指明疾病中"心脏相关疾病"的诊断 |
| 五年前签的那份纸 | 危疾保险利益附约 |
| 每月交几百块、交了五年 | 持续缴纳保费 |
| 心脏专科医生的报告 | 医学证据：主诊医生发出的报告 |
| 保险公司一次性给付二十万整 | 危疾利益一次性给付 |
| 老夏不用卖门面、不借高利贷 | 这笔钱用来覆盖大额医疗支出 |
| 老夏没让两个孩子辍学 | 一次性给付维持家庭原有生活 |
| 老周后悔当年没办 | 体现危疾保障对家庭顶梁柱的意义 |
