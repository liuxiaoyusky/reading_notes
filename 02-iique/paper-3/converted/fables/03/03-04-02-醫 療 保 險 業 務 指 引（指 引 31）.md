# 3.4.2 醫 療 保 險 業 務 指 引（指 引 31）

## 📜 寓言故事 —— 《村口的药铺掌柜》

清水镇只有一家药铺，掌柜姓沈，五十出头，做了三十年药。镇上人都喊他沈半城，意思是这镇上一半人家的药钱，都从他手里过。但去年冬天，沈掌柜做了一桩让自己后悔不已的事。

起先，是隔壁王村来了一位张屠户。张屠户是个卖肉的，常年烟熏火燎，嗓子粗得像破锣，进门就拍桌子：「沈掌柜，给我来副最好的补药，我出钱大方，但东西必须是真的。」沈掌柜一瞧，这是个不差钱的主儿，连忙把自己店里最贵的那款「千年老参」推了过去，价钱报到平时的三倍。张屠户掏钱痛快，连价都没还，拎着药就走了。

过了半年，张屠户拖着咳嗽的身子又来了，进门就嚷：「你这参是假的！我吃了半年，病一点没好，反而重了！」沈掌柜心里咯噔一下——他当时根本没过问张屠户到底是咳嗽还是虚劳，到底能不能吃这种参。他只想着人家出手阔，要最贵的，他就把最贵的递过去。

两人闹到镇公所。里正翻开柜子上那本灰皮的《商户守则》，第一页就写着：「凡卖货与人，须先问清用途；不问而售，出了岔子，卖家先担三分责。」这守则是县衙统一下发的，每家店铺开业时都发了一本，但沈掌柜那本压在柜台底下积灰，已经十几年没翻开过。

里正又翻开第二页：「货有价，售前须明告——什么成色、什么禁忌、能用多久、退换规矩，逐一说清。」沈掌柜一愣：成色他口头提过一句，但「禁忌」和「退换」他根本没提。镇公所最后判沈掌柜退还一半药钱，还罚他在镇口的老槐树下挂一块木牌，写清「本铺问病卖药，不问不售」。

沈掌柜蹲在老槐树下抽着旱烟，闷了半天。忽然想起一件事：张屠户是王村的，他一个外乡人，是怎么找到自己这小镇药铺的？沈掌柜开铺三十年，从没派人去王村发过传单，也没托人介绍。原来是赶集那天，张屠户恰好来买肉，路过药铺闻见药香，自己进来的。

这才是关键。平日里，沈掌柜从不考虑「我这个药铺，到底是给谁准备的」。街坊邻居、街外乡绅、走脚的货郎、过路的教书先生，什么人都有，沈掌柜的药是「通用版」，啥都卖，啥都敢推，从不想想哪个人其实并不该吃自己这味药。

那天回到家，沈掌柜把那本灰皮守则翻到第三页，上面写着：「为商之道，先想明白三件事——我卖什么，给谁卖，他用着合不合适。」他提笔把这段抄下来，贴在柜台正上方。然后他又细细回忆了一遍张屠户的事：他若当时多问一句「您这咳是多久了、平时身子如何」，张屠户八成会换一种温和的止咳药，而不是那根根本不对症的「老参」。他若卖之前就说清「此药虚寒者忌用，三日内不见效请来退」，张屠户也不会吃了半年才来闹。

从此以后，沈掌柜的药铺多了三条规矩：第一，进门先问哪里不舒服，不是来买药的也要问一声；第二，贵重药材的「禁忌」和「退换」白纸黑字写在药方背面，签字画押才算数；第三，他重新把店铺收拾了一遍，把适合年轻人的和适合老人的药分开摆，外头立个小木牌，写明「本铺只接本镇及周边十里乡邻」。

镇里人笑他：「沈半城，你这是把生意往外推啊。」沈掌柜摆摆手：「不是推，是接得住才接。接不住的人硬卖给他，将来闹出事倒的是我这招牌。」媳妇也埋怨，沈掌柜笑了笑：「嫌烦的就不是咱该接的人；肯答的才是真主顾。强扭的瓜不甜，卖错的药也伤人。」

还有一回，隔壁陈裁缝的老母亲脾胃不爽来抓药。沈掌柜问了饮食习惯，断定脾胃虚寒，开了副温补方，临走在药包外贴一张纸条：「此方连服七日，第三日若不见好转请来换方。」陈裁缝后来专程送了半匹细布来道谢——这就是「售前说清、售后有交代」的好处。

半年后，镇上另一家药铺把孕妇忌用的药材卖给了一位不知情的年轻媳妇，被闹到县衙，铺子关了门。沈掌柜站在自家柜台后面，听见那消息，摸了摸那张贴在正上方的纸，长长吐了一口气。他暗暗庆幸：亏过那一次，但亏得早、亏得明白，往后才能把药铺安安稳稳再开下去。

**📖 原文定义**

> 為確保在銷售醫療保險產品時能公平對待客戶，保監局制訂了指引31，該指引被視為授權保險人、持牌保險中介人和持牌保險經紀人的最低標準。指引31適用於所有承保醫療保險業務的獲授權保險人，以及所有進行與醫療保險業務有關的受規管活動的持牌保險中介人，亦適用於個人及團體業務、自願醫保的認可產品及其他種類的醫療保險業務。指引31要求：開發、推銷和銷售產品時充分顧及客戶的利益和需要；不論在銷售產品之前、期間或之後，均應向客戶提供準確、清晰及並非誤導的資料；將未能切合客戶利益和需要的銷售風險減至最低；確保所提供的意見達專業水平；公平及適時地處理客戶索償、投訴及爭議；及保障從客戶取得的資料的私隱。在產品設計方面，須設計符合目標客戶群的已識別需要和預期的醫療保險產品，考慮產品的可持續性並合理定價，及採用針對已識別的目標客戶之銷售渠道。在銷售過程中，獲授權保險人、持牌保險代理機構及持牌保險經紀公司應監察產品的分銷程序，確保客戶在銷售過程中獲公平對待；如發現任何不符合規定之處，應採取適當的補救行動。指引31不具法律效力，不遵從指引31本身不會令任何人士在任何法律訴訟中負上法律責任，但保監局在考慮某人是否適宜繼續持牌時，會將不遵從指引31列為相關事項之一。

**💡 对应点**

| 故事元素 | 概念对应 |
|---------|---------|
| 张屠户进店就喊「要最贵的」 | 销售场景中客户提出需求，触发销售人员的判断义务 |
| 沈掌柜不问病因直接递上最贵的药 | 销售人员未充分顾及客户的实际利益和需要 |
| 镇公所翻开《商户守则》判沈掌柜担责 | 指引31 作为最低标准的监管定位 |
| 守则第二页「须明告禁忌和退换」 | 销售前、中、后均应提供准确、清晰及不误导的资料 |
| 沈掌柜重新思考「我的药铺到底给谁开」 | 产品设计须符合目标客户群的已识别需要和预期 |
| 把适合年轻人的药和适合老人的药分开摆 | 采用针对已识别目标客户的销售渠道与产品策略 |
| 沈掌柜把三条新规矩贴在柜台正上方 | 授权保险人和持牌中介人须建立的内部合规常規 |
| 半年后别家药铺因卖错药关门 | 不遵从指引31虽不致直接法律诉讼，但会影响持续持牌的合适性 |
