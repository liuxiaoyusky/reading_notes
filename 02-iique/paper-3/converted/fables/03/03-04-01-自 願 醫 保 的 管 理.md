# 3.4.1b 自 願 醫 保 的 管 理

## 📜 寓言故事 —— 《老周的诊所》

老周是清水镇上的老中医，行医三十年，方圆几十里都认他的招牌。前些年镇上只有他一家诊所，看病抓药从不马虎，乡邻们都放心。可这几年，外地商人陆续涌进镇上，连着开了六七家诊所，有的大夫连药材真假都分不清，有的把脉三秒钟就开方子，还有的明明治不了也敢拍胸脯说包好。镇民们被坑过几次后，开始吵着要镇公所管一管。

镇长老吴被吵得头疼，便去找县里的"卫健所"请示。卫健所的赵所长听完后，从抽屉里摸出一份厚厚的本子，拍了拍说："老吴，这事我们早想过了。县里打算搞一个'放心诊所'的招牌，只有挂在门口，老百姓才认。但你回去告诉那些想挂招牌的诊所——想挂牌，先得过我这一关。"

老吴回到镇上，把消息告诉了老周和另外三家新诊所的东家。大家都想要那块招牌，但谁也不知道"过关"到底怎么过。

开小诊所的刘老板第一个跑去问："赵所长，您就直接告诉我，要不要交钱？"赵所长摇头，把那本厚厚的本子翻到第一页，指着第一条说："第一步，'挂牌注册规则'。你们诊所必须先向我们提出申请，提交你们的资质、过去有没有出过事故、大夫有没有正经执照。我们审核通过了，给你发一个'挂牌诊所'的资质牌，你才有资格开始后面的事。没拿到这块资质之前，你就算把招牌挂出去，我们也会派人来摘掉。"

刘老板愣了一下："那我先把资质报上去。"赵所长点头："报上来之后，才进入第二步。"他翻到本子的另一页，"第二步，'诊所样板手册'。这本手册写明了什么叫'合格诊所'——每天几点开门、大夫怎么问诊、开药必须有处方记录、遇到重病必须转诊不能硬扛、出了问题怎么赔，等等。这一套是最低标准，所有挂牌诊所必须做到。"

刘老板有点为难："可我家那间铺子小，没法转诊啊。"赵所长平静地说："那你就过不了这一关，挂牌就别想了。或者你可以挂在我们手册里说的'升级版诊所'里——升级版除了手册里那些最低标准，还要额外提供更好的服务，比如能上门出诊、能做针灸理疗、能请大医院专家远程会诊。但你必须在'最低标准'的基础上加码，不能在最低标准里打折扣。"

老周在一旁听着，突然开口问："赵所长，那如果我既想挂牌，又想在我诊所旁边开个'养生馆'，卖卖膏药、做做按摩呢？"赵所长翻了翻本子："可以。'养生馆'可以挨着你的诊所开，但'养生馆'里卖的那些膏药按摩，不属于'挂牌诊所'的内容，我们不会替它背书。只是有一个规矩——'养生馆'卖的东西不能比你的诊所差，更不能让病人觉得买了养生馆的东西反而影响在诊所的看病。"

老周点头，心里把这条记下了。

几个老板陆续回去准备材料。过了半个月，刘老板又跑来，一脸委屈："赵所长，我按您那本样板手册做了，可我看隔壁张老板挂出来的招牌跟我差不多，价格却便宜一半。他是不是有什么门道？"赵所长脸一沉："我会派人查的。但先跟你说清楚——挂牌诊所的宣传必须真实、不夸大、用老百姓听得懂的话。要中英文对照（朋友圈广告可以除外），得让老百姓一眼就能看出哪些是挂牌服务、哪些不是。比如你不能说'本诊所包治百病'，也不能比标准诊所少宣传该告诉人家的服务。如果哪家诊所敢乱吹，我们随时摘牌。"

刘老板赶紧点头。赵所长又补了一句："还有，挂牌诊所在给病人开方子之前，必须告诉病人：你有责任把过去的病历、过敏史、吃过的药老老实实交代清楚，隐瞒的话，将来出了问题你自己担。这是挂牌诊所的规矩，也是你保护自己的一道墙。"

老周在回去的路上，把这几个月听到的、看到的，一条一条在心里串了起来——

第一步先注册，不注册连上场资格都没有。
第二步照着样板手册做，那是最低门槛，谁也不能少做。
第三步想升级就在最低门槛上加码，但绝不能在最低门槛上打折。
第四步，宣传必须真实、清楚、不夸大，让百姓一眼分清"挂牌"和"没挂牌"。
第五步，看病之前先讲清规矩，双方都清楚自己的责任。

他把那张"挂牌诊所"的资质牌，小心翼翼地挂到了自家诊所门口。镇上那些想挂牌的诊所，也都按着这一道一道的关，一家家地走了过来。

**📖 原文定义**

> 自願醫保由食衞局下的自願醫保計劃辦事處負責管理。有意提供符合自願醫保規定的產品的保險公司，必須先成功註冊為自願醫保的產品提供者，並就有意推出的標準計劃及靈活計劃（如適用）取得食衞局的認可，方可將有關產品以認可產品的名義推出市場。
>
> 食衞局制定了一套闡述計劃規則的計劃文件，供自願醫保的產品提供者遵守：
>
> （i）《註冊規則》：保險公司必先獲食衞局根據《註冊規則》的規定註冊為自願醫保的產品提供者，方可獲准銷售認可產品。
>
> （ii）《保單範本》：闡明認可產品（包括基本計劃和靈活計劃）在保單結構、條款及保障的最低要求。
>
> （iii）《產品的合規規則》：闡述保險產品獲認可為符合自願醫保規定的產品設計要求及相關的產品認可程序。基本原則包括：個人償款住院保險產品必須先獲得食衞局的認可；所有認可產品必須為個人償款住院保險產品；標準計劃的產品設計基本上是固定的，必須等同最低合規要求；靈活計劃必須在「基本保障」的基礎上，提供「額外保障」；標準計劃和靈活計劃均可在「基本保障」和「額外保障」以外包括少量其他類型額外保障。
>
> （iv）《實務守則》：為《保單範本》作出補充，給自願醫保的產品提供者訂明操守及準則，當中涵蓋產品提供、轉移安排、銷售及推廣、投保申請的處理、冷靜期、售後服務等方面。

**💡 对应点**

| 故事元素 | 概念对应 |
|---------|---------|
| 卫健所赵所长 | 食衞局下的自願醫保計劃辦事處 |
| 老周等诊所先申请"挂牌资质" | 註冊規則——保險公司必須先註冊為產品提供者 |
| 赵所长出示的厚本子里的最低门槛 | 保單範本——認可產品的最低要求 |
| "升级版诊所"在最低门槛上加码 | 靈活計劃——在基本保障基礎上提供額外保障 |
| "养生馆"挨着诊所但不被背书 | 同一保單下其他保險產品——不視為認可產品的一部分 |
| 宣传必须真实、中英对照、不夸大 | 實務守則——銷售及推廣資料須準確、非誤導性 |
| 看病前先讲清"你得如实交代" | 實務守則——投保人有責任披露個人資料及重要事實 |
