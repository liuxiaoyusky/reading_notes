# 3.3.2 長 期 護 理 利 益 (Long-Term Care (LTC) Benefit)

## 🏺 寓言故事 —— 《茶馆边的半年》

老范在镇东街口开茶馆,做了二十多年,街坊邻里都认他。六十岁那年,他把茶馆交给儿子小范打理,自己每天早上到隔壁的面馆吃碗面,下午找老邻居下两盘棋,日子过得舒坦。

清明前几周,老范开始觉得腿脚不对劲。起初只是蹲下去捡个棋子,膝盖发软,站半天才能起来。后来连上台阶都要扶着墙。儿子小范带他去看郎中,郎中说是年纪大了,膝关节磨损,加上早年做茶馆时落下的寒腿,往后只会越来越重,不会自己好起来。

到了端午前后,老范已经下不来床了。洗澡要老伴帮着擦,穿衣服要小范一把一把往身上套,连端碗到嘴边都颤颤巍巍,得有人喂。最让老范难受的不是疼,是那种"什么都得别人搭把手"的感觉。他躺在床上看着窗外,想:要是就这么瘫上三五年,这家可怎么办?

小范算了算账,请一个护工每月要八百文,在家照顾老范吃喝、翻身、擦洗。镇上有一家济养堂,条件好些,但每月要两千文,住进去省心,又怕老范不愿意离开家。茶馆一天的流水也就几十文,撑不了几个月。

老范的老朋友——在城里当账房的郑先生——回镇探亲,听说了这事,来找小范。郑先生从包里抽出一张纸,是十年前小范爹替老范买的一份老合约,后面附了一张小纸条,写着"如投保的人因年老或疾病无法自理日常生活,可获长期护理金按月发放"。

郑先生说,这份合约里有一条,叫"长期护理利益",正是为老范现在这种情况准备的。只要医生证明老范已经不能自己完成吃饭、穿衣、洗澡这些基本动作——也就是行话说的"失去了指定数目的日常起居活动能力"——保险公司就会开始按月发钱。每月打来一些,直到老范好转或者人走了,这部分钱不用再还,也不用再交钱。

小范眼睛一亮,问:"现在就能用?"郑先生说有一条规矩,叫等候期,要等满九十天,确实是在护理状态下,才开始发钱。这份合约本身也得已经生效满一年。这两条老范都够条件。

小范把老范的郎中请来,写了一份证明:老范因膝关节退化,已经不能自己洗澡、穿衣、走动,需要他人长期照护。证明递上去,九十天一过,保险公司开始每月打来一笔钱。在家请护工的,每月打来的少一些;送去济养堂的,每月打来的多一些,最高累计能拿到老范那份合约身后赔款的一半到全部,看住多久、怎么住。

更让小范意外的是,从开始发钱的那天起,这份合约本身要交的钱也不用再交了——不管是这份小合约的钱,还是当年买的那份主合约的钱,都不用小范再掏。老范躺在济养堂里,每月有钱进来,儿子也不用为他的护理费发愁,茶馆虽然清淡,但总算没被拖垮。

小范后来才琢磨明白:这份合约本来是人走了以后留给家人的"身后钱",但如果老范真的不能自理了——洗澡穿衣走路都做不了、需要长期有人照看——这笔钱就会提前变成"身前钱",一笔一笔按月发下来,让他在最后的日子里能体面地活着,而不必让一家人都被拖进困境。

**📖 原文定义**

> 這種產品目前在香 港 並 不 常 見,但這個附 約 的 基 本 特 點 是:
> ( a ) 含义:因某些疾病而须接受长期护理的受保保单所有人,可获支付死亡保险金的规定部分。
> ( b ) 护理类型:会在附约中加以说明,例如:在认可的护理院(approved nursing home)接受护理或在受保保单所有人的家中由正式注册的护理员护理。
> ( c ) 医学证据:附约通常会规定:相关的护理在医学上是必需的。要证实这点并不容易,有时出示受保保单所有人的医生所发出的证明即可,但是,许多保险人都会规定,受保保单所有人必须已经失去指定数目的日常起居活动能力(activities of daily living (ADLs)),才能确立长期护理的必要性。(日常起居活动能力包括人类的基本需要和功能,诸如洗澡、穿衣和走动。)
> ( d ) 利益的金额:一般来说,每月在护理院护理的利益为死亡保险金的2%,每月在家中由正式注册的护理员护理的利益为死亡保险金的1%。最高支付总额介乎死亡保险金的50%至100%之间。
> ( e ) 等候期:通常在给付长期护理保险利益之前有一个为期90日的等候期。有些保险人更同时规定,保险单于作出给付以前须已生效了一年或以上。
> ( f ) 豁免保费(Premium waiver):受保保单所有人在接受长期护理利益的期间,通常都会获得豁免保费——包括附约的保费及基本保险计划的保费。

**💡 对应点**

| 故事元素 | 概念对应 |
|---------|---------|
| 老范因膝关节退化,无法自己洗澡、穿衣、走动 | 失去指定数目的日常起居活动能力(ADLs)——触发给付的核心医学条件 |
| 小范在家请护工 vs 把老范送去济养堂的两种选择 | 护理类型:家中由正式护理员护理 / 在认可的护理院护理 |
| 郎中写下的"已不能自理,需长期照护"证明 | 医学证据:医生证明 + ADLs 评估 |
| 每月从保险公司拿到一笔钱 | 利益的金额:在家给付死亡保险金的 1%/月,在护理院给付 2%/月 |
| 给付前必须等满 90 天,且保单已生效满 1 年 | 等候期 90 日 + 保单生效满 1 年 |
| 老范开始领取护理金后,茶馆和小范都不用再为保费发愁 | 豁免保费:给付期间,附约与基本计划的保费一并免除 |
| 老范身后赔款的一部分,被提前按月用来照顾他 | 长期护理利益 = 死亡保险金的一部分提前用作生前护理金 |
