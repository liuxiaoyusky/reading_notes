# 3.5 可 保 權 利 益 (Insurability Benefits)

## 🏺 寓言故事 —— 《老木匠的"后门"》

小镇上有个木匠叫阿桐,四十出头,手艺好,口碑也不错。十年前他在镇东头的张掌柜那里给自己办了一份"出行平安"的保障——每年交一袋米的钱,万一他出门在外出了意外,家里人能拿到十袋米的补偿。阿桐当时身体壮得像头牛,办手续那天,张掌柜只是随便问了几句"有没有旧伤、有没有老毛病",阿桐笑着说"我连感冒都少有",张掌柜便在单子上盖了个章,事情就成了。

这一年,阿桐的儿子阿松要出远门去学手艺。临走前,阿桐心里嘀咕:儿子万一在路上有个闪失,家里的顶梁柱就塌了。他想给儿子也办一份同样的保障,可张掌柜这回却皱起了眉头。

"阿桐啊,"张掌柜翻了翻阿松的记录,"这孩子小时候得过一场咳疾,虽然早好了,可按现在的规矩,要让他重新过一遍'审查'——查身体、问病史、量体重,都得来一遍。万一查出来点什么,这份保障就办不成,或者只能办得很小。"

阿桐急了:"可他十年前也在这办过——"

"那是十年前的他,"张掌柜摇摇头,"人是会变的,十年前的健康不代表现在的健康。我们得重新看一看。"

阿桐回到家,坐在门槛上发愁。他琢磨着:街坊老周身体一年不如一年,想再加点保障,办不下来了;对门老林前两年生过一场病,如今想给老婆办一份,也被挡了回来。"办过的人想再办,怎么反倒比头一次还难?"他越想越堵。

第二天,阿桐去找张掌柜理论。张掌柜叹了口气,从柜子里翻出一份旧单子:"你看,你这十年前办的这一份,里头有一条你可能没留意——它写着,在某些特定的时候,你和你家里人都可以'直接加一份',不用再重新跑一遍审查。"

阿桐愣住了:"有这种好事?"

"有,"张掌柜说,"十年前你办这份保障的时候,我们就给你留了这样一扇'后门'——只要你符合单子上写的那几个条件,到时候你只要来递个申请,我们就给你加,不再回头查你身体。这条'后门',叫做'保证可保利益'。当年你年轻健康,你觉得用不上;现在派上用场了。"

阿桐看着那张十年前的旧纸,忽然明白了:原来这份保障,不只是"出事时拿补偿"那么简单。它还藏着一份对未来健康的"提前预约"——当年锁定的"健康资格",可以在某些关键时刻被重新拿出来用,不必再跟一个已经不再年轻的自己较劲。

"那——我儿子这次能加吗?"阿桐问。

"看看符不符合条件,"张掌柜说,"符合,就来办。不符合,我们就只能按正常流程走,该查还是得查。"

阿桐点点头,心里那块石头落下了一半。他明白了:这份"后门"不是万能钥匙,不是想买多少就买多少;它是有条件的、有限的。可它真真切切地解决了一个问题——当你已经不是当年那个最健康的自己时,还有一条路,让你不必被"重新审查"挡在门外。

---

**📖 原文定义**

> 顧名思義,可保性(Insurability)是指按照正常的核保和商業準則,某一風險是可以受保的。影響可保性的常見因素,當然是準受保生命的健康狀況。檢查一個人是否具有可保性是核保過程的基本因素(見 5.3)。不過,現有客戶有時也會出現可保性的問題(例如在保單復效時見 4.7 或在其他情況)。但如果保單是根據保證可保利益 (Guaranteed Insurability (GI) Benefit)訂立的,便可以避免這問題。

**💡 对应点**

| 故事元素 | 概念对应 |
|---------|---------|
| 张掌柜十年前给阿桐办保障时"随便问几句就盖章" | 正常的核保过程,以健康状况为准 |
| 阿松小时候的咳疾,如今办新保障要被"重新审查" | 现有客户因健康变化可能失去可保性 |
| 老周、老林被"挡在门外"办不下来 | 可保性问题在续办、新办时确实存在 |
| 阿桐十年前那份旧单子里藏着的"后门" | 保单附带"保证可保利益"(GI Benefit) |
| "符合条件就来办,不符合还得查" | GI 是有条件的,不是无条件免核保 |
| 阿桐的领悟:"当年的健康资格被提前锁定了" | GI 的本质:把"可保资格"在健康时预先约定 |
| 故事只讲"为什么需要 GI",不展开具体适用情形 | 3.5 是概述,具体类型留给 3.5.1 |
