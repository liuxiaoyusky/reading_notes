# 3.2.1 意 外 死 亡 及 喪 失 肢 體 (Accidental Death and Dismemberment)

## ⚖️ 寓言故事 —— 《电锯惊魂后的赔付》

长江边上的家具厂里,有个叫郑师傅的木匠,四十出头,干活利索,工友都叫他"郑一手"——一只手就能把一整块木板刨得平平整整。妻子老陈带着一个儿子,住在厂里分的家属楼里。儿子刚上初三,郑师傅盘算着再干几年,攒够钱给儿子念大学。

五年前,郑师傅经人介绍,跟城里一家老字号签了份"护身符"。每月从工资里扣一笔钱,图的就是万一哪天出了横祸,家里不至于塌了顶。这份"护身符"里还附了一张小纸条,上头写着两件事:第一,要是哪天郑师傅因为突然的横祸走了,厂里会另外再赔一笔跟"护身符"等额的"抚恤金";第二,要是横祸断了胳膊断了腿,或者眼睛看不见了,也按规矩赔一笔钱,但赔多少,看出事的轻重。

郑师傅当年签完,把那张小纸条随手往抽屉里一扔,心想:"我这一身腱子肉,哪那么倒霉。"他没想到,这种事从来不会提前打招呼。

去年腊月,厂里赶一批出口家具,郑师傅连着加了好几个夜班。那天下午,他用惯了十年的电锯,忽然跳了一下——他没戴护目镜,一小块木屑直接崩进了他的左眼。他惨叫一声,扔下电锯,双手捂住脸。工友七手八脚把他送到市里的大医院。医生摇头:"左眼视网膜剥脱太厉害,视力保不住了。"几个月后,另一只眼因为发炎感染也跟着失明。三十八岁的郑师傅,一夜之间成了完全的盲人,再也摸不了他最爱的木头。

郑师傅躺在病床上,关了三天。三天后,他摸索着抓住老陈的手,哑着嗓子说:"娃儿他妈,完了,我这辈子完了。"老陈抹着泪问:"他爹,你别这样,当年那张'护身符'还在不在?"

老陈把家里翻了个底朝天,终于从抽屉底层翻出那张发黄的小纸条。她不识字,跑到厂里找工会主席老吴帮忙念。老吴戴上老花镜,一字一句地念,念到最后,自己也倒吸一口凉气:

"按这小纸条上写的:双目失明,赔一笔跟'护身符'等额的款——跟你家老郑那份钱一样多。如果只是断一只手或者瞎一只眼,就赔一半。"

老陈愣了一下:"等额?那就是说,眼睛瞎了,跟人没了赔的一样多?"

老吴点头:"写得清清楚楚——两只手、两只脚、双目失明,这三种最重的,赔全额;一只手、一只脚、一只眼睛瞎了,赔一半。"

老陈的手开始发抖:"那……那要是又瞎了眼,又没了命呢?还能再赔一次吗?"

老吴叹了口气,把纸条翻到背面:"同一场横祸里,既要赔伤残又要赔命的,只能挑一样赔。不能两样都拿。"

老陈听完整个人蹲在地上大哭。哭完,她擦了擦眼泪,站起来对老吴说:"吴主席,我家老郑这两年的收据都在,'护身符'还在。那就按规矩办,该赔多少,帮我们走手续。"

老吴点头:"行。郑师傅双目失明,属于最重的那种,赔全额,一分不会少。"

两个月后,老陈存折上真的多了那笔等额的款。她拿这笔钱,在医院附近租了个带厨房的小房子,安顿了郑师傅;再拿出一部分给儿子报了好学校;剩下的存起来,等儿子念大学。

郑师傅出院后,虽然再也看不见木头上的花纹,但他常让老陈扶他到阳台上站一站。他说:"我看不见了,但这护身符,救了我一家。我儿子还能念书,我老婆还能过日子,这就够了。"

**📖 原文定义**

> (b) 喪失肢體(Dismemberment):「喪失肢體」從詞義上看是指喪失一個或多個肢體(四肢),但在意外死亡及喪失肢體附約中,「喪失肢體」包括喪失肢體及喪失視力的意思。一般的條款有:
>
> (i) 基本保障:在正常情況下,若受保生命在意外事故中喪失任何兩肢或雙目失明,則會支付一筆與意外死亡保險金相等的款項;
>
> (ii) 較低額保險利益:若意外事故導致受保生命喪失單肢或單目失明,或遭受其他較輕微的指明受傷,給付額通常相等於意外死亡保險金的規定比率;
>
> (iii) 定義:喪失一肢可以描述為實際喪失肢體(由手腕/足踝關節或以上完全斷離),或喪失該肢體的功能;
>
> (iv) 組合:一般來說,保單會規定:在同一意外事故同時引致喪失肢體和死亡的情況下,保單只須支付喪失肢體保險利益或死亡保險利益,而非同時支付兩項利益。

**💡 对应点**

| 故事元素 | 概念对应 |
|---------|---------|
| 郑师傅签的"护身符"附带的小纸条 | 意外死亡及丧失肢体附约(AD&D Rider) |
| 郑师傅双目失明 | 丧失肢体附约中"丧失视力"的触发情形 |
| 眼睛瞎了赔一笔跟"护身符"等额的款 | 基本保障:双目失明 = 全额给付(等于意外死亡保险金) |
| 单肢或单目失明赔一半 | 较低额保险利益:部分伤残 = 规定比率(通常为意外死亡保险金的50%) |
| 丧肢等于断离或失去功能 | 丧失一肢的定义(实际断离 / 功能丧失) |
| "既要赔伤残又要赔命,只能挑一样赔" | 组合条款:同一意外不可同时给付两项 |
| 老陈拿这笔赔偿安顿丈夫、供儿子念书 | 保险利益的用途:对家庭的经济补偿 |
