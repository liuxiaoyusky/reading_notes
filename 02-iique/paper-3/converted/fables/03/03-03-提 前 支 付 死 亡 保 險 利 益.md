# 3.3 提 前 支 付 死 亡 保 險 利 益

## 🏺 寓言故事 —— 《老林的最后一笔钱》

江南有座老镇,镇上有个叫老林的中年汉子,今年五十有二,在码头边上开了一辈子干货铺。铺子不大,靠着诚实守信,几十年攒下了口碑,也攒下了一份长远打算。

三年前,老林干了大半辈子,身子骨开始出毛病——腰疼、腿软、夜里咳得睡不踏实。媳妇儿劝他别再亲自搬货,他闲不住,非要亲自盯码头。儿子小林在省城念书,再过两年就该毕业找工作了。老林盘算过:自己这份干货铺,等干到六十交给侄子打理,自己跟老伴儿回乡下养老。可儿子还没立业,买房、娶媳妇,哪样不要钱?光靠干货铺的流水,远远不够。

镇东头的赵掌柜,跟老林做了几十年街坊,开了家老字号的"身后钱庄"——说白了,就是专做那种"人走了才赔钱"的买卖。两年前一个下午,赵掌柜把老林请到柜上喝茶,慢条斯理地说:"老林,你这一身常年熬夜搬货的毛病,我看着都替你揪心。我这钱庄有一样东西,叫'人在钱就在'的约定,你要不要听一听?"

老林端着茶杯,没接话。赵掌柜也不急:"你现在每年往钱庄里存一千两银子,存二十年。等你人走了,钱庄一次性赔给你儿子五万两。这是身后钱,谁也动不了,只能留给下一代。"老林听完,心里一动——这就是他想要的安排。他当场拍板办了。保单签下来那天,他揣着合同回了家,心里头踏实得像揣了一块石头。

可这两年,老林的身子骨越来越差。年初,大夫摇着头告诉他:肺里头长了个东西,位置不好,手术风险太大,只能靠养着。他原本想着再干八九年,儿子也成家了,自己也该歇了——没想到这病来得这么急。

儿子小林从省城赶回来,看着病床上的父亲,眼眶一下子就红了。老伴儿坐在床边,一边抹眼泪一边算账:干货铺子早交给侄子了,一年到头剩不了几个钱;存款也七零八落地花出去了——跟儿子以后拿到的那五万两比,差得不是一星半点。老林躺在病床上,听着妻子儿子压低了声音在走廊里商量,心里头像压了一块磨盘:他想开口说"把铺子卖了",又舍不得;想说"跟亲戚借",又开不了这个口。

就在一家人愁得几夜没合眼的时候,赵掌柜提着点心上了门。他把点心放下,拉过小林,轻声说:"孩子,你爹当年跟我签那份约定的时候,我问过他一句——'老林,你这身子,万一哪天躺下了,要不要提前拿点?'你爹拍着胸脯说,'我身子骨硬朗,用不着那一项。'可我还是把那一项写进了合同里,叫'人在钱就在'的提前给付加项。"

小林一愣:"提前……给钱?"

赵掌柜点点头:"这一项写得明白——只要经过大夫按规矩认定,你爹已经到了'非常严重、命在旦夕'的地步,他那份身后约定里的一部分钱,就能现在就拿出来给他用。他活着、符合规矩,他就能先用上这笔钱。"

小林眼眶一下就湿了:"那……那原本说好的五万两呢?"

赵掌柜一字一句地说:"你爹提前拿走多少,将来那五万两就扣掉多少。剩下的,还是留给你。白纸黑字写明的规矩,谁也不能赖。"

小林听完,转身冲进病房,把这事原原本本告诉了父亲。老林听完,先是愣住,然后长长地叹了口气,眼角也湿了。他喃喃地说:"当年签这份约,我就图个身后有个交代。没想到赵掌柜多问了我那一句,加了这一个加项……这一项,救了我,也救了我儿子。"

后来,小林拿着父亲住院的单据和大夫的认定书,找到了赵掌柜。赵掌柜按规矩,把那份身后约定里的一部分钱,提前打到了老林的账上——用来付医院的开销,撑起这个家。老林走之前那几个月,医疗费有着落,儿子不用再四处借钱,一家人能踏踏实实地陪他走完最后一程。

老林走的那天,小林捧着那本合同,又来找赵掌柜。赵掌柜按合同上写明的数,扣掉老林生前已经提前拿走的部分,把剩下的身故钱,一笔一笔交到了小林手里。小林红着眼,深深地给赵掌柜鞠了一躬。

镇上的人后来听说了这事,都感慨:"老林这辈子做的最对的一件事,就是当年签那份约定的时候,没把'人在钱就在'的那一项省掉。"

---

**📖 原文定义**

> 提 前 支 付 死 亡 保 險 利 益(accelerated death benefits)是指:在受保保單所有人處於訂明的嚴重狀況下,儘管他仍然在生,但保單所列明的全部或部分死亡保險金已可支付給他。這方面的條款包含在提前支付死亡保險利益附約(accelerated death benefit rider (ADB rider))之內,也稱為生前支付保險利益附約(living benefit riders)。
>
> 基本原因:在極度精神緊張、悲哀和生命受威脅的情況下發放這些保險利益,可以幫助當事人應付有關開支,並至少為已經非常悲傷的當事人提供部分援助以解決新增的財務困擾。
>
> 合資格計劃:為了降低行政成本,這種附約往往只准附加於保額相當大的保單。
>
> 受益人:由於向在世的受保保單所有人發放保險利益會對保單受益人的期望造成一定的影響,因此有些保險人會於處理此類附約的給付申請時,要求受益人簽署一份棄權聲明(release)(或稱解除責任憑證),同意提前支付的保險利益數額會從將來的死亡保險金中扣除。
>
> 承讓人:如果保單已被轉讓,承讓人必須簽署同樣的棄權聲明,保單才會作出給付。

**💡 对应点**

| 故事元素 | 概念对应 |
|---------|---------|
| 老林投的"身后钱庄"约定(每年存,人走了赔五万两) | 受保保单(死亡保险) |
| 赵掌柜多问一句加上去的"人在钱就在"加项 | 提前支付死亡保险利益附约(ADB rider / living benefit rider) |
| 老林肺里长东西,大夫说命在旦夕 | 订明的严重状况(末期疾病) |
| 老林还没走,赵掌柜就先打了一笔钱到账上 | 全部或部分死亡保险金在受保人在世时提前支付 |
| 医院开销有了着落,一家人能踏实陪老林走完最后一程 | 在极度紧张/生命受威胁时帮助当事人应付开支、提供部分援助 |
| 老林提前拿走的部分从五万两里扣掉,剩下的留给儿子 | 受益人签署弃权声明,提前支付的金额从将来死亡保险金中扣除 |
| 赵掌柜在签合同时多问一句"要不要提前拿点" | 附约须事先附加,不能事后追加 |
| 五万两的身后钱,扣完提前拿的部分剩下的归儿子 | 保单受益人的最终权益按扣除后的数额给付 |
