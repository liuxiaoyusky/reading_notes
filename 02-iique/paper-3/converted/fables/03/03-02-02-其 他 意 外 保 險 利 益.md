# 3.2.2 其 他 意 外 保 險 利 益

## 🏺 寓言故事 —— 《一份手册的补丁》

深圳华强北的电子厂里,有个叫孙海的车间班长,三十六岁,河南人,当了十二年兵退伍,身上一股子雷厉风行。妻子小慧在老家带着八岁的女儿豆豆,每月五千块寄回去,房租奶粉学费刚好够。他最大的心愿,是再熬几年,攒够钱给豆豆买学区房。

五年前,厂里统一给大伙儿办了一份"护身符"——每月扣八十块,管到六十五岁。孙海翻开看了看,首页写着:"意外身故赔一笔,断胳膊断腿按比例赔。"他点点头,把册子往抽屉里一塞,心想:"够了,我天天小心点就是了。"他不知道,这本小册子后面几页,密密麻麻印着另一堆"补丁"——是厂里再加钱升级的"扩展补丁"。

去年八月,厂里赶一批出口大单,孙海连着三周没歇。那天夜里收工,塑料外壳做表面喷涂,临时工没戴防静电手套,火星溅到旁边一桶稀释剂,"嘭"的一声,火苗蹿起来。孙海离得最近,下意识推开身边两个女工,自己却被火舌扑到右臂和小腿上,工友拿灭火器喷了半天才把人救出来。

市第一医院烧伤科医生看完孙海的伤口,脸色一沉:"右臂三度烧伤,小腿部二度。三度的皮肤以后长不回来了,要植皮。"小慧接到电话连夜赶到深圳,看到丈夫裹成半个粽子的样子,软了腿。医生催手术费:"植皮加康复,大概二十多万。"小慧翻遍银行卡,凑了八万,还差十二万。她坐在走廊里哭,孙海躺在病床上,另一只手拽着小慧:"你……回厂里找老钱,问问那本红册子上有没有别的……"

小慧找到老钱时,他正在车间里盘点损失。他把孙海那本红色小册子抽出来,翻到中间那一页:"嫂子,孙海这本跟别人不一样,后面这几页是厂里升级的扩展补丁,你们每年多交一百二十块,买的就是这个。"

小慧不识字,老钱一页页念给她听。

"'严重烧伤:三度或以上,可获支付一笔指明金额'——孙海是三度烧伤,这条能赔一笔。"

"还有呢?他这一躺,工资停了。"

"'每周津贴:在伤残期间可获支付,最长为五十二周'。前五十二周每周都能领一笔,顶了一半工资。"

"那住院呢?他起码住三个月。"

"'住院津贴:每日津贴,上限一千天'。住一天就有一天的钱。"

小慧松了口气,又问:"我听工友说,这种'护身符'有些是双倍赔的……"

老钱摇头:"这本没有。双倍赔是有条件的——得是坐一般公共交通工具出的事,或者在电影院这种公眾场所里烧出来的。孙海这个是车间稀释剂起火,不算公共交通,也不算那种公眾场所。所以不能双倍赔。"

小慧沉默了一会儿:"那还有什么不能赔的?"

老钱念:"蓄意自残不行,打仗不行,违法犯罪不行,生孩子的伤不行,疾病不行——除非是这次意外直接引发的——还有,蹦极攀岩这种危险运动,得看单项约定。"小慧把每个字都记在心里。回到医院,她一边照顾孙海,一边按老钱指点的路径去交材料。一个月后,严重烧伤那笔钱到账;第二个月起,每周津贴准时打进卡里;出院后,住院津贴按天打到卡上。

半年后,孙海躺在出租屋的床上,右臂还裹着纱布。他问小慧:"我以后还能上班吗?"小慧翻到红册子最后一页:"老钱说,等你能下地了,去厂里办复工评估。"不能再干车间,可以转岗看大门,工资少一点,但不扣你这个'护身符'。"孙海闭着眼想了想:"要是没这本红色小册子,咱家就完了。"小慧把红册子郑重地放到床头抽屉里——这一次,没再塞回工位下面。

**📖 原文定义**

> 不同的保險人會提供不同形式的保障,但一個典型提供其他意外保險的附約皆具有以下特點:
>
> (a) 利益給付表(Benefit schedule):承保意外身體受傷,以表格的形式列出指定的受傷類別及相應的保險利益金額。該表格的內容通常包括:
>
> (i) 死亡保額的 100%
>
> (ii) 喪失兩肢 - 指明的比率
>
> (iii) 完全失明 - 指明的比率
>
> (iv) 喪失單肢及單目失明 指明的比率
>
> (v) 喪失單肢或單目失明 指明的比率
>
> (vi) 各種指定程度較輕的傷殘 - 如下所示
>
> 程度較輕的傷殘:包含所有可能的傷殘狀況的細表,範圍從嚴重受損(例如:失去大姆指或食指)到相對較輕的受損(例如:失去一個手指關節)。
>
> (b) 其他利益:可以包括下列一項或多項保障:
>
> (i) 嚴重燒傷 第三級或以上程度燒傷可獲支付(指明金額);
>
> (ii) 每周津貼 在傷殘期間可獲給支付(指明金額)(最長為 52 周);
>
> (iii) 住院津貼 - 每日津貼(指明金額;上限為 1,000 日);
>
> (iv) 「雙倍賠償」- 如果傷殘是由於乘一般公共交通工具引起,或在某些公眾場所(如電影院)的火災所引起,所有利益／津貼(住院津貼除外)可獲加倍。
>
> (c) 除外責任(Exclusions):在此適用,並一般在人身意外保險中可以找到的除外責任,包括:
>
> (i) 蓄意傷害自己身體造成的傷殘(包括任何時候的自殺);
>
> (ii) 戰爭引起的傷殘;
>
> (iii) 參與違法活動時造成的傷殘;
>
> (iv) 疾病(除非由意外事故引起);
>
> (v) 生育及懷孕引起的傷殘;
>
> (vi) 參與危險運動時造成的傷殘按照個別運動項目的定義。

**💡 对应点**

| 故事元素 | 概念对应 |
|---------|---------|
| 红色小册子后面几页的"扩展补丁" | 其他意外保险利益的扩展范围(在 AD&D 主约之外加保的保障) |
| 严重烧伤三度或以上可赔一笔 | 其他利益(i):严重烧伤第三级或以上 — 指明金额给付 |
| 康复期每周都有津贴,最长五十二周 | 其他利益(ii):每周津贴 — 伤残期间支付,最长 52 周 |
| 住院期间每天都有津贴 | 其他利益(iii):住院津贴 — 每日津贴,上限 1,000 日 |
| 车间起火不算"双倍赔"范围 | 其他利益(iv):双倍赔偿 — 仅限于一般公共交通工具 / 公众场所火灾 |
| 老钱念的"自残、战争、违法、疾病、生育、危险运动"清单 | 除外责任(c):蓄意自残、战争、违法、疾病、生育、危险运动 |
| 厂里每年多交一百二十块换这套补丁 | 其他意外保险利益作为附约形式存在,需额外付费升级 |
| 小慧先茫然求助,后按册子路径办理 | 受益人(配偶)需主动凭保单条款主张扩展保障 |
