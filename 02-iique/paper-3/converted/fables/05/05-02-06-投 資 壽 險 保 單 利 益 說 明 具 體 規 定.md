# 5.2.6e 投 資 壽 險 保 單 利 益 說 明 具 體 規 定

## 🏺 寓言故事 —— 《茶水店四张表》

巷子口新开了一家茶水店，老板叫阿涛。他卖的不是普通茶水，而是按年付钱、之后可以一直取"茶钱"的长期约定。开业第一周，街坊老周就找上门来。

老周开门见山："我儿子明年要娶媳妇，我想在你这投一笔，连投二十年，约定好每年我能取多少、哪天人没了家里能拿多少。麻烦你给我一张表，写清楚。"

阿涛心里咯噔一下。这钱不是他说了算——最后能取多少，要看店里投了多少茶种生意，茶叶涨了跌了都影响。但老周不管这些，他只要一张白纸黑字的数字。换个别的店，肯定随手写几个"大概、估计、应该"糊弄过去。但阿涛的父亲临终前叮嘱过他："咱们这行是帮人算长远账的，数字含糊一辈子，良心也含糊一辈子。"

接下来的几天，阿涛把自己关在阁楼上，对着一摞账本发呆。他写废了三张纸：第一张只写了"最低能拿多少"，老周问"那最高呢"，他答不上来；第二张只写"三十年总共多少"，老周问"那第十年呢、我急用钱想退呢"，他又答不上来；第三张干脆写了一堆"乐观、悲观、适中"三个字，老周看了直摇头："你这跟没说一样。"

他去找巷尾的茶行老师傅老林讨教。老林听完后，从柜子里翻出四张表格模板，递给他："卖这种长期约定，规矩早就定好了，咱们一齐遵守，行业才不会乱。你听好——"

第一，回报率不能拍脑袋。老林说："你得准备几套数。最低一档写零——就是假设完全不赚，老周能拿多少，让他心里有底。再往上摆几档，比如百分之三、六、九，越往上越漂亮，但只能往下调，不能往上编。而且数得摆出来给他看，不能塞抽屉里。"

第二，每一笔费用都得说清楚。老林敲着桌子："店里做账、跑腿、记账员工资——这些都从老周的钱里扣，你得在表上列出来。唯独有一样，茶叶进货商那边的费用，那是他们家的事，你可以在旁边小字提一句，但不能混进你自己的扣费里，不然客户看你扣得多，就不信你了。"

第三，数字摆在哪里、讲多少年，也都有讲究。老林说："前五年的账，你得一年一年写出来——第一年末、第二年末……一直到第五年末，老周能拿多少、人没了家里能拿多少。这五年最关键，街坊们最爱看。之后每五年写一行就行，一直写到老周年满一百岁或者约定结束。最后那一行，你得标上'九十岁''九十五岁''一百岁'，让人一眼就知道是给老人看的。"

第四，也是最要紧的——提醒。老林压低声音："你得在表上用粗体大字写两句话。第一句：'要是生意不好，账户里钱扣光了，约定可能就停了。'第二句：'要是提前不投了、或者提前取钱，可能亏很多。'这两句话是保命的话，写不写，行业里查得严，写了，街坊才信你长久。"

阿涛把这些规矩一条条抄下来，回到店里重新画了四张表。最稳的一张是零回报：老周每年投多少、二十年后能拿多少，人没了家里又能拿多少，白纸黑字。最漂亮的一张是百分之九回报：同样投多少，数字漂亮得让人心动。两张表摆在一起，老周眯着眼睛反复看了半天，最后指着那张零回报的表说："我就照这个底来想，高的当个念想。"

签约定那天，老周又带了两个老哥们来。他们围在柜台前，把四张表翻来覆去地看，问这问那。阿涛耐心指给他们看：哪行是扣完所有费用的、哪行是假设行情好、哪行是提醒字样。一个钟头下来，三个人都签了。

三个月后，店里来了个穿制服的人，翻完账本和那张表，点了点头："你这表该有的都有，提醒也到位。" 阿涛松了口气，回家给父亲牌位上了一炷香。

他后来才明白——长期约定这行，最值钱的不是茶叶，是那张表上每一行字的可信度。数字写得到位，提醒写得显眼，街坊才愿意把二十年的钱托付给你。少一行，可能就是一辈子的麻烦。

**📖 原文定义**

> 5.2.6a 投資壽險保單利益說明文件的具體規定（指引28-附件I）
>
> (a) 假設淨回報率：(i) 獲授權保險人可選擇以下兩項的其中一項，以闡述假設淨回報率：
> a. 以四個假設年度淨回報率，即0%、3%、6%及9%，作闡述，並以不同的列表分別顯示其相應的退保發還金額及身故賠償額；及
> b. 以三個假設年度淨回報率，即0%、3%及6%，作闡述，並在同一列表中顯示其相應的退保發還金額及身故賠償額。
> (ii) 就上述兩個選項而言，除0%的假設年度淨回報率外，所有其他回報率（即3%、6%及9%）為獲授權保險人可採用的最高回報率。獲授權保險人亦可選擇使用較低的假設年度淨回報率（如0%、2%、5%及7%）作闡述。
>
> (b) 費用及收費：(i) 獲授權保險人的利益說明文件應以反映所有保單層面的費用及收費（但不包括基金管理費用）所編製。基金管理費用指僅由基金经理所收取的費用及收費。(ii) 獲授權保險人以基金管理費用名義所收取的任何費用及收費應透過數字說明反映，不論該等基金管理費用是以扣減單位形式收取或是直接反映於單位價格的計算上（例如"影子基金"）。
>
> (c) 披露：(i) 獲授權保險人可選擇在利益款項欄之前顯示各假設年度淨回報率下的相應戶口價值。如可供顯示的位置不足，獲授權保險人可刪除假設淨回報率為9%之一欄，但不得刪除其他欄的項目。
> (ii) 利益說明文件應顯示首五個保單年度之每一個年末的預計退保發還金額及身故賠償額（兩者均應為已扣除指引28（本指引5.2.6a第(b)段）所述的一切相關費用及收費後的金額），並於其後至少每五年的期間顯示該等資料，直至保單年期屆滿或終結。顯示的保單年度不得超過客戶年滿一百（100）歲或保單年期屆滿的年度。此外，最後所顯示之行列的項目應以"90歲"、"95歲"及"100歲"闡述。
> (iii) 利益說明文件的附註應包含基金经理所收取的基金管理費用並未包括在說明中提述。因此，需以淨回報率以支付中所達致說明的回報率。
> (iv) 利益說明文件中應以顯著的方式顯示一項清晰的陳述，以提醒客戶在低投資收益率的情況下，保單或會因戶口價值跌至零而被終止。
> (v) 利益說明文件中應以顯著的方式顯示一項警告，以提醒客戶提前退保或提前停止支付保費可能會導致重大損失。
>
> 註：投資壽險保單利益說明文件的式樣可以在《附件E》找到。

**💡 对应点**

| 故事元素 | 概念对应 |
|---------|---------|
| 阿涛必须给老周一张白纸黑字的数字表 | 投资寿险保单须有利益说明文件的强制性 |
| 四张表（0%、3%、6%、9%四档回报） | 假设净回报率的两套选项（0/3/6/9 或 0/3/6），9%为最高且不得删除0%档 |
| 阿涛不能自行编出比9%更高的回报 | 3%、6%、9%为可采用的最高回报率，仅可下调不可上调 |
| 店里做账、跑腿、记账员工资列入扣费，茶叶进货商费用单独小字提 | 须反映所有保单层面费用，但不含基金经理收取的基金管理费用（须以附注提述） |
| 老周最爱看前五年的账，老林要求"前五年一年一行" | 须显示首五个保单年度每一年末的预计退保发还金额及身故赔偿额 |
| 五年之后每五年写一行，写到"九十岁""九十五岁""一百岁" | 其后至少每五年显示一次，直至保单期满或客户100岁；末行须以"90岁""95岁""100岁"阐明 |
| 阿涛表上用粗体大字写"账户扣光可能停""提前退可能亏" | 须以显著方式显示"低投资收益率账户跌至零时保单或被终止"和"提前退保/停付保费或致重大损失"两项提示 |
