# 5.2.5b 監 察 投 訴 與 內 部 管 控

## 📜 寓言故事 —— 《饼铺的客诉簿》

老周在老街角开了二十年的烧饼铺，街坊四邻都认他这一口。每天天不亮揉面，天黑透了才收工。铺子虽小，规矩却立得死死的——盐一勺、糖一钱，绝不多放。徒弟阿贵是三年前从乡下来的，手脚麻利，老周一早想把铺子交给他。

这一年夏天，怪事来了。先是街尾的赵婶跑来投诉，说阿贵卖给她的红糖饼"齁甜"；紧接着张家大姐也说买的芝麻饼"皮厚馅少"；连着几天，铺子门口的客诉簿上黑压压写满了名字。老周心里犯了嘀咕——这饼的做法是他手把手教的，二十年了从没出过岔子，怎么突然集中冒出这么多抱怨？

他把阿贵叫到后厨，递给他一本空白的簿子："从今往后，每一笔来投诉的客人，你都给我记下来，哪一天来的、说了啥、买了哪样、退了没退。一笔不许漏。"阿贵照办了。三天过去，簿子记了十一笔。

第四天，老周又把簿子翻开，对着十一笔投诉一笔笔比对，发现一个规律：所有来投诉的人，事先都在街对面老孙的铺子里买过同样口味的饼。老孙去年新开了家分店，手艺比不上老周，却胜在花样多。老周一拍大腿："坏了——他们是从老孙那儿转过来的回头客，吃惯了咱们以前的甜头，结果口味稍有不同就受不了。"

老周没急着骂人，而是把阿贵拉回后厨，又在铺子门口立了块小黑板。第一，凡是之前在别家铺子买过、如今第一次来老周铺子的客人，伙计必须在簿子上单独立一栏，写明"回头客"。第二，每一位这样的"回头客"进门，伙计都要递上一张薄薄的小纸条，上面写着"咱们家的饼偏咸偏香，跟您以前吃的不一定一样，想清楚再下单"，签了字才能卖。第三，后厨装了一面小铜镜，阿贵每次揉面时都能看见身后，铺子里谁来了、谁走了，门儿清。

头一个月，簿子上的投诉反而多了一条——李大爷气哼哼地说"你们家规矩多"。老周没急躁，把那条投诉也记了下来。三个月后，奇怪的事发生了：簿子上的投诉越来越少，到后来一个月只有零星一两笔，写的也不再是"口味变了"，而是"上次的酱料用完了能补吗"这类老主顾才有的牢骚。

阿贵偷偷问老周："师父，您怎么知道问题出在'从别家转过来'这帮人身上？"老周笑了笑，把簿子往桌上一摊："人也好、饼也好，靠的不是事后骂人，而是事前把账一笔笔记清楚。簿子就是你的眼睛——你看不见的角落，簿子替你看见；你以为没事的客人，簿子替你记下。铺子是自己的，可规矩要是没有，客人跑得比面团还快。"

---

**📖 原文定义**

> 監 察 投 訴：獲授權保險人應記錄與轉保個案相關的投訴（並保存該等投訴紀錄），並持續監察投訴的趨勢。如發現有任何異常情況，應採取適當的管理行動以識別投訴的問題根源並採取相關的補救行動。
>
> 內 部 管 控 措 施：獲授權保險人、持牌保險經紀公司及持牌保險代理機構應設立有效的管控及程序，確保其委任的持牌個人保險代理及持牌保險代理機構遵守指引27的規定。管控措施應包括：識別客戶是否為轉保並保留紀錄；於識別為轉保的情況下確保客戶獲提供《重要資料聲明書——轉保》並簽署；設有有效機制識別並處理內部轉保個案；識別持牌保險中介人逃避或協助逃避管控措施的個案並採取補救行動；識別可疑的轉保個案（例如中介人銷售大量屬轉保的新保單）及其根源並於必要時採取補救行動。
>
> 備 存 紀 錄：獲授權保險人、持牌保險經紀公司及持牌保險代理機構應就轉保的事宜保存妥當的紀錄，包括但不限於指引27中所載的必要文件，以供保監局查閱及審閱。

**💡 对应点**

| 故事元素 | 概念对应 |
|---------|---------|
| 老周让阿贵把每一笔投诉记到簿子上 | 記錄與轉保個案相關的投訴並保存紀錄 |
| 老周翻看簿子发现投诉集中在"从老孙家转来的回头客" | 持續監察投訴的趨勢，識別異常情況 |
| 老周分析出问题根源（转保客人对口味期待不同） | 識別投訴的問題根源並採取補救行動 |
| 在门口小黑板上单独立栏标记"回头客" | 識別客戶是否購買人壽保險保單作為轉保，並保留紀錄 |
| 递上一张小纸条让客人签了字才卖 | 確保客戶獲提供《重要資料聲明書——轉保》並簽署 |
| 后厨装小铜镜、阿贵揉面时看见铺子动静 | 識別持牌保險中介人逃避管控措施的個案 |
| 把李大爷那条"规矩多"的投诉也老老实实记下 | 保存轉保事宜的妥當紀錄，以供監管查閱 |
