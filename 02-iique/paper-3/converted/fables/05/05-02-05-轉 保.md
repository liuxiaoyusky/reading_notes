# 5.2.5 轉 保 (Policy Replacement )

## 🏺 寓言故事 —— 《旧伞换新》

城东老街上有位林老板,今年五十二岁,经营茶叶铺子二十年,日子过得不紧不慢。五年前,林老板经朋友介绍,在镇上的钱庄老板孙四爷手里,办了一份"长寿合约":每月存一笔银子进去,二十年到期后,每月能领回一笔养老金,万一生病住院,医药费还能报销一大块。合约上还写明——头五年要是想退,只能拿回一半,五年之后逐年多退一些。这份合约,林老板心里踏实得很。

今年开春,孙四爷的侄子小孙从省城回来,说在城里新开了一家"鼎丰钱庄",规模比叔叔的大三倍,给的回报也更厚。小孙专程跑到林老板铺子里,带了一本花花绿绿的小册子,拍着胸脯说:"林叔,您这份旧合约已经交了五年,正好到'能全额拿回来'的边上。换到我们这儿,头三年每月就能领钱,五年后翻一番——比您那份强多了。"林老板心里一热,当晚就跟老婆商量。老婆问:"那原来那份怎么办?"小孙笑答:"退掉就行,您那份现在正好能全额拿回,一分不少,正好做我们新合约的头期。"

林老板犹豫了几天,心里反复掂量——每月早领钱,五年后还翻番,听着确实划算。可又总觉得哪里不对。他想起了早年一起做生意的周大哥,那年周大哥也是嫌原来的钱庄回报低,把存了八年的老本一次性提出来,换到省城一家更大的钱庄。结果呢,新钱庄头两年倒是准时给钱,第三年老板跑路,血本无归——更糟的是,周大哥那一年正好生了场大病,新合约才买半年,不算"老客户",医药费几乎没得报销,前前后后搭进去大半辈子积蓄。这事街坊邻居到现在还在念叨。

林老板坐不住了,第二天一早去找街口的王伯。王伯是镇上出了名的"明白人",做了三十年的中人,什么事都见过。林老板把前后经过一五一十说了,又把省城小孙带来的小册子摊在桌上。王伯看了半天,一句话没说,先把小册子合上,给林老板倒了一杯热茶。

"老林,我问你三件事。"王伯慢慢开口,"第一,你现在这份旧合约,头五年退只退一半——你那五年攒下的钱,真能'一分不少'全拿回来?小孙的话,你听清楚了没有?"林老板愣住了:"他……他说正好能全额拿回。"王伯摇头:"合约条款上写的是什么,你得自己回去看。退保的扣费、现金价值的折损、还有之前已经花掉的医药报销额度——这些,新钱庄不会替你补。"

"第二,"王伯接着说,"你现在五十二。换到新合约,头三年每月领钱——可你想过没有,新合约要再等九十天才能开始'算保障'。这九十天里你要是病了、出了事,旧合约已经退了,新合约还没生效——这两头都不靠的九十天,你赌得起?"

林老板的手微微一抖。王伯看在眼里,继续说第三件事:"第三,你今年五十二。五年后,新合约给你翻一番,可那时候你也五十七了。再过十五年,新合约到期,领养老金——那时候你已经七十二。再想买第二份,年龄更大,身体也说不准。这就是'一份顶一份'的算法——你得把十五年、二十年、三十年的账,一起算。"

林老板沉默了很久,茶凉了两遍才端起来。临走时他跟王伯说:"王伯,我回去把原来那份合约翻出来,一字一字看清楚,再让小孙把新合约的每一条都给我讲明白。要是退的代价我能承受,新合约九十天的空窗我也想得到办法,十五年二十年的账我也能算清楚——那再换不迟。要是其中任何一条我没想透,我就老老实实守着原来那份,不当这冤大头。"

王伯笑了:"老林,你这话说到点子上了。一个真正为你好的合约,不怕你问、不怕你比、不怕你想清楚再来;凡是催你今天就退、明天就签、还要你把钱全挪过来的——多半,不是为你着想。"

小孙后来又来过几次,林老板都没开门。他坐在铺子后头,翻着旧合约,一个字一个字地读,心里反倒踏实了。

>

>

| 小孙劝说"把旧合约退掉,全款挪到新合约" | 转保(Policy Replacement)的行为本质 |
| 王伯追问"五年攒的钱真能一分不少拿回?" | 退保或提取保单款项的收费 / 现金价值损失 |

| 王伯强调"五年后你也五十七,十五年后七十二" | 转保后年龄增加带来的长期影响 |

| 林老板最终选择回去把合约看清楚再说 | 客户应基于充分知情作出转保决定 |
