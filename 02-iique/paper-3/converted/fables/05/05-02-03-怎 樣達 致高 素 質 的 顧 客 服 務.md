# 5.2.3b 怎 樣達 致高 素 質 的 顧 客 服 務

## 🍜 寓言故事 —— 《福满楼的转机》

清晨六点,小镇上的"福满楼"面馆刚开门,老板娘林大姐正在擦桌子。十五年前她和丈夫阿海用攒了八年的积蓄盘下这家店,靠着街坊一勺一勺捧场,成了镇上最热闹的老字号。林大姐性子急,脾气冲,街坊都说她"刀子和嘴一样快",但也都知道她心肠不坏。

这天下午三点,店里来了位穿藏青色夹克的中年男人,姓周,坐在靠窗那张桌子前,点了一碗牛肉拉面。面端上去不到两分钟,周先生筷子一顿,脸色变了——汤里漂着一根长头发。林大姐正好从后厨出来,看见周先生那副表情,心就咯噔一下。店里七八双眼睛齐刷刷看过来,后厨的小刘和小陈都停下了手里的活。

林大姐心里飞速转:要是当众认错,等于砸自家招牌,前阵子工商所还来检查过卫生;要是赔一碗面糊弄过去,周先生可能就此走人,日后也不会再来,反倒省事。可周先生是镇上小学的校长,口碑好、人头熟,要是处理砸了,一个传一个,满条街都知道"福满楼不讲理"。林大姐咬了咬嘴唇,愣在原地。

正在这个当口,门口突然进来一位穿西装的中年人,开口就喊林大姐名字。林大姐抬头一看——是表弟阿强,十年前去省城开连锁餐饮,做得风生水起,今天是专程回来取经的,想让她讲讲"十五年老店怎么没出过岔子"。林大姐苦笑一声,把手里那根头发扬了扬:"你瞧,岔子这就来了。"

阿强没接头发,反问她一句:"大姐,你打算怎么收这个场?"林大姐嘟囔:"赔碗面呗。"阿强摇摇头,把那碗面端到周先生面前,九十度一鞠躬:"周先生,对不起,是我们卫生没做到位。这碗面免单,再送您一张本店的终身会员卡,以后每次来,牛肉面免费加一份肉。您要是觉得身体不舒服,我们可以陪您去医院,所有费用店里出。"周先生愣了一下,怒气消了大半,接过那张卡,反倒有点不好意思:"也没那么严重,头发不长,我没那么娇气。"

事后阿强没走,留在后厨帮林大姐收拾,一边擦桌子一边把省城那套做法一五一十讲给她听。林大姐这才明白,刚才阿强那一番动作不是"做戏",而是背后有四根支柱撑着:一是店里从上到下,都得把客人当自家人对待,不是嘴上说说,是要真信;二是遇到这种事,前厅服务员当场就能做主免单送卡,不用打十几个电话请示,客人等得心急,店才会真砸;三是店里要有一套记录客人抱怨的小本子,谁接的、怎么处理、客人满不满意,一周一回看,问题出在哪里一目了然;四是每隔三个月,所有员工都得重新学一遍怎么跟客人说话、怎么端面、怎么发现头发。

林大姐听完没说话,当晚就把后厨小刘叫来:"从明天起,头发一律戴网帽,谁再掉一根,扣半天工钱。"又把小陈喊到前厅:"以后客人说汤有问题,你直接免单,我签字就行,别等我出来。"她翻出那本蒙尘的小本子,从今晚开始重新写。三个月后,周先生不光自己每周来一次,还介绍了学校里五个老师都办了会员卡。街坊传的不是"福满楼有头发",而是"福满楼出问题,认账最快,改得最快"。

林大姐后来跟阿强说:"我以前总以为老字号靠的是手艺,现在才知道,手艺顶多撑十年,后面撑下去的是这四样东西。"

---

**📖 原文定义**

> 關於這一點,沒有簡單的答案。不過,下述各方面肯定有助於達到理想目標:
> (a) 公司文化:應該盡量做到以客戶為本。
> (b) 權力下放:給前線僱員足夠和恰當的權力和責任。
> (c) 系統:應該建立監察客戶滿意程度的系統。
> (d) 培訓:應該提供實現這些目標的培訓及技術。
>
> 註:上述建議基本上適用於保險人,但背後之重要原則可略為修改並使之適用於保險中介人。

**💡 对应点**

| 故事元素 | 概念对应 |
|---------|---------|
| 林大姐从"嘴硬"到"心肠不坏"再到真正把客人当自家人 | (a) 公司文化——以客户为本 |
| 表弟阿强当场免单送卡,不需要请示任何人 | (b) 权力下放——前線僱員有足夠權力 |
| 那本记客人抱怨的小本子,每周一回看 | (c) 系统——监察客户满意程度的系统 |
| 小刘戴网帽、小陈学说话、每季度重新培训 | (d) 培训——提供实现目标的培训及技术 |
| 林大姐选择当众认错而不是赔碗面糊弄 | 真实两难:回避问题 vs 直面问题 |
| 周先生从不满意到主动介绍同事办卡 | 高素质服务的最终回报:客户回头与转介 |
| 阿强从省城回来"取经",反成了点醒林大姐的人 | 中介人(代理人)同样适用此原则 |
