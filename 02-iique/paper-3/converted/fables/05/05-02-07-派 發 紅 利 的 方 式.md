# 5.2.7b 派 發 紅 利 的 方 式

## 🏺 寓言故事 —— 《三家分账》

江南小镇上有个布庄，年底算账时老板要把一年的红利分给三个老伙计——老张、老李、老孙。三人各有各的家境。

老张的儿子明年要娶媳妇，彩礼酒席都要现钱。老板对他说："今年分红八两银子，三种法子随你挑。"老张第一个选了当场拿走。老李没说话，他想了一会儿问："能不能先放你这儿，往后年年再多分点？"老板点点头说成。老孙却问："我明年不缺钱，但听说镇外河运将来会兴旺，能不能把分到的钱换成船股，等到年底或者事情办完再一起算？"老板想了想，说这条路也走得通。

开春后，老张的银子进了彩礼匣子，酒席办得热闹。老李那八两银子搁在老板铺里，一年年往上涨，他心里暗暗得意：等攒够了，给闺女置办嫁妆正好。老孙选的船股头几年没动静，第四年河运真的兴旺起来，船队跑出大钱，老孙这一年拿到的数目比老张老李加起来的总和还多。三个老伙计各自捧着各自的红利回家，谁也没吃亏。

老板站在柜台后头，看着三人远去的背影，想起自己早年也只用第一种法子，后来才学会灵活搭配。其实分账的路不止一条，每家每户要的也不一样；能拿现钱的拿现钱，想存着生息的存着生息，能等大钱来的就放长线——三种法子并不冲突，用得恰当，人人都满意。

---

**📖 原文定义**

> 在香港，保单红利一般是透过三种方式派发的：
>
> （a）派发现金红利：许多保单持有人选择把红利存放於其保险人那里。
>
> （b）派发复归红利：保单利益会跟随所宣布的金额而不断增加的（见1.3.1b(a)）。
>
> （c）派发期终额外红利：即按照基本资产的总回报，派发的红利价值通常会与基金的资产股值相若（即保单持有人的假设分红股值）。
>
> 现金红利和复归红利通常每年都宣布的，而期终额外红利则通常於保单期满或保单生效了一段特定期间后才宣布的。
>
> 在香港，大部分保险人都采用方法(a)，少部分采用方法(b)，而方法(c)则可以与(a)及(b)同时补足使用。虽然上文所述属於典型的分红方法，但须注意，每个保险人所采用的分红方法都有所不同。

**💡 对应点**

| 故事元素 | 概念对应 |
|---------|---------|
| 老板要分年度红利给三位老伙计 | 保单持有人获得红利 |
| 老张当场拿走银子 | 派发现金红利（方式 a） |
| 老李把银子继续存放在铺子里往后逐年增长 | 派发复归红利（方式 b） |
| 老孙选择把分到的钱换成船股等大钱 | 派发期终额外红利（方式 c） |
| 老板三种法子灵活搭配、人人满意 | 各保险公司分红方法可不同、需灵活选用 |
| 三人各自满意、无人吃亏 | 三种方式并非冲突，可同时使用 |
