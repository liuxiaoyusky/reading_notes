# 5.6.2 死 亡 索 償 (Death Claims)

## 📜 寓言故事 —— 《最后一程》

老郑在码头边上开了二十年的杂货铺，街坊四邻都叫他"郑伯"。去年冬天的一个清晨，他的小儿子阿涛从医院打来电话，声音发颤——老爷子夜里走了，梦里走的，没遭罪。

郑伯这辈子最得意的事，就是十年前在街口那家"信得过"保险铺子，给家里置办了一份长期的人身保障合同。每年交一些钱，写明白若是哪天人不在了，家里能拿到一笔钱让老伴和孩子有个依靠。郑伯生前总是笑嘻嘻地说："就当是给家里人存了个放心。"

郑伯一走，麻烦来了。这份合同摆在桌上，白纸黑字写着"若投保人离世，款项将给付某某人"，可阿涛翻开一看，里头牵扯的人和关系比自己想象的要复杂得多。

第一个卡住阿涛的是：到底谁有权去领这笔钱？合同上写了几个名字，有阿涛的母亲（郑伯的老伴），有阿涛自己，还有当年合同里特别提到的另一个人。按理说，那个人应该出面。可一打听，那人常年在外地，连郑伯的葬礼都没来。阿涛心里嘀咕：他不来，是不是这笔钱就没人能领了？后听街坊黄律师说，合同毕竟没做过任何过户、也没立过什么信托，按规矩，能去主张这笔权益的，是继承了郑伯身后事务的那一方。合同里虽然写了要给第三方，但只要当初的约定仍然成立，钱还是会按照合同走下来——只是"谁来伸手接"这件事，必须由该接手的人出面办手续。

第二个让阿涛犯难的，是"哪一天算走了"。医院的死亡证明上写得很清楚，可阿涛突然想起，父亲这份合同里头有一项是"逐年递减"的保障。差一天，保障的额度就可能不一样。再有，合同里还约定了某种跟年份挂钩的额外利益。阿涛这才明白：原来"走的这一天"不是悲伤里随便记住的日子，而是能算钱的起点。

第三件事更让阿涛心里一紧——怎么证明父亲真的不在了？医院出具了正式文书，这是最基本的。可万一有一天，人是在外地走的，或者情况一时说不清楚，光凭一份文书够不够？街坊老陈听了这事摇头："这种关头最容易被钻空子。要是情况有点可疑，人家那边一定会查到底。"

第四件事让阿涛彻底睡不着了：父亲走的原因。死亡证明上写的两个字是"心脏"。可阿涛后来翻合同才发现，合同里专门列了一条：若是投保人在签合同后没多久就走了，而且走的原因按常理需要更长时间才会发生，保险公司是会重新仔细看一看的。"不是不赔，是要先把事情弄清楚。"老陈说，"再说，万一写的是自杀，那又是另一条规矩；万一写的是意外，那还有专门的附加保障要看；万一……写的是被人害的，而害他的人偏偏还是合同里写着要领钱的那个人，那这个人一分钱也拿不到——法律不允许害人者反过来得利。"

阿涛听了一身冷汗。一份看似简单的合同，背后竟藏了这么多门道。

第五件事是最微妙的。父亲走的时候，找不到他的出生证明。身份证上写着年份，可合同里要求必须核验年龄。阿涛翻了半天家里那个旧木箱子，总算在角落翻出一本发黄的出生登记簿，这才把年龄这件事落实。

等所有的事情都一一办妥，阿涛在那家信得过的铺子里签完最后一份文件，领到了那笔款子。走出门口时，他回头看了一眼招牌，忽然明白了父亲当年为什么坚持要办这件事——不是为了钱本身，而是为了让"家里人不再为这些繁琐的事发愁"。专业的事，终究要按专业的规矩走。悲伤归悲伤，流程归流程。把流程走完，让该到的人安安稳稳拿到那份安心，才是对离开的人最实在的交代。

**📖 原文定义**

> 期滿索償通常是在「愉快」的氣氛下進行的，原因顯而易見。另一方面，死亡索償無可避免地會在嚴肅、甚至有時是悲慘的情況下進行。保險人及保險中介人應該對這種情況寄予同情及理解，但不能因此過分干擾處理索償的專業過程。關於這類索償，應特別注意以下事項：
>
> (a) 索賠權：可能有權獲取保單的死亡利益的人包括：第三者保單的尚存保單所有人，受保保單所有人的遺產代理人，承讓人及受託人。
>
> (b) 死亡日期：必須確定此日期，因為它會影響如遞減定期壽險的支付金額，及任何紅利／英式紅利的計算。
>
> (c) 死亡證明：一般而言，這不難得到，尤其在具有死亡證明書的情況下（必須出示正本）。
>
> (d) 死因：這會在死亡證明上註明，可能很重要——(i) 自殺；(ii) 意外；(iii) 可疑或令人驚訝；(iv) 謀殺——若殺人犯是受益人，法律（公共政策）是不會容許殺人犯本人獲益的。
>
> (e) 推定死亡：在不能簽發死亡證明書，但可以推定受保生命已經死亡的情況，可能須由法庭裁決。
>
> (f) 年齡證明：一般而言，年齡證明不難取得，如出示死者的出生證明書、身分證明文件或護照即可。

**💡 对应点**

| 故事元素 | 概念对应 |
|---------|---------|
| 郑伯当年办的长期人身保障合同 | 投保的保单（被保人=郑伯） |
| 阿涛梳理谁有权去领钱的过程 | (a) 索赔权——遗产代理人、承让人、受托人 |
| 阿涛意识到"走的日期"会影响赔付金额 | (b) 死亡日期——影响递减定期寿险与红利计算 |
| 医院出具的正式文书与外地理赔的隐患 | (c) 死亡证明——必须出示正本，外地情况易生欺诈 |
| 父亲走的原因及合同里的"自杀/意外/可疑/谋杀"条款 | (d) 死因——四种需特别审查的情形 |
| 杀人者本人不能得利的法律原则 | 公共政策：谋杀受益人无权获益 |
| 阿涛翻箱倒柜找出生证明 | (f) 年龄证明——身份证、护照、出生证明书 |
| 郑伯坚持办这份合同的本意 | 死亡索偿的严肃性与专业流程并行的意义 |
