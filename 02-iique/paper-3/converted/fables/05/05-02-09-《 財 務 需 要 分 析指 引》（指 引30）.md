# 5.2.9 《 財 務 需 要 分 析指 引》（指 引30）

## 🔍 寓言故事 —— 《裁缝的量身》

城南布庄街,周嫂开了家"锦云成衣铺",做了二十年的街坊生意。前些天,街口的李家阿婆来找她做过一身寿衣,一边量尺寸一边抹眼泪——阿婆上个月刚把家里八万块的养老本,交给卖保障的小伙子买了份"返本型大礼盒",说每月有分红,五年后还能翻一番。结果合同拿来一看,五年里要交的"杂费"比利息还高,真到急用钱想拿出来,只能领回三成。阿婆哭了一晚上,第二天就病倒了。周嫂听着这事,心里一直搁着。

这天傍晚,街坊王大姐推门进来,手里攥着一张皱巴巴的宣传单,满脸兴奋:"周嫂,快帮我看看——卖保障的小陈说,这款'全家福'最划算,一年才两千多块,生病住院能报,人走了也能给家里留一大笔。他说今天不签,下周就要涨价了!我今天就想签!"

周嫂放下手里的针线,接过宣传单扫了一眼,没急着点头。她从柜台后头翻出一个旧账本,拍拍王大姐的胳膊:"大姐,先别急。咱们这行有句老话——量体裁衣。你要做的不是'买一件大家都在买的衣裳',是'买一件合你身的衣裳'。你刚才说小陈催你今天就签,越催越要慢。来,坐下,我问你几件事。"

周嫂一边问,一边在本子上记:王大姐今年四十八,在菜市场帮人卖鱼,丈夫老王去年刚下岗,儿子正在念大三,每月还要还两千块的房贷。一家三口的吃穿用度、孩子的学费、每月雷打不动的房贷——周嫂一笔一笔加完,摇摇头:"大姐,你这收入一个月不到六千,出去这些硬开销,能攒下来的也就几百块。你要再拿出两千多去买这份合同,等于把家里所有的活钱都锁死。一旦老王找不到工作、孩子临时要交什么费用、你自己生个小病——你家连一个月都撑不过去。"

王大姐急了:"可小陈说,这个就是保生病住院啊?"周嫂把宣传单翻过来,指着背面一行小字:"你看——这款只报'住院七天以上的大病',感冒发烧、跌打损伤这些小毛病,一分钱不报。你家最常出的是小毛病,真要摊上大病,光靠这份合同也远远不够。而且,它不是只交一年——小陈有没有跟你说,要连续交十五年?十五年里头,一年两千多,加在一起就是三万多。这笔钱锁在里头,中途急用想拿出来,是要打折扣的。"

王大姐的脸一下白了。周嫂继续说:"还有一笔账你更要想。你和老王都已经四十多,再过几年,想再添保障,价钱要贵一大截;你儿子将来大学毕业,要结婚、要买房,哪一样不是钱?你现在把'活钱'全变成'死钱'放进这份不合适的合同里,等于把你家未来十年的腾挪余地,提前全押上去了。"

王大姐低下头,半天才说话:"那……我该怎么办?"周嫂合上账本,认真地看着她:"大姐,不是我替你做主——我只是个裁缝,不是大夫。你明天再去找小陈,把今天跟我说的这些,一样一样问他:我家里每月硬开销多少,我能拿出来的闲钱最多多少,我最怕家里出什么事——你按我这账本上的数,替我算清楚,看看哪款才真正合身。他要是答不上来,这份合同你就别签;他要是答得上来,咱们再一件一件比。比完以后,还要白纸黑字写下来,签上你俩的名字,留一份给你自己。这事关一笔钱,不能只凭嘴说。"

王大姐点点头。临走时她又回头问:"周嫂,你又不开卖保障的铺子,干嘛这么替我操心?"周嫂笑了:"大姐,你在这条街住了二十年,我看着你儿子从小屁孩长成大小伙子。我替你把把关,就是替这条街的街坊把把关。要是只图自己卖得快,不管街坊穿得合不合身,这店我也开不到今天。"

一周后,王大姐再来布庄,手里还是那张宣传单,但眉眼舒展了许多:"小陈上周把账给我算了一遍,说这款不适合我家,给我另推了一款——一年只要几百块,专保住院和意外,还有九十天的冷静期,不合适随时退。还把账一项项写在表上,签了字,留了一份给我。周嫂你看,这份靠不靠谱?"

周嫂接过新单子,认真翻了半天,点点头:"这份,才像你家的样子。买合身的衣裳,穿十年都舒坦;买不合身的,头一年就想去换——可惜那时候再换,价码可就不是今天这个了。"

**📖 原文定义**

> 基於壽險保單的長期性質,保單所有人可能被鎖定資金,流動性嚴重受損。因此,獲授權保險人及持牌保險中介人就任何合適的人壽保險保單作出建議前,須確保對各客戶的情況,包括需要、財務狀況、支付保費的能力及意願等作適當評估,及所作出的建議是建基於該評估,而此事宜實屬十分重要。為進行財務需要分析,保險業監管局("保監局")已發出《財務需要分析指引》(指引30)。

> 財務需要分析所需的資料包括:客戶的目標、需要、財務狀況、支付保費的能力及意願。持牌保險中介人必須妥善記錄客戶在財務需要分析過程中所提供的資料、所作的分析及相關評估,並妥善記錄其向客戶所提出的建議及所持理由。

> 填妥的財務需要分析表格必須由客戶及持牌保險中介人簽署並註明日期,於其簽署日起計的12個月內持續有效。如客戶在財務需要分析過程中所提供的資料有任何重大變更,則須告知相關的獲授權保險人或持牌保險中介人。

**💡 对应点**

| 故事元素 | 概念对应 |
|---------|---------|
| 王大姐拿着宣传单一进门就要签 | 客户被推销冲昏头脑,未做评估 |
| 周嫂问收入、硬开销、活钱 | 收集客户财务状况与支付能力 |
| 周嫂翻出宣传单背面的细则 | 评估产品与客户需要的匹配度 |
| 周嫂点出"只保大病不保小病" | 识别客户真正的保障缺口 |
| 周嫂算十五年总账 | 评估长期支付能力 |
| 周嫂说"先别签字,回去和小陈一项项算" | 建议须建基于评估,而非冲动 |
| 周嫂要求"白纸黑字签下来" | 财务需要分析表格须签署并记录 |
| 周嫂是街坊,不是卖保障的人 | 中介人须以客户利益为先 |
| 王大姐一周后拿着重新算过的新方案 | 评估后再作建议,推荐合身合同 |
