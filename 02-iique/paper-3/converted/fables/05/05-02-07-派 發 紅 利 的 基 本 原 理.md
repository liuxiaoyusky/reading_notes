# 5.2.7a 派 發 紅 利 的 基 本 原 理

## ⚖️ 寓言故事 —— 《果园的余粮》

江南有个叫沈记的果农会，每年秋天收完果子，会长都要做一件头疼事——把会员们一起存在仓库里的"公粮"算一算，看是赚是赔，赚了怎么分。这规矩是祖上传下来的，沿用了几十年。

沈记果农会今年刚起步，拢共八户人家入会，每家出二十石米作为公账，由会长老沈统一打理。开春，他雇了短工、买了肥料、还租了两亩山坡地。日子一天天过去，到了秋天果子下树，老沈把账拢了拢，公账里多出十八石米。他心里一喜，可又一沉——喜的是收成好，沉的是这十八石该怎么分。

消息传开，会员们围坐在祠堂里，七嘴八舌——"老沈，我家出了二十石米，是不是该还我二十石再分利？""凭啥先还我？大家一起担的风险，一起分的利啊。"入会最早的周大伯，仗着资历老，开口就想要三成；入会最晚的何家媳妇，怯怯地坐在角落，不敢吱声。老沈被问得哑口无言。他翻出去年拟的章程，发现写得含含糊糊：只说"年底结算，余粮按贡献分"，但"贡献"到底指什么——是看出米多少，还是看出力多少，还是看担的风险多少？没人说得清。有几户入会早，有几户入会晚，出米多的和出米少的该怎么摆平？老沈越想越乱，怕分得不公，怕伤了和气，更怕自己担了私吞的嫌疑。他一连三个晚上没睡好，夜里翻来覆去，脑子里像一团乱麻——一边是周大伯的嗓门，一边是何家媳妇的沉默。

第四天夜里，老沈实在憋不住，跑去村里找德高望重的账房先生吴伯。吴伯八十二岁，给村里几代人算过账，从不出错。他没直接答老沈，而是反问："你这十八石余粮，从哪来的？"

老沈一怔，掰着手指头数：第一笔，粮食卖价比预想的高，市场行情好，多卖了八石米；第二笔，雇短工比预算省了几石米，因为今年雨水足，杂草长得慢，少锄了几遍地，省下了工钱；第三笔，还有几户入会迟，但他们地里的活没少干——挑肥、浇园、看守仓库，一家顶一家用，这一笔是大伙儿共同出的力。吴伯点点头："你瞧，余粮不是天上掉的——是这三样凑出来的。每一笔账，你都得跟大伙儿说清楚。谁出力多，谁就该多拿；谁出力少，就少拿。这叫按贡献分。"

老沈心里一亮，可又犯了难："那入会早的和入会晚的，怎么分？周大伯仗着资历要三成，何家媳妇不敢开口——这俩怎么摆平？"吴伯笑了笑："你把章程里的话再念一遍。""余粮按贡献分。""那就照贡献分。入会早的，等于担了更长时间的风险，多拿一份；入会晚的，少拿一份，但拿到的也是实打实的。账上每笔进出都摊开，让大伙儿自己看得明白，谁也不会疑心你老沈。周大伯要三成，你问他出力是不是三成；何家媳妇不出声，你替她把该拿的那份算清楚——这也是章程的本意。"

老沈回到祠堂，第二天把会员叫到一起，先把十八石余粮的来龙去脉一笔一笔摊开：哪一笔是市场好带来的，哪一笔是节省下来的，哪一笔是大伙儿共同出的力。然后按各家实际出的米、出的工、担的风险，定了一个分法——早入会的、出力多的多拿几石，晚入会的少拿几石；周大伯出力确实多，按数多分；何家媳妇出的工少，但守了三个月仓库，也按规矩分到一份。最后他又加了一句：今年余粮多，照这个数分；明年若年景不好，余粮少了甚至亏了，也照这个法子——该退的退，该补的补，账目公开，谁也不偏。

会员们听完都点头。周大伯数着自己那一份，没再多说；何家媳妇攥着分到的米，眼眶有点红。有人说："老沈，你这法子我服。"老沈长出一口气。他明白了一件事：余粮不会凭空冒出来，也不会凭空消失——它的每一粒，都对应着大伙儿的某一份付出。只要账目说得清，分法讲得明，谁也不会疑心有人中饱私囊。

**📖 原文定义**

> 也在本手冊的其他部分進行討論（見 1.3.1b(a)及 4.10）的分紅保單，是帶着獲得保單紅利這類回報的期望而購買的，它一般也會產生現金價值的。一般來説，所宣佈及派發的紅利金額與相關的分紅保單的匯集基金的業績情況有直接的關係的。（所謂「匯集基金」(pooled fund)是指相關的保險人隨着提供了分紅保單而在其資產負債表上顯示出來的資產的全部，而之後保險人須為這些保單管理該等資產。）滙集基金在特定期間的業績情況與其在同一段期間的投資收益、費用、賠付金等因素有密切的關係。一般而言，滙集基金的投資回報對紅利額有最大的影響，但和保險人的整體業績就不一定一致。一個謹慎的保險人只會在得知了實際的業績情況比其之前所作的精算和財務假設更有利後才宣佈保單紅利的。
>
> 如前所説，紅利金額視乎滙集基金的業績情況而定的。也值得注意，保險人一般保留釐定紅利金額的權利。實務上，紅利金額是基於各自的獲委任精算師的意見，並經各自的董事會批准而釐定的。在制定建議時，精算師會考慮滙集基金的業績情況、經濟展望、及如何公平的對待同一個滙集基金内不同類別的保單持有人及在不同時間投保的保單持有人。而且，保險人一般會將紅利平均派發，以減低短期大幅波動。平均派發的形式各有不同，各保險人可因應相關保險合約的條款及自身的政策決定平均派發的方法。

**💡 对应点**

| 故事元素 | 概念对应 |
|---------|---------|
| 八户人家凑米成立的公账 | 分紅保單的「匯集基金」(pooled fund) |
| 十八石余粮的三个来源（粮价高、雇工省、共同出力） | 滙集基金業績的三大要素：投資收益、費用、賠付 |
| 老沈翻章程发现"按贡献分"写得很模糊 | 保險人需有清晰記錄的盈餘分配公司政策 |
| 吴伯让老沈把余粮来源一笔一笔摊开 | 公司政策須清晰記錄、經董事會批准 |
| 按各家实际出的米、出的工、担的风险分 | 如何公平的對待同一個匯集基金内不同類別及不同時間投保的保單持有人 |
| 老沈承诺明年亏了也照这个法子分 | 保險人只在實際業績比精算假設更有利時才宣佈紅利；業績不好時亦按章程處理 |
| 账目公开，谁也不偏 | 公平對待客戶原則，受監管審查 |
