# 5.5 售 後 服 務

## 📜 寓言故事 —— 《老周的布庄》

老周在镇东头开布庄，性子沉稳，做事利落。柜上挂着块老匾，写着"百年老店"。可这几年，镇上布庄越开越多，李记、王记、孙记一家挨一家，新客不好拉，老客又留不住。老周每晚在柜台后头叹气：要是客人买完布就再也不登门，这匾再老，也撑不了下一个百年。

这年春天，王婶来布庄扯了八尺藏青棉布，做了件对襟褂子。取布那天，她随口问了句："周掌柜，我那件藏青的，要是颜色褪了，能不能再染一回？"老周愣了一下。他卖了三十年布，从没想过客人买走之后的事——他只管卖，卖完就完了。

王婶走后，老周坐在柜前琢磨：客人买了布，会不会再回头？什么时候回头？回头时她要什么？他心里忽然冒出一串事：过两月棉布起球了怎么办？三个月后王婶想改件棉袄，旧布能不能拆？开春要是搬家，布票子弄丢了呢？这些事，件件都还没人管。

他把这些事一条条写在账本背面：王婶要改尺寸，要换颜色，要补收据，要寄存布头，要寄包裹给外地的女儿，还要万一买错想退。这些零零碎碎的小事，从前他觉得是麻烦。可这晚，他盯着账本，忽然转过弯来——客人买走的是一块布，她带走的是一份对布庄的信任；这份信任要是有个地方接着、保着、应答着，她下回要做衣裳，第一个还是会推门进来。

第二天，老周在柜上贴了张纸条，纸条上写着「售后诸事，可来柜问」。王婶头一个回来，要把藏青褂子改大两寸；李嫂子来问去年的收据还在不在；孙大娘托他寄一匹红绸给城里的小孙女。每一桩，他都认认真真记在账本上、答复清楚、把事情办妥。慢慢的，柜前那张条子越贴越长，能办的事越列越多：提醒染布、帮改衣裳、补开收据、退还布料、寄送外地、代交费用、保管旧物。

到年底，老周翻开账本，发现一件事：那些只来买过一次布的人，再没登门；可来问过售后事的，十个里头有八个，后来又添了新料子。布庄没换匾，可推门进来的脚步，却比哪一年都密。

**📖 原文定义**

> 有關保留現有業務的問題已經在前文（見5.2.3a(a)）提過。正如前文所述原因，這是非常重要的。在這方面，售後服務(after-sales service)的素質是一個很重要的因素。這類服務屬於顧客服務人員的責任（見上述5.1.1(e)），他們所屬的部門現在可能稱為保單所有人（或稱客戶）服務部，或 Policyowner Service (POS)。下面提醒大家，POS 的職責包括：
> (a) 通訊：信件及與客戶的其他溝通。
> (b) 文件整理：複印保單、退保、轉換計劃等。
> (c) 收取保費：處理這方面所有事宜。
> (d) 保險權益管理：現金價值、保單抵押貸款及紅利。
> (e) 更改保單：見下述內容。

**💡 对应点**

| 故事元素 | 概念对应 |
|---------|---------|
| 老周原本只管"卖完就完" | 销售即终点，无后续服务 |
| 王婶随口一问"褪色能再染吗" | 售后服务是客户主动提出的真实需求 |
| 老周账本背面列出的零零碎碎小事 | POS 部门的全部职责范围（通讯/文件/收费/权益/更改） |
| 柜上贴的"售后诸事可来柜问" | 建立专门服务窗口，承担 after-sales service 责任 |
| 客户能回头办改衣、补收据、寄包裹等具体事 | 持续服务把"一次性买卖"变成"长期关系" |
| 回头办过事的客人八成又添了新料 | 售后服务品质直接影响续留率（即保留现有业务） |
| 这类事归"顾客服务人员"负责 | 售后服务是客服部门（POS / 保单所有人服务部）的责任 |
