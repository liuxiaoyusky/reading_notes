# 5.2.5a 重要资料声明书与内部转保

## 📜 寓言故事 —— 《两张保单》

老周在镇上开了一家杂货铺，一年前在某家商号投保了一份家财险，每年交一笔钱，若店里遭灾就能赔。今年初，镇上来了另一家商号的伙计小林，向老周推销一款"更划算"的家财险。老周心里一动，打算再买一份新的，把旧的退掉换新的。可小林临走前从包里掏出一张纸，认真地说："周叔，您这种情况属于'换保'，麻烦您在这份声明上签个字。"老周愣了一下："换保还要签字？"小林点点头："您得亲自看一遍，明白新保单和旧保单比起来，哪里吃亏、哪里划算，再决定要不要买。"

老周接过那张纸一看，里面列得清清楚楚：旧保单已经交了一年钱，中途退掉能拿回多少；新保单头一年还没交，但又要重新核保——意思是说，得重新查一遍他的店、家、家里人有没有什么新的风险，比如去年添的货、家里老人身体变化，这些都得重新审一遍；而且新的合同一开始的"等候期"又得从头算起，万一签完没多久就出事，新的可能赔不了。老周越看越明白——小林卖给他的是一张全新的"入场券"，不是把旧的升级。

签完字，小林又提了一句："周叔，您本来就是这家商号的老客户吧？我们商号里有规矩，凡是老客户一年内再买新保单的，系统会自动提醒我们再跟您确认一遍，看您是不是真要动旧的、买新的。"老周听明白了：哪怕是同一家商号，"内部换保"也跟头一回买一样，重新查、重新算、重新问一句"您想清楚没"。他把那张声明收进抽屉，跟老伴说："买新保险这事，急不来。"

---

**📖 原文定义**

> 當一份新的人壽保險保單被識別為轉保個案，有關獲授權保險人或持牌保險中介人應要求客戶簽署《重要資料聲明書--轉保》。此規定旨在讓客戶意識到轉保可能產生的不利之處，以一併考慮由持牌保險中介人提供的資料和意見，就是否繼續購買新的人壽保險保單作出經掌握充分資料的決定。
>
> "內部轉保"指就購買新的人壽保險保單的交易已被識別為轉保的情況下，該新的人壽保險保單的獲授權保險人同時為客戶現有人壽保險保單的保險人的個案。
>
> 獲授權保險人應根據準則，實施核對其內部紀錄和數據庫的程序，以識別內部轉保的情況：每當收到新的人壽保險保單的申請時，獲授權保險人應核對：(a) 就新保單的申請日期而言，客戶有否在緊接該申請日期前的12個月內曾經與該獲授權保險人訂立現有人壽保險保單，及 (b) 如有此情況，現有人壽保險保單在緊接該申請日期前的12個月內有否出現任何可構成轉保的情況。

**💡 对应点**

| 故事元素 | 概念对应 |
|---------|---------|
| 老周打算退旧买新 | 转保个案的事实基础 |
| 小林掏出的那张纸 | 《重要资料声明书——转保》 |
| 声明上列明的费用对比、退保损失 | 客户须充分掌握的资料 |
| 让老周亲自签字 | 中介人须要求客户阅读并签署 |
| 同一家商号老客户一年内再买 | 内部转保的识别范围 |
| 商号系统自动提醒再确认 | 12 个月内的内部核对程序 |
| 重新查店、家人、等候期 | 视同新保单须重新核保 |
