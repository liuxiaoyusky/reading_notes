# 5.2.11 送 贈 禮 品 指 引 （ 指 引 25）

## 🎁 寓言故事 —— 《长寿面卡的礼物》

老周在街口开了二十年的小面馆，最近想给自己买一份"长寿面卡"——一种要连续供三十年、每月交一笔钱、等他六十岁之后每月能领回一笔面钱的长期安排。摊开三家推销员的宣传单，他心里嘀咕：都说自己家最好，到底听谁的？

第一个上门的是小赵，提着一兜鸡蛋、一箱牛奶、一张超市购物卡，笑着把东西往桌上一放："周叔，您看看，咱这长寿面卡最划算，先把礼物收了再说。"老周心里一热，手都有点痒：这些鸡蛋牛奶，够面馆省一个月伙食钱了。但他又想，这礼物越重，是不是里头藏着什么没说清的事？小赵被这一问问住了，支支吾吾说"反正比别家划算，您签就是了"。

第二个来的是小林，只带了一张折页、一支笔，往桌上一摊："周叔，我给您讲清楚这张卡怎么交钱、怎么领钱、什么时候能拿回本，您听完再决定。"没带礼物，没套近乎，但讲得慢、讲得细。老周听完，知道每个月交多少、哪一年开始领、能领多少，还知道万一中途不想供了能拿回多少钱。他点点头，心里踏实了不少。

第三个上门的是老孙，胳膊下夹着一个本子，进门先把礼物的事摊开说："周叔，我这儿按规定不能送您鸡蛋牛奶那种大礼，但能送您两样东西——一是公司给的积分徽章，等您供满一年可以换个小锅；二是我们面馆同业会的联名围裙，因为我自己也开面馆，咱们同行算建个交情。这两样都在规矩里写明了，您看要不要。"老周接过围裙和徽章，听老孙把卡的内容一项项说清，发现和小林讲的差不多，但老孙为人更敞亮，连自己能送什么不能送什么都先讲明了。

晚上老周关了店，坐在灯下把三家的小票一字排开，越想越明白：小赵的鸡蛋牛奶，是想让他签了字再说，礼物一收，脑子就不清醒了；小林不送东西，是让他自己用耳朵判断；老孙送的徽章围裙是小意思，而且在规则里写得清清楚楚，收了也不影响他判断哪张卡真正适合自己。他最后在老孙的本子上签了字，并把鸡蛋牛奶原封不动让小赵拿回去。

---

**📖 原文定义**

> 在保險產品的營銷、推廣或分銷過程中為客戶送贈禮品或其他相類的報酬，對客戶就保險產品作出知情的決定或判斷該產品能否滿足其保險需要和其他情況時，可能會構成不當的影響或分散客戶的注意力。因此，送贈禮品指引（指引25）為獲授權保險人和持牌保險中介人在營銷、推廣或分銷歸類為長期業務的保險產品時，提供在使用禮品和回扣方面應遵從的特定限制的指引。
>
> 一般而言，根據指引25，獲授權保險人和持牌保險中介人在營銷、推廣或分銷長期保險產品（類別C（相連長期）產品、類別A（人壽及年金）產品及類別D（永久健康）產品）時，不應直接或間接地向客戶送贈禮品。
>
> 然而，在提供類別A產品及類別D產品時，僅於獲授權保險人或持牌保險中介人根據相關情況作出的合理評估，認為所送贈或提供的禮品不會影響客戶對是否購買產品一事所作之知情的決定，方可向客戶送贈或提供禮品。因此，獲授權保險人和持牌保險中介人有責任就擬送贈的禮品進行評估，以評核在其合理意見下，該禮品會否影響客戶作出該知情的決定。
>
> 就上述情況的唯一例外是，授權保險人和持牌保險中介人在提供類別A產品、類別C產品或類別D產品時，可以送贈指引25內指明的許可禮品，例如獲分配的基金單位花紅、為建立關係而提供的禮品、或在客戶忠誠獎勵計劃下累積的積分於其所兌換的禮品、為客戶提供的贊助和支援、品牌建立活動及輔助服務的禮品，惟有關保險人或保險中介人須嚴格遵守指引25附件中提述與每項許可禮品相關的準則。

**💡 对应点**

| 故事元素 | 概念对应 |
|---------|---------|
| 老周想签"长寿面卡"前的真实犹豫 | 客户面对长期保险产品时需要作出"知情决定"的处境 |
| 小赵提着鸡蛋牛奶上门、急着让他先签 | 直接或间接送赠礼品，可能构成不当影响、分散注意力 |
| 老周反问"礼物越重是不是藏着没说清的事" | 评估礼品是否会左右客户判断的内在动机 |
| 小林不带礼物、用折页一笔一笔讲清 | 不送礼品、靠讲清产品本身让客户判断 |
| 老孙送的积分徽章和同业围裙 | 指引25附件列明的"许可礼品"——小额、为建立关系、规则明确 |
| 老孙先把"能送什么不能送什么"讲明 | 中介人有责任先评估礼品对知情决定的影响 |
| 鸡蛋牛奶被原封不动退回 | 对类别人寿及年金产品，礼品原则上是不可送的 |
