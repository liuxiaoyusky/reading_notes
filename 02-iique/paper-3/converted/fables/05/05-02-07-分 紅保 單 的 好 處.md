# 5.2.7c 分 紅保 單 的 好 處

## 🎯 寓言故事 —— 《三种养鸡人》

村东头有三个养鸡人，老钱、老孙、小周。三人各自养了一群蛋鸡，靠卖鸡蛋过日子。可这三人的做法，却完全不一样。

老钱性子最稳。他听老辈人说，鸡下了蛋总能卖钱，于是他定了一个规矩：每天每只鸡保证下四个蛋，一个都不能少。剩下多下的蛋，都归老钱自己。年景好的时候，鸡争气，下了六个，老钱笑眯眯收走两个；年景差的时候，鸡只下三个，老钱宁可从自己口袋里掏钱补上，也得把四个蛋如数送到买家手里。村人都说，老钱这人实在，从不坑人，可他自己家底薄，一年到头剩不下几个钱。

老孙不一样。他觉得自己懂行情、能判断哪只鸡最会下蛋，于是买了一只普通的鸡，逢人便吹："这鸡下的蛋，涨了归我，跌了也得我兜着。"结果那年鸡瘟来袭，蛋价腰斩，老孙亏得底朝天，老婆孩子连过年肉都买不起。

小周呢，小周刚入行，没什么经验，又怕亏本。他找到村里养鸡最久的王大爷请教。王大爷想了想，给小周出了个主意："你找老钱那种保证每天给你四个蛋的养鸡人，再跟他签个补充的约定——年景好的时候，鸡多下的蛋，你们一人一半；年景差的时候，先保证你那四个，剩下的再说。"小周一听，眼睛亮了。

十年过去，村子里起了大变化。鸡蛋价钱一年比一年贵，老钱给的那四个保证蛋虽然稳，但越来越不够用了。老孙早就改行去城里打工，他那只自负盈亏的鸡，他再也不敢养了。唯独小周，靠着这个"保底加共享"的法子，日子越过越稳。每年除夕算账，小周都能从老钱那里领到一笔"年景分红"——有时候多，有时候少，但从来没有哪一年是负数。小周坐在自家门口，看着满院子跑的小孙子，心里踏实得很。

---

**📖 原文定义**

> 分紅保單的主要優點在於除了有保證現金價值和保證死亡利益之外，保單持有人還可以以收取紅利的方式受惠於匯集基金比該等保證更佳的業績情況。第二項優點是：由於上述保證的緣故，保單持有人的回報所面臨的風險比投資相連保單為低。投資相連保單的情況是這樣的：由於保單持有人自行決定投資基金的組合，而保單一般沒有回報保證的，所以投資回報是好是壞，都要他自己一力承擔。分紅保單的回報一般是平均派發則是另一優點。

**💡 对应点**

| 故事元素 | 概念对应 |
|---------|---------|
| 老钱承诺"保底四个蛋" | 分红保单中的保证现金价值与保证死亡利益 |
| 小周领取的"年景分红" | 保单持有人以红利形式分享保险公司比预期更佳的业绩 |
| 老孙自负盈亏、亏得底朝天 | 投资相连保单无回报保证、所有风险由保单持有人独自承担 |
| 小周每年除夕算账、回报稳定 | 分红保单回报波动较低、风险低于投资相连保单 |
| 鸡蛋价钱一年比一年贵、老钱保底逐渐不够用 | 分红保单红利能在一定程度上抵御长期通胀 |
| 小周与老钱的"保底加共享"约定 | 分红保单的红利分配机制 |
