# 5.2.6b 分 紅 保 單 利 益說 明文 件 的 具 體 規定（指 引 28 - 附 件 II）

## 📜 寓言故事 —— 《阿禾的店铺说明书》

阿禾在城南盘下一间绸缎铺,打算做一份「未来五年盈利说明书」,贴在店门口给所有供货商和街坊看。他算盘打得很响,心想只要数字漂亮,大家就愿意赊账给他进货。

阿禾托朋友老周写这份说明。老周说,写之前先得做两件事:一是把「明年能卖多少匹布」「每个月的房租人工是多少」「汇率会不会变」这些最可能的数字,老老实实算清楚——这就是"基本情景"。阿禾瞪大眼睛问:"基本情景用什么数?"老周说:"得请个真正懂行的人来估,不能凭空说。估的时候心里要有一杆秤——这个秤的标准,全城三十家大铺子都认同一份公开手册,大家都照着那份手册来估。"阿禾点头,这就相当于"按业内公认的最佳估算来定假设"。

老周接着说第二件事,叫阿禾心里咯噔一下:"光写基本情景不够,你得把最差和最好的情况也算出来。"阿禾急了:"最差是多差?"老周翻出一本厚厚的账册说:"你去找全城过去十年所有绸缎铺的盈利记录,按从高到低排成一列——排在倒数那一头的数字,就是'最差情景'的依据;排在最前面那一段的数字,就是'最好情景'的依据。"阿禾算了算,发现自己选的数字已经超出了"前头那一段"——他赶紧把最好情景的数字往下调,跟老周说:"咱铺子刚开,头一年再好也好不过老字号,我别把牛吹太大。"老周点头:"这规矩就是——最差那档不能比过去十年里倒数第一还差,最好那档不能比过去十年里数一数二还好。"

说明书写好了,阿禾拿给茶馆里识字的老先生过目。老先生戴起老花镜,看了开头就皱眉:"'进账率'是什么?"阿禾一愣,自己造的词。老先生说:"城南所有铺子做生意,描述盈利用的词都是'毛利'、'净利'、'回本'这几个。你自己造的词,街坊看不懂,供货商看不懂,以后打官司法官也看不懂——这就是误导。"阿禾赶紧把"进账率"全换成了"净利"。老先生又翻到末尾:"你写'入账二十八万'——别人看着以为是一整年,你下头用小字注了是'五年累计'。不行,这种'写大字引人误读,小字圆谎'的做法,全城三十家大铺子共同抵制。"阿禾一边擦汗一边改,把每一年的数字都单列出来。

定稿那天,阿禾在店门口贴告示,旁边贴说明书。告示上写着:"本店五年盈利情况,请看下方说明书。"说明书一共有三栏:最左边是"基本情景",中间是"最差情景",最右边是"最好情景"——三栏必须并排出现在同一页纸上。阿禾原本打算最差那栏不写,理由是"吓人"。老周拦下他:"最差那栏必须写,不然街坊会以为你只报喜不报忧;最好那栏你可以不写,但既然写了最差,最好也要写——让看的人心里有数,天不会塌,也不会一步登天。"

说明书的时间跨度也讲究。阿禾本来只打算写三年,老周说不行,得至少写三十年——而且不能密密麻麻从头排到尾,得挑几个关键节点:头五年每一年都写;从第六年起,每隔五年报一次;等到他六十五岁那年要写一次;等到他一百岁那年再写一次;保单到期那年还要写一次。阿禾算了一下,这一长串时间点排下来,街坊翻到哪一页都能找到自己关心的那个年龄。

贴出去那天,阿禾站在铺子门口,看着那张并排三栏的说明书,长长舒了一口气。他现在明白了:一份让人信得过、不带水分的说明书,不是把最好看的那一面搬出来,而是把基本、最差、最好三种情况都摆在阳光下——用大家都认得的词,用大家都认可的标准估出来的数,挑几个街坊最在乎的年龄节点说清楚。这份说明书要的不是漂亮,是可信。

---

**📖 原文定义**

> (a) 制定假設:在制定基本情景的最佳估算假設時,委任精算師應參照香港精算學會發出的《最佳估算假設》(精算指引9),尤其是該指引附錄A中涵蓋利益說明假設的指引及考慮事項。獲授權保險人只可以不高於根據最佳估算所釐定的投資回報率闡述利益價值。
>
> (b) 悲觀情景及樂觀情景:獲授權保險人須採用預計投資回報的第二十五(25th)及第七十五(75th)百分位數以計算悲觀和樂觀情景(除非獲授權保險人已向保監局闡明並使其信納遵從此規定的實際困難,及獲得保監局另行的書面同意),並同時須保留其他假設不變(紅利/可支取現金的累積利率(如適用)除外)。獲授權保險人可採用低於第二十五百分位數的回報率以計算悲觀情景,但不得採用高於第七十五百分位數的回報率以計算樂觀情景。
>
> (c) 披露:利益說明文件中的保險術語應使用「指引28」附件第一部分(見附件I)所述的可接納的保險術語,並與其他產品資料文件(如產品小冊子、保單條款等)保持一致。獲授權保險人可選擇用獨立的表格,以退保發還金於身故賠償額的方式列出該等數字,而「保費總額」欄則必須顯示於各個表格中。悲觀情景和樂觀情景須在同一頁面。如獲授權保險人選擇顯示與基本情景有分別的情景,則最低限度須顯示悲觀情景。利益說明文件只應顯示於「保單年度終結」時的數字,並應就下列年度提供利益說明:a. 顯示不少於30年(於第5個保單年度後,以至少每5年的期間顯示)或保障年期(如較短);b. 在65歲時,或在保單年期屆滿時(如較早);c. 在100歲時,或在保單年期屆滿時(如較早);d. 在保單年期屆滿時。

**💡 对应点**

| 故事元素 | 概念对应 |
|---------|---------|
| 阿禾请懂行的人按公开手册估基本数字 | (a) 制定假设——按精算师最佳估算设定 |
| 老周拿全城十年记录排队的倒数第一与第一段 | (b) 25/75百分位确定悲观/乐观情景 |
| 老先生要求把"进账率"换回"净利" | (c)(i) 必须使用可接纳的标准术语 |
| 三栏并排出现在同一页纸上 | (c)(iii) 悲观、乐观、基本情景同页展示 |
| 阿禾原本想不写最差那栏,老周拦下 | (c)(iv) 选择显示其他情景时,至少要显示悲观情景 |
| 说明书挑五年、六十五岁、一百岁、到期几个节点 | (c)(v) 显示不少于30年,含65岁、100岁及保单届满 |
