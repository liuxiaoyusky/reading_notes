# 5.2.9a 作出建議與處理錯配

## 🎯 寓言故事 —— 《鞋不合脚》

老范在巷口开了二十年的布鞋店，街坊邻里要买鞋，头一个想到的就是他。这天傍晚，他正准备关门，进来一位穿西装的中年人，后面跟着个小伙子，看样子是父子俩。

老范热情招呼："两位看鞋？"中年人点点头："我儿子下个月要进山里的施工队干活，得给他挑一双结实耐穿的。"老范打量了一下小伙子的脚型和脚码，转身从货架最上面拿下一双精致的黑色牛皮鞋，鞋面锃亮，鞋底却只有薄薄一层皮。"这双好看，配西装也体面。"老范笑眯眯地推荐。

小伙子犹豫地看了看父亲。中年人想起身旁的顾客，便随口问了一句："有别的吗？"老范摇摇头："就这一款最合适，您要不要再想想？"

父子俩走出店门时，小伙子小声嘟囔："这鞋底这么薄，进山踩石头不两天就烂了。"中年人停下脚步，回头看了一眼店里的老范——他正把刚才那双黑皮鞋放回货架最高处。

原来，老范心里早就盘算过：这双鞋利润最高。至于小伙子要进山、底子要厚——这些信息，他听过就放下了，没放在心上。

回到店里，老范的徒弟小林不解地问："师傅，那双鞋明明不适合他，你怎么还推荐？"老范摆了摆手："人家又没说不买。再说了，款式这么好看，他穿着也体面。"

小林没有再说话，但当晚在自己的小本子上写了一行字："客户说要结实耐磨的鞋，师傅却推荐了薄底皮鞋。客户穿着进山不合适。"写完，他又在下面加了一句："师傅说对方没拒绝，但师傅也没问清楚对方到底要什么。"

第二天清早，一位穿工装的老客户来找老范，说自己儿子也要进山施工。老范正打算重复昨天的推荐，小林忽然开口："张叔，要不要看看这两双？"他从柜台下面拿出两双——一双厚胶底劳保鞋，一双加厚帆布鞋。老范愣住了，没想到徒弟备了这些。

张叔眼睛一亮，挑了厚胶底那双，临走时拍着小林的肩膀说："小伙子实在！"

晚上收工后，老范坐在店里想了很久。他翻开小林的笔记本，看见那句"师傅说对方没拒绝"——忽然意识到，推荐一双鞋，不能光看它好不好看、利润高不高。客户穿着要合适，这才是根本。

如果客户明明要的是耐穿的劳保鞋，店里却硬塞给他一双底薄好看的皮鞋，那就叫"配错了鞋"。真要配错了，店家有两条路：要么不卖，要么清清楚楚告诉客户"这双鞋底薄，可能不太适合进山穿，但您要是图个样子，我也可以卖"，并且把这话原原本本记下来。

至于"穿多少年合适"这种事，也得对准。比如客户本想穿三年就换一双，店家却给他推荐了一双"终身保修、十年不坏"的款式，价钱贵了十倍——这叫负担不对等，是另一种配错鞋。但反过来，客户本想穿十年，你给他推荐一双只耐穿三年的便宜货，价钱省了——这就不算配错，因为少花钱正好合他心意。

老范合上本子，对小林说："明天起，每一位客人，先听他说完要什么，再挑鞋。挑完了，如果鞋和他要的不太对得上——比如他要耐穿、我们只有好看的——要么换个挑法，要么老老实实告诉他哪儿对不上、为什么还推荐这一双，并且记下来。"

小林笑着点头："师傅，这叫'听清楚，再配鞋'。"

老范长长舒了一口气。

---

**📖 原文定义**

> (d) 在作出建議前所需考慮的事項：客戶的需要、風險承受能力、財務狀況，否則不應向該客戶介紹產品。
>
> (e) 提供保險選擇：當向客戶建議投資相連壽險保單時，亦應介紹能符合其投資目標的分紅保單；持牌保險經紀完成財務需要分析後，須同時介紹最少一項由不同獲授權保險人提供的合適選擇。
>
> (f) 處理錯配的個案：若基於財務需要分析過程中所收集的資料顯示某保險產品並不符合客戶的需要和狀況，而持牌保險中介人仍向客戶建議該保險產品，則此情況將被視為「錯配」的情況。獲授權保險人、持牌保險代理機構及持牌保險經紀公司須基於「公平待客」原則，制訂適當的管控措施以處理錯配的個案。在錯配存在的情況下，如持牌保險中介人仍不論此錯配的情況就有關保險產品作出建議，則持牌保險中介人須向客戶清楚解釋有關錯配的情況，以及為何儘管存在錯配的情況仍向客戶建議有關產品。持牌保險中介人亦必須記錄該解釋的詳情。
>
> 建議的保障水平與財務需要分析過程中識別的保障水平的偏差（即建議的保障水平高於或低於財務需要分析所識別的保障水平）不會被視為錯配的情況，惟該偏差須具有恰當、良好及合理的依據（如基於客戶的健康狀況）。如建議的產品無法在客戶表明的時間內達到目標儲蓄金額，除非有關偏差具有恰當、良好及合理的依據，否則應被視為錯配的情況。如所建議的產品的保費繳付期較客戶所表明的目標保費繳付期短，則不會被視為錯配的情況。

**💡 对应点**

| 故事元素 | 概念对应 |
|---------|---------|
| 小伙子要进山施工 | 客户的实际需要与状况（财务需要分析资料） |
| 老范没问清需求就推荐薄底皮鞋 | 未充分考虑客户需要就作出建议 |
| 小林笔记本上写的"客户要结实耐磨" | 必须记录客户的需要与状况 |
| 老范说"人家又没说不买" | 不能仅凭客户未拒绝就忽视错配 |
| 张叔最后挑走厚胶底劳保鞋 | 介绍符合客户需要的合适选择 |
| 老范最后想通"听清楚再配鞋" | 公平待客原则下的建议流程 |
| 若坚持推荐薄底皮鞋须如实告诉客户 | 错配仍建议时须清楚解释并记录 |
| 客户要穿三年却推荐十年不坏款 | 负担能力错配 / 储蓄时间目标错配 |
| 客户要穿十年推荐便宜短款 | 缴费期/使用期短于目标不算错配 |
