# 5.3.2b 要體檢業務

## 🩺 寓言故事 —— 《老周的复查》

老周今年五十三，在镇上的厂里做了二十年的车间主任。年初厂里办了补充养老的保障项目，工会的同事小陈来找他，说只要每年交一笔钱，等退休后家里能领一大笔。老周一听挺划算，当场就要签字。小陈却把笔收了起来："周叔，您这个年纪、这个额度，按规矩得先去医务室跑一趟。"老周脸一沉："我年年体检都正常，还查什么？"小陈耐心解释："您年年体检那是公司福利，单位付钱。这次是项目方要求您做的，目的不一样，查得也细——除了量血压、称体重，还得抽血、做心电图。费用项目方出，您不用掏一分钱。"

老周越想越别扭。一来他怕针头，二来他觉着自己身体棒得很，根本没必要。可小陈接着说："您要保的金额高，年纪也过了五十的坎，项目方光看您自己填的那张表，心里没底。他们不是不信您，是规矩如此——金额越高、年纪越大，他们越要亲眼看一看才踏实。"老周这才半信半疑地去了镇上的医务所。

医生姓林，戴副眼镜，问得很细：最近胸口闷不闷？夜里睡得好不好？家里父母有没有高血压、糖尿病？原来林医生并不认识老周，是项目方专门请来的"体检医生"，查完就走，资料直接交给项目方。老周躺在检查床上有点紧张，林医生笑着说："其实查清楚是好事，很多人不敢查，结果小毛病拖成大问题。"抽了两管血，又让他在跑步机上走了一刻钟。一周后结果出来了——血糖有点偏高，其余都没事。老周拿到报告，心里一块石头落了地。

临走时项目方的小陈又拿来一张薄薄的纸，让老周签收："周叔，您之前在登记表上写的血糖偏高，我们林医生按这个写了一份'专项问卷'，回头会寄给您常去的那位社区医生，请他补几句您过去几年的血糖变化。这样项目方心里更有数。"老周点了点头——他这才明白，项目方不只是查一次身体，还会专门发问卷给一直给他看病的那位医生，把过去的病历也摸一遍。

手续办完，老周回家路上琢磨起来：今天查的项目、为什么查、结果怎么样，他全知道；可他的血糖报告、抽血化验单，全是项目方的人锁在保险柜里，连林医生的名字都打了码，连小陈都没多看一眼。老伴听他念叨完，点了点头："对，身体的事本来就该保密。项目方让你知道查什么、为什么查，结果也告诉你——这规矩说得过去。"老周拍了拍大腿："往后我再不把这当麻烦了。"

**📖 原文定义**

> 然而，有時候合資格醫務人員所提供的進一步資料是有必要的。這類調查的來源可以是主診醫生（指通常或曾經向投保人提供醫療護理的醫生或其他合資格的醫務人員），或體檢醫生（指在保險人的要求下為投保人進行身體檢查的醫生，費用由保險人支付）。關於這點，須考慮幾個因素：
>
> (a) 敏感問題：一想到身體檢查就會緊張乃人之常情。但這也是很不合邏輯的，因為知道真相對個人有好處，可是，大部分人卻不會這樣想。保險人通常會意識到這個問題，只有確定體檢為非常有必要時才會要求健康資料。另外，在處理這類資料的時候亦須非常小心，以免違反有關保護個人私隱的任何法定條文。
>
> (b) 主診醫生報告 (Attending Physician's Statement [APS])：這是最通常要求的醫療報告，要求的理由一般如下：
> (i) 須進一步調查投保單中所披露的某些健康資料；
> (ii) 要求的保險金額很高；
> (iii) 投保人年齡較高（例如：超過50歲）。
>
> (c) 特殊醫療問卷：保險人可能會向投保人的檢查（或主診）醫生發出一份特別設計的問卷，以求獲得投保人的某些疾病或身體狀況的資料作進一步了解。這可能與許多狀況有關，只要保險人認為有必要就投保人在投保單上填寫的狀況作進一步的了解，範圍從高血壓到癌症。
>
> (d) 保密：健康資料屬個人私隱，獲得的資料必須按最高機密原則處理。然而，當投保人真的被建議進行身體檢查時，投保人有权知道要進行甚麼檢查，需要有關資料的目的，及（如果他想的話）任何檢查的結果。

**💡 对应点**

| 故事元素 | 概念对应 |
|---------|---------|
| 老周五十三岁、想保高额养老 | 投保人年龄较高或保额较高时须体检 |
| 项目方付费、老周不掏钱 | 体检费用由保险人支付 |
| 抽血、心电图、跑步机一刻钟 | 体格检查 + 血液化验等具体项目 |
| 老周怕针、怕查出毛病 | 体检作为"敏感问题"的普遍心理 |
| 项目方寄问卷给社区医生 | 主诊医生报告 / 特殊医疗问卷 |
| 报告专人保管、医生名字打码 | 健康资料按最高机密原则处理 |
| 老周事后能拿到结果 | 投保人有权知道检查内容和结果 |
