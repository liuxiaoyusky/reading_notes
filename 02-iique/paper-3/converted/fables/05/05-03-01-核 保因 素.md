# 5.3.1 核保因素

## 🎯 寓言故事 —— 《客栈掌柜的三把锁》

江南有位客栈掌柜老周，开店二十年了，迎来送往什么人都有。每年冬至前后，他都要为一件事伤脑筋——来年要不要让隔壁的钱庄继续把银两寄存在他这里。

找他寄银子的，理由都不一样。有个跑船的汉子要存三百两，说自己长年在江上讨生活，浪大船翻是常事，他想让老周多关照几分。有个教书先生也想存二百两，人瘦瘦的，烟不离手，一张嘴就咳嗽。还有个做绸缎生意的胖掌柜，笑呵呵地拿出一千两，说这是给儿子将来娶亲留的，自己近来应酬多酒也喝得多。还有个年轻的木匠，每天攀上爬下爬树砍木头，衣服上还沾着松脂味儿，也捧来五十两想托老周保管。

老周坐在柜台后面，看着这四个人，心里像拨算盘一样响。跑船的汉子天天跟江浪搏命，银子放在他家里，万一哪天船翻了人来取钱怎么办？教书先生瘦是瘦，可他抽的那口烟、咳的那几声，让人心里没底。胖掌柜酒喝得多，肝火旺，谁知道哪天身体撑不住？木匠呢，爬树砍木头的人，跟跑船的也差不到哪里去。

但老周也没法一竿子打翻一船人，毕竟人家都是凭本事挣的辛苦钱。于是他想了个法子：他给钱庄老板寄了一张条子，写明自己要“掂量掂量”每个人。

掂量的第一把尺，叫“看得见的难处”。老周把每个人从头到脚看一遍——胖瘦、抽不抽烟、喝不喝酒、做的是安稳营生还是刀尖上走的活计。这些一眼就能瞧出来的事，摆在明面上，他想躲也躲不掉。教书先生尽管说自己“身体还行”，可那咳嗽声做不了假；胖掌柜尽管拍着胸脯说“没事”，可他手心泛黄的气色藏不住。这些明摆着的难处，老周一笔一笔都记下来。

掂量的第二把尺，叫“说不清的念头”。这一把尺就玄了。老周问自己：这位客人是真的想寄存银子，还是想趁机讹自己一笔？教书先生把烟龄说少了两年，是忘了还是故意？胖掌柜把每天喝的酒说成“一小杯”，是随口一说还是想少交点看管费？这些藏在心里的小念头，老周没法当面问出来，只能靠经验和眼神去猜。猜不准的地方，就得多留个心眼。

掂量的第三把尺，叫“口袋深不深”。老周还得反过来想：这位客人真的拿得出他说的那个数吗？跑船的汉子一年到头跑船能挣多少？胖掌柜生意场上今天赚明天赔，万一哪天口袋瘪了，答应寄存的银子又从哪里来？木匠一个月赚几吊钱，他要存五十两，是攒了三年的家底还是一时冲动？这跟前面两把尺不一样，前面是看“人能不能平平安安”，这一把是看“银子能不能稳稳当当存进来”。

等这三把尺都掂量完了，老周心里就有了数。教书先生和胖掌柜，看着有点让人不放心，但他也不想把人往外推。于是他跟钱庄老板商量：教书先生的银子可以存，但要单独放在一个角落，看管费多收一点；胖掌柜的也行，但要他写个字据，说明家里还有什么别的进项，万一将来取钱时手头紧，好让大家心里有数。跑船的汉子，银子也能存，但他常年在外，万一船出事家人来取钱，得提前留下家里人的名字和画像，省得到时候乱作一团。

那个年轻木匠呢？老周琢磨了半天，最后摇了摇头。不是不让他存，是他要存的这个数，跟他每个月赚的钱对不上。老周也说不清哪里不对劲，但就是觉得再收下去，将来怕是要闹出麻烦。他客客气气地把银子退回给木匠，还送了他一壶酒，权当赔礼。

冬日黄昏，钱庄的伙计来取银子时，老周把这三把尺的道理讲给他听。伙计听得直点头：“原来掌柜不是凭感觉行事，是心里早有一套门道。”

老周笑了。他端起桌上的茶喝了一口，慢慢说道：“做这行二十年，我看明白了一件事——存银子这事，最怕的就是只听客人嘴上说的。看得见的难处要掂量，看不见的念头要掂量，口袋深浅更要掂量。三把尺都用上了，心里才有数；心里有数，对人才公道。”

**📖 原文定义**

> 核保分為兩階段：(a) 確定風險程度——人壽保險核保人憑經驗可以確定投保的風險程度，通常根據兩大主題：(i) 實質危險(Physical hazard)：主要考慮可能增加受保事件（死亡）發生率的客觀因素，包括明顯超重、煙吸得多、濫用物質（酒精、毒品等）、高危職業或消閒活動、家族不良遺傳病歷或個人不良病歷；(ii) 道德危險(Moral hazard)：涉及較主觀的因素，環繞準被保險人的基本誠信或正直意向，例如刻意隱瞞重要資料或提交虛假資料以求受保。(b) 將建議風險分類：分為標準風險、次標準風險（或稱特殊風險）、拒保風險、優良風險四類，以確定公平的保費。此外還需注意財務性核保(Financial Underwriting)，包括評估投保人繳付保費的能力、所顯示的風險程度、同一受保生命已累積購買的保單計劃，以及保額是否超出與投保人年齡和一般情況類似的通常水平。

**💡 对应点**

| 故事元素 | 概念对应 |
|---------|---------|
| 老周掂量的第一把尺"看得见的难处" | 實質危險（Physical hazard）——客觀可見的健康與風險因素 |
| 跑船漢子、抽煙的教书先生、喝酒的胖掌柜、爬树的木匠 | 核保中考虑的具體客觀因素：高危職業、吸煙、濫用酒精、超重等 |
| 教书先生少报烟龄、胖掌柜少报酒量 | 道德危險（Moral hazard）——隱瞞或虛報資料的主觀傾向 |
| 老周掂量的第二把尺"说不清的念头" | 道德危險難以確定、需憑經驗判斷的特點 |
| 老周掂量的第三把尺"口袋深不深" | 財務性核保（Financial Underwriting）——評估繳費能力與保額合理性 |
| 教书先生和胖掌柜被加收看管费 / 要求写字据 | 次標準風險的處理：仍可受保但附帶條件 |
| 年轻木匠被退回银子 | 拒保風險——保額超出投保人經濟能力時不予承保 |
| 老周最终"心里有数、对人才公道" | 核保的兩階段目標：確定風險程度 + 分類確定公平保費 |
