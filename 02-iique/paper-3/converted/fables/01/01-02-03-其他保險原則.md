# 1.2.3 其他保險原則

## 🏺 寓言故事 —— 《兩份保單》

南方有個做瓷器生意的老周，五十多歲，膝下一兒一女。兒子小周剛大學畢業，在城裡一家貿易公司做事。某個週末小周回鄉看父親，吃飯時兩人聊起了「買保險」這事。

小周說：「爸，我在城裡跟同事湊熱鬧，買了一份壽險，受益人寫的是您和我媽。」老周聽罷放下筷子：「我也買了一份，受益人是寫你的。前幾天去鎮上的醫院做個小手術，順便又諮詢了隔壁保險櫃檯，買了一份大病險——寫的也是你。」小周愣了一下：「那加起來，您就有兩份保險了。」老周點頭：「對啊，一份是死了才賠，一份是得了大病就賠。我這不叫『重複買』，這叫『雙保險』！」

父子倆說完都笑了。可這事兒不知怎麼就傳到了村裡理財老李那裡。老李是鎮上公認的精明人，聽完之後特地騎車過來，一臉嚴肅：「老周，你這事兒——我得說你兩句。你買車險的時候懂不懂？同一輛車，你拿去保了兩家公司，出了事兒只能各賠一半，誰也不會多給你——這叫『分著賠』！你買壽險跟車險不一樣嗎？」

老周被問住了，回家路上心裡犯嘀咕。他坐在田埂上想了很久，忽然想起去年鄰村老陳家的真事：老陳開貨車運貨，半路上被別人一輛失控的卡車撞了。交警判卡車司機全責。老陳的車險公司賠了他修車的錢，賠完之後公司轉頭就去找那個卡車司機討錢——「你撞的，你賠。」後來老陳聽說卡車司機確實掏了錢出來。可是同一場事故裡，老陳的司機助手當場身亡，他家裡之前給助手買過壽險——保險公司照樣賠了一大筆，賠完之後……卻沒去跟卡車司機追討。老周想：這就對上了。

他又想老李說的「分著賠」。為什麼車險要分，壽險就不分？因為車壞了，可以修回原樣；人可以嗎？人沒了就沒了，賠多少錢都換不回來。所以壽險本來就不是為了「補回損失」，而是為了「給家裡一筆錢過日子」。既然不是補損失，就沒什麼「重複賠償」這回事——只要出了事，每一份保單都該全額賠給家裡。買兩份壽險不叫欺詐，叫「責任疊加」。

至於車險公司為什麼賠完還要找肇事者討錢？老周又想通了：那是因為車險公司賠的只是「老陳那輛車的損失」，真正該負責的是撞人的司機，保險公司只是先幫他墊了錢，所以事後有權「站到老陳的位置上」去找司機要回來，這叫「接過別人的權利」。可壽險呢？賠的是「一個家庭的依靠」，人已經沒了，難道保險公司還要去找司機要錢來「補回一條命」嗎？補不回來。所以壽險公司賠完就賠完，不會去找別人。

老周站起身，拍拍褲腿上的土，心裡亮堂了：他買的那兩份壽險，一份保「走得太突然」，一份保「走之前還要治病花錢」——兩份責任，兩份保障，並不重複。村裡老李那套「買保險像買東西，多買就重複」的想法，是把壽險當成了普通商品，沒分清「補回一個東西」和「撐起一個家」的根本差別。

晚上回到家，老周打電話給小周：「兒子，我那兩份保險都留著。受益人寫你，是想不管哪種情況先走一步，家裡都有一筆錢能撐下去。」小周在電話那頭沉默了一會兒：「爸，我懂了。」

**📖 原文定義**

> **(a) 近因 (Proximate Cause)**：這原則涉及識別索償個案中損失的主要和有效成因。這原則當然適用於所有保險種類，但是它對人壽保險的重要性可能並不顯著。
>
> **(b) 彌償 (Indemnity)**：指對所受損失提供精確的財務補償，這對大多數類型的一般保險來說非常重要。然而，就人壽保險來說：(i) 非常明顯，保險收益絕不可能構成人命的精確財務補償。這就是為什麼人壽保險亦稱為利益保單 (Benefit Policies)，而非彌償保單的原因；(ii) 不可能超額賠償，因為可保權益在大多數情況下是無限的。
>
> **(c) 彌償的引伸 (Indemnity corollaries)**：引伸是一個次原則。彌償有兩個引伸，即分擔及代位權。
>
> **(i) 分擔 (Contribution)**：在大多數一般保險類別中，如果某人偶然就同一損失擁有多於一份保單，他不會收到重複賠償。每份保單會按比例分擔損失。人壽保險一般不受彌償原則所規限，因此，一個人擁有多於一份人壽保單是很正常的。而且，在受保事件發生後，每份保單都必須全額賠償。
>
> **(ii) 代位權 (Subrogation)**：這涉及保險人的法律權利。保險人提供賠償後獲得被保險人向第三者提出索償的權利，以彌補他向「保單持有人」所提供的賠償。但這一點並不適用於人壽保險。

**💡 對應點**

| 故事元素 | 概念對應 |
|---------|---------|
| 老周買了兩份壽險（一份身故、一份大病） | 彌償原則不適用於人壽保險，因此可擁有多份保單 |
| 小周質疑「兩份算不算重複買」 | 對應一般保險的「分擔」原則（會按比例分賠） |
| 老李用車險「分著賠」來類比壽險 | 引出分擔原則與人壽保險「利益保單」性質的根本差別 |
| 老陳的車險公司賠完再去找肇事司機要錢 | 代位權的具體表現（保險人接過被保險人的索償權） |
| 同一事故身亡的司機助手，壽險公司賠完卻不追討 | 代位權不適用於人壽保險 |
| 老周想通「補不回一條命，所以不再追」 | 人壽保險屬利益保單而非彌償保單的本質 |
| 老周對小周說「兩份責任，兩份保障」 | 點明近因原則在壽險中重要性較低，因少用除外責任 |
