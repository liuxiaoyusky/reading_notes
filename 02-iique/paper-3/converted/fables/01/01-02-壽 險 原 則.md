# 1.2 壽 險 原 則

## 📜 寓言故事 —— 《六把锁》

老周在江南开了一间布庄，三十年没出过岔子。儿子周小满刚成年，老周琢磨着要把店交给他，自己去乡下养老。可儿子太年轻，性子又急，老周心里一直悬着一块石头。

这一年的春天，镇上忽然来了一场大火，三十几家铺面一夜烧成了灰。老周站在废墟前看着小满，心里冒出一个念头——万一哪天我不在了，儿子一个人撑这家店，扛不住。镇上的钱庄掌柜听说这事，主动找上门来推销一种新玩意儿：把一笔钱交给钱庄代管，每年交一点保管费，将来万一出了事，钱庄就把这笔钱赔给小满。

小满眼睛一亮，正要签字。老周一把按住了他的手："慢。"

老周拉着小满坐下来，说："爹问你几件事，你答得上来再签。"

第一件——"你跟这家钱庄熟吗？"小满说："不熟。"老周摇头："你不熟，钱庄也不熟你。那人家凭什么信你？你得让他们相信，这笔钱是用来保护你的店，不是用来还赌债的。这叫什么？这叫'有合理的托付理由'。"

第二件——"你得把钱庄想知道的事都告诉人家。"小满皱眉："我店里账本也得给看？"老周说："对。人家把钱托在你身上，你却藏着掖着，哪有这个道理？你要是开船却不说船底有裂缝，保险公司将来不赔。这叫什么？这叫'把底亮给人看'。"

第三件——小满追问："那将来真出了事，谁说了算？"老周指着契约说："钱庄只赔'出事'的钱。什么叫出事？烧了、塌了、被偷了——这叫'直接的原因'。要是你自个儿点火烧店骗赔，钱庄不赔；要是你跟邻居打架被砸了，跟店铺没关系，钱庄也不赔。赔，只赔跟事故直接挂得上钩的那条线。"

第四件——小满又问："赔多少呢？"老周伸出一根手指："赔多少？赔你实际损失的那个数。你那批布值一百两，就赔一百两；你要是狮子大开口要三百两，钱庄不干。赔钱，是把你拉回出事之前那个位置，不是让你发财。"

第五件——"那我能不能在三家钱庄都投一份，出了事拿三份？"老周一巴掌拍在小满后脑勺上："你想得美！你投三家，三家各赔你一百两，你白拿三百两？这不叫保护，叫占便宜。所以行里有个规矩——多家一起保的，要按份额分摊，谁也别想多拿。"

第六件——"还有一条。"老周把声音压低，"要是这场火是隔壁老王抽烟引起来的，钱庄赔了你之后，你不能再去跟老王要一份钱。你的'追究权'要让给钱庄，由钱庄去找老王算账。"

小满听得一愣一愣："爹，你怎么懂这么多？"

老周把笔递给小满，叹了口气："爹三十年前也跟你一样，啥也不懂。后来自己开了店，被人骗过，也差点骗过人，慢慢才明白——这套规矩不是哪一家定的，是几百年做买卖的人一起琢磨出来的。它保护你，也保护钱庄，保护的不是哪一边，是'买卖还能做下去'这件事本身。"

小满这回没犹豫，郑重签下了自己的名字。

镇上后来的三十年，街坊邻居照着这套规矩来来回回打交道，没人扯过皮。老周坐在乡下院子里喝茶，常跟人说：做生意最怕的不是亏钱，是没规矩。有了规矩，钱庄敢托、商家敢投、街坊敢信，生意才做得长久。

**📖 原文定义**

> 在本保險中介人素質保證計劃的核心科目「保險原理及實務」中，我們已經詳細研究了保險的原則，這裏不再作詳細論述。現再一次提醒大家，這些原則包括：
> (a) 可保權益 (Insurable Interest)：投保的合法權益；
> (b) 最高誠信 (Utmost Good Faith)：主動申報重要事實的責任；
> (c) 近因 (Proximate Cause)：關乎在保險索償中確定損失的主要有效成因；
> (d) 彌償 (Indemnity)：保險人提供精確的財務補償；
> (e) 分擔 (Contribution)：保險人（或稱保險公司、承保人、承保商）分擔彌償付款；
> (f) 代位權 (Subrogation)：提供彌償的保險人接收然後行使被保險人向第三者追討損失的權利。

**💡 对应点**

| 故事元素 | 概念对应 |
|---------|---------|
| 老周问"你跟钱庄熟吗" | (a) 可保權益：投保必须有合法的利益关联 |
| 老周要求小满亮出账本和船底裂缝 | (b) 最高誠信：双方主动披露重要事实的责任 |
| 火灾与打架两类事故的区分 | (c) 近因：只赔与损失直接有效挂得上钩的原因 |
| "赔你一百两，不是三百两" | (d) 彌償：精确把投保人拉回损失前的位置 |
| 三家钱庄分摊赔付 | (e) 分擔：多家承保时按份额分担，不允许多拿 |
| 老王抽烟引火后追究权让给钱庄 | (f) 代位權：赔付方接手向第三方追讨的权利 |
| 小满最终签字、街坊三十年无扯皮 | 整套原则的总效果：让交易双方都能信任地长期合作 |
