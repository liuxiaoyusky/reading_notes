# 2.1.1a 定 額／遞 減／遞 增 定 期 壽 險

## 🏺 寓言故事 —— 《老周的三把伞》

老周在巷口开了一家小杂货铺,日子过得不算富裕,但也安稳。某天,他忽然冒出个念头——趁自己还能干,得给家里人留点后路。琢磨来琢磨去,他跑去找镇上的老赵请教。

老赵听完,把店里三把伞往桌上一摆。

第一把伞是青布的,平平整整,没有花纹。"这把叫'定额伞'。"老赵说,"你买一次,保十年。不管哪一年你走了,家里人都拿到同样一笔钱。比方说一万块,第一年是这样,第五年也是这样,最后一年还是这样。十年里,分文不少。"

老周点点头,又指了指那把伞骨明显短了一截的黄布伞:"这把呢?"

"这把是'递减伞'。"老赵把伞撑开,又慢慢收回去,"也是十年。第一年赔一万,第二年赔八千,第三年赔六千……越来越少。好处是便宜,比定额伞便宜不少。"

老周愣了一下:"那买这把干啥用?"

老赵笑起来:"你欠着债呢。借银行的钱,今年还一万,明年还八千,后年还六千——债也是越来越少的。万一你中间出了事,刚好赔的那笔钱能把剩下的债还清,不让家里背一屁股债。要是债都还清了,你想,后面几年赔的钱再多也没用,钱就当白送了对吧?"

老周琢磨了一会儿,觉得有道理。可他刚要伸手拿那把黄伞,忽然瞥见第三把伞——伞面上用红线绣着花纹,撑开后明显比前两把大了一圈。

"这把又是什么讲究?"

"递增伞。"老赵把伞收起来,又撑开,比划了一下,"也是十年。第一年赔一万,以后每年往上加。可以加个固定的数,比如每年多赔一千;也可以跟着物价走,米涨它也涨。它为啥要越赔越多?你想啊,十年前的一万块,和十年后的一万块,买到的东西差远了。这把伞就是怕赔到手的钱越来越不值钱。"

老周站起来,在三把伞前来回走了好几趟。青伞十年不变最稳妥,黄伞便宜但越赔越少,花伞越赔越多又怕通胀。他不是个有钱人,做这个决定比进货还难。

最后他在柜台前站定,问老赵:"要是你,挑哪把?"

老赵把三把伞收进布袋,慢悠悠地说:"哪把都不挑,要看你是谁,日子怎么过。欠着债,就选黄的;没欠债又怕出事,就选青的;物价呼呼涨的年头,红的才顶事。"

老周摇摇头,说自己既不欠债,也不觉得物价会乱涨,就图个心安。老赵便把黄伞和花伞都推到一边,只把那把青伞放在桌面上:"那就这把。简单、稳当、不折腾人。十年里你不管哪天出事,赔的数都一样,你老婆拿着不糊涂。"

老周还是不放心:"那万一十年里什么都没出呢?"

老赵笑了:"什么都没出,那是你赚到了。钱没花出去,日子还在过,这就是这把伞的本意——它不是让你一定出事,而是让你万一出事时,家里不至于乱。"

老周还是不放心:"那万一十年里什么都没出呢?"

老赵笑了:"什么都没出,那是你赚到了。钱没花出去,日子还在过,这就是这把伞的本意——它不是让你一定出事,而是让你万一出事时,家里不至于乱。"

老周没再说话,把青伞收进袋里,往家走。巷子里还湿着,他脚步比来时慢了不少。走到巷口他回头看了一眼赵记的招牌,心里忽然踏实下来——青伞陪他十年,十年里他大概还是会守着那间杂货铺,每天进货、理货、关门,但知道哪怕某天自己不在了,铺子也不会乱,这就是这把伞的全部意思。回家后他把伞挂在门后头,谁也没告诉。

**📖 原文定义**

> (a) 定 額 定 期 壽 險：在整個保險期內,死亡保險金均維持定額(不變)。年保費的水平通常維持不變。它通常解決短暫的保障需求,而這種需求在相關期間內不會有任何顯著的增加或減少(例如一項不以分期付款形式償還的貸款)。
>
> (b) 遞 減 定 期 壽 險:死亡保險金按年或其他特定周期遞減。年保費的水平通常維持不變。由於保險利益不斷地遞減並且只有在保險期內死亡方可獲得支付,因此它是現有人壽保險種類中最便宜的。它特別適合於逐漸減少的短暫保障需求,典型實例包括信用壽險、家庭收入壽險、抵押贖回保險。
>
> (c) 遞 增 定 期 壽 險:這種計劃所保的死亡保險金按年或按其他相隔期間遞增:可以按固定百分比增加,也可按某個約定的指數(例如綜合消費物價指數)增加。其基本概念是使保險利益維持其購買力,這在嚴重的通貨膨脹的預期下尤其重要。保費通常按所保利益水平的增加的比例增加。

**💡 对应点**

| 故事元素 | 概念对应 |
|---------|---------|
| 青布伞十年赔一万不变 | 定額定期壽險:身故保額在保險期內固定不變 |
| 黄布伞越往后赔得越少 | 遞減定期壽險:死亡保險金按年遞減 |
| 花布伞按年增加 | 遞增定期壽險:死亡保險金按年遞增 |
| 老赵说递减伞适合欠债的人 | 信用壽險/抵押贖回保險等遞減型場景 |
| 花伞跟著物价一起涨 | 遞增的依據可以約定為物價指數 |
| 老赵最后没替他挑 | 三種壽險無絕對優劣,視投保人需求而定 |
| 老周回家路上还在想 | 投保決策取決於個人財務狀況與保障目的 |
