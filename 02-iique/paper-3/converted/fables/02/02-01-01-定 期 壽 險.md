# 2.1.1 定 期 壽 險 (Term Insurance)

## ⚖️ 寓言故事 —— 《雨季撑伞》

林师傅在南方一座小城开了家搬家公司，手底下六个工人，每天开着卡车给人家搬货。最让他揪心的，是那六个跟他吃饭的兄弟——一个个都是家里的顶梁柱，上有老下有小，万一哪个出了事，那一家子立马就塌了半边天。

城里的保险经纪人老周上门那晚，正赶上梅雨季，屋外哗哗下着雨。林师傅泡上两杯茶，开门见山：六个人，我要保一份人走了能赔钱的，到底要花多少？老周从包里掏出三份单子，往桌上一摊："林哥你看，一份是只管到六十岁的，一份是管一辈子的，还有一份……"他把最薄的那张往林师傅面前推了推，"这一份最便宜。"

林师傅愣住了，拿起那张单子翻来覆去地看，便宜到让他心里犯嘀咕——六个人一年下来才几千块，比他给工人发一个月的工资还少。"这……真出事赔吗？"老周点头："赔。只要出事那天伞还撑着——我是说，只要人还在保险这段时间里、合同也还在生效，钱就照约定打到家属账上。"林师傅追问："那要是这几个人平平安安干到合同到期呢？"老周笑了笑，很坦白地说："那钱，就不退了。这把伞，本来就是给最坏那几天下雨准备的。" 林师傅听完，端着茶杯没说话，眼睛一直盯着窗外那场雨。

转机来得很突然。那年七月，老陈——跟了林师傅八年的老伙计——在高速公路上出了事，当场人没了。林师傅接到电话时手直抖，开车去现场的途中满脑子都是"嫂子怎么办、两个孩子下学期学费怎么办"。办完后事的第三天，他把老陈家属的银行卡号递给了老周。一周后，五十万到账。老陈的老婆打来电话，哭着说："林哥，这笔钱……够孩子们读到大学毕业。"林师傅攥着电话站了很久，回头看了一眼墙上贴的那六张保单——只管到六十岁的那批——心里突然明白：自己花的那一点点钱，是买了一把伞放在那，最怕的那几天真的下雨了，伞撑得住。

雨季过去，搬家公司又恢复了忙碌。林师傅把那张最薄的保单续了一年、又一年。他说，自己不会因为这把伞便宜就觉得它不值——它值不值，要看那几天下没下雨。他更不会因为那几年没下雨就扔掉它，因为下一场雨，从来不会提前打招呼。

---

**📖 原文定义**

> 這類保險僅為特定期間或時期提供保障，因此又稱短期人壽保險(temporary life insurance)。保單利益限於下述情況下支付：(a)受保生命在特定期間或時期內死亡；及(b)死亡發生時保單是有效的。在大多數情況下，定期壽險計劃到期時仍沒有出現索償。有鑒於此，它是現有最便宜的保障形式（當然也要明白它的局限性）。理論上，保險期(term)可長可短，甚至可以是幾個小時(例如：保障一次飛行旅程)。實際上，短於一年的定期壽險並不多見。

**💡 对应点**

| 故事元素 | 概念对应 |
|---------|---------|
| 只管"到六十岁"的那批保单 | 定期壽險的「特定期間」 |
| 林师傅嫌便宜到心里犯嘀咕 | 定期壽險保費低 |
| 老陈不幸身亡，五十万到账 | (a)期内死亡 + (b)保單有效 時的理賠條件 |
| 平安干到合同到期钱不退 | 到期仍無索償，保費不返還 |
| 老周说"买把伞放那" | 定期壽險作為保障形式而非儲蓄 |
| 林师傅年年续保不扔 | 風險不確定性，下一場雨不會提前打招呼 |
