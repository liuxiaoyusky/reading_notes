# 2.3.1 年 金 (Annuities)

## 🏺 寓言故事 —— 《老范的四份月钱单》

江南有位老范，六十岁那年把种了四十年的菜地卖了，得了一笔厚实的大钱——三千两白银，分装在六个坛子里，藏在堂屋的米缸后头。老伴走得早，儿子在府城做木匠，一年回不来两趟，孙子在镇上念书，用不着老人接济。按理说，老范该舒坦了。可他夜里总睡不踏实——米价年年涨，万一活到九十呢？三千两看着多，照自己大手大脚的花法，怕是撑不到那一天。

他想了三天，决定去找村东头的陈先生讨个主意。陈先生早年在府城做过账房，给好几家大户理过账，如今告老还乡，最爱给乡亲们出点子。老范提了一篮新摘的丝瓜上门，刚坐下就把心事倒了出来。

陈先生听完，捋着胡子笑了："老哥，你这事儿说难也难，说简单也简单。钱在你手里是死的，换个法子让它活起来就行。"他转身从柜子里摸出四张空白的契纸，一字排开摆在桌上，"我这儿有四种'月钱单'，各有各的脾气。你先听我说完，再挑一张。"

第一张，陈先生管它叫"立刻就拿钱"。老范今天签完约、交了钱，下个月初一就能开始领月钱，一直领到老范闭眼那天为止。"好处是痛快，没等头。坏处是——三千两一次全交出去了，你这会儿手头就空了。"

第二张，叫"先攒几年再说"。老范可以一次性交钱，也可以按月按年慢慢往里存钱，存它个十年八年。存钱期间一分不取，等老范到了约定的那一年——比如六十五或者七十——才开始领月钱，同样领到闭眼。"好处是攒的时间越长，以后每个月领得越多；坏处是中间这段你干看着。"

第三张，叫"定好年头就停"。不管老范活多久，这张单子只发十年或者十五年的月钱——年头一到，契纸就算完了。"好处是每个月能领到的钱比前面两种都多。坏处是——万一你活过那个年头，后头的日子可就没着落了。"

第四张，叫"保底不亏"。约定一个保底期，比如十年。这十年里，不管老范还在不在，月钱都照发；十年满了，老范若还活着，接着领，一直领到老范闭眼。"好处是两头都顾着，前头不亏、后头不愁；坏处是每个月领到手的钱比第三种少一些，因为保险公司替你担了风险。"

陈先生把四张契纸往老范面前一推："老哥，你慢慢想。"

老范端着茶杯没吭声，眼睛一会儿瞟瞟这张，一会儿又瞅瞅那张。第一张痛快可手头空，第二张太慢等不住，第三张稳当可后头没着落，第四张两头顾可拿少了。他忽然抬头问了一句："老陈，要是我身体好，活个九十出头呢？要是我身体差，说不定六十五就走了呢？"

陈先生还没接话，门帘一掀，老何进来了。老何是村里的孤老头，无儿无女，前两年也办过一张"月钱单"。老范还没问，老何自己先叹上了："我办的是第一张，立刻就拿钱的。六十岁办完，下个月就领，一直领到现在。我这身子骨，五大三粗的，估计还得领二十年。要是早知道我这么硬朗，第二张'先攒几年再说'才划算——可惜钱已经交出去了，没回头路。"

老范心里咯噔一下。他低头再瞅那四张契纸，忽然就明白了——这四张单子没有谁好谁坏，得看自己这把老骨头经不经得磨，也得看自己花钱的手松紧。要是身体壮、想立刻见回头钱，选第一张；要是不急用钱、想让钱先变大，选第二张；要是不在乎活多久、只图每个月拿得多，选第三张；要是又怕活不长、又怕活太长——那就选第四张。

老范把第一张、第二张、第三张都拨到一边，只把第四张按在掌心："老陈，就它了。我不知道自己哪天走，可前十年、后头日子，都得顾着。"

陈先生点点头，提笔在契纸上写下："保底十年，活多久领多久。"老范签了字，揣着契纸回家。第二天一早，米缸后头的六个坛子搬走了——换来的，是一张纸，一份从下个月初一开始、每个月准时敲门的月钱。

老范坐在院里的老槐树下，看着日头一点点挪过屋脊，忽然轻声笑了：从今往后，他再也不用半夜爬起来数坛子了。

**📖 原文定义**

> (a) 即期年金 (Immediate annuity)：通常以整付（趸缴） (single payment)方式购买，年金利益于年金购买后的第一个年金期（即两个连续预定付款日期的相距时间，如一个月）完结时开始支付。
>
> (b) 延期年金(Deferred annuity)：可以整付或分期保费购买。年金利益并非即时，而是从某个特定时间或年金标的人（或称「年金领取人」）到达某个特定年龄后才开始予以支付。延期年金保单包括累积期和年金期两个阶段。
>
> (c) 变化：确定年金 (annuity certain) 仅于规定年内定期支付年金利益，不论年金标的人在此期间内是否已死亡。终身年金(life annuity)则于年金标的人在世时提供周期性保险利益付款。临时终身年金 (temporary life annuity) 于指明年期间内，当年金标的人还活着时支付年金利益。确定期间终身年金 (life income annuity with period certain)（或称保证年金 (guaranteed annuity)）至少于指定年内支付利益，即使年金标的人已於该年内死亡；如果年金标的人在该年期完结後还活着，年金更会给他终身支付利益。

**💡 对应点**

| 故事元素 | 概念对应 |
|---------|---------|
| 老范的四个"月钱单"摆在桌上 | 年金的不同分类 |
| 第一张"立刻就拿钱" | 即期年金 (Immediate annuity)，趸缴、下一个年金期开始支付 |
| 第二张"先攒几年再说" | 延期年金 (Deferred annuity)，含累积期与年金期 |
| 第三张"定好年头就停" | 确定年金 (annuity certain)，仅规定期限内支付 |
| 第四张"保底不亏" | 确定期间终身年金 / 保证年金 (guaranteed annuity) |
| 老范最后只按着第四张 | 按自身寿命的不确定性选择合适分类 |
| 老何选了第一张却后悔身体好 | 即期年金与寿命长短的内在矛盾 |
| 老范自言自语"不知道哪天走" | 年金以"生存期"为核心支付依据 |
