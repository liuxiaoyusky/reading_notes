# 2.1.2 儲 蓄 壽 險 (Endowment Insurance)

## 🏺 寓言故事 —— 《阿财的二十年》

江南水乡的木匠阿财,今年三十岁,手艺好,名声在外。镇上的人都说,阿财有一双神奇的手,能化腐朽为神奇。可阿财心里一直有个疙瘩:他想让儿子阿宝长大以后,无论遇到什么事,都能稳稳当当过一辈子。这念头在他心里翻来覆去,让他睡不踏实。

有一天,他去找镇上最会算账的老吴请教。老吴听完,没有直接答话,而是反问了一句:"阿财,你最怕的是什么事?"阿财愣了一下,说:"最怕自己哪天突然出了事,家里没了顶梁柱,老婆孩子没法过日子。"老吴点点头:"还有呢?"阿财又说:"也怕等儿子长大了,自己想留给他一些本钱做点小营生,却拿不出钱来。"老吴笑了:"你看,你要的东西挺简单——人没了,家里要撑得住;人还在,手里要存得住。这两样,其实可以放在一起。"阿财听糊涂了,这事怎么放在一起?

老吴想了想,给他提了个方案:"你每年从工钱里拿出一部分钱,交给我,我帮你保管二十年。这二十年里,你每年都交,不能断,也不能提前拿。但是,我给你立个字据——这二十年间,如果哪一天你突然不在了,我当天就把一笔大钱送到你家里,够你老婆孩子十年的开销;如果你平平安安活过这二十年,期满那一天,我再把这笔钱原原本本还给你,另加一些利息,作为你儿子创业的本钱。"阿财瞪大了眼:"真有这样的好事?那万一我中间出了事呢?"老吴指了指字据:"我都写明白了,白纸黑字。"

阿财回家想了整整三天。第一天,他想:万一我运气不好,头几年就出了事,那之前交的钱岂不是白费了?第二天,他想:万一我交了二十年,最后只拿回那么一点利息,岂不亏了?第三天,他把字据拿出来又看了一遍,忽然笑了:管他哪一头,我都赢。人没了,家里有保障;人还在,手里有积蓄。这不是两全其美吗?于是他签下了字据。

从那以后,阿财每月按时交钱。头几年,村里人笑他傻:"这钱放自己手里能买几亩地呢,干嘛送给老吴保管?"阿财不解释,只是笑笑。第十年,镇上出了事,有个木匠干活时被锯断了腿,家里一下子塌了半边天。消息传来那天,阿财忽然觉得后背一阵凉意,回家抱了抱儿子,心里默默感激自己当年的那个决定。第十五年,阿财的儿子阿宝考上了县里的学堂,束脩要一大笔钱,阿财心里有点痒——如果这笔钱现在能拿出来就好了。可他一想到字据上写的"不能提前拿",硬是按下了念头。第十八年,他遇到了一个意外:接了一笔大活,对方预付了一半的工钱,加上他这些年的积蓄,手头其实已经很宽裕,根本不需要期满那笔钱应急了。可阿财心里反而更踏实——这钱,稳稳当当地在那里,谁也动不了,谁也拿不走,就像地里埋着一坛酒,等儿子成亲那天再启封。

第二十年期满那天,老吴真的把当初约定的那笔钱,加上历年积攒的利息,一分不少地送到了阿财家。阿财把儿子叫到跟前,把那个沉甸甸的红布包推过去:"这是爹留给你的第一桶金,去做你想做的事吧。"阿宝接过布包,眼眶有点红。村里人这才明白阿财当年的选择,纷纷感慨:这人啊,聪明不在一时,聪明在二十年。

**📖 原文定义**

> 這種壽險承諾於受保生命活到指定期間結束時給付保額,但萬一受保生命在該期間內死亡,則即時給付保額。保險期限屆滿後受保生命還活着的話,我們說該保單已經期滿了(mature)。如同定期壽險一樣,對儲蓄壽險保單的描述必須包括保險的年期,例如:一份20年期的儲蓄壽險。關於這種計劃,應注意以下特點:
>
> (a) 保費:並不便宜,因為在正常情況下,必定不會遲於指定的未來期間給付保額;保費是維持於固定水平的,一般按年繳付,儘管也可以是整付保費儲蓄壽險(single premium endowments)。
>
> (b) 技術上:這種計劃是一份定期壽險與一份相同金額的純生存保險(pure endowment)的結合。(純生存保險是一種只在受保生命在保險期結束時仍然生存的情況下,才支付死亡保險金的合約);
>
> (c) 分紅或不分紅:這類計劃分分紅(或有利潤 (with-profit))及不分紅(或無利潤 (without-profit))兩類,保費則須適當地釐定;
>
> (d) 流行性:原則上,這類計劃提供了兩全其美的保障(為保單所有人提供早逝保障及保單期滿的個人儲蓄),因此計劃表面上很有吸引力。然而,也許是保險費率相對較高的緣故,目前這類計劃在香港或其他市場並不流行。

**💡 对应点**

| 故事元素 | 概念对应 |
|---------|---------|
| 阿财和老吴签下的20年字据 | 储蓄寿险的固定年期(例如一份20年期的储蓄寿险) |
| 每年按时交钱、不能断也不能提前拿 | 保费的固定水平,按年缴付 |
| 阿财万一中途出事,家里立即拿到大钱 | 期内死亡即时给付保险金额 |
| 20年期满阿财还在,本金加利息还给儿子 | 期满生存给付满期金 |
| 字据里"人没了有保障,人还在有积蓄"的双重承诺 | 兼具保障与储蓄,两全其美 |
| 老吴既写"死亡给付"又写"期满给付" | 技术上是定期寿险+纯生存保险的结合 |
| 字据里白纸黑字的承诺 | 保单本身就是一份受法律保护的合约 |
