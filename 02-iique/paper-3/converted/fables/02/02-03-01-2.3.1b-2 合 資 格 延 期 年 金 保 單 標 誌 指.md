# 2.3.1b-2 合 資 格 延 期 年 金 保 單 標 誌 指 南

## 📜 寓言故事 —— 《镇上的"诚信布庄"标牌》

青石镇上有三家布庄，挨着开在同一条街上。老周的"诚信布庄"门口挂着一块乌木小牌，上面刻着一朵梅花，下方一行小字："镇商会认证 · 真材实料"。另两家布庄——老钱的"锦华布行"和老孙的"瑞云绸庄"——门口却什么标牌都没有，货架上摆的布也是五颜六色，叫人一时分不清谁家更靠得住。

镇上要办喜事的张婶，这天揣着攒了三年的银子出来买布。她原本只打算扯两尺红绸给女儿做嫁衣，可一抬头就被满街的绸缎晃花了眼。锦华布行的伙计嗓门大，拉着她介绍"上等苏绸"；瑞云绸庄的掌柜亲自端茶，笑盈盈地推销"杭缎"。张婶心里直打鼓：两家都说自家布好，可她一个外行，怎么知道谁讲的是真话？

正犹豫间，她瞥见老周门口那块乌木小牌。梅花标下还有一行更小的字："凡本店所售布匹，若以次充好，凭此标可至商会退一赔三。"张婶心头一热——原来这块小牌子，是商会替她这样的外行提前验过的一道关。她转身走进诚信布庄，指着标牌问老周："这块牌子，是你花钱买的？"老周笑着摇头："不是我买的，是商会看我年年守信用，主动给我挂的。我若哪天卖了假布，牌子立刻就被摘走。"张婶恍然大悟：标牌本身不是装饰，是镇商会替每一位买布人提前把关的信号；只要标在，就意味着这家店的货已经过了硬门槛；而那两家没挂标牌的店，并不是布一定不好，只是她作为外行，得多长一双眼睛去分辨。

故事讲完，道理已经藏在里头——一个专门设计出来、专门为方便老百姓识别的"小牌子"，一旦被允许挂在某家店门口，它就不再只是装饰，而是替每一个路过的外行，提前打好了"这家已经过审"的信号；反过来，没挂标牌的店，也不一定是坏的，但外行想分清真假，就只能靠自己多长一份心。

---

**📖 原文定义**

> 根據保監局發出的使用合資格延期年金保單標誌指南(Guide for Using The Qualifying Deferred Annuity Policy Logo)，合資格延期年金保單標誌—一個專為方便公眾輕易識別合資格延期年金保單而設計的標誌 — 必須透過顯眼的方式顯示在所有合資格延期年金保單的產品手冊上。如合適的話，獲授權保險人可顯示該標誌於其合資格延期年金保單的營銷、推廣和廣告物上。該指南嚴禁就任何其他保險產品（不論其是否作營銷、推廣、廣告或其他之用）或一般企業品牌營銷採用該標誌。

**💡 对应点**

| 故事元素 | 概念对应 |
|---------|---------|
| 老周门口挂的"镇商会认证"小标牌 | 合資格延期年金保單標誌——专门为方便公众识别而设计的标志 |
| 这块标牌必须显眼地挂在布庄门口 | 標誌必須透過顯眼的方式顯示在產品手冊上 |
| 商会主动给守信的店挂牌，不守信的摘走 | 標誌只授予符合资格的保单，不可用於其他保險產品 |
| 张婶是外行，靠这块牌子一眼认出"已过关"的店 | 標誌的核心作用——方便公眾輕易識別合資格延期年金保單 |
| 另两家店没挂牌，并不等于布一定差 | 沒有標誌≠不合資格，只是消费者需要更多自行判断 |
| 老周说"我若卖假布，牌子立刻被摘走" | 標誌的使用受保監局指南严格约束——一旦违规即失去认证资格 |
| 标牌同时出现在店门口和宣传单上 | 標誌亦可顯示於營銷、推廣和廣告物上（"如合適的話"） |
