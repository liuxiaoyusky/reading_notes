# 2.3 年 金 及 退 休 金

## 🏺 寓言故事 —— 《老周头的鱼塘》

江南水乡边的小村，有个打了一辈子鱼的老周头。他六十岁那年，腰已经弯不下去，跟船撒网更是吃力。儿子在城里做工，劝他歇下来。老周头想了想，把渔船、渔网、还有那口攒了一辈子的老鱼塘，一并卖给邻村的鱼商，得了一笔厚厚的大钱——三千两白银，锁进床底下的木箱子里。

头几个月，老周头过得很舒坦。买肉、买酒、给孙子买糖人，箱子里的钱似乎花不完。可到了第三年，他慢慢慌了。米价涨、药价涨、孙子上私塾要交束脩，每回开箱子取钱，那叠银票就薄下去一截。他夜里翻来覆去地想：照这花法，三千两撑不了十年，自己却可能活到八十、九十。

村里有个老秀才，姓陈，年轻时在外头做过账房。老周头提了一壶黄酒去请教。陈先生听完，把酒推回去，慢慢说："老哥，你手里握的是一潭死水呀。一次性拿出来的钱再多，总有用完的一天。你得把它换成一个会下蛋的母鸡——每个月都能给你生蛋，生到你闭眼那天为止。"

老周头眯起眼："咋换？"

陈先生在纸上画了一个圈："村东头的王大户，前些年发了财，正想找个稳妥的法子安置一笔钱。你把三千两交给他，签个约，让他每月给你发一份月钱。发到你不在的那一天为止。你不用再操心钱怎么花、怎么省、怎么投，到月就有，旱涝保收。"

老周头回去琢磨了整整三天。他想：自己这辈子只会打鱼，钱放手里只会越花越少；交给王大户，虽说是"让他管"，可每月都能见到回头钱。他咬咬牙，揣着银票去找王大户。

签完约那天，王大户当场递给他第一个月的月钱——十二两白银。老周头接过来，手心有点抖。这不是自己挣的，是钱"自己长出来的"。从那天起，每逢月初，王大户家的小厮就会准时登门，把月钱送到他手里。

老周头不用再半夜惊醒盘算米缸，不用再为了孙子的束脩发愁。他每天清早在老柳树下喝茶，午后去镇上听戏，日子过得安稳又舒坦。五年过去，他没动过床底下的木箱——因为那里面已经空了。真正的"钱罐"，换成了每月上门的那份月钱。

他坐在河边跟人感叹："从前我以为存够钱就能安心，原来钱放在手里是会漏的。倒不如换个法子，让它一笔一笔地慢慢流回来。一辈子流不尽，那才叫真的安心。"

---

**📖 原文定义**

> ( a ) 年 金 (Annuity)：根据年金合约，保险人为得到由合约的另一方，即「合约持有人」（或称「年金购买人」），预缴的一笔过付款或一连串付款（称为「年金代价」），承诺在某 人（称为「年金标的人」(annuitant) 生前或一约定期限内，向一指定个人（称为「收款人」(payee)）周期性地支付一连串款项（称为「年金利益款项」(annuity benefit payments)）。很多时候，该收款人、年金标的人和合约持有人均是同一个人。
>
> (b) 退休金 (Pension)：这个计划按月（或其他周期）向一名已退休的人提供收入利益，直至该人去世。它可以包含年金。

**💡 对应点**

| 故事元素 | 概念对应 |
|---------|---------|
| 老周头一次性卖出鱼塘得到的三千两 | 预缴的一笔过付款 / 年金代价 |
| 与王大户签订的那份合约 | 年金合约 |
| 老周头本人 | 合约持有人 / 年金标的人 / 收款人（同一人的常见情况） |
| 每月初准时送来的十二两月钱 | 周期性的年金利益款项 |
| 月钱发到老周头去世为止 | "生前"的支付期限 |
| 陈先生说"让它一笔一笔慢慢流回来" | 一次性资产转换为定期收入流的核心逻辑 |
| 床底木箱里的钱越花越少 vs 每月稳定的月钱 | 现金握在手里会耗尽 / 年金提供持续保障 |
