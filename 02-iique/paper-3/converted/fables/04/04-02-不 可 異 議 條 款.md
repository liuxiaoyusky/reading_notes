# 4.2 不 可 異 議 條 款 (Incontestability Provision)

## 📜 寓言故事 —— 《两年后的契约》

江南水乡有位老木匠叫周德，做了三十年家具，在镇上极有声望。他做的椅子榫卯严丝合缝，他打的柜子能用三代不散架。方圆百里办喜事的人家，都要提前半年到他这里排队。周德有个小儿子叫周小满，刚满十八岁，跟着父亲学手艺已经两年，刨花刮得平，墨线弹得直，活儿做得有模有样。周德心里盘算着，等小满满了二十岁手艺再硬实些，就让他去城里接大单子，把木匠铺做成父子两人的字号。

镇东头新开了一家当铺，姓吴的掌柜精明能干，穿一身藏青长衫，手里常年摇着一把折扇。开业头一个月，吴掌柜就想揽一笔长期生意，他听说周德父子手艺好，便登门拜访，想把家中百年老宅的修缮活交给周家。吴掌柜问周德："周师傅，你这徒弟满师了吗?签个长期契可好?"周德摇头："小满还差两年才满师，这两年还得跟我再学两年功夫。"吴掌柜笑着说："那咱们就签个三年契约，三年里我家老宅所有修缮都交给你们，价钱从优，您看如何?"周德想了想，三年不短，价钱又公道，便应了下来。两家当面写下契约，白纸黑字，周德按下手印，吴掌柜也落了款。

契约里有一行周德坚持要写上去的字："自签约之日起满两年，本约生效稳定，任一方不得以签约时之未明事项为由反悔。"吴掌柜当时不解，问这是何意。周德说："吴掌柜，做手艺的人讲的是稳字。您签了约，我教儿子，您给活儿，这两年里万一谁家有个想法变了，另一家不能翻脸说不算。等两年期满，咱们都摸清对方脾气了，契约才算真正生了根。"吴掌柜心里虽觉得啰嗦，但看在价钱便宜的份上，便点头应允。

转眼过了两年零三个月，小满已经二十岁过半。有一天小满去集市买木料，半路上突发急病，晕倒在路边。等邻居发现时，人已经没了气息。消息传回镇上，周德当场昏过去，醒来后白发人送黑发人，哭得说不出话。他抚着小满留下的刨子，想起当年教他磨刃的清晨，眼泪一颗颗滴在木屑上。木匠铺的招牌还在，人却少了一个。

吴掌柜听说后，第一反应却不是悲伤，而是眉头一皱。他想起当年签约时，自己曾隐瞒了一件事——他家中其实有个八十岁的老母亲，常年卧病在床，他在签约前并未向周家说明。吴掌柜担心周家将来追究修缮质量时反咬自己一口，便偷偷找了个做讼师的朋友商量。讼师说："您当时没如实禀明情况，按规矩是您理亏，将来若周家来索赔，您还得出钱。"吴掌柜一听慌了神，连夜赶到周家，灵堂前假惺惺哭了几句，然后话锋一转："周师傅，我听说小满走的时候，您木匠铺还没给他立正式契约对吧?我这一年来跟你们合作，银子都给了，但我家老母的事您们之前并不知道。按规矩，这份契约不能算数!"

周德抬头，红着眼睛盯着吴掌柜。吴掌柜避开他的目光，又说："再说小满走的时候，还没满师呢，对不对?他手艺不到家，将来若出了修缮问题，我找谁说理?这份契约，我看就作废吧!"

周德气得手抖。他慢慢站起身，从供桌底下抽出一本发黄的册子——那是当年两家签的契约原件。他翻开其中一页，指着那一行字："吴掌柜，您当年签的时候，可还记得这一行字?"吴掌柜凑近一看，正是当年周德坚持写下的那一句"满两年生效稳定"。周德一字一字念完，吴掌柜的脸瞬间白了下来。

周德收起契约，慢慢说道："吴掌柜，您家老母的事，我当年确实不知道。但咱们白纸黑字写在前面，过了两年，您就不能再拿这件事来推翻契约。这不是我定的规矩，是咱们两家签字画押那天就定下的规矩。您若要打官司，我奉陪;但您若讲理，就该知道这份契约生效已是板上钉钉。"吴掌柜嘴角抽了抽，扔下一句"我回去再想想"，便灰溜溜走了。

街坊们议论纷纷，有人说吴掌柜过河拆桥，也有人说周德拿着契约硬邦邦不近人情。周德没有辩解，转身回了灵堂，对着儿子的牌位沉默了很久。他心里清楚，吴掌柜心里有鬼，但他心里也有底——契约讲的是两家的信誉，吴掌柜不讲信誉在先，但反过来周家也得守规矩。两年期满，契约生根，谁都不能拿过去的事来翻盘。这规矩既保护了吴掌柜，让他不必担心周家反悔;也保护了周家，让他不必担心吴掌柜借故抵赖。公道在契约里，不在谁嗓门大。

三天后，吴掌柜托人送来一封信，承认自己一时糊涂，愿意继续履行契约。老宅的修缮活按约照做，年底的尾款一分不少。那年冬天，周德独自一人坐在铺子里，把契约册子锁进了抽屉最深处，对着炉火发了一夜的呆。窗外雪落无声，炉中炭火明灭，他想起儿子，想起那句"两年生效稳定"，忽然觉得——这八个字看似冰冷，却是他这辈子听过最温厚的一句话。

**📖 原文定义**

> 按照這些條款的規定，保險人不能對保險合約的有效性（validity）提出異議（質疑）。保險人可能會以懷疑投保人違反最高誠信原則為理由（即投保人不披露（omitted）某些重要事實，或就這些事實作失實陳述（misrepresented）），而對保險合約的有效性提出異議。
>
> (a) 典型的不可異議條款（Incontestability Provision / Incontestable Clause）規定：保險合約於受保生命在世時從保單發出日起計已生效了兩年後，保險人不會（指在一般情況下——見下文說明）對該合約提出異議或質疑。
>
> (b) 根據香港法律，若證實索償人或被保險人曾作欺詐行為（fraud），他們便不能依賴不可異議條款。不論合約的內容如何，香港法律是不會助長欺詐行為的。

**💡 对应点**

| 故事元素 | 概念对应 |
|---------|---------|
| 周德与吴掌柜签下三年契约 | 保单签订，建立保险合约关系 |
| 契约中"满两年生效稳定"的明文规定 | 不可异议条款的两年时限保护 |
| 吴掌柜事后翻出"隐瞒老母"想推翻契约 | 投保人当初未披露重要事实，保险人原本可依此质疑合约有效性 |
| 周德拿出契约原件反驳 | 不可异议条款对保险人的约束力——时限到则不得再以失实陈述为由反悔 |
| 吴掌柜家老母的事属未披露但非欺诈 | 一般性失实陈述（非欺诈）受两年期限保护 |
| 吴掌柜最终认账继续履约 | 时限届满后合约稳定性受法律保障 |
| 契约"既保护吴掌柜，也保护周家" | 不可异议条款双向稳定合约的双重价值 |
