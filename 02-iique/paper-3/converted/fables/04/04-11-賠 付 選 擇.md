# 4.11 賠 付 選 擇

## 🏺 寓言故事 —— 《老周的最后一笔款》

老周在村里开了一辈子布庄,熬到六十岁那年,身子骨终于顶不住了。他膝下一儿一女,儿子阿福在城里学做木匠,女儿阿珍刚嫁到邻村,丈夫是个教书先生。老周心里最放不下的,就是自己攒下的那一大笔养老钱——整整一百两银子,锁在床底下的木箱里。

秋天的一个清晨,老周把儿子阿福叫到床前,气息已经很弱了。他费力地从枕头下摸出一张纸,递给阿福。阿福接过来一看,愣住了——那是老爹的遗嘱,白纸黑字写着:家中一百两银子,留给阿福和阿珍两兄妹平分。

阿福攥着那张纸,脑子里乱成一团麻。一百两银子,听上去挺多,可要怎么给?是哥哥一个人全拿了,再分给妹妹?还是兄妹俩一人一半?更要命的是——妹妹阿珍的丈夫是个教书先生,一年到头也就挣个温饱,万一这笔钱一下全给了妹妹,会不会被人惦记上?反过来想,要是让妹妹按月来领,每个月领二两、十个月领完,妹妹会不会嫌麻烦?还有一种可能——把这笔钱先放在钱庄里,每年给妹妹一笔利息,本金一直留着,以后谁家有急用再拿。

阿福坐在门槛上想了三天三夜。他先去问了村里的钱庄老板老吴,又去问了城里的大掌柜陈先生,最后还专门跑到邻村,把妹妹阿珍和妹夫一起请了回来。

全家人围坐在堂屋里,阿福把这几种法子一一摆出来,让妹妹自己挑。

第一种,最简单。一百两银子,兄妹俩一人五十两,一次给清,从此两清。阿珍听到这儿,点了点头,说这样省事,可又嘀咕了一句:"五十两银子揣在怀里,总觉得不踏实。"

第二种,把钱留在钱庄里,本金不动,每年给妹妹一笔利息。妹夫听了眼睛一亮:"这个好!本金一直都在,以后孩子读书、家里盖房,都能用得上。"可阿珍又担心:"万一钱庄哪天垮了呢?本金是不是就打水漂了?"

第三种,按月来领。每个月领二两,十个月领完。阿珍苦笑:"十个月跑来跑去,光路费都得花不少,而且领完了就没了,心里反而不踏实。"

还有一种,是阿福从陈先生那儿听来的——把钱留给钱庄专门打理,只要妹妹活着,每个月都能领钱,领一辈子。妹夫摇头:"听起来是好,可万一妹妹走得早,本金是不是就归钱庄了?"

阿福心里也犯嘀咕:第一种最干脆,可妹妹是个心软的人,手里一下子攥着五十两,怕守不住;第二种最稳当,可本金一直压在钱庄,妹妹心里总不踏实;第三种是细水长流,可妹妹要跑十趟腿;第四种虽然能领一辈子,可万一妹妹走得早,后面的钱就没了。

老周躺在床上,听见儿子和女儿在外屋你一句我一句地争,浑浊的眼睛里忽然有了光。他把阿福又叫到床边,声音很轻:"儿啊,这事儿不归你一个人定,也不归钱庄定。你让阿珍自己挑——她这辈子最怕什么、最想要什么,她自己最清楚。"

阿福愣了愣,随即明白了。

第二天,阿珍拉着丈夫的手,跟哥哥说:"哥,我选第二种。把钱留在钱庄里,本金不动,每年给我一笔利息。这样本金一直都在,我心里踏实;每年拿到的利息,够我和孩子一年嚼用。"

阿福长舒一口气。他把五十两银子郑重地交到钱庄,签好了文书,从此每年开春,钱庄都会把一笔利息送到邻村阿珍的家里。

很多年过去了,阿珍的孩子考上了秀才,家里的日子越过越好。每到年底,阿珍都会带着孩子回村里看哥哥,顺道去钱庄核对一下本金还在不在。她笑着跟孩子说:"你外公留下的这笔钱,每年给我利息,本金一分没少,这就叫稳妥。"

阿福坐在院子里,看着妹妹和外甥离去的背影,心里忽然想起老爹临终前那句话——"你让阿珍自己挑"。原来,把选择权交给真正要用这笔钱的人,比替她做主,更让她安心。

**📖 原文定义**

> 給付保單利益時,受益人及／或保單所有人可以在幾個選項(「賠付選擇」)(settlement options / optional modes of settlement)之間選擇收取收益的方法,包括：
>
> (a) 整筆支付(lump-sum settlement):一次性付款,以完成整份保險合約;
>
> (b) 利息選擇:保單收益保存於保險人處,而保險人則每年或按其他約定的更短周期支付利息;
>
> (c) 定期支付選擇:在約定的時期內,分期支付等額保單收益(及利息),實際上,這項選擇是以該項保單收益作為整付保費,購買一份確定年金;
>
> (d) 定額支付選擇:保險人分期給付約定等額,直至付完所有保單收益(及利息)為止;
>
> (e) 終身收益選擇:在收款人在世時向其分期支付約定的保單收益(及利息)——這項選擇實際上是以該項保單收益作為整付保費,購買一份終身年金(life annuity)。與定期支付選擇或定額支付選擇相比,終身收益選擇的預期分期付款額會較低。

**💡 对应点**

| 故事元素 | 概念对应 |
|---------|---------|
| 阿福纠结"钱怎么给妹妹"这件事 | 受益人面对赔付方式的选择 |
| 兄妹一人五十两、一次给清 | (a) 整笔支付 —— 一次性付款 |
| 把钱留在钱庄不动、每年给一笔利息 | (b) 利息选择 —— 本金保留,按约定周期支付利息 |
| 每个月领二两、十个月领完 | (c) 定期支付选择 —— 在约定时期内分期等额支付 |
| 按月领钱、直到本金领完为止 | (d) 定额支付选择 —— 分期给付等额,直到付完所有收益 |
| 只要阿珍活着、每月都能领钱 | (e) 终身收益选择 —— 收款人在世期间分期支付 |
| 阿珍最终选了"留本金、每年领利息" | 受益人根据自身情况自主选择赔付方式 |
| 老周临终说"让阿珍自己挑" | 赔付选择权交给实际收款人,体现条款的人性化设计 |
