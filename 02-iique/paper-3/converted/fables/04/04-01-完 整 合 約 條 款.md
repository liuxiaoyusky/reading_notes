# 4.1 完 整 合 約 條 款 (Entire Contract Provision)

## 📜 寓言故事 —— 《一纸老契》

清末民初的江南小镇上，有个做丝绸生意的掌柜叫陆长庚。他精明能干，把父亲留下的绸缎庄打理得红红火火。一年冬天，老父病重，躺在床上拉着他的手说："家里的地契、房契，统统收在那个青花瓷罐里，千万别弄丢。"陆长庚含泪点头。

老父过世后，陆长庚打开瓷罐一看，果然——地契一张，房契一张，另有一张父亲亲笔写的"分家单"，上头写着几个弟弟应得的份额。瓷罐里再无其他纸片。

可就在办丧事的那几日，远房堂叔陆老三找上门来，手里端着一壶黄酒，笑眯眯地说："长庚啊，你爹当年跟我借过八十两银子办绸缎庄，这事儿他亲口答应的，村里人都瞧见过。如今人没了，债还在，你看着办吧。"陆长庚心里一沉——这事他从未听父亲提起，可堂叔说得有鼻子有眼，乡下人又最讲究"口说为凭"。

他犹豫了两天。一面是刚刚过世的父亲留下的那张分家单（上面并未提到这笔借款），一面是堂叔言之凿凿的"口头约定"。陆长庚琢磨着：要是这事儿是真的，自家生意正紧，贸然赖账怕坏了名声；可要是认下来，又不知道还有没有别的"口头约定"埋着雷。

夜里翻来覆去睡不着，他忽然想起小时候陪父亲去镇上"官契局"过户的情形。书办老先生当时说过一句话——"白纸黑字，签字画押；口说无凭，立契为证。一桩买卖、一笔账目，立了契的才算数，没立契的，进不了局子，也判不了案。"

陆长庚一下子坐了起来。他翻开父亲留下的分家单，又打开地契房契，一张张摊在桌上：地契上盖着县衙的红印，载明四至与亩数；房契上写着间数与门牌；分家单上白纸黑字，签着父亲和三位族中长辈的名号。这三张纸合起来，就是父亲留下的全部家业——除此之外，再无其他。

至于堂叔所谓"八十两的口头约定"——既没有借据，也没有任何文书上提及。乡邻们的"瞧见过"，只能算人证，不能作为契书的一部分。

第二日清早，陆长庚请来族中三位长辈和镇上通晓契书的钱先生，把瓷罐里的文书一一登记造册，白纸黑字列明"家业以罐中所存三契为凭"。堂叔陆老三赶来，听说这一节，脸涨得通红，掏出一张皱巴巴的纸条——上头既无借款人画押，也无中人签字，更无日期。钱先生接过来只扫了一眼便搁下："这不算数。契者，合也——合意而成字据；无字无据，何以成契？"

陆老三讪讪收了纸条，灰着脸走了。陆长庚站在堂屋中央，看着桌上那三张纸，良久没说话。钱先生拍了拍他的肩："掌柜的，记住了——日后无论谁来凭一句话讨债、许诺、认账，你只认手里这一摞纸上写的。纸外的话，进不了家门，也进不了官府。"

陆长庚把父亲的瓷罐重新封好，锁进柜中，又在账本的扉页工工整整写下八个字：

白纸为凭，口说无据。

多年以后，他把这八个字也传给了自己的儿子。

---

**📖 原文定义**

> 「完整合约」条款（"entire contract"provisions）有以下规定：
>
> (a) 完整的合约由保单、任何夹附的附约及夹附的投保单(application)複印本构成（这么一个保险合约称为封闭式合约）；
>
> (b) 只有保险公司中某些指定的高级职员才有权更改保险合约；
>
> (c) 除非以书面形式作出，否则对该合约的修改不会生效；及
>
> (d) 除非得到保单所有人的同意，否则不能修改该合约。

**💡 对应点**

| 故事元素 | 概念对应 |
|---------|---------|
| 父亲瓷罐里的三张契（地契、房契、分家单） | (a) 完整的合约 = 保单 + 附约 + 投保单複印本 |
| 陆老三拿来"口头借款"的空口无凭 | (a) 口头承诺 / 销售说法不构成合约内容 |
| 钱先生验契——无字无据，何以成契 | (a) 「封闭式合约」——以书面为限 |
| 陆老三的纸条既无画押也无中人签字 | (c) 除非以书面形式作出，否则修改不会生效 |
| 陆长庚请族中长辈 + 钱先生共同登记造册 | (d) 除非得到保单所有人同意，否则不能修改 |
| 账本扉页八字"白纸为凭，口说无据" | 整条规则的核心精神——以书面为准，口头不算 |
| 陆长庚自己封罐、登记、写八字 | (b) 只有指定的高级职员才有权更改；旁人无权擅动 |
