# 4.4 受 益 人 的 指 定 (Beneficiary Designation)

## 📜 寓言故事 —— 《老周的家书》

老周是镇上开布行的掌柜,膝下一儿一女。儿子阿明跟着他学做生意,女儿阿秀嫁到了邻村。老周心里清楚,自己这把年纪,早晚得把身后的安排想清楚。

有一年开春,老周盘算着写一份家书,把家里的事定一定。他琢磨着:这家里的钱,等我走了,留给谁呢?要是都留给儿子,女儿那边说不过去;要是平分,又怕儿子觉得吃亏伤了和气。他坐在柜台后面,一支笔悬在半空,迟迟落不下去。

琢磨了几天,老周终于写下了第一稿。他把财产分作两份,一份留给儿子,一份留给女儿,白纸黑字写得清清楚楚。写完之后,他把家书锁进了抽屉,心里总算踏实了一阵。

可没过多久,邻村传来消息,说女婿做买卖赔了钱,一家人日子过得紧巴。阿秀回娘家时,眼眶红红的,只说没事。老周看着心疼,又想起儿子阿明最近想自己开铺子,正缺本钱。他翻出那份家书,看了又看,提笔把给女儿的那一份添了一些,给儿子的那份减了一些。改完,他把新的家书重新锁好。

又过了大半年,儿子阿明的铺子渐渐有了起色,生意越做越大。老周欣慰之余,又开始担心另一件事:要是哪天儿子遇到难处,急需用钱,这份家书岂不就把他绑死了?他想改,但又怕改来改去,伤了女儿的心,也让儿子觉得家书不过是一张废纸。

老周坐在堂屋里,把旧家书和新家书并排摆在桌上,盯着看了很久。他慢慢明白了一件事——这家书的好处,恰恰在于它可以变。从前的安排是给那时的情形定的,如今情形变了,安排自然也可以变。只要变的时候,心里装着孩子们,变多少次都不算错;怕的是写完就再也不能改,那才真把人逼进了死胡同。

他站起身,把新家书重新誊抄了一份,末尾特意加了一句话:日后若有更改,以最后所写为准。第二天,他把两份家书都交到了镇上德高望重的王伯手里,请他做个见证。

---

**📖 原文定义**

> 人壽保單的保單所有人一般會指示保險人把應付的死亡保險金支付給某人,此人稱為受益人(beneficiary),而付款的基本條件之一是受益人在受保生命去世時還活着。
>
> 人壽保單通常允許保單所有人在保單有效時變更受益人的指定,在這情況下,該指定受益人稱為可撤換受益人(revocable beneficiary)。另一做法是在保單中加入條文,規定受益人一經指定後就不得撤換,真的要撤換的話,必須先取得現有受益人的書面同意。
>
> 實務上,指定方式和受益人的種類是多樣化的:保單一般會指名受益人的,而概括式指定(class designation)(即指定一組人為受益人而非指名每個人)也可以,例如:「我的子女」和「我的兄弟姊妹」。
>
> 死亡保險金應付時,由第一順位受益人(primary beneficiary)(或第一受益人(first beneficiary))收取(如果被指定者超過一人,每人所得金額將相等,除非保單另外指明)。以防所有第一順位受益人都不能比受保生命活得久,可在第一順位受益人以外,指定一個或一個以上的次順位受益人(contingent beneficiaries)。

**💡 对应点**

| 故事元素 | 概念对应 |
|---------|---------|
| 老周把身后钱留给谁 | 受益人(beneficiary)的指定 |
| 白纸黑字写在纸上的安排 | 保单中的指定条文 |
| 「我的子女」一类写法 | 概括式指定(class designation) |
| 儿子一份、女儿一份的写法 | 第一顺位受益人(primary beneficiary) |
| 老周反复涂改家书 | 可撤换受益人(revocable beneficiary) |
| 末尾那句「以最后所写为准」 | 保单有效期内可变更受益人 |
| 阿秀夫妇、阿明开铺等情形变化 | 受益人指定应随情形调整 |
