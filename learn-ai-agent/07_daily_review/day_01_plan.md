# Day01 · 只理解“代管”

路线版本：2026-11-16。原始材料截至香港时间11月13日，今日不讲完整攻击链。地图留在后台，一次一个疑问。

## 第一轮可直接使用的讲解

在这次2026年的案件中，币安称，有人未经允许转走了平台保管的数字资产。我们先把数字资产理解为有价值的东西，今天只问：为什么用户的东西会由平台保管？

这叫代管：东西属于你，但你请别人帮忙保管。像把行李寄存在酒店前台，行李仍然是你的，拿回时却要靠前台处理。有些用户也把资产交给平台帮忙保管和处理转出。类比只解释关系，不代表数字资产真放在柜子里。

**D01-CUSTODY-01：把书包交给商店保管后，商店保管出了问题，为什么可能连累你的书包？用一两句话说说。**
