# C02 · 2022 BSC Token Hub 跨链桥事件

## 已读材料与事实边界

据 [S02：BNB Chain 2022-10-07公告](https://www.bnbchain.org/en/blog/bnb-chain-ecosystem-update)，受影响的是BNB Beacon Chain与BNB Smart Chain之间的BSC Token Hub，涉及2,000,000 BNB；公告将问题描述为底层证明伪造，并说明协调验证者限制事件扩散。

上述是该公告口径。事件发生日与详细交易时间需结合技术复盘或链上记录另核；10月7日是公告日期。访问日期：2026-11-13。

## 边界与金额
