# 练习与交付

每个模块有三道独立练习（M01.md–M12.md，共36道），[答案键](answer_key.md)仅在作答后使用。每题0–2分；模块≥5/6且满足模块验收项才通过。

每日成果放在 `submissions/day_XX.md`；30份文件均为待填写工作页，创建模板不计学习完成。具体主题、练习和验收见 [路线](../30_day_roadmap.md)。允许表格、图、计算过程、证据卡和讲稿，不要求每天写长文。

[模拟提现数据](withdrawal_fixture.csv)用于P02。它不含真实平台记录；金额以虚构统一计价单位USD计，不是链上币种数量。risk_label是课堂事后标注，不能作为线上检测时可用的字段。

离线时可以据案例摘要练习证据分级；未读取的交易字段仍须标“待核验”，不能编造成真实观察。
