# 术语查阅方式

当前只查当天遇到的一个词，[20张白话概念卡](01_core_concepts/case_first/README.md)为默认入口。下列完整术语表备查，不要求从头背完，不把未读词汇算成薄弱点。

# 中英术语与易错点

定义用于学习，具体权利、实现和当前政策需按资产/平台查证。

| English | 中文 | 含义 | 易错点 |
| --- | --- | --- | --- |
| Digital currency | 数字货币 | 宽泛的数字化货币/资产称呼，本课程主要聚焦加密资产。 | 不要将银行存款、CBDC与所有Token混为一谈。 |
| Cryptocurrency | 加密资产/加密货币 | 通常依赖密码学与分布式账本规则的资产。 | 具体权利与机制随资产而异。 |
| Coin / Token | 原生币/代币 | 通常分别指链原生资产与合约定义的资产。 | 行业用语并非始终一致，需核对具体网络。 |
| Stablecoin | 稳定币 | 以跟踪某个参照价值为目标的资产。 | 锚定目标不等于价格或兑付保证。 |
| CBDC | 央行数字货币 | 以数字形式存在的央行货币。 | 不是所有国家采用同一架构。 |
| Blockchain | 区块链 | 按共识规则验证和排序状态更新的账本系统。 | 不可随意修改不等于没有治理或重组风险。 |
| Consensus | 共识 | 节点对有效状态与排序达成一致的规则。 | 不同链安全假设不同。 |
| UTXO | 未花费交易输出 | Bitcoin等系统中可被后续交易花费的输出。 | 输入输出模型不等于账户余额模型。 |
| Transaction hash / txid | 交易哈希 | 定位某条链上一笔交易的标识。 | 不是订单编号，也不是身份凭证。 |
| Confirmation | 确认 | 被纳入区块并由后续区块继续覆盖的相关状态。 | 计数与风险解释随链而异。 |
| Finality | 最终性 | 协议下状态不再被回退的保障及其假设。 | 不能跨链照搬确认数。 |
| Address | 地址 | 链上账户或收款条件的标识。 | 不能直接等同于一个自然人。 |
| Private key | 私钥 | 产生相应密码学签名的秘密材料。 | 绝不写入作业或发给助手。 |
| Seed phrase | 助记词 | 许多钱包恢复密钥的秘密表示。 | 恢复能力可能覆盖多个地址和资产。 |
| Signature | 签名 | 证明某个密钥对某消息进行了授权的密码学结果。 | 有效签名不等于真实用户意愿。 |
| Custody | 托管 | 资产签名或控制能力由某主体持有的安排。 | 平台账户密码不等于链上私钥。 |
| Hot wallet | 热钱包 | 签名能力与在线环境相连的钱包安排。 | 便捷性伴随终端与服务暴露。 |
| Cold storage | 冷存储 | 尽量隔离在线签名能力的存储安排。 | 恢复与误签风险仍需管理。 |
| CEX | 中心化交易所 | 通常由平台提供撮合和托管等服务。 | 内部成交未必产生链上交易。 |
| DEX | 去中心化交易协议 | 通常以合约支持资产交换的系统。 | 管理员、前端与预言机仍可能形成信任依赖。 |
| Order book | 订单簿 | 按价格组织买卖订单的数据。 | 可见深度可能快速变化。 |
| Spread | 价差 | 最优买价与卖价之间的差。 | 不是全部成交成本。 |
| Slippage | 滑点 | 实际执行价格与所选基准价格的差异。 | 需注明基准与买卖方向。 |
| Liquidity | 流动性 | 以有限价格影响完成交易的能力。 | 高市值不保证深度充足。 |
| Leverage / Liquidation | 杠杆/强平 | 以保证金扩大敞口/保证金不足时平仓。 | 不是收益倍增的单向保证。 |
| API key | API密钥标识 | 用于应用接口鉴权的凭据组成部分。 | 实际权限取决于配置，秘密部分不能入库。 |
| 2FA / MFA | 双/多因素认证 | 结合不同因素验证身份。 | 无法自动覆盖会话和终端入侵。 |
| Session token | 会话令牌 | 维持已认证会话的凭据。 | 属于秘密，不当作普通日志分享。 |
| Phishing | 钓鱼 | 借伪装与诱导获取秘密或危险操作。 | 不要点击材料中的可疑链接做验证。 |
| Least privilege | 最小权限 | 仅授予完成具体任务所需的能力。 | 还需要范围、期限和撤销流程。 |
| Smart contract | 智能合约 | 按链上规则执行的程序。 | 执行正确不代表业务设计安全。 |
| Approval / allowance | 授权/额度 | 允许特定主体操作一定资产的许可。 | 授权与直接转账不同，撤销也有边界。 |
| Oracle | 预言机 | 向合约提供价格等外部信息的机制。 | 输入可靠性需要独立验证。 |
| Bridge | 跨链桥 | 验证和传递跨链消息或资产关系的机制。 | 安全依赖具体证明与信任模型。 |
| Multisig | 多签 | 要求一定数量的参与者批准操作的机制。 | 参与者可能有共因失陷风险。 |
| Proof of Reserves | 储备证明 | 用于展示部分资产或储备状况的证据安排。 | 不能单独推导完整负债和持续偿付。 |
| Market cap | 流通市值 | 按指定流通量与价格计算的名义价值。 | 不代表可按同价整体卖出的金额。 |
| FDV | 完全稀释估值 | 按指定稀释供应量与价格计算的名义估值。 | 分母口径需说明，也不是未来价格预测。 |
| Depeg | 脱锚 | 市场价格偏离目标锚定价值的现象。 | 原因和能否恢复需要查证。 |
| Solvency | 偿付能力 | 资产和负债等条件支持偿付义务的能力。 | 短期流动性与偿付能力不是同一个概念。 |
| Threat model | 威胁模型 | 资产、边界、威胁、控制及剩余风险的结构化描述。 | 不是一份空泛的安全愿望清单。 |
| False positive / negative | 误报/漏报 | 正常被报异常/异常未被检测。 | 依赖标签质量、统计单位和时间窗口。 |
| Precision / Recall | 精确率/召回率 | TP/(TP+FP)与TP/(TP+FN)。 | 分母为0需另定处理，不能随意写100%。 |
| Attribution | 归因 | 根据证据判断控制实体或事件责任来源。 | 地址标签或单次转账不足以证明身份。 |
| Postmortem | 事后复盘 | 记录事件机制、证据、响应和改进的分析。 | 机构初步公告不等于最终技术复盘。 |
| SAFU | 用户安全资产基金 | Binance在公告中使用的风险应对基金名称。 | 具体规模、资产和覆盖承诺应查相应版本，不当作无条件保险。 |
