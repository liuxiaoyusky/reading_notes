# C06 · 冒充身份

本页是后台备查卡，不一次全讲。课堂先读事件的一小段，确定只学这个点，问一道题后等待。每日时长是上限。

## 真实案例入口

初步报告称工程师收到假招聘联系，随后参与了伪造的面试。

来源：[report原帖](../../sources/2026-10-30-binance-hot-wallet-incident/posts/2117632624651125019.md)。这里保留机构声明与资料截止范围；本地归档不等于最终独立取证。

## 一句话解释

用假的身份让别人接受本来不会接受的请求。

## 生活类比与边界

像有人自称维修员请你开门；制服和自我介绍不能代替身份核实。

## 复述后再深入

检查对方真实身份与其要求的动作，不因渠道看似正规就自动相信每个联系人。

## 只问一道练习

求职平台是真的，为什么联系人仍可能是假招聘者？

先独立回答，检查后才深入；参考要点见[教师答案](../../03_exercises/case_first_answer_key.md)，课堂不提前展示。

## 输出与验收

成果可为50–100字理解卡或一张简单图。

- [ ] 区分平台和联系人
- [ ] 能说出需核实什么而非仅贴骗子标签

解释不清时先换熟悉场景，不直接认定个人知识差；按真实回答区分四类错误，并更新progress.md。
