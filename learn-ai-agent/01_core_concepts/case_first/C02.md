# C02 · 资产转移

本页是后台备查卡，不一次全讲。课堂先读事件的一小段，确定只学这个点，问一道题后等待。每日时长是上限。

## 真实案例入口

初步报告描述多笔资产转移，不能只因东西看不见就说没有发生转移。

来源：[report原帖](../../sources/2026-10-30-binance-hot-wallet-incident/posts/2117632624651125019.md)。这里保留机构声明与资料截止范围；本地归档不等于最终独立取证。

## 一句话解释

把资产从一方可支配的记录转到另一方。

## 生活类比与边界

像账本上把一笔余额从甲名下记到乙名下，不是运钞车搬实物；不同系统的具体记法以后再学。

## 复述后再深入

区分资产所有者、可处理转出的一方及转入对象，暂不要求读复杂交易字段。

## 只问一道练习

用两个方框和一条箭头说明“被转走”至少涉及什么变化。

先独立回答，检查后才深入；参考要点见[教师答案](../../03_exercises/case_first_answer_key.md)，课堂不提前展示。
