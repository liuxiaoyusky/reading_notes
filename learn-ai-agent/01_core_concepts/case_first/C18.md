# C18 · 回填

本页是后台备查卡，不一次全讲。课堂先读事件的一小段，确定只学这个点，问一道题后等待。每日时长是上限。

## 真实案例入口

11月13日原帖称受影响资产已完成回填，并发布新储备快照。

来源：[full原帖](../../sources/2026-10-30-binance-hot-wallet-incident/posts/2120925031790502362.md)。这里保留机构声明与资料截止范围；本地归档不等于最终独立取证。

## 一句话解释

平台拿出资金或购入对应资产，把受影响的缺口补上。

## 生活类比与边界

像寄存物损坏后保管方先用自己的钱补偿，不代表原物已经找回。

## 复述后再深入

检查补足对象、资产种类、完成时点和声明依据；预留资金与实际对应资产到位也有差别。

## 只问一道练习

平台自己出钱补齐缺口，能否据此说原来被盗的东西全追回了？

先独立回答，检查后才深入；参考要点见[教师答案](../../03_exercises/case_first_answer_key.md)，课堂不提前展示。
