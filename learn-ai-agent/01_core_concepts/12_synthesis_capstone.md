# M12 · 综合研究、讲解与复盘

层级：综合｜学习日：28–30｜先修：M01–M11

全局定位：先看[知识地图](../00_domain_map.md)，指出本模块的先修、当前位置和它为[最终展示项目](../04_projects/SHOWCASE.md)提供的材料，再进入下面的局部概念。模块引入多个新概念时，教学中须逐个补齐“一句话解释、生活类比、技术解释、真实案例、一个练习”。

## 概念解释

### 一句话解释

掌握一个领域，要能交付可复核作品、独立讲解并处理新情境。

### 技术解释

综合报告要回答发生了什么、证据是什么、哪里还不知道、控制能改变什么及其成本。研究质量取决于可追溯性与可复核性，不取决于篇幅或结论的戏剧性。用闭卷讲解与迁移题检查理解，再按错题决定下一阶段计划。

## 生活类比

像完成一场可被别人重做的实验：报告不仅给结果，还留下材料、方法、误差和下一步。听众应能指出哪条证据支持哪条结论。

## 真实案例

整合 C01/C02，并给 C03 做单独的调查阶段说明。不得把历史结论直接迁移为当前服务状态或新事件定论。

案例与原始出处见 [案例索引](../02_case_studies/README.md) 和 [来源台账](../SOURCES.md)。课堂计算和模拟数据不能充当事件证据。

## 练习题

1. 用五分钟向非技术听众解释交易所事件与桥事件的区别。
2. 为你的核心结论写出一个可推翻它的新证据条件。
3. 闭卷完成终测，再选择两个薄弱点设计七天补强计划。

把答案写入当日成果；练习工作页见 [模块练习](../03_exercises/M12.md)。先由学习者作答，再检查。

## 输出任务

提交三项目索引、终测答卷、五分钟讲稿及下一阶段计划。

对应具体文件和每日拆分见 [30天路线](../30_day_roadmap.md)。输出必须注明使用真实、历史还是模拟材料。

## 验收标准

- [ ] 三项目各≥80分，且无伪造来源或秘密泄露
- [ ] 终测≥80分；不通过则保留待复测
- [ ] 能闭卷解释三项机制并完成一题新情境迁移
- [ ] 三道练习合计≥5/6分，且能用自己的话解释一题。

## 检查与复盘

检查每题结论、依据和适用边界，给出0–2分。若答错，先依据实际回答判断“不懂概念 / 不会应用 / 表达不清 / 知识混淆”，再指出证据、计算或权限等具体错误位置；给针对性提示和迁移重试。复盘写入当天日志，每次均更新progress.md并登记复测日；根据薄弱点调整后续任务，保留调整记录，不能用阅读次数替代验收。
