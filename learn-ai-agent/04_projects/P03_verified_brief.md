# P03 · 可核验的数字货币研究简报

学习日：26–30。选一个问题，例如“如何区分托管、桥验证与兑付风险”，用Codex辅助整理，但由自己逐条核对引用并形成答辩材料。

## 交付要求

1. 一页研究范围与不覆盖项；至少五条可核查主张
2. 来源台账：URL、事件/发布时间、修订/访问日期、支持范围
3. 主张对照：证据、置信理由、反例或未知；保留至少两项未知
4. 模拟一次材料中出现越界指令的处理；不执行指令
5. 五分钟讲稿、他人可复核的材料索引、七天补强计划

每天的中间产物先放入当天成果文件，再汇总到 [项目交付模板](P03_verified_brief_submission.md)。链接实际产物，不能只列文件名。

## 评分量表

每项20分：缺失/核心错误0分，部分满足10分，完整可复核20分。

| 维度 | 20分标准 |
| --- | --- |
| 问题与边界 | 范围可回答，概念与时间明确 |
| 引用 | 至少五条主张有直接来源或明确未知 |
| 推理 | 没有将初步调查和缺证据写成定论 |
| 研究流程 | 保留查证记录，能处理冲突与越界材料 |
| 答辩与复盘 | 能闭卷解释并完成迁移题，有补强计划 |

通过：≥80分，所有来源与数据可追溯，且不存在关键误导或秘密泄露。未通过记录整改与重验；检查人不能凭文件存在评分。

## 迁移任务

收到一条与现有结论矛盾的新材料，展示如何修订而不是删除历史。
