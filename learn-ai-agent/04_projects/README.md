# 一个展示项目，三个阶段成果

最终完成[Binance安全事件研究与风险观察包](SHOWCASE.md)，以一个入口向他人展示。以下P01–P03作为该项目的三个组成部分，原有评分继续适用。

每个阶段包括任务书、交付模板与100分量表。各维度20分：0=缺失/核心错误；10=部分完成或不可复核；20=完整准确且可复核。总分≥80且没有伪造来源、泄露秘密等关键问题才通过。模板创建本身不计完成。
