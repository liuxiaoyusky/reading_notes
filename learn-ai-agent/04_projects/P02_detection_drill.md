# P02 · 离线异常检测与应急演练

学习日：19–21。使用模拟提现CSV设计可重算的告警规则与纸面响应流程。可用表格或Python，不依赖API。

## 交付要求

1. 规则R1：amount_usd≥1000即告警；R2：同账户向新地址在滚动10分钟内累计≥1500
2. 窗口定义为(t−10分钟,t]，含当前笔；按时间排序，同一账户仅累计destination_status=new的记录
3. 每条记录输出id、规则命中、理由；检测阶段不能读取risk_label
4. 检测后再用risk_label统计误报漏报；给首15分钟应急卡与恢复标准

每天的中间产物先放入当天成果文件，再汇总到 [项目交付模板](P02_detection_drill_submission.md)。链接实际产物，不能只列文件名。

## 评分量表

每项20分：缺失/核心错误0分，部分满足10分，完整可复核20分。

| 维度 | 20分标准 |
| --- | --- |
| 规则定义 | 字段、窗口边界、阈值明确，无事后标签泄漏 |
| 结果 | 能重算，原始数据未被修改 |
| 评估 | 混淆矩阵、precision/recall和局限正确 |
| 响应 | 明确责任人、证据保全及恢复条件 |
| 迁移 | 给一种误报、一种漏报及改进取舍 |

通过：≥80分，所有来源与数据可追溯，且不存在关键误导或秘密泄露。未通过记录整改与重验；检查人不能凭文件存在评分。

## 迁移任务

改变阈值，解释误报和漏报为何变化；不要仅按这10条数据拟合规则。
