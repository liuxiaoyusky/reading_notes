# P01 · 双事件证据档案

学习日：16–18。比较C01与C02，并对C03写一段调查阶段说明。目标是让读者知道每个结论从哪里来。

## 交付要求

1. 两案各一张系统边界图和时间线
2. 至少六条关键主张；每条保留URL、时间、证据类型和支持范围
3. 资产/金额口径表，至少两项未知和两条可验证的补充问题
4. 控制建议与局限、相互冲突的材料和处理理由

每天的中间产物先放入当天成果文件，再汇总到 [项目交付模板](P01_incident_dossier_submission.md)。链接实际产物，不能只列文件名。

## 评分量表

每项20分：缺失/核心错误0分，部分满足10分，完整可复核20分。

| 维度 | 20分标准 |
| --- | --- |
| 边界与机制 | 两案主体、受影响层及机制表述正确 |
| 证据 | 至少六条来源可追溯，引用支持对应主张 |
| 时间与金额 | 不混用事件/公告时间或不同金额口径 |
| 不确定性 | 事实、声明、推断、未知清晰 |
| 防御与讲解 | 建议针对具体故障，能用自己的话解释 |

通过：≥80分，所有来源与数据可追溯，且不存在关键误导或秘密泄露。未通过记录整改与重验；检查人不能凭文件存在评分。

## 迁移任务

换一份后续公告：指出哪条结论可能改变，哪条仍成立。
