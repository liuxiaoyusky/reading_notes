# 给普通人看的2026年Binance事件说明图

状态：未开始。当前只计划作品，不伪造结果。整个课程围绕这一件小作品积累，不要求同时完成原P01–P03。

## 最小成品

一页图或一页图文，讲清：平台帮忙保管→初步报告所述入口→资产被未经允许转走→应对与后续资产处理。不要为了图完整补造没公开的环节。

- 至少六条原帖出处，其中有不同发布主体更好；六条帖子不等于六个独立调查机构。
- 三项真实未知或待核差异，不能把它们写成已解决。
- 用日常话区分冻结、回填和追回，并保留资料截止日。
- 一份五分钟讲稿和一次实际问答反馈。

## 验收量表

每项20分：完整可复核20，部分10，缺失或核心错误0。≥80且下列内容实际完成才通过，空模板不能评分。

| 维度 | 检查什么 |
| --- | --- |
| 白话解释 | 外行能听懂，能解释一个关键点和类比边界 |

| 出处 | 至少六条可定位原帖，主体和时间保留 |
| 不确定性 | 至少三项未知/差异，分清回填与追回 |
