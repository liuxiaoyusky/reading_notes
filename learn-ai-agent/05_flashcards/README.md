# 当前回忆卡使用方式

[案例主线20张卡](case_first_cards.tsv)只抽实际学过的卡，每次一张；初始不能因为卡已创建就算掌握。原cards.tsv是进阶备查，不默认随机抽取，避免提前引入没学的术语。

# 主动回忆卡

[cards.tsv](cards.tsv)有48张卡，字段为id/module/front/back；可直接用文本编辑器看，或导入支持TSV的卡片工具并映射正反面。系统不自动安排通知。

每天选择相关模块4张卡，遮住背面先说答案。0=答错/想不起，1=部分正确，2=能解释并给边界。答错的卡登记到progress，按实际答题日+1/+3/+7/+14天重答，失败时重排。

模块解释卡较长，背面用于检查要点，不要求逐字背诵。记住具体金额但说不清主体和证据不算掌握。
