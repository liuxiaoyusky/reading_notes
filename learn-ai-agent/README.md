# Binance 黑客事件与数字货币：30 天领域学习仓库

围绕2026年这起真实案件，从一个未知点开始，逐步理解经过、入口、资产处理和资料证据，最后做出给普通人看的一页事件说明图。目录名按请求保留为 `learn-ai-agent`；AI Agent 是笔误，本课程没有 AI Agent 知识模块。Codex 只作为学习导师和研究助手。

## 从这里开始

1. 从[Day01真实事件](07_daily_review/day_01_plan.md)进入，只挑一个未知点；[知识地图](00_domain_map.md)后台备查，不要求先读完。
2. 参考[30天路线](30_day_roadmap.md)，每天最多60分钟；真实事件→一个疑问→白话拆解→复述后深入，不为赶进度扩展。
3. 从当天原帖的一小段和[一张白话概念卡](01_core_concepts/case_first/README.md)开始，回答一道题后再深入，将答案与作品写入 `03_exercises/submissions/day_XX.md`。已有模板并不代表完成。
4. 让 Codex 依照 [AGENTS.md](AGENTS.md) 检查，完成当天 `07_daily_review/day_XX.md`，把得分、证据路径、错因和下一步填进 [进度表](progress.md)。
5. 第7、14、21、28天参加每周阶段测验，第30天做综合终测；将五阶段的小卡累积成[一页事件说明图](04_projects/SHOWCASE.md)。每天最多60分钟，测试也可逐题、分段进行；未理解可顺延。

```text
答错时判断四类错误并给针对性补练。每次学习结束更新progress.md，通过后才标为完成。
```

继续学习时说“根据 progress.md 继续”；复测时说“针对错题给我一道新情境题”；审稿时说“逐条检查我的主张与来源是否对应”。无需安装库或购买服务。

## 如何算学会

平日检查一道题与当天小成果，阶段测验≥80分；最终一页说明图按量表≥80分。原模块5/6门槛只用于主动选学，不再额外要求所有旧模块或三个旧项目通过。每日成果还需有独立作答、检查反馈和复盘记录。没有通过就保留“待复测”，不要把进度条填满代替补练。

卡片按答题日之后1、3、7、14天复习，失败则登记错因并从次日重排；这是学习安排，不是已启用的自动提醒。补课可以顺延学习日，不要求连续30个自然日。只有30分钟时，完成一题、有依据的半页成果和复盘，状态记为部分完成。
