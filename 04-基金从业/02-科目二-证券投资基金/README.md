## 学习流程

1. **选一节要学的内容**：从 [index.md](index.md) 找到节 markdown（如 `converted/sections/01-证券投资基金概述/01-证券投资基金简介.md`）。
2. **打开提问**：把节 markdown 喂给 AI（直接复制整节，或让 AI 用 `cat` 读）。第一节是细粒度的（平均一页纸的密度），丢进 AI 完全够上下文。
3. **随时追问**：节 markdown 顶部有 frontmatter（`chapter` / `section` / `page_idx_start`），AI 可以直接定位。
4. **学完勾选**：在 [progress.md](progress.md) 把对应行打勾。回退就取消勾选。
5. **累积笔记**：每节后可以在该节 markdown 末尾追加自己的笔记。

## 用 AI 怎么问效果好

- **节 markdown 内提问**：直接复制整节，问「请用简单的话解释 XX」「帮我画一个表格对比 XX」等。
- **跨节总结**：学完一章后，可以让 AI 把该章的多个节综合成思维导图或顺口溜。
- **真题练手**：配合 `sources/02-历年真题/` 用。真题 PDF 暂未拆分，直接整本喂也行。

## 维护约定

- **不改原文**：`converted/sections/` 下的 markdown 是「原文」层，AI 可以引用但不修改正文。要改请在该节末尾追加自己的笔记。
- **图不抽离**：所有图都引用 `../../../converted/images/` 下的原图，不要再 OCR 或重渲染。
- **进度 2 态**：已完成 `[x]`，未完成 `[ ]`。不要引入第三种状态。
- **新增笔记**：在该节 markdown 末尾用 `## 我的笔记` 之类的小节追加。
