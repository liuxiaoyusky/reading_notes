# 二、投资交易流程

## 📜 寓言故事 —— 《一剂救命方》

清平镇东头的回春堂，传到周老大夫手里已是第三代。堂口不大，前后三进：前头问诊，中院抓药，后院起居。镇上百姓都认他——不只认医术，还认他那张写方子的纸。

周老大夫治了一辈子病，见过太多"方子开得好，病人吃错药"的惨剧。年轻时他亲历过一回：邻镇同行给急症病人开方，药童手忙脚乱，把三分附子抓成一钱，病人当晚就走了。从那以后他立下一条死规矩——回春堂的方子，从落笔到病人手里，要过五道手，少一道都不行。

这一日，堂里来了一位不寻常的病人。八个轿夫抬进一顶小轿，轿帘一掀，露出一张雪白的脸，是邻县钱粮师爷冯子敬的老母亲，七十有三，已昏沉三日。请了四位大夫，没人敢下药。轿夫撂下一句话："救得活，赏银五百两；救不活，棺材钱他出，但不能砸回春堂的招牌。"

周老大夫把了脉，看了舌，问了病史，沉吟良久。他没急着下笔，先起身往后院走。后院书房里，住着他的大徒弟宋拙——跟了他十二年、却从没独自开过方的年轻人。周老大夫把冯老太太的病情细细说了一遍，最后问："换你开方，你敢不敢？"

宋拙的手心全是汗。他知道，五百两银子不是小事；可他也知道，自己从没独立下过一张方子，分量差一厘就是生死。他咬了咬牙："师父，我敢。您写完后，让我先核一遍。"

周老大夫点头。师徒两人回到中院的小库房，桌上摊开白纸。周老大夫提笔，一味一味地写：黄芪、党参、附子、干姜、炙甘草……写到"附子"时，他回头看了宋拙一眼："附子多少？"宋拙答："三分，先煎一小时。"周老大夫落笔。写完最后一行，他在方子右上角画了一个小圆圈——这是回春堂的暗记，意思是"此方由我亲定"。

方子写完，转入第二道手：宋拙核方。他对着原方一味一味地核对，每一味药名、每一种剂量、每一道脚注，都用小楷另抄在右边的对照栏里。抄到附子，他默念了三遍"附子三分"。核对完毕，在对照栏末签下"核讫"二字，盖了自己的小方印。

第三道手是中院的药柜。药柜后头站着一个老药工，叫张守拙，跟周老大夫三十年了。他从方子最上方看到最下方，又从最下方看到最上方，看完两遍才开口："宋先生，附子这味——您让先煎一小时，对吧？"宋拙点头。张守拙这才一味一味地称、一味一味地包，每一味称完都把戥子上的刻度朝着灯光的方向，让宋拙看清。最后他把附子单独放在最上面，用红笔另画了一个圈："附子单包，先煎。"

第四道手是周老大夫亲自把关。他把三样东西摆在桌上——方子、对照栏、单包好的药。一样一样地看：方子上的笔迹是他自己的，圈是他自己画的；对照栏的字是宋拙的，印是宋拙盖的；药包上每味药的戥子刻度他都点过。三样东西对得上，他才点了点头，让张守拙把药装进布袋，封口，盖回春堂大印，交给候在前厅的轿夫。

第五道手，是冯子敬的回文。当晚冯子敬亲自跑来回春堂，递上一张红纸：母亲服药一剂，半夜退烧，今晨已能喝粥。末尾一句："贵堂之方，严若军令。冯某治下亦然。"周老大夫接过红纸，递给宋拙，宋拙看完又递给张守拙。三个人都没说话，但每个人的眼角都带着一点不易察觉的湿意。

送走冯子敬，周老大夫把回文和自己的方子、宋拙的对照栏、张守拙的戥子记录一起，用红绳扎成一束，挂到后院书房墙上。他转身对宋拙说："一个方子，从我落笔到病人嘴里，要走五道手：定方、核方、抓药、把关、回报。少一道，方子就是一张废纸；多一道，病人等不起。每一道手都替下一道手看着。这不是繁琐，是救命。"

宋拙站在那面挂满四联单的墙前，第一次懂了——方子不是大夫一个人开的，是五个人的命连在一起的。

**📖 原文定义**

> 基金管理人投资交易流程包括形成投资策略、构建投资组合、执行交易指令、绩效评估与组合调整、风险控制等环节。

> 投资策略的制定是投资交易的基础环节：研究部门提供研究成果；投资决策委员会参考研究成果形成指导性决议；投资部门制定投资组合的具体投资方案。

> 基金经理根据投资决策委员会的指导性决议及研究部门的研究报告，结合对证券市场、上市公司、投资时机的分析，在公司相关投资管理制度规定的权限范围内拟定所管理基金的具体投资计划，包括资产配置、行业配置、证券选择。

> 交易部门是基金投资运作的具体执行部门，负责投资组合交易指令的审核、执行与反馈。

> 基金管理人内部会定期和不定期对基金进行投资绩效评估，并提供相关报告。绩效评估包括业绩归因、业绩比较、风格分析等。根据绩效评估结果，基金经理可以对投资策略和投资组合进行适当调整。

> 风险管理并不是投资流程中的最后一环，而是贯穿于投资组合整个生命周期。风险管理既是风控和合规部门的职责，也是投资、市场、运营等部门的工作内容之一。

**💡 对应点**

| 故事元素 | 概念对应 |
|---------|---------|
| 周老大夫开方、画圆圈 | 形成投资策略、拟定投资计划（资产配置、行业配置、证券选择） |
| 宋拙核方、抄对照栏、盖印 | 指令审核环节，确保品种、方向、价格、数量准确 |
| 张守拙抓药、戥子朝着灯光 | 交易部门以有利价格执行交易指令 |
| 周老大夫亲自把关、把三样东西对上 | 多重核对保证执行结果与原指令一致 |
| 冯子敬的回文 | 成交回报与绩效评估环节 |
| 把方子、对照栏、戥子记录、回文四联单挂在墙上 | 投资交易流程留痕，便于事后追溯与组合调整 |
| "五道手、缺一不可" | 投资交易流程是一个连续链条，决策→指令→执行→核对→回报环环相扣 |
| "每一道手都替下一道手看着" | 风险管理贯穿投资全生命周期，是各环节共同职责 |
