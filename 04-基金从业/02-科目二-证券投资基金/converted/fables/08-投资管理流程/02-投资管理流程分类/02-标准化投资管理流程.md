# 二、标准化投资管理流程

## 🏺 寓言故事 —— 《成衣店的买卖》

与裁缝铺相对，镇上还有一家**成衣店**。成衣店不量体裁衣，而是设计师先设计出几款衣服——风衣、西装、夹克——挂在店里，顾客根据自己的身材和喜好挑选。基金管理中的**标准化投资管理流程**就是这个思路。

### 谁用这种流程？

公募基金面向广大不特定投资者，采用**基金管理人主导**的标准化流程。管理人根据产品线布局、市场关注点、基金经理特长等因素设计基金产品，投资者自己选择合适的基金。

### 关键区别

| 对比维度 | 定制化流程 | 标准化流程 |
|---------|-----------|-----------|
| 出发点 | 投资者需求 | 管理人产品线、基金经理特点、市场需求 |
| 业绩比较基准 | 投资者需求决定 | 投资策略决定 |
| 基准决定人 | 投资者与管理人商定 | 管理人 |
| 投资策略制定 | 投资者与管理人商定 | 管理人 |
| 策略重大变化 | 签补充协议 | 变更基金合同 |
| 变化难易程度 | 容易 | 较难，需召开持有人大会 |
| 业绩是否公开 | 否 | 是 |
| 业绩评价 | 无法与同类产品比较 | 可与同类产品比较 |

### 流程特点

基金管理人在设计公募基金时，会明确：
- 投资范围（股票、债券、港股通等）；
- 业绩比较基准（如沪深300×50% + 港股通指数×30% + 国债指数×20%）；
- 投资方法（价值投资、成长投资、指数跟踪等）；
- 费率结构。

基金成立后，基金经理严格按基金合同管理，**不会根据个别投资者的需求调整策略**。开放式基金还要应对资金进出的不确定性——今天有人申购，明天有人赎回，这和资产管理计划的资金锁定很不一样。

---

**📖 原文定义**

> 公募基金不同于私募基金和资产管理计划，其成立和策略选择并非源于特定投资者的需求，而是基于基金管理人的多方面综合考虑，包括产品线布局、市场关注点和基金经理特点等因素。在这种模式下，基金管理人承担了投资策略设计的责任，而投资者根据需求及风险承受能力选择产品，无法直接影响基金的投资策略。

> 当基金管理人确定了其拟发行基金的策略后，会进一步明确基金产品的各项关键要素，如投资范围、业绩比较基准、投资方法、费率结构等。

> 基金成立后，基金经理将严格按照基金合同执行投资管理。基金经理不会根据个别投资者的需求变化来改变投资策略，而是基于对市场的判断，在法规和基金合同框架内进行投资管理。此外，开放式基金的基金经理还需要应对资金进出不确定性的问题。

**💡 对应点**

| 故事元素 | 概念对应 |
|---------|---------|
| 成衣店 | 公募基金 |
| 设计师先设计款式 | 基金管理人主导 |
| 顾客自己挑选 | 投资者选择产品 |
| 衣服款式不能因一个人改 | 不根据个别投资者调整策略 |
| 尺码规格统一公开 | 业绩公开、可与同类产品比较 |
| 众人买众人退 | 开放式基金资金进出不确定性 |
