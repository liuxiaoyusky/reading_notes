# 二、大宗商品的投资方式

## 🏺 寓言故事 —— 《四种买货法》

投资大宗商品有四种途径，各有利弊。

### 第一种：直接买实物

理论上，你可以直接买一百桶原油、一吨铜放在仓库里。但问题是：运输贵、仓储贵、还要防变质。而且期货合约通常有最小交易单位（比如原油最少1000桶），一般人根本玩不起。这种方式更多是产业参与者（如炼油厂、钢厂）在用，金融投资者很少直接采用。

### 第二种：买相关股票

投资矿产公司的股票、农业公司的股票，间接参与大宗商品。但有个陷阱：这些公司为了规避商品价格波动，往往自己做对冲。你买股票想赌铜价涨，结果公司把铜价风险对冲掉了，你的股票可能根本不随铜价动。

### 第三种：投资衍生工具

这是最常见的方式。通过期货、期权、远期、互换等衍生品来投资大宗商品。期货合约在交易所交易，标准化、透明、流动性强、成本低。中国的商品期货交易所主要在上海、大连、郑州和广州。期货市场的价格发现功能，使得商品期货价格成为现货交易的基准。

### 第四种：投资结构化产品

有些投资者（如某些机构）由于投资范围限制，不能直接买期货。他们可以通过银行或金融机构发行的**结构化产品**间接参与——这些产品的收益挂钩于商品价格，但本身是一种新创造的证券。

四种方式，从最直接到最间接，风险和门槛各有不同。

---

**📖 原文定义**

> 投资者可以直接购买并持有大宗商品实物，但这种方式通常面临高昂的运输、仓储成本以及品质管理问题，且交易通常有最小单位限制，因此很少被金融投资者直接采用，更多是产业参与者的行为。

> 投资者可以通过购买主营资源勘探、开发或大宗商品生产加工企业的股票来进行大宗商品投资。但相关企业为减少商品价格波动对公司运营的影响，会对所运营商品进行风险对冲，购买此类企业股票无法获得对相关商品的风险敞口。

> 对单一商品或商品价格指数采用衍生产品合约形式进行投资，是大多数大宗商品投资者常用的投资方式。期货合约是在交易所交易的标准化产品，有固定的交易场所、规范的合约、透明的合约价格、较低的交易成本和很强的流动性。

> 某些投资者由于投资范围的限制，无法直接投资于大宗商品及其衍生工具。这些投资者可以通过投资银行或其他金融机构发行的结构化产品间接投资于大宗商品市场。结构化产品主要用金融工程的方法创造新的证券，并将其收益挂钩于其他资产。

**💡 对应点**

| 故事元素 | 概念对应 |
|---------|---------|
| 直接买原油放仓库 | 购买大宗商品实物 |
| 买矿产公司股票 | 购买大宗商品相关股票 |
| 公司做对冲 | 无法获得商品风险敞口 |
| 买期货合约 | 投资大宗商品衍生工具 |
| 期货价格成基准 | 价格发现功能 |
| 通过银行产品间接参与 | 投资大宗商品结构化产品 |
