# 三、协方差与相关系数

## 🤝 寓言故事 —— 《同涨同跌还是此消彼长》

投资者买了多只股票，他不仅关心每只股票自己的波动，还关心它们之间的关系——**同涨同跌？还是此消彼长？**

### 协方差

**协方差（Covariance）**衡量两只股票收益率**共同变化**的程度。

- 协方差 > 0：两只股票倾向于同向变化（一起涨或一起跌）
- 协方差 < 0：两只股票倾向于反向变化（一只涨时另一只跌）
- 协方差 = 0：两者变化没有线性关系

但协方差的数值大小依赖于变量的单位和尺度，不易直接比较不同资产之间的相关性。

### 相关系数

为了消除单位影响，引入**相关系数（ρ）**：

**ρ_ij = Cov(r_i, r_j) ÷ (σ_i × σ_j)**

相关系数的取值范围：**-1 ≤ ρ ≤ 1**

| 相关系数 | 含义 |
|---------|------|
| ρ = 1 | **完全正相关**：总是同向变化 |
| ρ = -1 | **完全负相关**：总是反向变化 |
| ρ = 0 | **零相关**：没有线性关系 |
| 0 < ρ < 1 | **正相关**：一个增加通常伴随另一个增加 |
| -1 < ρ < 0 | **负相关**：一个增加通常伴随另一个减少 |

### 实际例子

- 工商银行与中国银行：相关系数**0.89**（高度正相关，同属银行业）
- 中石油与宝钢股份：相关系数**-0.72**（高度负相关，能源涨价→钢铁成本增加）

### 投资组合中的应用

通过合理配置**相关性较低**的资产，投资者可以在不显著增加风险的情况下提高组合预期收益。这就是**分散化投资**——降低非系统性风险的有效方法。

完全正相关或完全负相关在现实中极为少见，大多数相关系数在(-1, 1)之间。

---

**📖 原文定义**

> 协方差（Covariance）衡量两个随机变量共同变化的程度。当i=j时，协方差退化为单个随机变量的方差，即Cov(r_i, r_i) = Var(r_i)。协方差反映了两个变量的共同变化趋势。

> 相关系数ρ_ij定义为协方差与各自标准差的比值：ρ_ij = Cov(r_i, r_j) / (σ_i × σ_j)。

> 相关系数的取值范围为-1 ≤ ρ_ij ≤ 1：
> - 当ρ_ij = 1时，表示完全正相关
> - 当ρ_ij = -1时，表示完全负相关
> - 当ρ_ij = 0时，表示零相关

> 在实际市场中，完全正相关或完全负相关的情况极为少见。大多数情况下，相关系数在(-1,1)之间。

> 通过合理配置相关性较低的资产，投资者可以在不显著增加风险的情况下提高组合的预期收益。这种策略被称为分散化投资，是降低投资组合非系统性风险的有效方法。
