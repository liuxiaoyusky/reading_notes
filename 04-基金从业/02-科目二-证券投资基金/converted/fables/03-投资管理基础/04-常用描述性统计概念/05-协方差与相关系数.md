# 五、协方差与相关系数

## 🏺 寓言故事 —— 《两棵树的秘密》

山腰上有两棵老树，一棵是枣树，一棵是梨树，中间隔着一条窄窄的石板路。枣树的主人叫老周，梨树的主人叫老吴，两人是几十年的老邻居，也是镇上最大的两家果商。

每年秋天，两棵树的收成决定了镇上果价的走势。老周和老吴心里都清楚一件事：如果今年枣子丰收，梨多半也丰收；如果枣子歉收，梨往往也好不到哪去。它们像是被同一只手拨弄的琴弦，一个响了，另一个也跟着颤。

有一年大旱，枣树只结了往年三成的果，梨树更惨，连两成都没有。老周和老吴蹲在树下抽了一下午的旱烟，烟圈飘上去，和枯黄的叶子混在一起。老周忽然说："咱俩这树，命是连在一起的。"

老吴点点头："老天爷赏饭的时候一起饱，老天爷收碗的时候一起饿。"

但他们谁也没想过，这种"一起"到底意味着什么。直到镇上来了第三个果商——小郑。

小郑年轻，脑子活，他不种果树，而是四处收果子再转卖。他观察了三年，发现了一个规律：枣价涨的时候梨价也涨，枣价跌的时候梨价也跌。他把这个规律记在本子上，起名叫"同涨同跌"。靠着这个发现，小郑每次进货都能押对方向，三年就成了镇上最有钱的果商。

老周和老吴看着眼红，也各自找了本子来记。老周记的是"枣和梨一起变好的次数"，老吴记的是"枣和梨一起变差的次数"。两人记了满满两本，却越记越糊涂——因为他们发现，这个"一起"的劲儿，有时候大，有时候小。大旱那年，两棵树都几乎绝收，"一起"的劲儿大得吓人。普通年份，一棵多收了两成，另一棵只多收了一成，"一起"的劲儿又小得几乎看不见。

老周把本子一摔："这数字忽大忽小，到底怎么比？"

老吴也摇头："我家梨树比你家枣树高一头，结的果子本来就不是一个数，这么硬比，比不出个所以然。"

两人去找小郑请教。小郑正在打算盘，听了他们的困惑，放下手里的活，带着他们走到院子里。

院子里有两口缸，一口装水，一口装米。小郑问："你们说，水和米，哪个沉？"

老周说："米沉。"老吴说："水轻。"

小郑笑了："可如果我把水倒进大海，把米倒进一只碗，怎么比？水在碗里也沉，米在海里也轻。要比沉和轻，得让它们站在同一个秤上。"

他回到屋里，从抽屉里翻出一张泛黄的纸，上面画着两个圈，圈里各有一条线。"我爹活着的时候是个账房先生，他教过我一个道理：要看两样东西是不是一起走，不能只看它们走了多远，要看它们走的步子是不是一样大。"

小郑指着纸上的线说："枣树和梨树，各自有自己的'步子'——有的年份步子大，有的年份步子小。先把各自的步子量出来，再把它们'一起走的劲儿'除以两个步子的乘积，得到的数，就能真正说明它们有多'像'了。"

老周皱眉："这数能有多大？"

"最大就是一模一样，"小郑竖起一根手指，"你往东走一步，我也往东走一步，你往西退一步，我也往西退一步，那就是顶天了。"

"最小呢？"

"你往东，我往西，你进我退，你退我进，那就是反着来的，也是顶天了，只是方向相反。"

老吴问："那要是零呢？"

"那就是各走各的，谁也不管谁。"小郑顿了顿，"不过这世上，零很少见。大多数东西，都在中间晃荡。"

老周和老吴回去之后，照着小郑的法子算了一遍。他们发现，枣树和梨树的"像"，大概在零点八几——很亲近，但不是一个人。这意味着，如果他们把全部身家都押在枣和梨上，好年景一起赚，坏年景一起赔，没有退路。

老周做了一个决定。他把自己的地分了一半，改种了柿子。柿子树和枣树的"像"，只有零点三——它们听的不是同一个老天爷。枣子怕旱，柿子怕涝；枣子喜欢晒，柿子喜欢阴。老周发现，当枣子歉收的时候，柿子有时候反而结得好。

那一年，枣树遭了虫灾，老周的枣子亏了三成。但柿子却意外丰收，补回了亏空，还多赚了些。老周坐在院子里，看着三棵树——枣树、梨树、柿子树——忽然明白了小郑没说完的话。

他把老吴叫来，两人各斟了一杯酒。老周说："以前我觉得，找两棵'像'的树一起种，是稳妥。现在才知道，找几棵'不像'的树一起种，才是长久。"

老吴举杯："老天爷不会同时让所有的树都枯死。"

老周摇头："不是老天爷的问题。是两棵太'像'的树，其实在赌同一个命。命好了一起好，命差了一起差。只有把'不像'的放在一起，才能互相兜底。"

夜风吹过来，枣树的叶子沙沙响，梨树的叶子跟着响，柿子树却静悄悄的，像是什么也没听见。

老周看着它们，忽然说了一句："知道两棵树有多'像'，不是为了让它们更'像'，是为了找到那些'不像'的。"

这句话后来成了镇上果商们的口头禅。

**📖 原文定义**

> 在统计学中，人们用协方差（Covariance）衡量两个随机变量共同变化的程度。协方差反映了两个变量的共同变化趋势：协方差为正，表示两个变量同向变化；协方差为负，表示两个变量反向变化。然而，协方差的数值大小依赖于变量的单位和尺度，因此不易直接用来比较不同资产之间的相关性。

> 为了消除协方差的单位影响，统计学家引入了相关系数的概念，用于衡量两个变量相关性的强度和方向。相关系数定义为协方差与各自标准差的比值：ρ_ij = Cov(r_i, r_j) / (σ_i × σ_j)。相关系数的取值范围为-1 ≤ ρ_ij ≤ 1：当ρ_ij = 1时，表示完全正相关；当ρ_ij = -1时，表示完全负相关；当ρ_ij = 0时，表示零相关。相关系数反映了两个变量线性相关性的强弱，且不受原始数据单位的影响。

> 在实际市场中，完全正相关或完全负相关的情况极为少见。大多数情况下，相关系数在(-1,1)之间。通过合理配置相关性较低的资产，投资者可以在不显著增加风险的情况下提高组合的预期收益。这种策略被称为分散化投资，是降低投资组合非系统性风险的有效方法。
