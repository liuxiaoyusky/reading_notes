# 一、(二) 期望、方差与标准差

## 📊 寓言故事 —— 《平均与波动》

### 期望（均值）

查账先生看了某基金过去10天的收益率：4.684%、4.597%、4.321%、4.373%、4.280%、4.136%、4.150%、3.982%、4.270%、4.261%。

他算了一下平均值：**(4.684 + 4.597 + ... + 4.261) ÷ 10 = 4.305%**

这个平均值就是**样本均值**，用来估计这只基金的**期望收益率**——长期平均回报的估计值。

期望是对所有可能取值按照概率加权后的平均值。如果投资多只股票，组合的期望收益率是各股票期望收益率按投资比例加权：

**E(r_p) = w_1 × E(r_1) + w_2 × E(r_2) + ... + w_n × E(r_n)**

### 方差与标准差

平均值是4.305%，但每天的实际收益率有高有低——有的天4.684%，有的天只有3.982%。这种"上下波动"的程度就是**风险**。

**方差(σ²)** 和 **标准差(σ)** 衡量收益率偏离期望的程度：
- 方差/标准差**越大** → 波动越大 → 风险越高
- 方差/标准差**越小** → 波动越小 → 风险越低

上面那只基金的标准差约为0.209%，远小于期望收益率4.305%，说明波动相对较小。

方差的计算中，n-1是**自由度调整**（不是n），为了使样本方差成为总体方差的无偏估计。

投资者不仅关心"平均能赚多少"（期望），还关心"实际可能偏离多少"（标准差）。这两个指标缺一不可。

---

**📖 原文定义**

> 随机变量X的期望，或称"均值"，记作 E(X)，衡量了X取值的平均水平。期望值是对X所有可能取值按照其概率加权后得到的平均值。

> 在金融领域，期望值通常用于评估投资的长期平均回报率。

> 对于投资收益率r，我们用方差(σ²)或者标准差(σ)来衡量它偏离期望值的程度。方差和标准差越大，表明收益率r偏离期望收益率E(r)的程度越大；反之，方差和标准差越小，说明数据分布更集中，波动性也越小。

> 当r的分布未知时，我们可以通过抽取样本计算样本方差和样本标准差来估计总体方差σ²和标准差σ。这里n-1是自由度调整，是为了使样本方差成为总体方差的无偏估计量。

> 假设由n项资产构成资产组合A=w_1A_1+...+w_nA_n，其中w_i为投资于资产A_i的资金所占总资金的比例，满足Σw_i=1，若A_i的期望收益率为r_i，则资产组合A的期望收益率为：E(r_p) = w_1r_1 + w_2r_2 + ... + w_nr_n。

**💡 对应点**

| 故事元素 | 概念对应 |
|---------|---------|
| 算10天收益率的平均 | 样本均值估计期望值 |
| 期望 = 按概率加权的平均 | 期望值是对所有可能取值按概率加权后的平均值 |
| 每天的实际值有高有低 | 收益率的波动 |
| 方差/标准差衡量偏离程度 | 衡量偏离期望值的程度 |
| 方差越大风险越高 | 方差和标准差越大，波动性越大，风险越高 |
| n-1不是n | 自由度调整，使样本方差成为无偏估计 |
| 多只股票按比例加权 | 资产组合期望收益率 = Σw_i × E(r_i) |
