# 一、(一) 随机变量与分布

## 🎲 寓言故事 —— 《掷骰子和称体重》

金融市场充满了不确定性。明天股价涨还是跌？公司会不会违约？这些难以预测的事件，在数学上叫做**随机变量**——能取得多个可能值的数值变量。

### 离散型随机变量

取值是**跳跃的、可数的**。比如：
- 掷骰子的点数：1、2、3、4、5、6
- 抛硬币：正面(1)或反面(0)
- 家庭子女数量：0、1、2、3...
- 债券违约状态：违约(1)或不违约(0)

这些变量的取值之间有"间隔"，不能取小数。

### 连续型随机变量

取值是**连续的**，某个区间内的任意实数都可以取。比如：
- 人的身高体重
- 某地区的年降雨量
- **股票在交易时间内的价格**

任意两个取值之间总存在其他取值。

### 概率分布

随机变量的分布描述了它取不同值的**概率**。

- **离散型**：列出每个可能值的概率 p_i，所有概率之和 = 1
- **连续型**：无法列出每个值的概率，用**概率密度函数**来描述。概率密度函数曲线下的面积就是变量落在某个区间的概率

理解随机变量是金融分析的基础——股价、收益率、违约概率，这些都是随机变量。

---

**📖 原文定义**

> 随机变量是一个能取得多个可能值的数值变量，是统计学中的核心概念，用于描述不确定性。

> 离散型随机变量：如果随机变量X只能取有限个或可数无限多个不同的值，则X为离散型随机变量。其特点为取值是跳跃的，中间可能存在间隔。例如，抛硬币的结果、骰子的点数、家庭的子女数量，以及债券的违约状态都属于离散型随机变量。

> 连续型随机变量：如果随机变量X可以取某个区间内的任意实数，则称为连续型随机变量。其特征是取值是连续的，任意两个不同的取值之间总存在其他取值。人的身高或体重、某地区的年降雨量、制造过程中产品的重量误差，以及股票在交易时间内的价格都是连续型随机变量的典型例子。

> 随机变量的分布描述了它取不同值的概率。如果X是离散型随机变量，所有概率的总和 Σp_i = 1。如果X是连续型随机变量，我们使用概率密度函数来刻画X的分布。

**💡 对应点**

| 故事元素 | 概念对应 |
|---------|---------|
| 掷骰子 | 离散型随机变量：取值跳跃、可数 |
| 称体重 | 连续型随机变量：取值连续 |
| 1到6的整数 | 离散型：有限个或可数个不同值 |
| 任意实数 | 连续型：区间内任意实数 |
| 债券违约(1)或不违约(0) | 离散型随机变量的金融例子 |
| 股票价格 | 连续型随机变量的金融例子 |
| 每个值的概率 | 概率分布 |
| 所有概率之和=1 | Σp_i = 1 |
| 概率密度函数 | 连续型随机变量的分布描述工具 |
