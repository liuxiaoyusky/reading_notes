# 一、(二) 分位数与中位数

## 📊 寓言故事 —— 《站队和中间人》

### 分位数

查账先生把某ETF过去100个交易日的每日涨跌数据从小到大排好队。他想找一个"分界点"：比这个点差的交易日占多少比例？

**分位数（Quantile）**——将数据从小到大排列后，在特定位置上的数值点。该点将数据分成两部分：小于等于该值的比例为p，大于等于该值的比例为(1-p)。

比如**下5%分位数**：100个交易日中第5个（100×5%）的值。如果排序后第5个值是-12.02，意味着有5%的交易日跌幅达到或超过-12.02。

如果算**下2.5%分位数**：100×2.5%=2.5，不是整数，就取第2个和第3个的平均值。

分位数在风险管理中非常有用——比如计算在95%置信水平下的最大可能损失（VaR）。

### 中位数

**中位数**——排在正中间的那个数。一半的数据比它大，一半的数据比它小。

- 数据个数为奇数：中位数就是中间那个数
- 数据个数为偶数：中位数是中间两个数的平均值

比如某投资者近年的年收益率排序：-16%、4%、5%、5%、6%、8%
- **中位数 = 5%**（中间两个数5%和5%的平均）
- **均值 = (-16+4+5+5+6+8)/6 = 2%**

为什么中位数比均值更合理？因为-16%是一个极端异常值（金融危机期间），严重拉低了均值。中位数**不受极端值影响**，能更好地反映投资策略的真实水平。

再比如336只股票型基金的年度净值增长率，中位数13.665%可以作为评价基准——高于它的表现优于行业一般水平，低于它的表现劣于行业一般水平。

---

**📖 原文定义**

> 分位数（Quantile）是指将一个概率分布按从小到大的顺序排列后，在特定位置上的数值点。p分位数(0≤p≤1)是指至少有p比例的数据小于或等于该值，并且至少有(1-p)比例的数据大于或等于该值。

> 样本中第n·p个数用于估计p分位数。如果n·p不是整数，则取相邻两个整数位置的样本值的平均数作为分位数估计值。

> 中位数，又称中值，指按顺序排列的一组数据中居于中间位置的数。对于一组数据，有一半的数据大于或等于中位数，有一半的数据小于或等于中位数。

> 与均值相比，中位数的评价结果往往更为合理和贴近实际。中位数不易受极端值影响，能较好地反映投资策略的真实水平；平均数则很容易受到极端值的冲击。

**💡 对应点**

| 故事元素 | 概念对应 |
|---------|---------|
| 把数据从小到大排队 | 分位数：按顺序排列后的特定位置 |
| 排在第5%位置的值 | 下5%分位数 |
| n×p是整数直接取 | 第n·p个数估计分位数 |
| n×p不是整数取平均 | 相邻两个整数位置的样本值平均 |
| 排在正中间的数 | 中位数 |
| 奇数个取中间，偶数个取平均 | 中位数的计算方法 |
| -16%拉低均值到2% | 极端值对均值的影响 |
| 中位数5%不受极端值影响 | 中位数不易受极端值影响 |
| 336只基金中位数作为基准 | 中位数用于行业业绩评价 |
