# 五、即期利率与远期利率

## 📈 寓言故事 —— 《现在的利息和未来的利息》

### 即期利率

**即期利率（Spot Rate）**——从今天开始到未来某个时点的零息债券年化收益率。比如1年期即期利率5.571%，意味着今天借钱出去，1年后收回，年化收益率是5.571%。

不同期限的即期利率连起来，形成**即期利率曲线**——展示了从短期到长期的收益率走势。通常期限越长，利率越高（因为不确定性更大）。

即期利率用于将未来现金流**贴现到现值**。

**贴现因子 d_t = 1 ÷ (1 + S_t)^t**

贴现因子可以理解为：未来某个时间收到1单位现金，现在值多少钱。时间越久，贴现因子越小。

### 远期利率

**远期利率（Forward Rate）**——未来某一时点到另一时点的隐含利率。它反映了市场对未来利率走势的预期。

即期利率的起点是**现在**，远期利率的起点是**未来某一时刻**。

例如：当前1年期即期利率 s_1 = 7%，2年期即期利率 s_2 = 8%。那么第2年的1年期远期利率 f 是多少？

根据无套利原则：
- 方式一：直接存2年 → (1 + 8%)^2
- 方式二：先存1年，再以远期利率借出1年 → (1 + 7%) × (1 + f)

两种方式结果应该相等：(1 + 8%)^2 = (1 + 7%) × (1 + f)

解得：**f = (1.08)^2 ÷ 1.07 - 1 ≈ 9.01%**

市场预期的第2年利率是9.01%！

### 远期利率的应用

1. **货币政策参考**：央行观察远期利率了解市场对未来经济和通胀的预期
2. **衍生品定价**：利率互换、远期利率协议（FRA）等产品的定价依赖于远期利率
3. **投资决策和风险管理**：评估未来投资机会，管理利率风险

注意：远期利率只是市场预期，不一定准确预测未来实际利率。

**📖 原文定义**

> 即期利率（Spot Rate），通常记作 s_t，是金融市场中的基础利率，指从当前时刻（t=0）到未来某个特定时点 t 的零息债券年化收益率。即期利率反映了不同期限资金的时间价值，被用于将未来现金流贴现到现值。

> 贴现因子 d_t = 1 ÷ (1 + S_t)^t。贴现因子将未来现金流直接转化为相应的现值，可以看作是未来某个时间点上收到1单位现金的现值。

> 远期利率（Forward Rate）是指资金在未来某一时点到另一时点的隐含利率，也可以理解为未来指定期间的借贷成本或投资收益率。它反映了市场对未来利率水平的预期，通常通过当前的即期利率推导得出。

> 远期利率和即期利率的区别在于计息日起点不同：即期利率的起点在当前时刻，而远期利率的起点在未来某一时刻。

> 根据无套利原则：(1 + s_2)^2 = (1 + s_1)(1 + f)。解得远期利率 f = (1 + s_2)^2 ÷ (1 + s_1) - 1。
