# 一、货币的时间价值

## ⏳ 寓言故事 —— 《今天的一两银子》

镇上有个老账房，他常说一句话："今天的一两银子，比明年的一两银子更值钱。"

为什么呢？

**第一，钱能生钱。** 今天的一两银子存入钱庄，明年就变成一两零一钱——多出来的一钱就是利息。

**第二，物价会涨。** 今年一两银子能买十斤米，明年可能只能买九斤。货币购买力被通胀侵蚀了。

**第三，机会成本。** 你今天花了一两银子，就放弃了这笔钱未来可能带来的所有收益。

这就是**货币的时间价值（TVM）**——相同金额的货币在不同时间点上具有不同的价值。现在的一元比未来的一元更有价值。

在金融分析中，我们把投资活动看作一个独立的系统：
- **现金流入**：收进来的钱
- **现金流出**：花出去的钱
- **净现金流量** = 现金流入 - 现金流出

要准确评估一笔投资值不值得做，必须考虑时间因素。这就需要用到三个核心概念：**终值、现值和贴现**。

---

**📖 原文定义**

> 货币的时间价值（Time Value of Money，TVM）是指相同金额的货币在不同时间点上具有不同的价值。通常情况下，现在的一元比未来的一元更有价值。

> 在投资分析中，我们通常将某一投资活动视为一个独立的系统，其中资金的收支称为"现金流量"。资金的支出称为"现金流出"，资金的收入称为"现金流入"。某一段时间段的净现金流量是指该时段内现金流量的代数和，即：净现金流量 = 现金流入 - 现金流出。

| 故事元素 | 概念对应 |

| 今天的一两比明年的一两更值钱 | 货币的时间价值 |
| 钱能生钱 | 资金可以产生利息收益 |
| 物价会涨 | 通货膨胀侵蚀购买力 |
| 机会成本 | 放弃未来可能的收益 |
| 收进来的钱 | 现金流入 |
| 花出去的钱 | 现金流出 |
| 净现金流量 = 流入 - 流出 | 净现金流量公式 |
| 终值、现值、贴现 | 分析资金运动的核心概念 |
