# 二、基础设施基金的类型

## 🏗️ 寓言故事 —— 《两种包租方式》

大家一起凑钱建基础设施，但"拥有"的方式分两种。

### 方式一：买下来（产权类基础设施基金）

大家凑钱把这座桥、这个仓库、这个产业园**彻底买下来**，归基金所有。就像你买了一套房子，房产证上写的是你的名字。你可以一直收租金，将来房子升值了还能卖个好价钱。

这类基金投资的项目主要是：
- **仓储物流**：仓库、物流中心
- **信息网络**：数据中心、通信基站
- **产业园区**：科技园区、工业园区
- **保障性租赁住房**：公租房、人才公寓
- **消费基础设施**：商场、购物中心

产权类的优势是：既有租金收入，又有资产增值的潜力。

### 方式二：租经营权（经营权类基础设施基金）

大家凑钱不是把这座桥买下来，而是**买下了收费的权利**——未来20年这座桥的过路费归基金收。但桥本身还是朝廷的，20年后要交回去。就像你承包了一块地种果树，地不是你的，但果子是你的。

这类基金投资的项目主要是：
- **交通设施**：高速公路、铁路
- **市政设施**：供水厂、污水处理厂
- **污染治理**：垃圾处理、废气治理
- **清洁能源**：风电、光伏、水电

经营权类的特点是：有稳定的收费现金流，但没有资产所有权，到期后项目要归还。投资回收主要依赖项目运营期间的现金流。

| 类型 | 权属 | 主要项目 | 收益来源 |
|------|------|---------|---------|
| 产权类 | 完全所有权 | 仓储物流、产业园、保障房、消费基础设施 | 租金+资产增值 |
| 经营权类 | 经营权利 | 交通设施、市政设施、污染治理、清洁能源 | 收费现金流 |

2021年6月，我国首批试点的9只基础设施基金成立，既有产权类也有经营权类，底层资产覆盖产业园区、仓储物流、收费公路和垃圾污水处理等领域。首批封闭期均超过20年，最长99年。

---

**📖 原文定义**

> 根据基础设施基金投资的基础设施项目权属类型的不同，可以将基础设施基金分为产权类基础设施基金、经营权类基础设施基金。

> 产权类基础设施基金，是指基础设施基金通过基础设施资产支持证券，穿透取得基础设施项目的完全所有权。此类基础设施基金投资的基础设施项目，主要为仓储物流、信息网络、产业园区、保障性租赁住房、消费基础设施等。

> 经营权类基础设施基金，是指基础设施基金通过基础设施资产支持证券，穿透取得基础设施项目的经营权利。此类基础设施基金投资的基础设施项目，主要为交通设施、市政设施、污染治理、清洁能源等。

> 2021年6月，我国首批试点的9只基础设施基金成立，包括产权类基础设施基金和经营权类基础设施基金，底层资产覆盖产业园区、仓储物流、收费公路和垃圾污水处理等领域。首批基础设施基金的封闭期均超过20年，最长封闭期为99年。

> 首批基础设施基金均采用"公募基金+资产支持证券"的模式向下穿透最终持有项目公司股权，部分基础设施基金还在资产支持专项计划与项目公司之间构建了SPV。

**💡 对应点**

| 故事元素 | 概念对应 |
|---------|---------|
| 买下来，房产证写名字 | 产权类：穿透取得基础设施项目的完全所有权 |
| 仓库、产业园、保障房、商场 | 产权类主要项目 |
| 既有租金又有资产增值 | 产权类收益特点 |
| 买下收费权利，地还是朝廷的 | 经营权类：穿透取得基础设施项目的经营权利 |
| 高速公路、污水处理厂、风电 | 经营权类主要项目 |
| 稳定收费现金流，到期归还 | 经营权类收益特点 |
| 2021年6月首批9只试点 | 首批基础设施基金成立时间 |
| 封闭期超过20年，最长99年 | 首批基础设施基金的封闭期 |
| 公募基金+资产支持证券模式 | 产品架构 |
| 部分构建了SPV | 资产支持专项计划与项目公司之间构建SPV |
