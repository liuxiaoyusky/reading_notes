# 一、指数基金的概念与特点

## 📜 寓言故事 —— 《按菜谱做菜的学徒》

镇上有一位老厨师，写了一本流传百年的**标准菜谱**，上面列明了每道菜的食材、分量、做法。比如"红烧肉"这道菜：五花肉一斤、酱油三勺、冰糖二两、八角三颗……步骤一、二、三写得清清楚楚。

老厨师收了一个学徒。这个学徒有个特点：他**从不自创菜式**，严格按照菜谱来做。菜谱写什么，他就做什么；菜谱说放三勺酱油，他绝不多放半勺。他的目标不是超越师傅，而是**做出和菜谱描述完全一致的味道**。

这位学徒就是**指数基金**——以特定指数为标的，通过购买该指数的全部或部分成分证券构建投资组合，以跟踪标的指数或者基准业绩表现为主要投资目标。

### 学徒的三大优点

**第一，透明。** 菜谱是公开的，谁都能看到今天做的是什么菜、用了什么料。投资者通过标的指数就能了解投资组合的信息。

**第二，分散。** 一道大菜里有十几种配料，这道菜不好吃，那道菜来补。通过投资指数中的多个证券，实现分散投资。

**第三，便宜。** 学徒不用动脑子创新，照着做就行，所以工钱（管理费）比那些爱搞创新的厨师低得多。定期按菜谱调整一下食材即可。

这就是指数基金：不追求超越市场，只求**和市场保持一致**。

---

**📖 原文定义**

> 指数基金，是以特定指数为标的，通过购买该指数的全部或部分成分券构建投资组合，以跟踪标的指数或者基准业绩表现为主要投资目标的基金产品。

> 相比主动型基金，指数基金主要有以下特点。

> 一是透明度高。指数基金因为跟踪标的指数表现，而标的指数的编制方案、成分券及其权重设置等信息都是公开透明的，所以投资者可以通过标的指数的情况了解投资组合的信息。

> 二是风险分散。指数基金通过投资于指数中的多个证券，实现分散投资。

> 三是成本低廉。指数基金采取跟踪标的指数、定期调整样本的策略，相比主动型基金管理费用通常较低。

**💡 对应点**

| 故事元素 | 概念对应 |
|---------|---------|
| 流传百年的标准菜谱 | 特定指数（标的指数） |
| 学徒严格按照菜谱做菜 | 指数基金：跟踪标的指数或基准业绩表现 |
| 菜谱公开透明 | 透明度高：编制方案、成分券、权重公开 |
| 一道菜十几种配料 | 投资于指数中的多个证券，实现分散投资 |
| 不用动脑子创新，工钱低 | 成本低廉：管理费用通常较低 |
| 定期按菜谱调整食材 | 定期调整样本的策略 |
| 不求超越只求一致 | 被动投资，不主动寻求超越基准 |
