# （三）ETF联接基金

## 🌉 寓言故事 —— 《场外的代购桥梁》

ETF魔法摊位虽好，但它开在集市上（交易所场内），要买必须得先在集市管理处开个户（证券账户）。很多老百姓觉得麻烦，或者根本不知道怎么开户。

于是有人想了个办法：在集市外面开一家"ETF代购店"——**ETF联接基金**。

这家代购店自己不直接买菜做菜，而是把绝大部分银子（不低于基金资产净值的90%）投到集市上的某个ETF摊位（目标ETF），跟着那个摊位的菜谱走。紧密跟踪标的指数表现。

代购店为没有集市账户的场外投资者提供了便捷的渠道——通过银行、独立基金销售机构就能买到。它是连接场外投资者与场内ETF的**"桥梁"**。

### 代购店和摊位的六大区别

| 对比项 | ETF联接基金（代购店） | ETF（魔法摊位） |
|--------|---------------------|----------------|
| **投资目标** | 都一样：紧密跟踪标的指数 | 都一样 |
| **运作方式** | 都一样：开放式 | 都一样 |
| **申购门槛** | 低（通常1~1000元） | 高（通常30万/50万/100万份） |
| **投资范围** | 目标ETF + 指数成分股 + 其他证券 | 指数成分股 + 其他证券 |
| **投资比例** | 投目标ETF不低于90% | 投成分股不低于90% |
| **交易渠道** | 场外：银行、证券公司、独立销售机构 | 场内：二级市场买卖 + 一级市场申赎 |
| **交易价格** | 申请当日净值（未知价，每天更新一次） | 二级市场竞价交易 / 一级市场按申赎清单 |
| **管理费** | 与目标ETF相同，但持有的ETF部分不再计提 | 标准管理费 |
| **托管费** | 与目标ETF相同，但持有的ETF部分不再计提 | 标准托管费 |
| **交易费率** | 认购、申购、赎回费率参照开放式基金 | 二级市场免印花税，收交易佣金 |
| **资金效率** | 赎回款3~4个交易日到账 | 盘中可交易，部分T+0；卖出资金当天可买股票，T+1可提现 |

### 代购店的额外好处

- **定投**：可以设置每月固定存一点，积少成多。
- **基金转换**：可以把代购店A的份额转换成代购店B的份额，灵活调整。

朝廷还有个规定：ETF联接基金的管理人不得对联接基金财产中的ETF部分计提管理费——避免对同一笔钱收两次费。

---

**📖 原文定义**

> ETF联接基金是将绝大部分基金财产投资于跟踪同一标的指数的某一ETF（称为目标ETF）、紧密跟踪标的指数表现、可以在场外（银行渠道等）申购赎回的基金。根据中国证监会的规定，ETF联接基金投资于目标ETF的市值不得低于联接基金资产净值的90%，并且ETF联接基金的管理人不得对ETF联接基金财产中的ETF部分计提管理费。

> ETF联接基金的主要特征有：
> 1. 联接基金主要投资于目标ETF。
> 2. ETF联接基金为没有证券账户的场外投资者提供了通过银行、独立基金销售机构投资目标ETF的便捷方式，被看作是连接场外投资者与场内ETF的"桥梁"。投资者通过申购联接基金，可以间接投资目标ETF。
> 3. 联接基金作为场外基金，可以提供投资者定期定额投资（定投）、基金转换等多样化的投资方式。
