# （一）按估值方法分类

## ⚖️ 寓言故事 —— 《两把算盘》

钱庄掌柜算"活期宝"的账，有两把不同的算盘。

### 第一把：摊余成本法算盘（固定净值型）

掌柜买了一张朝廷借条，面值十两，约定一年后还本付息，利息五钱。他用摊余成本法来算：每天赚多少钱是固定的——五钱除以365天，每天约1.37文。不管市场上这张借条现在值多少钱，账面上每天都按这个固定数来计。

这样算的好处是：**净值永远保持一两银子一份**，看起来特别稳。每天已实现收益要么以现金分红发给储户，要么转为新的份额。

但这里有个隐患：如果市场上这张借条突然不值钱了（比如朝廷信用出了点问题），掌柜的账面上还是按原价算，实际价值可能已经跌了。为了防范这种偏差，掌柜每天还要拨拉另一把"影子算盘"——用市场价格重新评估这张借条值多少钱。当"影子价格"和摊余成本法的偏离度达到一定阈值时，掌柜必须采取措施：调整偏离度、暂停申购、用风险准备金垫付、或者直接改用市值法。

### 第二把：市值法算盘（浮动净值型）

另一位掌柜更实在：每天按市场上这张借条的真实价格来算。今天值十两零五钱，净值就是十两零五钱；明天值九两八钱，净值就是九两八钱。不掩盖波动，如实反映。

这把算盘的好处是：**透明度高**，资产价格波动实时反映在每日净值中，降低了因估值偏差引发的赎回踩踏风险。但坏处也明显：净值会波动，不再是一两银子一份了，追求"本金安全"的储户可能接受不了。

### 对比

| 维度 | 固定净值型（摊余成本法） | 浮动净值型（市值法） |
|------|----------------------|-------------------|
| 净值 | 恒定为面值 | 随市场波动 |
| 收益显示 | 每万份收益、7日年化 | 基金份额净值、累计净值 |
| 优势 | 净值稳定、收益确定感强 | 透明度高、降低赎回踩踏风险 |
| 风险 | 极端情况下可能暴露估值偏差 | 净值波动、投资者心理压力大 |

传统上，固定净值型因为"看起来稳"吸引了大量投资者。但2018年《资管新规》后，监管鼓励发展浮动净值型，打破"刚兑幻觉"。

---

**📖 原文定义**

> 按照估值方法，货币市场基金可分类为：固定净值型和浮动净值型两大类。与固定净值型相适配的估值方法为摊余成本法，与浮动净值型相适配的估值方法为市值法。

> 固定净值型货币市场基金采用摊余成本法对持有的投资组合进行会计核算，并于估值日对外披露经托管人复核一致的每万份基金已实现收益和7日年化收益率。将其每日已实现收益以现金分红的方式转为应付利润或者以分红转投的方式转为基金份额，从而确保其基金份额净值始终保持与面值相等。

> 为了避免采用"摊余成本法"计算的基金资产净值与按市值法计算的基金资产净值发生重大偏离，基金管理人于每一估值日采用估值技术进行重新评估，即"影子定价"。当"影子定价"与摊余成本法的偏离度达到一定阈值时，基金管理人应在规定时间内采取措施。

> 浮动净值型货币市场基金采用市值法对持有的投资组合进行会计核算，在不晚于估值日的次日对外披露基金份额净值和基金份额累计净值。

> 传统摊余成本法估值的固定净值型货币市场基金通过平滑资产价格波动，提供了净值稳定和收益确定的优势。然而，在市场极端情况下，存在大额赎回可能迫使基金抛售资产的情况，使得其真实市场价格与摊余成本估值之间的差异将被暴露，从而引发流动性风险和赎回踩踏效应。

> 浮动净值货币市场基金采用市值法估值，资产的市场价格波动和损益实时反映在每日净值中，提高了透明度，降低了因估值偏差引发的赎回踩踏风险，但同时也意味着基金净值会因市场利率和资产价格波动而产生波动。

**💡 对应点**

| 故事元素 | 概念对应 |
|---------|---------|
| 第一把摊余成本法算盘 | 固定净值型货币市场基金：摊余成本法 |
| 净值恒定为面值 | 基金份额净值始终保持与面值相等 |
| 每万份收益、7日年化 | 固定净值型披露指标 |
| 影子算盘 | 影子定价：用市值法重新评估 |
| 偏离度达阈值采取措施 | 调整偏离度、暂停申购、用风险准备金、调整估值方法 |
| 第二把市值法算盘 | 浮动净值型货币市场基金：市值法 |
| 次日披露净值 | 不晚于估值日次日披露基金份额净值和累计净值 |
| 固定净值型优势：稳 | 净值稳定、收益确定 |
| 固定净值型风险：极端赎回暴露偏差 | 流动性风险和赎回踩踏效应 |
| 浮动净值型优势：透明 | 提高透明度、降低赎回踩踏风险 |
| 浮动净值型劣势：波动 | 净值会因市场利率和资产价格波动 |
