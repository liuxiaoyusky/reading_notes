# 07、私募基金依投资对象分类

## 🏺 寓言故事 —— 《周记账房的五种钱袋》

一九五二年的上海，十六铺码头往西三条巷子里，有一间不起眼的"周记账房"。账房主人周慎之是前清秀才出身，做过私塾先生，后来下海给街坊们管钱。说是管钱，其实就是把几位老主顾的家底儿拢在一起，替他们做点稳妥的安排——什么时候该把钱放出去、什么时候该收回来，都由他一个人说了算。

找他管钱的有这么几家：开纱厂的陆先生，开绸缎庄的孙夫人，南洋回来做橡胶生意的陈老板，还有松江的几位老地主。每个人手里的钱不一样，性子也不一样：陆先生的钱来得急、用得也急，恨不得今天进货明天就能卖出去；孙夫人的钱是要留给女儿出嫁的，慢吞吞的，十年八年不能动；陈老板的钱是到南洋买橡胶树的，三五年不回来属正常；老地主的就更慢了，是留给孙子的，能放在地窖里一百年不挪窝。

周慎之从前只有四个口袋，分门别类装钱，倒也井井有序。可这一年春天，麻烦来了。

先是南洋那边的橡胶价突然腰斩。陈老板的钱没回来，他派去的人回来说，海上船沉了一艘，剩下的还在漂。本来说好三年回本的，如今五年都没个影儿。陈老板急得像热锅上的蚂蚁，每隔两天就派伙计来问："周先生，我的钱呢？"

接着是陆先生的纱厂。朝鲜那边打起来了，美国人的船堵了上海港，棉花进不来，纱出不去。纱厂停工了三个月，工人要吃饭，机器要上油，仓库里堆着卖不出去的布。陆先生的钱本来指望半年周转一次，现在被死死地摁在了仓库里。

最让周慎之头疼的是孙夫人。孙夫人的女儿年底要出嫁，这是十年前就定好的事。可那十年里，钱生钱的速度根本赶不上物价上涨的速度。原本攒够的一份嫁妆，如今只够办一桌酒席。孙夫人哭哭啼啼地来问："周先生，我的钱呢？"

周慎之关上账房的木门，一个人坐在那里，盯着那四个口袋发了半天呆。

四个口袋里的钱，原本都长着一样的脸——都是"信托"二字。可眼下，他忽然明白，钱和钱不一样，钱要去的地方不一样，钱能等的时间也不一样。把它们都装在四个口袋里，像把四条腿长短不一的狗拴在同一棵树上，谁也跑不了，谁也跑不快。

那晚他没回家。他翻遍了祖父传下来的那本老账，又托人从南洋带回来几本新式的簿子。第二天清早，他把四个口袋变成了五个。

第一个口袋，他只装"马上能拿回来"的钱——比如国库券、比如银行短期存折。钱放进去，最短一周，最长不超过一年。陆先生工厂周转不开时，就从这个口袋里拿。这口袋他叫"日日通"，意思是今天能取、明天还能取，门槛极低，进出最自由。

第二个口袋，他只装"借出去收利息"的钱——比如松江几位地主的田契、比如几家老字号的借条。钱放进去，一年两年不动，到期收回本金和利息。孙夫人的女儿要出嫁，这钱就是从这口袋里出的——慢是慢了点，但稳当。

第三个口袋，他只装"出海去找机会"的钱——比如陈老板那笔投去南洋买橡胶树的本钱。钱放进去，三年五年不见人，回来时可能翻倍，也可能打了水漂。陈老板的钱就是从这个口袋出去的——急不得，也停不得。

第四个口袋，他留出来装"什么都沾一点"的钱。陆先生有，孙夫人有，陈老板也有，凡是上面三个口袋都不太合适放的钱，就都往这里头搁。放多少没死规矩，赚了大家分，亏了大家摊。这口袋他叫"杂拌儿"，意思是没什么个性，但胜在面面俱到。

第五个口袋，是他新加的，也是最让他得意的。他把这口袋叫"钱袋子的钱袋子"——他不直接放钱，而是把前四个口袋各抄出一部分，再把街坊其他账房里的好口袋也凑一凑，放在一起。这个口袋自己不做事，它做的事是挑别的好口袋。这种钱最慢，可能十年八年都不动一次，可一旦动起来，分的是别人家口袋里的红利，自己不用再操心哪个橡胶园涨了、哪条田埂塌了。

"周先生，这第五个口袋跟那四个不一样啊。"陆先生第一次听他讲完，有些迟疑。

"是不一样。"周慎之笑了一下，"前四个口袋，是我自己下场干活——买什么、卖什么、什么时候进、什么时候出，都得我盯着。第五个口袋，我不下场，我只挑谁下场。我把活儿交给信得过的别人去做。"

孙夫人倒是立刻听懂了："那我这嫁妆钱，能不能也放一点进去？"

"能。您的性子，最适合这个口袋。"周慎之说，"您不必管谁在替您干活，您只管十年后这口袋里的钱比您放进去时多就行。至于那干活的人行不行、靠不靠谱、出了事怎么办——那是第五个口袋该操心的事，不是您该操心的。"

陈老板更是乐了："周先生，您这是要开个'钱庄的钱庄'啊。"

"不敢这么说。"周慎之把五个口袋按顺序摆在账桌上，"我只是个替街坊看钱的人。看钱这门手艺，窍门不在钱多钱少，而在分得清。分得清哪些钱该快、哪些钱该慢、哪些钱该挑人干，自己才不会乱。"

那年腊月，十六铺的街坊们聚在周记账房里分红。五个口袋摆成一排，从"日日通"到"杂拌儿"再到最里头的"钱袋子的钱袋子"，清清楚楚。陆先生拿了急用的钱去救活纱厂；孙夫人的女儿体体面面出了嫁；陈老板的钱没回来，但他心里踏实，因为他知道那笔出海的钱，去了它该去的地方。

散场时，孙夫人问周慎之："周先生，您这五个口袋的规矩，是您自己想的？"

周慎之摇摇头："是我这一年被人问'我的钱呢'问出来的。"

他顿了顿，又说："再好的管家，也得有分钱的本事——分得清钱该去哪，钱才能替钱说话。分不清，再多钱也只是一堆钱。"

那年冬天，十六铺下了场少见的大雪。周记账房的木门上，第二天被人贴了一副新对联：

上联：**一个账房，五种口袋**；
下联：**各路银子，各归其位**。

横批：**分得清**。

---

**📖 原文定义**

> 2024年4月发布的《私募证券投资基金运作指引》规定私募基金分为权益类、固定收益类、期货和衍生品类、混合类，以及私募证券投资母基金。
>
> 权益类私募基金，是指投资于股票等股权类资产的比例不低于私募基金已投资产80%的基金，已投资产不包含现金管理工具（下同）。现金管理工具是指银行活期存款、国债、中央银行票据、政策性金融债、地方政府债券、货币市场基金等中国证监会认可的现金管理工具。
>
> 固定收益类私募基金，是指投资于存款、债券等债权类资产的比例不低于私募基金已投资产80%的基金。
>
> 期货和衍生品类私募基金，是指投资于期货和衍生品的持仓合约价值的比例不低于私募基金已投资产80%，且期货和衍生品账户权益超过私募基金已投资产20%的基金。
>
> 混合类基金，是指投资于固定收益类、权益类、期货和衍生品类资产的比例不符合前三类基金标准的基金。
>
> 私募证券投资母基金，是指组合投资于其他基金的比例不低于该私募证券投资母基金已投资产80%的基金。

**💡 对应点**

| 故事元素 | 概念对应 |
|---------|---------|
| 周记账房、私下给老主顾管钱、靠信任而非招股 | 私募基金——非公开募集、合格投资者 |
| 四个口袋变五个口袋的过程 | 私募基金按投资对象分类的依据 |
| "日日通"口袋——存银行短期、国库券、进出自由 | 现金管理工具——存款、国债、央票、政策性金融债、地方政府债、货币市场基金等 |
| 第二个口袋——存田契、借条、慢但稳 | 固定收益类私募基金——主要投资于存款、债券等债权类资产（80%以上） |
| 第三个口袋——出海买橡胶树、三年五年不见人 | 权益类/出海类私募基金——投资于股权类资产（80%以上） |
| "杂拌儿"口袋——什么都沾一点、比例不固定 | 混合类私募基金——不符合前三类标准的基金 |
| 第五个"钱袋子的钱袋子"——自己不下场，挑好口袋投资 | 私募证券投资母基金——80%以上资产投资于其他基金份额 |
| 各家主顾的钱性子不同（急用、慢用、留给孙辈） | 不同投资者的资金属性与风险收益需求 |
| 周慎之"分得清"三个字 | 私募基金按投资对象分类的核心意义——把钱分到该去的地方 |
| 散场时五种口袋分门别类分红 | 私募基金分类的本质——按主投方向把钱分清楚 |
