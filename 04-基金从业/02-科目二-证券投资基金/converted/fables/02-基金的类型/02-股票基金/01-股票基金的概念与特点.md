# 一、股票基金的概念与特点

## 🎯 寓言故事 —— 《种果树的老农》

村里有个老农，他决定不种粮食了，专门种果树。苹果树、梨树、桃树……他的地里八成以上都是果树。

老农的目标很明确：**长期收获果实**。他知道，果树从种下到丰产需要好几年，中间要浇水、施肥、剪枝，不能急于求成。但一旦进入丰产期，收益就源源不断。

种果树的风险不小：遇上干旱、虫害、霜冻，一年可能颗粒无收。但相应的，如果年景好，收成也远比种粮食高。村民们都知道：**高风险、高收益**。

老农的果园还有一个好处——抗通胀。粮价涨了，水果价也涨；钱贬了，果树还在那，年年结果。所以，准备给孩子攒学费、给自己攒养老钱的村民，都喜欢把银子交给老农，让他帮忙种果树。这是**长期的资本增值**。

买股票基金就像投钱给老农种果树——追求的是长期增值，能承受短期波动，用来满足教育、养老等远期支出，也是应对通货膨胀的有效手段。

按照朝廷的规定，如果一个基金把**八成以上的银子都投在股票（果树）上**，那它就是**股票基金**。

---

**📖 原文定义**

> 股票基金主要以股票为投资对象，根据中国证监会对基金类别的分类标准，80%以上的基金资产投资于股票的为股票基金。

> 股票基金以追求长期的资本增值为目标。与其他类型基金相比，股票基金风险较高，但预期收益也较高。股票基金提供了一种长期投资增值性，可供投资者用来满足教育支出、退休支出等远期支出需要，同时也是应对通货膨胀有效的手段之一。对于股票基金，投资者需主要关注基金的投资策略、投资风格及基金的长期业绩等因素。

**💡 对应点**

| 故事元素 | 概念对应 |
|---------|---------|
| 专门种果树 | 主要以股票为投资对象 |
| 八成以上都是果树 | 80%以上基金资产投资于股票 |
| 长期收获果实 | 追求长期的资本增值 |
| 干旱虫害风险大但收成也高 | 风险较高，但预期收益也较高 |
| 攒学费、养老钱 | 满足教育支出、退休支出等远期支出需要 |
| 抗通胀 | 应对通货膨胀有效的手段之一 |
| 关注老农怎么种、种什么品种 | 关注投资策略、投资风格及长期业绩 |
