# 二、股票与股票基金的区别

## 🍎 寓言故事 —— 《一棵苹果树 vs 一片果园》

村民老李有两条路可以投资果树。

### 路一：自己买一棵苹果树

老李花十两银子买了一棵苹果树。这棵树是他的，他想怎么打理就怎么打理。
- **价格**：今天十两，明天可能有人出价十二两，也可能只出八两——价格随市场供求变化，实时波动。
- **收益**：树上的苹果归他，卖苹果的钱也归他。但如果这棵树得了病，或者品种过时了，他可能就亏了。
- **风险**：全部押在这一棵树上。树倒了，血本无归。

这就是**买股票**——买一家公司的股份，价格实时波动，收益和风险都集中在这家公司上。

### 路二：投钱给老农的果园

老李也可以把十两银子交给老农，老农的果园里有几十棵不同品种的果树。
- **价格**：每天收盘后，老农算一算整个果园值多少钱，除以总份数，就是每份的"净值"。这个价格一天只算一次。
- **收益**：果园整体的收成分给所有投资人。某棵树歉收了，其他树可能丰收，总体收益更平稳。
- **风险**：分散在几十棵树上，一棵树的病不会毁掉整个果园。

这就是**买股票基金**——买一篮子股票的组合，每天收盘后计算净值，风险和收益都分散了。

### 关键区别

| 比较维度 | 单一股票 | 股票基金 |
|---------|---------|---------|
| **价格** | 实时波动 | 每日收盘后计算净值 |
| **收益** | 取决于一家公司 | 取决于一篮子公司的组合表现 |
| **风险** | 集中 | 分散 |
| **决策权** | 你自己决定买卖哪家 | 基金经理帮你选股 |

老李想了想，自己不懂果树，还是交给老农更省心。

---

**📖 原文定义**

> 作为一篮子股票组合的股票基金，与单一股票之间存在许多不同。

> 股票价格会实时波动，受市场供求、公司基本面、宏观经济等多种因素影响；而股票基金的价格（净值）一般每日收盘后计算一次。

> 单一股票的收益完全取决于该股票所属公司的经营表现；股票基金的收益则取决于基金所持一篮子股票的整体表现。

> 单一股票投资风险集中；股票基金通过投资多只股票分散了单一股票的风险。

**💡 对应点**

| 故事元素 | 概念对应 |
|---------|---------|
| 自己买一棵苹果树 | 买股票 |
| 价格今天十两明天八两 | 股票价格实时波动 |
| 收益取决于这棵树 | 收益取决于一家公司 |
| 全部押在一棵树上 | 风险集中 |
| 投钱给老农的果园 | 买股票基金 |
| 每天算一次果园净值 | 基金净值每日收盘后计算 |
| 几十棵不同果树 | 一篮子股票组合 |
| 一棵树歉收其他可能丰收 | 分散风险 |
