# 一、衍生工具的定义

## 🏺 寓言故事 —— 《影子契约》

镇上的米商老赵，每年秋收都要大量收购稻谷。旁人都羡慕他生意大，可老赵自己知道——这买卖一年到头悬着心。

去年丰收，谷子堆成山，米价反倒跌下去，跌得连雇工钱都差点凑不齐。今年开春又赶上大旱，眼看着价要往上窜，可老赵手头没囤货，涨了也赚不着——**他担心的不是稻谷，是稻谷价格**。今年涨明年跌，明年涨后年跌，十年里有八年他睡不踏实。

这天，镇上来了个外乡人，自称是帮商户"对冲"风险的账房先生。这名字老赵头回听说，琢磨了半天也不太懂，只当是账房那路人。

账房先生在老赵的米行里坐下，喝了口茶，慢慢说道："赵老板，你怕的不是没米，是**米价**。今年天旱，市价一两五，你若按一两三签了明年的收购合同，等于把价格锁死——涨了你亏，跌了你赚。反过来也行：明年市价一两二，你按一两四签，明年米价跌了你省一笔。**签合同的本质，是你和我赌明年的米价往哪边走**。"

老赵听得半懂，账房先生又补了一句："咱们赌的不是稻谷。稻谷一斤都没动过——咱们赌的，是稻谷**价格**这件影子。"

老赵愣了一下："影子？"

账房先生拿起桌上的筷子，在茶杯里蘸了点水，在桌面上画了个圈："稻谷是实在的东西，但**稻谷的价格，是个影子**——它是稻谷的影子，跟在稻谷后面晃。影子打哪儿跟哪儿，咱们赌的是这玩意儿。"

老赵笑出声来："你这比喻倒有意思。可我要是赌错了怎么办？"

"赌错了，按契约赔钱——一两银子一两银子算。但咱们谁都不碰真正的稻谷，只赌这影子的变化。**签这种'影子契约'，买的不是稻谷，是稻谷价格的风险**。"

账房先生接着解释了几个老赵原本不知道的名字：

"**这种影子契约，就叫衍生工具**——它是从稻谷这种'基础资产'里**衍生**出来的工具。稻谷在这里被称作'合约标的资产'，价格涨跌是**风险的来源**。我买契约，就是看好价格往上走，叫**多头**；你卖契约，就是赌价格往下走，叫**空头**。"

"还有，**契约有明确的到期日**。到期那天，咱们按当时市价算账，多退少补。"

老赵想了想，问了一句关键的："账房先生，你这一路帮我锁住价格风险，你图啥？"

账房先生笑了："赵老板，我赌的是你赌错的那一面。你要是不怕涨，我就是赌涨的那个人；你要是不怕跌，我就是赌跌的那个人。**风险从你手里转到我手里，咱们各自承担**——不靠谁发善心，靠契约上白纸黑字的赔钱规矩。"

老赵当天夜里把这笔账在油灯下重新算了一遍。一份影子契约，价格定在一两三（他心里能接受的中间价）。不管明年米价涨到一两八还是跌到九两，他这一船稻谷的成本都被锁在一两三上下——涨了他少赚点，跌了他少亏点，**最坏也不过是少赚，不是赔光**。

他合上账本，忽然想起个问题："账房先生，你说这跟保险有点像——"

"是有点像，"账房先生点头，"都是把风险从怕的人手里转给敢担的人手里。但**保险保的是已经发生的事故，赌的是万一**；**衍生工具赌的是还没发生的价格变化**。一个看'会不会出事'，一个看'会往哪边走'。"

"懂了，"老赵说，"一个是病，一个是天气。"

账房先生点头："赵老板这个比喻，我自己都想不出来。"

老赵签下这份影子契约的那晚，米行里难得安静——他睡了十年来最踏实的一觉。**不是因为风险没了，而是因为这回他知道风险在谁手里，自己手里这头被圈住了**。

**📖 原文定义**

> 衍生工具（Derivatives）是由基础资产（股票、债券、货币或商品等）衍生而来的金融工具。衍生工具的价值取决于一种或多种基础资产，这些基础资产通常被称作"合约标的资产"。合约标的资产可以是黄金、原油等贵金属或大宗商品，也可以是股票、债券、货币等金融资产。常见的衍生工具有远期合约、期货合约、期权合约和互换合约等。

> 衍生工具和保险类似，均具有风险管理功能，但其风险转移机制与保险有本质区别。衍生工具的标的资产价格是风险的来源。常见的衍生工具的标的资产是股票、债券、货币和商品，但有的衍生工具的标的资产是利率、信贷、能源、天气，甚至是其他衍生品，这些标的并不一定被认为是传统资产。衍生工具通常有明确的存续期和指定的到期日，并以合同形式确立，合同定义了相关方的权利和义务。购买衍生品的买方被称为"多头"，持有多头头寸；卖方则被称为"空头"，持有空头头寸。

**💡 对应点**

| 故事元素 | 概念对应 |
|---------|---------|
| 影子契约 | 衍生工具 |
| 真正的稻谷 | 基础资产/合约标的资产 |
| 稻谷价格涨跌 | 风险的来源 |
| 老赵把价格风险转给账房先生 | 风险转移机制 |
| 老赵（买方） | 多头 |
| 账房先生（卖方） | 空头 |
| 契约有到期日 | 明确的存续期和到期日 |
