# 三、货币互换

## 🏺 寓言故事 —— 《铜币与银元的婚约》

泉州城有个绸缎商叫林远舟，祖上三代经营丝绸，生意铺到了南洋。去年秋天，他在马六甲订了一船香料，对方只收银元，而且要三个月后货到付款。林远舟手里攥着的全是铜钱，去钱庄兑银元，掌柜把算盘拨得噼啪响，最后报出一个价比市价高出两成。林远舟咬咬牙，还是把合同签了——香料不等人。

同一时候，马六甲有个橡胶园主叫阿米尔，祖辈种胶，想趁泉州绸缎价低的时候囤一批货，可他手里只有银元，而泉州的钱庄见他是个外乡人，兑换铜钱的汇率也黑得吓人。两人各自在对方的地盘上吃了哑巴亏，却都不知道世上有另一个人，正和自己承受着同一种委屈。

转机出现在一个暴雨夜。泉州港的老船夫周把式在码头酒馆避雨，听林远舟倒完苦水，又碰巧在另一桌遇见了来泉州采买绸缎的阿米尔的手下。周把式跑了一辈子船，脑子里装的不是账本，是人情和门道。他端着酒壶凑过去，三言两语就听出了门道：这两个人，一个在银元市场上被人宰，一个在铜钱市场上被人宰，可要是把他们拧到一块儿呢？

第二天，周把式把两人约到了天后宫的后院。林远舟和阿米尔面面相觑，语言不通，全靠周把式比划着传话。

"林老板，你在泉州借铜钱，利息多少？"
"三分利，固定。"
"阿米尔，你在马六甲借银元，利息多少？"
"也是三分，但跟着市面的浮动利率走。"

周把式一拍大腿："巧了！我打听过了，林老板你要是去马六甲借银元，人家只认本地熟脸，给你的浮动利率要加二厘。阿米尔你要是来泉州借铜钱，人生地不熟，固定利率得加到四分五。可反过来——林老板你在泉州借铜钱，三分利轻轻松松；阿米尔你在马六甲借银元，三分浮动也是老主顾的价。你们各自在自家门口便宜，到了对方门口就挨宰，这叫什么？这叫老天爷给你们留了一道门缝，就看你们推不推。"

林远舟和阿米尔对视一眼，都从对方眼里看出了光。

周把式趁热打铁："这样，林老板你在泉州以三分固定利借入铜钱，阿米尔你在马六甲以三分浮动利借入银元。借到之后，按现在的汇率把本金互换——林老板拿银元去付香料款，阿米尔拿铜钱去囤绸缎。往后每半年，林老板替阿米尔付铜钱的固定利息，阿米尔替林远舟付银元的浮动利息。三年期满，再把本金按原汇率换回来。我周把式跑个腿，收你们一点茶水钱。"

阿米尔迟疑："万一三年后汇率变了怎么办？"

周把式笑了："婚约都按成亲那天的价，哪有三年后翻旧账的？你们互换的时候锁了汇率，三年后还按这个数换回来，各不相欠。"

林远舟却想到了另一层："等等，我付的是银元浮动利息，可我原本想借的是固定利的银元啊。"

周把式摇头："林老板，您要的是银元，至于是固定还是浮动，那是衣裳的里子，不是面子。您想想，您直接借银元要SOFR加二厘，现在通过阿米尔只付SOFR，里外里省了二厘。阿米尔也一样，他直接借铜钱要四分五，现在通过您只付三分，省了一厘五。你们俩合起来省下的，分我一点跑腿钱，剩下的各自揣兜里，谁也没吃亏。"

契约签下的那天，天后宫的香火格外旺。三年后，林远舟的香料生意翻了一番，阿米尔囤的绸缎在泉州卖了个好价。两人在码头告别时，阿米尔用刚学会的蹩脚官话说了一句："下次，还换。"

周把式蹲在船头抽旱烟，看着两个商人远去的背影，对身旁的小徒弟说："看见没有？铜钱和银元，隔着一片海，各守各的地盘。可只要找对了人，把各自家门口的便宜串起来，就能搭一座桥。这桥不是我搭的，是比较优势搭的。我不过是那个把两块拼图凑到一块儿的人。"

小徒弟问："师父，要是他们中途有人反悔呢？"

周把式磕了磕烟灰："所以得立字据，按手印，找保人。这叫信用风险。这世上没有白得的便宜，只有算得清的账。"

**📖 原文定义**

> 货币互换（Currency Swap），是指互换合约双方同意在约定期限内按相同或不同的利息计算方式分期向对方支付由不同币种等值本金额确定的利息，并在期初和期末交换本金。

> 与利率互换的不同之处在于，货币互换中双方要以不同货币支付利息及本金，所以在每一个阶段双方都要以不同货币支付现金利息给对方，而不是只有一方支付现金给另一方。根据利息支付方式不同，货币互换可分为三种形式：（1）固定对固定，即将一种货币的本金和固定利息与另一种货币的等价本金和固定利息进行交换；（2）固定对浮动，即将一种货币的本金和固定利息与另一种货币的等价本金和浮动利息进行交换；（3）浮动对浮动，即将一种货币的本金和浮动利息与另一种货币的等价本金和浮动利息进行交换。

> 货币互换产生的主要原因是双方在各自国家中的金融市场上具有比较优势。

**💡 对应点**

| 故事元素 | 概念对应 |
|---------|---------|
| 林远舟（泉州绸缎商） | A公司 |
| 阿米尔（马六甲橡胶园主） | B公司 |
| 铜钱 vs 银元 | 两种不同货币 |
| 林远舟在泉州借铜钱便宜、借银元贵 | A公司在欧元市场有比较优势 |
| 阿米尔在马六甲借银元便宜、借铜钱贵 | B公司在美元市场有比较优势 |
| 各自在本地借钱后互换本金 | 期初交换本金 |
| 林远舟拿银元付香料款 | 获得所需币种资金 |
| 互相替对方支付利息 | 期中交换不同币种利息 |
| 三年期满按原汇率换回本金 | 期末再交换本金 |
| 周把式撮合交易、收茶水钱 | 银行中介赚取利差 |
| 固定利铜钱 vs 浮动利银元 | 固定对浮动货币互换 |
| 锁定的汇率三年后不变 | 货币互换按约定汇率交换本金 |
| 双方各自降低融资成本 | 比较优势带来互换利益 |
