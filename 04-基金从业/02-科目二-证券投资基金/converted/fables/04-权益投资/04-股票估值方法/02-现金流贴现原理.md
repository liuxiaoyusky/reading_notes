# 02、现金流贴现原理

## 🏺 寓言故事 —— 《老周的米行账》

一九五二年初春，十六铺码头边的青石板还泛着湿光。德兴米行的老周坐在铺子门口，面前摊着三本账册，每一本都记着数字，眉头却越锁越紧。

事情是这样的：老周有个老主顾，在南市开着三爿米店，姓孙，人称"孙半城"。孙半城年纪大了，想把米店连同仓栈、地契、招牌，一股脑儿卖给老周，作价三千块银元。老周有心买下，可三千块到底是贵是便宜，他没底。

孙半城急了，撂下一句狠话："周兄若不要，三日后我去寻张老板，他已开到三千五。"老周不答话，挥手让伙计先送客，转身进了里屋，把门一关，三天没出门。

头一天夜里，老周从柜底翻出孙半城这五年交下来的租簿——孙半城租他的仓栈，每年付租银。孙半城三爿米店每年净赚多少，老周心里大致有数。可账不能这么算，他提笔写下："未来的钱，不是今天的钱。"

他接着写下第二行："明年的十块银元，搁到今天，只能算五块；后年的十块，搁到今天，只能算三块。"这道理他懂——码头上的船老大陈四，去年借他一百块去做大豆，今年还他一百一十块，整整十个月，那十块就是这一年的"借用代价"。而码头上的行当一年一个样，货有起落，船有凶险，凶险越大，这"借用代价"就越高，越稳当的买卖，"借用代价"就越低。孙半城的米店稳当得很——十六铺的老主顾三代人吃他家的米，从来没断过货——老周就按"借用代价"算得低一些；可毕竟年头一长，谁也说不准，就又往上抬一点。

老周就这样，把孙半城未来十年——不，十五年——能揣进腰包的银子一笔一笔写下来：头一年四百，第二年四百三十，第三年四百七十……再扣掉雇工、缴税、添置麻袋、修缮仓栈，剩下能"自由"花用的银子，从今年往后排，逐年递减着往账上摆。摆完，再一笔一笔地折回今天，加在一起。

他算了又算，纸上的数字来回跳动。到了第三天清晨，老周终于搁下笔，纸上只剩一个数——两千八百块。

他对着这个数发了半天呆。差两百块才到三千，可这"两千八"，已经是他把孙半城往后十五年每一年能赚到的钱、剔除所有该花销的钱之后、按十六铺最稳当的米行算出来的"借用代价"折扣到今天、再一笔一笔加起来的总和。换句话说：孙半城这爿米店今天到底值多少，不看张老板喊的价，也不看孙半城自己开的价，得看往后十五年他能赚到手的真金白银折回来还剩多少。

老周把三本账册合上，叫来小周："去请孙半城来。我出两千八。"小周一愣："爹，张老板三千五，咱们两千八，孙半城肯卖？"老周笑了："张老板看的是'今天'，我看的是'往后'。孙半城肯不肯，得看他信不信我算的这本账。"

孙半城到底还是来了。他一进门便拍桌子："周兄，两千八！你这是趁人之危！"老周没急，把三本账册摊开："老孙，你自己看——这十五年，你每年能揣进腰包的银子，我都按十六铺最稳当的米行折扣到今天。加在一起，就是两千八。"

孙半城看着账册，看了半天，叹了口气："周兄，你这账我服。可你这一加一减，凭什么就该是两千八？"

老周指了指窗外黄浦江上来来往往的货船："你看这江上的船。今天从十六铺出发的船，要去的地方不一样，有的去吴淞口，有的去武汉，有的去宁波。走多远的水路，船上要装多少货，水手要吃多少粮——这些加在一起，才是这一趟船的'花销'。你的米店也一样，雇工、缴税、添袋、修仓，这些是花销。花销之后的银子，按十六铺最稳当的米行折扣到今天，加在一起，就是你这爿米店今天该值多少。"

孙半城沉默良久，最后一咬牙："两千八就两千八。"

契书签下的那天，十六铺的春雨又下起来了。老周站在铺门口，看着孙半城佝偻着背走远的背影，对小周说："做米行的人，最忌讳'看今天'。今天的市场价，是别人嘴里喊出来的；今天值多少钱，得自己算——算明天能赚多少，算明天能留多少，再一笔一笔折回来加在一起。这本账算清了，今天的价才看得清。"

小周点点头，第一次觉得父亲那本旧账册，比十六铺码头上所有的喧嚣都重。

---

**📖 原文定义**

> 股票绝对估值法认为，股票价值体现在其未来能够给股东带来的现金流，将所有现金流折现到当前即为股票价值。由此可见，绝对估值法是直接从公司股权价值的内在驱动因素出发对股票进行价值评估。

> 贴现率是预期现金流量风险的函数。风险越大，现金流的贴现率越大；风险越小，则资产贴现率越小。

> 由于未来收益及市场利率的不确定性，各种价值模型计算出的"内在价值"只是股票真实内在价值的估计。

**💡 对应点**

| 故事元素 | 概念对应 |
|---------|---------|
| 老周估算孙半城未来十五年能"自由"花用的银子 | 预测未来各期现金流（DDM/FCFE/FCFF 共同基础） |
| 把往后十五年的银子一笔一笔折回今天再相加 | 现金流贴现原理：将未来现金流折现求和得到现值 |
| 码头上的行当越凶险，"借用代价"越高 | 贴现率 = 预期现金流量风险的函数 |
| 孙半城米店稳当，折扣打得低 | 风险越小，贴现率越小 |
| 未来十五年逐年递减着往账上摆 | 现金流的时序价值（货币时间价值） |
| 扣掉雇工、缴税、添袋、修仓后再算 | 自由现金流概念——扣除必要营运与再投资 |
| 老周算出"两千八" | 股票的内在价值：未来现金流现值之和 |
| 张老板喊三千五、孙半城自己开三千 | 市场价格 vs 内在价值（市场价格围绕内在价值波动） |
| "今天值多少钱，得自己算" | 内在价值是估计值，需自行评估 |
| 老周看的"明天"=孙半城往后十五年 | 评估内在价值需立足长期基本面 |
