# 21、收益与风险特性不同

## 🏺 寓言故事 —— 《两袋米的归途》

一九五二年的春天，上海十六铺码头上，米行的招牌一面挨着一面。靠江那一排，是永泰米行；往东拐过一条弄堂，是通合米行。两家相距不过三十步，做的事却全然不同。

码头上有个挑担子的老关，三十出头，靠替人跑船、搬货挣点脚钱。他把大半年的积蓄换成两袋白米，一袋扛进了永泰米行的仓库，另一袋托人捎去了通合米行。朋友阿炳问他："你把米往两家放，做什么？"

老关抹了把汗说："永泰的掌柜说，粮寄在他那儿，年底按八分给我粮息，米一粒不会少。通合的掌柜说，他替我把米放到长江沿线的米市上去做买卖，赚了钱按月结给我，赔了也实打实告诉我。两条路都试试，看看年底哪个划算。"

阿炳笑他："放着稳稳当当的粮息不拿，非要跟通合去冒那门子的险。"

老关没接话。

到了秋天，长江中游遭了水灾，粮船多半困在汉口。通合米行传来消息：老关那袋米跟着船队漂了两个月，有一船沉了底，亏了三成；另一船虽然到了镇江，可市价一落千丈，又折了一成。掌柜把账目一笔一笔写在信里，连同退回的七成米一起，差人送到了老关家里。

消息在码头上传开，阿炳拍着大腿乐："我说什么来着！永泰那袋米稳稳当当赚八分，你通合这袋米倒好，赔进去三成！"

老关没吭声。他打开永泰米行送来的条子：白纸黑字写着"本息合计两袋零一斗六升"。他转身又打开通合米行寄来的信：里头除了那袋米，还夹着沿途每一站的米价、每一次转手的开销、一条船沉没的日期和赔付的清单。

冬天到了，北方大熟，镇江的米价一夕之间翻了一番。通合米行的人找上门来，说年前还有一趟船要发，问老关愿不愿意把退回的七成米再放进去，"利钱到年后再结"。阿炳跑来劝："别折腾了，永泰那边已经稳赚八分，你还想咋的？"

老关沉默了很久，终于说："我想看看，那袋米最后能变成多少。"

他把退回的米重新交给了通合。

第二年开春，消息传来：那袋米跟着船队一路北上，赶上北地粮价奇高，整船卖出去了。通合米行的掌柜亲自登门，把账本摊开——除去船钱、仓租、人工，最后剩下来的，折成米，足足比原来多了一倍。老关在账本上摁了指印，掌柜转身就走，临走撂下一句话："明年还做不做？"

老关说："做。"

阿炳听说后，闷了半天，最后冒出一句："我那袋米，明年也从永泰挪出来。"

老关摇头："你别挪。你我不一样。你家里有老有小，等米下锅；我一个人，光棍一个，输得起。永泰那袋米，年年给你八分，稳得像黄浦江的潮水；可通合这袋米，潮起时能冲上天，潮落时也能打湿脚。两种米，两种命。"

他望向码头，永泰的招牌在春风里纹丝不动，通合的船队却正扯起新帆，慢慢驶向江心。

江水东去，米还在船上颠着。

---

**📖 原文定义**

> 基金收益具有一定的波动性，存在亏损风险；银行存款利率相对固定，投资者损失本金的可能性也很小。

**💡 对应点**

| 故事元素 | 概念对应 |
|---------|---------|
| 老关把米托给通合米行做买卖 | 证券投资基金——独立资产管理产品，盈亏随市场波动 |
| 永泰米行承诺"米一粒不会少，年底八分粮息" | 银行储蓄存款——利率相对固定，损失本金的可能性很小 |
| 通合米行寄来的沿途账目和米价清单 | 基金收益具有波动性（赚时翻倍，亏时三成） |
| 长江水灾致一船沉底、市价跌落 | 基金存在亏损风险 |
| 永泰米行白纸黑字写"本息合计" | 银行依据存款合同承担还本付息责任 |
| 北方大熟米价翻番，老关收益翻倍 | 基金收益的上行空间——赚时可能远超固定利率 |
| 阿炳家中有老小等米下锅 | 不同投资者风险承受能力不同，需按自身情况选择 |
| 老关"输得起"才选通合 | 基金风险自担，投资者需自行承担投资风险 |
| 永泰招牌纹丝不动 vs 通合船队扯起新帆 | 储蓄求稳 vs 基金求"更多可能"，两者并非同一种东西 |
