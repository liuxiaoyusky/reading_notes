# 21、收益与风险特性不同

## 🏺 寓言故事 —— 《两份折子》

一九五二年的秋天，十六铺码头的木牌子在江风里咯吱作响。街角那家协兴米行刚把最后一船芜湖米卸完，老陆坐在后堂的板凳上拨着算盘，等顾先生来对账。

老陆是这条街上的老米商，手里常年攥着几份份子。顾先生替他打理米行里的生意，赚了按份分，赔了也按份担。可他最近犯愁：手头还有一笔闲钱，五十块折实单位，是再投到米行的份子里图个大利，还是存进街尾的同德钱庄，落个踏实？

这天傍晚，顾先生拎着算盘来了。老陆开门见山："这笔钱，我想听听你的意思。"顾先生把算盘搁下，慢慢说："老陆，你要是把这五十块折实单位投到米行的份子里，米涨了你跟着分，米跌了你跟着担。赚了，可能五十变八十；赔了，也可能五十变三十。我顾某只管把米行经营好，赚的归你，亏的也归你——我替你担不了。"老陆点点头，这道理他懂。
第二天一早，老陆揣着五十块折实单位，去了街尾的同德钱庄。张掌柜一见是熟客，满脸堆笑："老陆啊，存钱踏实。我这儿按月给你一笔进账，月头一分五，一年稳稳当当九块钱，一分不会少。"老陆问："那要是市面乱了呢？我这五十块能拿得回来吗？"张掌柜拍着胸脯："拿得回来！你把钱存到我这儿，就是我欠你的，欠债还钱，天经地义。同德这块招牌立了三十年，你还不放心？"

老陆把五十块折实单位存进了同德钱庄，折子揣在贴身的口袋里，月月去领那一份进账，踏实得像吃了定心丸。

隔了几个月，米市行情陡变。入冬之后，南边运来大批洋米，价钱一天比一天低。协兴米行里囤的那批货砸在手里卖不动。腊月二十三，顾先生在后堂召集所有份主，把账本摊开。末了拱手："诸位，年成不好，账面上亏了一截。赚了是各位赚的，赔了是各位赔的，我这个掌柜只拿事先说好的工钱，窟窿填不上。"老陆领回自己那份折实单位，缩水了一截。他站在米行门口，看着江面上来来往往的运米船，半天没说话。

同一条街上，老沈头一年也把手头的钱分成了两份——一份投到米行，一份存在同德钱庄。年底一算账，米行那份缩水了二十块，钱庄那份反倒多进账九块。老沈的老婆在灶头念叨："早知道全存钱庄多好。"老沈摇摇头："你只看今年。去年米价涨的时候，我米行那份分到了四十块，比钱庄的九块多出好几倍。"

除夕夜，老陆、老沈、老冯在吴记茶馆围炉守岁。老陆先开了口："我原先想着，钱庄折子上的数字一是一、二是二，米行份子上的数字像江面上的浪，一会上来一会下去。存了一年我才看明白——钱庄那个数字是写死了的；米行那个数字是活的。"老冯接过话头："我那钱庄的折子，月月都长，可长得慢。米行的份子呢，大起大落，让人睡不踏实。"老沈点头："一个是死的——板上钉钉，长得少也不缩；一个是活的——涨得凶，缩得也凶，没人替你兜底。"

顾先生在一旁添茶，笑着说："正是我先前跟老陆说的——投到米行里，赚的可能多，赔的可能也大，谁也没法给你打包票。钱庄呢，借钱的人自个儿担，借出去的银子还是借出去的。"老陆端起茶碗，叹了口气："顾先生，早知今日要赔，当初那笔闲钱，是不是就不该往米行里送？"顾先生摆摆手："老陆，米行赚的时候你也乐过。米市这东西，有人敢博，就有人敢担——博不到的时候，就认。这可不是哪一家钱庄能替你许诺的事。"

江风从门缝里钻进来，茶馆里炭火烧得正旺。三个人守着一壶龙井，外头江上的雾又起了一层。屋里头老陆的米行折子瘪下去一截，老沈和老冯的钱庄折子稳稳地多了一行；可三个人脸上，谁也没多少沮丧，也谁也没多少得意。十六铺的除夕夜，照旧是万家灯火。

---

**📖 原文定义**

> 基金收益具有一定的波动性，存在亏损风险；银行存款利率相对固定，投资者损失本金的可能性也很小。

**💡 对应点**

| 故事元素 | 概念对应 |
|---------|---------|
| 老陆把闲钱投到米行份子里 | 投资于基金 |
| 米涨了分得多，米跌了也分得少 | 基金收益的波动性 |
| 米行赔了，老陆按份子担 | 基金存在亏损风险 |
| 顾先生明说"赚了归你，赔了也归你，我担不了" | 基金风险由投资者自担 |
| 顾先生"只拿事先说好的工钱" | 基金管理人只收固定费用，不兜底 |
| 老陆的钱庄折子 | 银行储蓄存款 |
| 张掌柜"月息一分五，一年九块钱" | 银行存款利率相对固定 |
| 张掌柜"欠债还钱，天经地义" | 存款本息由银行承担还本付息责任 |
| 钱庄折子"长得慢，但不会缩" | 投资者损失本金的可能性很小 |
| 老沈去年米行分四十块，今年缩二十块 | 基金收益浮动、年度波动大 |
| 老陆说"钱庄数字是死的，米行数字是活的" | 固定收益 vs 浮动收益 |
| 老冯说"钱庄是死的，米行是活的" | 风险与收益的对应特性 |
| 顾先生说"博不到的时候就认" | 投资者自担基金投资亏损 |
