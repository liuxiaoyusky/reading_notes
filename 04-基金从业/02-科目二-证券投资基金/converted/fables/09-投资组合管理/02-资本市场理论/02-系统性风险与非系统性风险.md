# 二、系统性风险与非系统性风险

## 🏺 寓言故事 —— 《两家互补的店》

镇上有一家**果汁店**（晴天生意好，雨天差）和一家**雨伞店**（雨天生意好，晴天差）。

如果你把所有钱投给果汁店：晴天赚10%，雨天亏2%，平均4%，波动很大。
如果你把所有钱投给雨伞店：晴天亏2%，雨天赚10%，平均也是4%，波动同样大。

但如果你能**各投一半**：
- 晴天：果汁赚10%的一半 + 雨伞亏2%的一半 = **4%**
- 雨天：果汁亏2%的一半 + 雨伞赚10%的一半 = **4%**

结果无论晴天雨天，你都稳定赚4%！风险被完全消除了。

这就是**分散化**的力量——当两种资产的收益波动**相反**时，组合在一起可以大幅降低风险。

### 两种风险

**非系统性风险**（可分散风险）：只影响个别资产的风险。比如果汁店受天气影响、某家公司管理层变动。通过投资多种不完全同步波动的资产，可以把这类风险分散掉。

**系统性风险**（不可分散风险）：影响所有资产的风险。比如经济衰退、战争、利率变化。无论你买多少种资产，这类风险都无法消除。

### 天下没有免费的午餐

投资者承担风险要求补偿（风险溢价）。但**非系统性风险可以通过分散化免费消除**，所以市场不会给这种风险补偿。**只有系统性风险才值得补偿**。

随着组合中资产数量增加，非系统性风险逐步下降，但系统性风险始终存在。

---

**📖 原文定义**

> 通过投资资产组合，可以降低风险，但不能完全消除风险。我们把可以通过构造资产组合分散掉的风险称为"非系统性风险"（Non-systematic Risk），不能通过构造资产组合分散掉的风险称为"系统性风险"（Systematic Risk）。

> 总风险 = 系统性风险 + 非系统性风险

> 非系统性风险可以通过构造资产组合分散掉，是可以避免的风险，因此，承担非系统性风险不能得到风险补偿。风险补偿只能是对于不可避免的系统性风险的补偿。

> 当组合中资产的数目逐渐增多的时候，非系统性风险就会被逐步分散，但是无论资产数目有多少，系统性风险都是固定不变的。

**💡 对应点**

| 故事元素 | 概念对应 |
|---------|---------|
| 果汁店 | 一种风险资产 |
| 雨伞店 | 另一种风险资产 |
| 晴天/雨天 | 不同市场环境 |
| 两家各投一半风险消除 | 分散化降低非系统性风险 |
| 影响所有店的因素（如战争） | 系统性风险 |
| 只影响果汁店的因素（如水果涨价） | 非系统性风险 |
| 分散化不能消除的风险 | 系统性风险 |
| 只补偿不可分散的风险 | 风险补偿原则 |
