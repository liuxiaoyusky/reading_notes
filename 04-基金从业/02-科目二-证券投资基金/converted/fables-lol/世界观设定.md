# 科目二 · LOL 故事版《世界观设定》

> 本档案是 `fables-lol/` 全部故事的**固定舞台**。每篇故事发生在这个世界里,开头只需交代"本篇场景 + 本篇主角",不必重新解释基本盘。凡与官方设定一致的(阵营、英雄性格、经典道具),一律沿用官方设定,不自造。
>
> 配套文件:《角色对照圣经.md》(业务身份 + 声音档案)。本篇只讲"世界怎么运转"。

## 一、核心舞台:召唤师联合金库

符文之地刚经历过大乱,各阵营的召唤师们发现:单枪匹马闯峡谷,十有九输。于是在皮尔特沃夫议会的撮合下,各方立下契约,成立了一座**召唤师联合金库**:

- 召唤师们把蓝色精华存入金库,换回烙着印记的**契约符文页**——这就是"份额"。
- 各阵营的统帅以金库的精华组建**军团**,替众人出征召唤师峡谷:开矿、夺宝、布防各路。
- 金库本身由**布隆**看管——他只守金库,不碰指挥,一把大盾挡住所有人的手。
- 整个体系由**凯尔**监管,定下铁律;**蔚与凯特琳**在市场上巡查,专抓违规者。
- 每十日,军团的战报必须挂上广场的**记分水晶**,所有人可查——这就是"信息披露"。

一句话:**召唤师联合金库 = 证券投资基金**。每篇故事,都是这座金库里发生的一件事。

## 二、沿用的官方元素(不自造)

| 官方元素 | 在本设定中的角色 |
|---|---|
| 召唤师峡谷 | 市场 / 战场,军团出征之地 |
| 蓝色精华、金币 | 召唤师投入的资金 |
| 海克斯核心 | 投资回报(收益) |
| 虚空 | 系统性风险 / 尾部风险,突袭即闪崩 |
| 弗雷尔卓德的寒冰 | 流动性冻结 / 熊市寒冬 |
| 各阵营(德玛西亚、诺克萨斯、艾欧尼亚、皮尔特沃夫、祖安、比尔吉沃特) | 不同的投资风格与策略,见《角色对照圣经》 |
| 英雄的性格与口头禅 | 一律沿用官方设定,见《角色对照圣经·声音档案》 |

## 三、每篇故事的结构约定

1. **1–2 个主角主演,其余角色辅助。** 主角承担本篇的主线冲突;辅助角色只在他们登场时带出各自的考点,不抢戏。
2. **开头先交代清楚**:本篇主角是谁、他遇到了什么事、为什么非解决不可。交代清楚再进冲突,不许开场即乱战。
3. **辅助角色登场即用声音档案的口吻说话**,首次出场的新角色当场补入《角色对照圣经·声音档案》。
4. **结尾照例**:📖 原文定义(照抄教材)+ 💡 对应点表 + 📝 来源脚注。
