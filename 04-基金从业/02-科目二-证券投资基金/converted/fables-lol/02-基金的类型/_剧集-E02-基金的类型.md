# 二、基金的类型

## 🏺 Arcane 故事 —— 《雾巷的口袋,雾巷的分法》

> 舞台:祖安底城·废弃桥头(Arcane 第一季第 2–3 集之间,傍晚雨后)。主角:**蔚**。辅助:**范德尔、Powder、Mylo、Claggor**

雨停没多久,桥面还亮着水光。

桥头原本是个生铁市集,今天没人摆摊,石板地上只有几只泼翻的口袋。范德尔挽着裤腿蹲在废铁桶边,膝上摊开一只油布袋,里头慢慢滑出几样东西:几个铜环、一卷揉皱的纸条、一小把盐。

蔚从桥头那边过来,手腕上还缠着早上那块布,没换。

"今天这堆不是药。"蔚蹲下看了一眼。

"不是。"范德尔把铜环往前推,"这是底城互助会攒下的,三天一户派给每家。怎么分,你来听。"

Claggor 拖着木板车从巷尾出来,Mylo 在后头踢那根翘起的轮辐。两个人凑过来。

"范德尔,"Mylo 指了指那堆,"今天怎么分?老规矩一股一份?"

"老规矩不够。"范德尔把纸条捡起,扬开,"今天这堆里,有四种来路。"

他用指甲把纸条划成四小叠。

"第一叠,"他点了第一叠,"赌。皮城哪几家铺子今天进项最旺,我把一瓣钱塞过去。中了翻倍,不中归灰。塞得越多,赚起来越凶,亏起来一样凶。"

Powder 从木板车后头钻出来,头发还沾着雨。

"那就赌呗。"Powder 说,"我赌范德尔今天一定赢。"

范德尔没理她。

"第二叠,"点了第二叠,"稳。皮城开铺子要钱,跟底城借钱一样,白纸黑字一张借条,写明年月日,到时候连本带利还。这种皮城那边说是拿去修桥铺路的,稳,但慢。"

"借条。"蔚想了想,"那要是皮城那家铺子赖账呢?"

"借条借条,"范德尔说,"一张不够,多买几张,那家赖了还有这家。摊得开,赖账就赖不空。"

他说完,从裤兜里摸出一张旧纸,边角发黑。

"这张我留了十九年。"他捏着一角给蔚看,"十七岁替我爹买的。皮城一家铜器铺,写明五年还。"

"赖了。"

"没赖。"范德尔把纸按在膝上,"到期我去领,连本带利,换回来够买三天面粉。"

"三天。"

"稳就是这个意思。"他把旧纸折回裤兜,"不是稳赚,是稳在小。"

"那第三叠呢?"Claggor 凑过来。

"第三叠,最短。"范德尔指了指最后那几张零碎,"今天放出去,明早就拿回来。皮城有个银行,他们银行与银行之间也借,最短的借条。咱们没资格进那个门,但可以托人把这一瓣塞进去,出不了大错,也挣不了大钱。"

"那我选最短的。"Powder 插嘴,"因为我等不及。"

范德尔这才看了她一眼。

"第四叠。"范德尔没再理 Powder,点了最后那叠,"什么都不单押。赌的借条的短的,全沾一点。今天沾多一点这个,明天沾多一点那个。这种最像看皮城风向的人,天天在调,哪头都不押满。"

Mylo 皱了下眉。

"范德尔,"Mylo 忍不住,"你数了一遍,我自己听一遍也糊涂。"

"那你是哪个?"Claggor 问蔚。

蔚没立刻答。她蹲在桥面湿石板上,想了一会儿。

"赌那一瓣。"蔚说,"看着凶,但只要不把最后一份押上去,亏也亏不到家。"

"那你倒霉那天,"范德尔说,"铜环不剩几只。我替你们家还过一回,记得。"

他把本子往前翻了两页,停住,把本子调过来朝着蔚。

那一页有一道红线,从上划到下。

"这户是谁?"蔚问。

"洗衣街那个寡妇。去年冬天她男人没了,留下四十几只铜环。她自己挑,挑了赌那一瓣。"

"中了没?"

"头三个月中了。"范德尔的手指压在红线上头那几行,"她拿到手,又全塞回去。"

"后来呢。"

"皮城那家铺子六月关了门。伙计连夜搬空,连门板都撬走。"他把指头往下移到红线,"这道是我划的。她那份现在剩九只铜环。"

Powder 探头看那页。

"九只能买啥?"

"半袋米。"

蔚没说话。她把手腕上那块布往紧里拽了一下。

"那她不是没赌错吗。"蔚终于开口,"前三个月她赢了。"

"赢和输是同一件事。"范德尔把本子合上,"她赢的时候,和输的时候,买的是同一叠。"

他不想再说下去,从布袋底又抽出一小张叠好的牛皮纸。

"还有一种。"他把牛皮纸翻开,"皮城另一头有帮人,本来不来底城招人,今天破例塞了一份进来。这份里,八成以上不押上面四样,押的是另一种东西——"

"什么?"

"皮城之外的铺子。"范德尔指着皮城那条河对岸,"德玛西亚、艾欧尼亚、恕瑞玛。底城人进不去,皮城有几家有牌子的,点过头了才放出去。把钱交给他们去那边买,赚了一起分,亏了一起扛。"

"那是偷跑过去的。"Mylo 说。

"皮城当官的点头,就不是偷跑。"范德尔说,"那种钱,锁得久,有时一只货锁二十年。你等不等得起。"

"等得起。"蔚说,"蔚姐等得起。"

"那就记上。"

桥洞那边上来一个人,肩上横着一根撬棍,裤脚全是泥。是灰水码头卸船的老陶。他把撬棍靠在桥栏上,蹲下来搓手。

"范德尔,你又给小孩讲这个。"

"她要听。"

老陶伸出四根手指,一根一根往下按。

"丫头,你那份漂过去的钱,今天上船。"他按第一根,"船走二十天到那边,买了东西,回信再二十天。"

"四十天。"蔚说。

"顺风四十天。"老陶按下第二根,"逆风六十。"

"那中间我要急用呢。"

"急用你就别上这条船。"老陶把手放下,"我在码头三十年,没见过谁能把船从半路叫回来。"

Claggor 推了推木板车。

"那船靠了岸,钱不就回来了。"

"回来的不是你送出去的那种钱。"老陶捡起一根木炭,在湿石板上画了两道杠,"那边一只桶换五个环。等船回来,那边一只桶换四个环。桶没变,你的环少了一个。"

"谁拿走了。"蔚问。

"没人拿。"老陶把木炭一扔,"两边换钱的价钱变了,就这么回事。"

范德尔把牛皮纸折好,塞回布袋。然后他又从袋子最底下抽出一只小一点的皮囊,皮囊口扎着麻线。

"最后一样。"范德尔把皮囊解下来,摆在四叠旁边,"这一份,和前面四份都不一样。"

"是啥?"Powder 又凑过来。

"买码头。"范德尔说,"皮城河对岸那片地方,有一座桥、一段高架、几个码头仓库。修好之后,过路的车船按月交过路费。这种货一开始花钱不少,修起来要几年,但修完那个钱就按月自己来,不用再熬。"

"那一瓣什么时候能拿钱?"

"按月。"范德尔说,"也可能按季。锁得很死。你要去打喷嚏把钱抽出,门都没有。"

"那就锁着呗。"蔚说,"锁着又不碍我睡觉。"

范德尔点了点头。

桥墩底下这时探出半个人来。是个皮城修桥的,身上系着安全绳,手里拎一只灰泥桶。他一直在下面凿石缝,听了半天。

"你说的那座桥,"他把泥桶搁在桥沿上,"我在修。"

蔚回头。

"修几年了。"

"第六年。"他解下绳扣,活动手腕,"今年底通车。通了车,过一辆收一枚。"

"那这六年谁给你发钱。"

"垫着的。"他敲了敲泥桶边,"塞钱进来的人,六年一个铜环没见着。"

"六年。"蔚说,"六年前塞钱那些人,有些人已经不在了。"

"是。"他把桶提起来,"所以门口写得清清楚楚,进来就锁,锁二十年,中途谁都不许抽。"

"那要是有人家里断顿呢。"

"那就别进这道门。"皮城人说得很平,"但通了车以后,收上来的过路费,十份里得派出去九份。剩一份留着修补路面。这条写在纸上,不派够我要挨罚。"

"派给谁。"

"当初塞钱那些人。按月派,一直派。"

蔚想了一会儿。

"所以锁得越死,派得越准。"

"锁不死就派不准。"他把绳扣往腰上一挂,"半路总有人要抽,今天抽明天抽,桥就修不完了。"

他顺着绳子又滑回桥墩底下,泥桶在下面磕出一声。

桥面远处,忽然传来几声脚步。

希尔科从废桥的第三根石柱后头转出来,肩上搭着一件带水汽的皮外衣。他没走过来,只靠在石柱边,看了范德尔一眼,又看了看蔚。

"四叠之外再加几叠。"希尔科说,"你今天挺舍得。"

"底城人不能不攒。"范德尔没抬头。

"那你攒得起那种吗?"希尔科抬了抬下巴,指向桥那头皮城方向,"皮城那些铺子,成天挂着一块板,上头写四百只,一会儿涨一会儿跌。有人专门照抄那块板,人家涨他就买,人家跌他就放。赌也不像赌,稳也不像稳。"

"照抄那一瓣。"范德尔说。

"照抄那一瓣。"希尔科重复了一遍,"在场子里挂单,按当下价买卖,快,也狠。今天进,今天出,有时比赌那一瓣还凶。"

"那就还选赌。"蔚没抬头。

"那你运气好。"希尔科转身走了两步,又停下,"还有一瓣,你忘了。"

范德尔抬头。

"二道贩子。"希尔科没回头,"自己不押,把钱再交给别人去押。你信他一回,他再信底下的人一回,一瓣钱拐三道才落到事上。"

"那是套娃。"Powder 突然接话。

希尔科停住了。

"啥套娃?"他回头。

"就是套娃呀。"Powder 理直气壮,"一个盒子里还有一个盒子,打开还有。钱放进去,我们不知道最后落到哪个盒子里。"

希尔科看了 Powder 几秒。然后他没再说什么,转身走进雾里。

雾里远远传来他一句。

"那二道贩子那一瓣,你也替自己记得。"

Powder 从石板上抓起三只铜环,塞给 Claggor。

"你替我押。"

Claggor 捏着不动。

"我不会押。"

"那你找会的。"

Claggor 转身把三只塞给 Mylo。Mylo 掂了掂,留下一只,把两只递回来。

"这只算我跑腿的。"

Powder 张嘴要吵。Mylo 已经把剩下两只塞进桥头那个卖灯油的老头手里,老头也留了一只,把最后一只往桥面上一放。

Powder 蹲下去,盯着那一只。

"我出了三只。"

"你现在有一只。"范德尔说。

"那两只呢。"

"在路上被人一层一层留下了。"

"可我什么都没干。"

"你是没干。"范德尔捡起那只铜环,放回她手心,"每经一个人,那个人都要吃一口。你隔得越远,吃的人越多。"

"那我下回自己押。"

"你下回自己押,就一个人吃你。"

范德尔收起那张大牛皮纸,拍了拍湿石板上的水。

"蔚。"他说。

"在。"

"四叠,加上漂过去那一瓣,加上买码头那一瓣,加上照抄那一瓣,加上场子里挂单那一瓣,加上二道贩子那一瓣。"

"在。"

"我替你妈记着。等你长大,自己翻。"

蔚点了点头。她没顶嘴。

"范德尔。"Powder 又开口。

"啥事。"

"你要是不赌那一瓣,只挑三种来搭,"Powder 抬起一根指头,"会怎样?"

"那就是哪样都不押满。"范德尔说,"这种比押一种的稳,比四种全沾的省心。"

"那我以后要选这种。"

"你以后长大再说。"

Powder 没说话。她从桥面捡起一只没人要的铜环,塞进口袋。

雾里的皮城灯火,今晚又多亮了三家。

**📖 原文定义**

> 股票基金主要以股票为投资对象，根据中国证监会对基金类别的分类标准，80%以上的基金资产投资于股票的为股票基金。
>
> 股票基金以追求长期的资本增值为目标。与其他类型基金相比，股票基金风险较高，但预期收益也较高。股票基金提供了一种长期投资增值性，可供投资者用来满足教育支出、退休支出等远期支出需要，同时也是应对通货膨胀有效的手段之一。对于股票基金，投资者需主要关注基金的投资策略、投资风格及基金的长期业绩等因素。

> 债券基金主要以债券为投资对象。根据中国证监会对基金类别的分类标准，基金资产80%以上投资于债券的为债券基金。
>
> 债券基金通过对债券进行组合投资，寻求较为稳定的收益。债券基金的波动性通常要小于股票基金和混合基金，高于货币市场基金，因此，常常被投资者认为是收益稳定、中低风险的投资工具。此外，当投资者将债券基金与股票基金进行适当的组合投资时，常常能较好地分散投资风险。对于债券基金，投资者需主要关注基金的平均持仓久期、杠杆率、基金所持债券信用等级等因素。

> 货币市场基金以货币市场工具为投资对象。根据中国证监会对基金类别的分类标准，仅投资于货币市场工具的为货币市场基金。根据中国证监会和中国人民银行2015年颁布的《货币市场基金监督管理办法》，货币市场基金被进一步明确为仅投资于货币市场工具，每个交易日可办理基金份额申购、赎回的基金；同时，在基金名称中使用"货币""现金""流动"等类似字样的基金视为货币市场基金。

> 基金中基金（FOF）是指将80%以上的基金资产投资于经中国证监会依法核准或注册的公开募集的基金份额的基金。基金中基金通过持有多个不同的基金，可以进一步分散投资风险，降低单一基金的波动对投资组合的影响。

> 混合基金是指投资于股票、债券和货币市场工具或其他基金份额，并且股票投资、债券投资、基金投资的比例不符合股票基金、债券基金、基金中基金规定的基金。
>
> 混合基金为投资者提供了一种在股票、债券等不同资产类别之间进行灵活配置的投资工具，基金管理人在基金合同约定的范围内对基金投资有比较大的调整自由权限。混合基金多元、灵活的资产配置有助于降低单一资产类别带来的风险，追求更加稳健的投资回报，其波动性通常小于股票基金，高于债券基金和货币基金。因其多样化的投资组合，可细分为多种风险收益特征，追求不同投资目标，适用于不同投资场景。对于混合基金，投资者需关注基金在股票、债券和其他资产之间的配置比例，了解其风险收益特征、投资目标和投资策略。

> 指数基金是以特定指数为标的，通过购买该指数的全部或部分成分券构建投资组合，以跟踪标的指数或者基准业绩表现为主要投资目标的基金产品。指数基金具有透明度高、风险分散、成本低廉等特点。

> QDII基金经中国证监会批准可以在境内募集资金进行境外证券投资。基金管理人应当在 QDII 基金合同和招募说明书中明确 QDII 的投资范围、投资策略、投资比例限制、基金资产境外托管安排、费率标准、信息披露等具体安排。QDII为境内投资者参与国际市场投资提供了便利。

> 公开募集基础设施证券投资基金（简称基础设施基金），需同时符合下列条件：（1）80%以上基金资产投资于基础设施资产支持证券，并持有其全部份额；（2）基金通过资产支持证券和项目公司等载体取得基础设施项目完全所有权或经营权利；（3）基金管理人主动运营管理基础设施项目，以获取基础设施项目租金、收费等稳定现金流为主要目的；（4）采取封闭式运作，收益分配比例不低于合并后基金年度可供分配金额的90%。

> 交易型开放式指数基金（ETF）是一种在证券交易所上市交易的、基金份额可变的开放式基金。ETF一般采用被动式投资策略跟踪某一标的市场指数；ETF联接基金是指将绝大部分基金资产投资于跟踪同一标的指数的目标ETF、采用开放式运作方式的基金，是一种特殊的基金中基金。

| 范德尔"稳那一瓣"——皮城修桥铺路的借条,多买几张防赖账 | 债券基金(80%以上投资于债券) |
| 多张借条摊开、某家赖账赖不空 | 债券基金通过组合分散单一债券信用风险 |
| "今天放出去明早就拿回来"、皮城银行之间的最短借条 | 货币市场基金(仅投资货币市场工具) |
| "出不了大错,也挣不了大钱" | 货币市场基金低风险、低收益、高流动性 |
| "什么都不单押,全沾一点,天天调" | 混合基金(股债现金比例不符合前三类) |
| "漂过去那一瓣"——德玛西亚/艾欧尼亚/恕瑞玛,底城人进不去,皮城点头才放 | QDII 基金(经批准投资境外证券市场) |
| "锁得久,有时一只货锁二十年" | QDII 基金锁定期较长、需承担汇率与境外市场风险 |
| "买码头、买桥、买高架、修好之后按月收过路费" | 公募 REITs/基础设施基金(投资基础设施,收益主要来自稳定现金流) |
| "锁得很死,打喷嚏都抽不出来" | 基础设施基金封闭式运作、强制分红特征 |
| "照抄那一瓣"——皮城墙上那块板四百只,涨跌就跟着 | 指数基金(被动跟踪特定指数,试图复制指数表现) |
| "在场子里挂单,按当下价买卖,快,也狠" | ETF(交易所上市、可二级市场实时交易) |
| "二道贩子"——自己不押,把一瓣钱拐三道才落到事上 | FOF(基金中基金,80%以上资产投资于其他基金份额) |
| Powder "什么都不单押,只搭三种"的将来选择 | 偏股/偏债/股债平衡/灵活配置型混合基金 |
| 范德尔"我替你妈记着,等你长大自己翻" | 投资者按风险偏好选择适合自己的基金类型 |
