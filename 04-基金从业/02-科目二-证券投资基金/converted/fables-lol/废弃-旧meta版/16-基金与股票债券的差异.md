# 十一、基金与股票、债券的差异

## 🏺 LOL 故事 —— 《一袋精华,三条路》

> 舞台:赛季招募大厅(见《世界观设定》)。本篇主角:**拉克丝**(冕卫家第一次自己做主的贵族少女)。辅助:**盖伦、杰斯、嘉文、布隆**。

峡谷记分水晶一片血红。虚空补丁上线第三分钟,召唤师峡谷闪崩。

拉克丝攥着三张契纸,站在招募大厅中央。

冕卫家的钱,从来是管家打理。这赛季她硬从哥哥盖伦手里抠来了自主权——这一袋精华,头一回自己拿主意。三份邀约刚摆上桌,虚空就砸了下来。

三张纸,此刻三样命。

**第一张,盖伦递的战队股权证。**

盖伦按着剑,惜字如金:"精华入股。战队姓盖伦——怎么打、ban 谁,我说了算。打赢,按你这股分;打输,股跟着缩。持有人大会,你有票。"

虚空闪崩那一刻,盖伦的战队正撞在风口,分红当场泡汤。可股权证还在手里,战队还姓盖伦,根还扎在峡谷的地里,下季还能重整。

——这就是**股票**。钱直接投进了战队经营:招兵、买装备、扩张。她成了**股东**,这关系叫**股东权利**。盈亏连着根,胜败她自己扛。

**第二张,杰斯的借条。**

杰斯不招兵,他修海克斯兵工厂。推了推单片眼镜,体体面面:"我不卖股——**借**。三年期,每年固定利息,到期精华如数奉还。借条在此。"

虚空一闹,到处急着补装备,兵工厂反倒接了军需大单。可这跟借条无关——杰斯按纸上的数,到点付钱,一分不多一分不少。

——这就是**债券**。钱照样投去了实业——修兵工厂。可她的身份是**债主**,这关系叫**债权债务**。她不掺和经营,只等还本付息。

**第三张,嘉文摆在桌上的份额宝石。**

皇子面前既无股权证,也无借条,只一块刻着数字的宝石。

"我既不垦地,也不修厂。"嘉文沉声道,"我只替你看——哪家战队的股权证值得收、哪张借条值得买、哪份海克斯衍生契约值得押,把你的精华分散进这些有价证券里。这宝石不代表哪支战队是你的,也不代表谁欠你债——它只代表,这篮子证券里有你一份。买谁卖谁,我定。持有人大会,你凭宝石有票。钥匙,我不拿——交布隆。"

虚空砸下来,嘉文替她布的那只篮子晃了晃:同时押着股权证、借条,还掺了几份海克斯衍生契约——虚空只啃掉一角。份额宝石上的数字缩了水,没归零。

——这就是**基金**。钱不再直接去垦地、修厂,而是投进一篮子"有价证券"。她的身份是**受益人**,这关系叫**信托**。组合一散,单一资产挖的坑,篮子替她扛下了大半。

拉克丝把三张纸并排摆上桌。股权证、借条、份额宝石。

她不缺精华——冕卫家的老底厚着呢。她缺的,是自己拿主意、挑路子的经验。三样摆在眼前,她忽然看通透了:股权证要她亲自盯战队胜败,借条要她到期才落袋,唯独那块宝石,有人替她布阵、有人替她守门,她只要信。

她一把抓起份额宝石,攥进手心,冲三个队长眨眨眼。

"哥,"她对盖伦笑,"你这股,风险自担——我可没闲心天天盯记分板。杰斯,你那利钱雷打不动,赚得太稳。嘉文这边……"她把宝石举到光里,"有人布阵、有人守库、还替我分散着押——这才配得上一个冕卫家的小姐。"

盖伦憋了半天,只吐出两个字:

"……德玛西亚。"

大厅外,虚空正退潮,记分水晶由红转暗。拉克丝把宝石塞进腰包,大步往外走,头也不回,丢下一句:

"证明给他们看。"

---

**📖 原文定义**

> 股票体现股东权利关系,债券体现债权债务关系,而基金体现信托关系(或信义关系)。基金份额持有人作为受益人,享有财产权利和参加持有人大会等权利。
>
> 股票和债券所筹集的资金主要投向实业领域,用于公司的经营活动或扩张计划等;基金所筹集的资金主要投向有价证券等金融工具或产品。

**💡 对应点**

| 故事元素(LOL) | 概念对应 |
|---------|---------|
| 盖伦、股权证、按股分红、"战队姓盖伦"、持有人大会有票 | 股票——体现股东权利关系,资金投向实业(经营/扩张) |
| 盖伦战队撞风口、分红泡汤、股权证还在、根扎峡谷地里 | 股东自担盈亏,股权关系不因一季胜败解除 |
| 杰斯、借条、固定利息、"三年期到期奉还" | 债券——体现债权债务关系,资金投向实业 |
| 杰斯按借条到点付钱、与兵工厂经营好坏无关 | 债权人不管经营,只等还本付息 |
| 嘉文、份额宝石、金库、布隆看钥匙 | 基金——体现信托(信义)关系,资金投向有价证券等金融工具 |
| 宝石"不代表哪支战队是你的,只代表篮子里有你一份" | 基金份额不代表具体某一证券的所有权 |
| 拉克丝持宝石是"受益人"、凭宝石有持有人大会票 | 基金份额持有人作为受益人,享有财产权利及参加持有人大会权利 |
| 嘉文同时押股权证、借条、海克斯衍生契约 | 基金组合投资、分散风险 |
| 虚空闪崩下宝石缩水却没归零 | 基金通过组合投资分散单一资产风险 |
| 股权证/借条钱进战队/兵工厂;宝石钱进"一篮子有价证券" | 股票、债券投实业;基金投有价证券等金融工具 |
| 拉克丝"不缺精华缺经验"、选宝石让人代管 | 富裕但缺经验的投资者(阶层约束),与基金"代客理财"契合 |
