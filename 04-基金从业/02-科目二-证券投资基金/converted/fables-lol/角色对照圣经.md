# 科目二 · LOL 故事版《角色对照圣经》

> 本文件是 `fables-lol/` 全部故事的**统一世界观基准**。所有章节的角色扮演、阵营气质、道具象征都必须与本表保持一致,做到"固定选角"——同一个基金业概念,在 691 篇里永远由同一批英雄/阵营扮演,读者一眼认得出、不串味。
>
> 原则:**故事换皮,考点不换。** 每篇 LOL 故事末尾必须照留教材的《原文定义》与《对应点》表,这两块是应试锚点,不做改动。

## 一、核心角色固定映射(人)

| 基金业角色 | 固定扮演者 | 选角理由 |
|---|---|---|
| 基金份额持有人 / 散户投资者 | **新人召唤师 / 独行探险者**(常以"提莫式单兵"作反面) | 本钱小、单打独斗、容易踩线触雷,需要把资源托付给强者 |
| 合格投资者 / 私募的富有出资人 | **诺克萨斯将军、德玛西亚贵族** | 家底厚、门槛高,能承担更大风险 |
| 基金管理人 / 基金经理(主动管理) | **嘉文四世**(德玛西亚统帅) | 统率一支军团、做战术决策、对追随者负有信义责任 |
| 基金托管人 | **不可撼动者 布隆** | 独立守护、持金库钥匙、只看管不决策,是"相互制衡"的化身 |
| 基金监管机构(证监会) | **审判天使 凯尔** | 降下最高审判、立规则、维护整个符文之地的秩序 |
| 市场一线稽查 / 交易所监察 | **皮城执法官 凯特琳 & 蔚** | 在皮尔特沃夫金融城里抓违规、查内幕交易 |

| 基金服务机构(登记、估值、外包) | **约德尔工匠、海克斯技师** | 幕后专业支持,不站台前但缺之不可 |

## 四、写作约束(每篇必须遵守)

1. **选角一致**:出现的角色/阵营必须来自上表,不得临时改扮。
2. **故事完整**:有真实冲突、转折、人物弧光,不是术语堆砌。
3. **原文照留**:末尾《原文定义》直接引用教材,不改写、不注水。
4. **对应点清晰**:用表格把"故事元素 → 概念"逐条对齐。
5. **来源脚注**:保留 `> 📝 来源:科目二 · 第X章第Y节 · 标题`。
6. **文件路径镜像**:与 `fables/` 下同名文件一一对应,便于对照与全量铺开。
