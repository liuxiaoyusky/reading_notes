# 一、证券投资基金概念

## 🏺 Arcane 故事 —— 《旧账本》

> 舞台:祖安底城,"最后一杯"酒馆(Arcane 第一季前期)。主角:**蔚**。辅助:**范德尔、金克丝(那时还叫 Powder)、希尔科、凯特琳**。

蔚把拳头锤在酒馆柜台上。血从指缝渗下来,在范德尔的旧账本上印了个红掌印。

"凭什么?"

她刚在底城东区打完一架。三对一,赢了,挂彩。回来讨口水喝,撞上一幕她看了十年的戏——一对夫妻抱着发烧的孩子,男人把家里最后一件海克斯废件敲在柜上,低声下气地求药。

范德尔把药推过去。"孩子先救命。"

"凭什么,"蔚指着那对夫妻,"他替我们做主?我们自己的东西,自己不能决定怎么花?"

酒馆里安静了几秒。金克丝蹲在角落,手里攥着蜡笔,在本子上画着,眼睛骨碌碌转。

"凭什么。"范德尔重复了一遍。他放下酒杯,绕过来,在蔚面前蹲下身,跟她平视。

"因为你们几家,凑不齐一剂药。"他说,"你爸走那年,你妈哭了一夜。她手里那点积蓄,买不了药也办不了丧。我出了钱。后来你跟金克丝没饭吃,我出了粮。底城二十几户,家家都有过这回事。"

"那我也出了力!"蔚攥拳,"我天天打架护着大家——"

"所以你也吃了我十年的饭。"范德尔说,"我替你记着账。"他翻开那本旧账本,密密麻麻的横道,从第一页一直画到最后一页。"你每打一次架,我在这里划一道。这就是你的份额——你出力,我管账,大家凑一起,谁有难谁先领。赚了,是大家的福分;亏了,大家一起扛。这不叫替你做主——这叫,我们没有一个人能单独活下来,可是凑一块儿,就能。"

蔚攥着拳,没再顶嘴。指缝的血结了痂。她懂了一件事:她妈哭那一夜,要是没有范德尔,她跟金克丝就散了。

金克丝举着本子凑过来:"我也要画!"

"你画什么?"

"画你的旧账本!"金克丝咯咯笑,"等蔚姐姐有难了,你从这里划一道——"

"不许咒你姐。"

门口传来一声冷笑。

希尔科靠在门框上,手里攥着一小瓶发紫光的液体。微光。他举起来对着光看,笑容阴冷:"范德尔的互助会,门槛是零——谁都能进来,谁都能分。可我的,门槛不是零。"

他举起那瓶微光:"你想用我的?拿你最值钱的东西来换。一百份起,只对底城最有本事的人开。"

范德尔皱了皱眉,没说话。

门外,远处皮城的方向,偶尔能听见执法者的警笛。金克丝不知道那意味着什么。蔚知道——总有一天,会有人来查这本账,问她为什么记的每一道都不在皮城的档案里。

金克丝翻着本子,忽然抬头:"范德尔,你这个叫什么?全符文之地都这样吗?"

范德尔拍了拍她的头:"不,叫法不一样。"

他掰着手指:

- 皮城银行,叫"**共同基金**":大家共同出资;
- 弗雷尔卓德的冰原部族,叫"**单位信托基金**":一份记一个"单位",大家信托长老;
- 艾欧尼亚的隐修会,叫"**集合投资计划**":把众人之力集合;
- 恕瑞玛的沙漠商队,叫"**证券投资信托基金**":把货物信托给首领运去远方。

"叫法千变,"他最后说,"内核只有一个:**众人把资源凑到一起,交给一个能管事的人统一调配,赢了输了都按份来算。**"

金克丝听不懂,继续画。蔚听懂了八成,攥着拳,血已经干了。她盯着底城酸雾里隐约亮着的皮城灯火,忽然问:

"范德尔——那我们这本账,什么时候能拿到皮城那间屋子去记?"

范德尔看着她的眼睛,很久没说话。

"等你长大。"他终于说,"等你强到皮城也得认你——这本账,才能见光。"

蔚没再问。她牵着金克丝回了家。底城的雾,照旧是紫色的。

**📖 原文定义**

> 证券投资基金通过公开募集或非公开募集的方式,汇集投资者的资金形成独立财产,由专业的基金管理机构按照合同约定的投资目标、投资范围和投资策略进行投资管理,主要投资于股票、债券、存托凭证、衍生品等各类证券资产,投资者按照所持有的基金份额享有投资收益并承担投资风险。

> 证券投资基金在国际市场上有多种称谓:在美国被称为"共同基金"(Mutual Fund),在英国和中国香港被称为"单位信托基金"(Unit Trust),在欧洲部分国家被称为"集合投资计划"(Collective Investment Scheme),在日本和中国台湾被称为"证券投资信托基金"(Securities Investment Trust)。

> 按照募集方式的不同,证券投资基金可分为公开募集证券投资基金(以下简称公募基金)和非公开募集证券投资基金两大类别。非公开募集证券投资基金仅面向合格投资者,按照基金管理人类型可进一步分为由私募基金管理人设立的证券投资基金(以下简称私募基金)和由证券期货经营机构设立的私募资产管理计划(以下简称资产管理计划)。本书提及的"基金"如无特别说明,均指包含公募基金、私募基金和资产管理计划在内的证券投资基金,"基金业"指证券投资基金行业。

| 故事元素(Arcane) | 概念对应 |
|---------|---------|
| 蔚和金克丝没饭吃、妈妈哭那一夜,范德尔替她们出了钱粮 | 汇集投资者资金形成独立财产 |
| 范德尔的旧账本上密密麻麻的横道 | 基金份额 |
| 二十几户底城人家有难同当、凑在一起才买得起一剂药 | 集合投资者资金形成规模,分散单一风险 |
| 范德尔"替大家看着"、"我替你记着账" | 专业基金管理机构按合同约定进行投资管理 |
| 出力的划一道、出钱的敲柜上、都记在账本上 | 按份额分享收益、分担风险 |
| 范德尔互助会门槛为零、谁都能进来 | 公募基金 |
| 希尔科"一百份起、只对底城最有本事的人开" | 非公开募集、仅面向合格投资者(私募基金) |

| 范德尔掰手指:皮城/弗雷尔卓德/艾欧尼亚/恕瑞玛叫法各异 | 各国/地区基金称谓:Mutual Fund / Unit Trust / CIS / SIT |
| 蔚问"什么时候能拿到皮城那间屋子去记",范德尔说"等你长大" | 底层逆袭的种子:底层互助会终要走向合规、被看见(呼应 Arcane 蔚的成长线) |
