# 一、证券投资基金概念

## 🏺 Arcane 故事 —— 《灰水港的横道》

> 舞台:祖安底城·灰水码头(Arcane 第一季第 2–3 集,清晨)。主角:**蔚**。辅助:**范德尔、金克丝(Powder)、Mylo、Claggor、希尔科**

天刚蒙蒙亮,雾还是灰的。

蔚蹲在码头边的石墩上,手腕上一道新伤,刚让 Mylo 给缠了两圈布。Claggor 把一只木箱从船板上滚下来,落到地上时发出闷响。

"慢点,"范德尔从栈桥那头走过来,"里头是药。碎了,底城三家病人没命等下一船。"

蔚抬头看了一眼。箱子外头用粉笔画着一道横线。

"那是什么?"她问。

范德尔蹲下,把粉笔递给她。

"码头上十二个人,谁出一份力,我在这箱子上画一道。一道顶一股。一股药,值一份口粮。今晚你 Mylo Claggor Powder 四个人,谁背得多,谁横道多,谁家里多领一份。"

"那我也算?"她问。

"你算。"范德尔说,"你妈走那年你才六岁。你吃的穿的,我都替你记在另一本上。等你长大,自己翻。"

Powder 蹲在木箱后头,手里捏着一截蜡笔头。

"那我呢?"

"你也算。"范德尔拍她脑袋,"画三道一道,你跟着蔚背,她一半你一半。"

"可我也想画。"

"等你能扛动那只箱子再说。"

蔚没再顶嘴。她站起身,走到栈桥上,接过那只比胳膊还粗的麻绳,一肩一肩往岸上拖。Claggor 在后头推,Mylo 在前头拉。三个人的脚印踩在湿木板上。

"再一道,"Claggor 喘着气,"蔚,你又一道。"

"我不要一道。"蔚把麻绳往肩上紧了紧,"我要八道。"

"行。"范德尔把粉笔头往栈桥上一丢,"你那股,我记上。"

一上午过去了。栈桥上堆了四只药箱,每只箱子上都画满了横道。范德尔把旧本子翻开,横道密密麻麻,排成竖排,排在每一页。

"底城二十七户,"他指着本子,"有十户今晚来领药。其余的等下一船。亏了,大伙一起扛。赚了,大伙一起分。这本账的道理,就这一桩。"

"凭什么?"蔚抬头,"多出力的人,不能多拿?"

"凭你出力多,你横道多,你拿的就多。"范德尔说,"少出力少拿,不出力不拿。"

"那我也想多出力。"

"没有'我也要多'。"范德尔打断她,"这本账,人人能进,人人有份。你今天来背,明天不想背,你那份作废。你下个月再来,我接着记。门槛零。"

蔚点了点头。她第一次没顶嘴。

Powder 蹲在栈桥栏杆上,腿一晃一晃,看着底城酸雾里的皮城灯火,忽然说:"范德尔,那要是有一箱药,比这一箱贵一百倍呢?你是不是也画一百道?"

范德尔愣了一下。

"那种药,"他说,"不会让我们来扛。"

"那谁来扛?"

"皮城的银行。"范德尔指着雾里那一点光,"他们叫'共同基金',大家共同出资,凑到一块儿,找个懂行的人去买。赚了归大伙,亏了也归大伙。"

"那跟我们这本账一个样。"

"一样。叫法不一样。"范德尔掰手指,"皮城那边叫'共同基金',德玛西亚叫'单位信托基金'。艾欧尼亚叫'集合投资计划',恕瑞玛叫'证券投资信托基金'。字不同,意思同一桩。"

"那为什么不叫一样?"

"因为皮城人爱写新词。"

Powder 还欲再问,栈桥那头先传来一声干咳。

希尔科靠在缆绳桩上,皮外套没扣,手里攥着一只发紫光的小瓶。他没看范德尔,只看着蔚。

"他这本账,"希尔科抬了抬下巴,"门槛是零,谁都能进。我这本,门槛不是零。"

他晃了晃那只小瓶。

"一百股起。我只对底城最有本事的十二个人开。你们码头上扛麻绳的,排不上。"

希尔科转身走了。紫色的光在雾里淡下去。

蔚盯着他背影,一句话没说。

"蔚姐,"Powder 从栏杆上跳下来,"一百股是多少?"

蔚看着她妹妹。

"很多。"她说,"很多很多。"

她低头看自己手腕上那道伤。布条渗出血来。她没让 Mylo 重新缠。她知道,今天她还要再去一趟。

底城的雾,还是灰的。

**📖 原文定义**

> 证券投资基金通过公开募集或非公开募集的方式,汇集投资者的资金形成独立财产,由专业的基金管理机构按照合同约定的投资目标、投资范围和投资策略进行投资管理,主要投资于股票、债券、存托凭证、衍生品等各类证券资产,投资者按照所持有的基金份额享有投资收益并承担投资风险。

> 证券投资基金在国际市场上有多种称谓:在美国被称为"共同基金"(Mutual Fund),在英国和中国香港被称为"单位信托基金"(Unit Trust),在欧洲部分国家被称为"集合投资计划"(Collective Investment Scheme),在日本和中国台湾被称为"证券投资信托基金"(Securities Investment Trust)。

> 按照募集方式的不同,证券投资基金可分为公开募集证券投资基金(以下简称公募基金)和非公开募集证券投资基金两大类别。非公开募集证券投资基金仅面向合格投资者,按照基金管理人类型可进一步分为由私募基金管理人设立的证券投资基金(以下简称私募基金)和由证券期货经营机构设立的私募资产管理计划(以下简称资产管理计划)。本书提及的"基金"如无特别说明,均指包含公募基金、私募基金和资产管理计划在内的证券投资基金,"基金业"指证券投资基金行业。

**💡 对应点**

| 故事元素(Arcane) | 概念对应 |
|---|---|
| 蔚和金克丝没饭吃、妈妈走后范德尔替她们出钱出粮,记在另一本账上 | 汇集投资者的资金形成独立财产 |
| 旧本子上密密麻麻的横道,每道代表一股出力 | 基金份额 |
| 二十七户底城人家共扛一只药箱、单家买不起合力才买得起 | 集合资金、形成规模(分散单一风险) |
| 范德尔统筹、记账、出多少力画多少道、按规矩来 | 专业基金管理机构按合同约定进行投资管理 |
| 多出力多画一道、多领一份;少出力少领;不出力不领 | 按份额享有收益、承担风险 |
| 药、粮、布匹等底城互助会换来的各类活命货物 | 投资于股票、债券、存托凭证、衍生品等证券资产 |
| 范德尔"门槛零、人人能进、人人有份" | 公开募集(公募基金) |
| 希尔科"一百股起、只对底城最有本事的十二个人开" | 非公开募集,仅面向合格投资者(私募基金) |
| Silco 举着发紫光的小瓶作为"入场券",码头上扛麻绳的排不上 | 私募的门槛品:非合规、不公开、只对少数合格投资者 |
| 范德尔掰手指:皮城/德玛西亚/艾欧尼亚/恕瑞玛叫法各异 | 各国/地区基金称谓:Mutual Fund / Unit Trust / CIS / SIT |
| 蔚听完"知道今天还要再去一趟",不靠码头扛麻绳就拿不到下一份 | 风险与收益并存、按份承担 |
| 范德尔说"亏了一起扛、赚了归大伙" | 证券投资基金的核心:集合资金、专业管理、收益共享、风险共担 |
