# 一、QDII基金的概念与特点

2007年6月18日，中国证监会颁布的《合格境内机构投资者境外证券投资管理试行办法》规定，符合条件的境内基金管理公司和证券公司等证券经营机构，经中国证监会批准，可在境内募集资金并运用所募集的部分或者全部资金以资产组合方式进行境外证券投资管理。这种经中国证监会批准可以在境内募集资金进行境外证券投资的机构称为合格境内机构投资者QDII。QDII是在我国人民币没有实现可自由兑换、资本项目尚未完全开放的情况下，有限度地允许境内投资者投资海外证券市场的一项过渡性的制度安排。目前，除了基金管理公司和证券公司外，商业银行等其他金融机构也可以发行代客境外理财产品，但这里主要涉及的是由基金管理人发行的QDII产品，即QDII基金。QDII基金可以人民币、美元或其他主要外汇货币为计价货币进行募集。

# 二、QDII基金的类型

QDII基金除了同样可以按照投资对象进一步分为QDII股票基金、QDII债券基金、QDII混合基金等之外，还可以按照以下标准进行分类。

# （一）根据投资市场分类

根据 QDII 基金投资的市场分布，可以分为单一市场 QDII 基金、跨市场 QDII 基金和全球 QDII 基金。

单一市场QDII基金约定仅投资于一个国家或地区的市场标的，投资专注度高，但也存在较高的单一市场风险。

跨市场QDII基金约定同时投资于两个及以上国家或地区的市场标的，风险相对分散。

全球QDII基金以全球市场投资标的为投资对象，进行全球化分散投资，可以有效克服单一国家或区域投资风险，但由于投资跨度大，费用相对较高。

# （二）根据投资模式分类

根据 QDII 基金投资的模式，可以分为主动管理型 QDII 基金和被动指数型 QDII 基金。

主动管理型QDII基金，基金经理根据市场情况和自身判断，主动选择投资标的和时机。

被动指数型 QDII 基金，主要跟踪某个特定的市场指数，如标普 500 指数、纳斯达克 100 指数等，以复制指数的表现为目标。

# （三）根据计价货币分类

根据购买基金份额时的计价货币，QDII基金可以分为人民币计价、美元（现汇或现钞）计价和其他外汇货币计价等。

# [案例2-4] 国泰纳斯达克100指数证券投资基金的投资

国泰纳斯达克100指数证券投资基金于2010年4月推出，是国内首只跟踪美国纳斯达克100指数的QDII基金，为国内投资者配置美股提供了一个有力工具。

国泰纳斯达克100指数证券投资基金主要通过投资纳斯达克100指数成分股或纳斯达克100指数相关ETF，以期紧密跟踪纳斯达克100指数的走势。纳斯达克100指数发布于1985年，是美国主要股票指数之一，它和道琼斯工业指数、标准普尔500指数一起，共同被看作美股股市的风向标。纳斯达克100指数涵盖纳斯达克股票交易市场上市值最大的100家非金融类上市公司，包括苹果、微软、亚马逊等，反映了成熟市场高科技行业的整体走势。

基金的投资范围为具有良好流动性的金融工具，包括纳斯达克100指数成分股，在已与中国证监会签署双边监管合作谅解备忘录的国家或地区证券监管机构登记注册的、以纳斯达克100指数为投资标的指数型公募基金（包括ETF），货币市场工具以及中国证监会允许的其他金融工具。原则上要求现金留存比例不低于基金资产净值的5%，指数成分股和指数相关ETF的总投资比例不低于资产的80%，其中后者市值不能超过资产净值的10%。相比国内指数基金，80%的最低限制比例并不高，这种设计给基金应付日常运作（如申购、赎回）留有一定空间；持有ETF既可以增强对指数的跟踪，同时也方便控制持仓流动性，在应对日常运作中同样具有灵活性。

基金原则上采取完全复制策略，根据指数成分股构成及其权重构建基金组合。基金的风险控制目标是追求以美元资产计价计算的日均跟踪误差不超过0.5%，年跟踪误差不超过5%。
