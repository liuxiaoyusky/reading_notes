# 一、中国债券市场的发展

中国债券市场是从20世纪80年代开始逐步发展起来的，经历了以柜台市场为主、以交易所市场为主和以银行间市场为主三个发展阶段。

# （一）以柜台市场为主（1988—1991年）

这一时期国债和企业债交易市场刚刚起步，还处于初级阶段，此时的债券投资者以个人投资者为主体，因此债券交易市场以柜台市场为主，通过商业银行和证券经营机构的柜台进行交易。这种市场模式符合个人投资者的交易需求，在一定程度上促进了债券市场的发展。

# （二）以交易所市场为主（1992—2000年）

1990年12月，上海证券交易所成立，国债逐步进入了交易所交易。1997年，国务院开始规范银行资金，要求商业银行退出交易所市场，将托管在交易所的债券全部转到中央结算公司，并通过全国银行间同业拆借中心提供的交易系统进行交易。1997年6月16日，银行间同业拆借中心开始办理银行间债券回购和现券交易，全国银行间市场正式运行。此阶段，中国的债券市场形成了场内交易所市场和场外银行间市场并存的格局，并且以交易所市场为主。

# （三）以银行间市场为主（2001年至今）

2001年，银行间债券市场的发行量、交易量和托管量首次超过交易所市场。由此，我国债券市场形成了银行间债券市场、交易所市场和商业银行柜台市场三个基本子市场为主的统一分层的市场体系。其中，银行间债券市场在债券分销量、托管量和现券交易量方面都占据主导地位。根据中国人民银行《2023年金融市场运行情况》，2023年，我国债券融资占社会融资规模增量的31.6%，较2022年上升2.9个百分点，对实体经济融资的支持力度不断加大。2023年，债券现券成交354万亿元，债券回购和同业拆借成交2273万亿元，金融市场活跃度和流动性进一步提升。2023年，债券市场共发行各类债券71.0万亿元，同比增长14.8%。其中，银行间债券市场发行债券61.4万亿元，占比86.5%，交易所市场发行债券9.6万亿元，占比13.5%。

# 二、中国债券市场的参与主体

我国债券市场的参与主体有监管机构和自律组织、发行方、交易市场、投资者和中介服务机构。

我国的债券市场监管机构主要包括中国人民银行、中国证监会、财政部、国家金融监管总局、国家外汇管理局等。债券市场自律组织主要包括证券交易所、中国证券业协会、中国银行间市场交易商协会等。监管机构和自律组织对债券市场的监管可以分为债券发行监管、挂牌交易和信息披露监管、清算结算和托管监管、市场参与主体的监管以及评级机构等相关服务机构的监管等。

发行方主要是指为筹集资金而发行债券的发行主体，包括中央和地方政府、中国人民银行、政策性银行、政府支持机构、金融机构以及具有法人资格的非金融机构或企业等。

我国债券交易市场包括银行间市场、交易所市场和柜台市场。债券市场实现了债券交易、登记、托管、清算和结算集中化的管理。银行间市场包含一个交易前台两个结算后台，交易前台是中国外汇交易中心，结算后台是中央国债登记结算有限责任公司和上海清算所。交易所市场是三个交易前台一个结算后台，交易前台是上海证券交易所、深圳证券交易所和北京证券交易所，结算后台是中国证券登记结算有限责任公司。

投资者主要是指认购债券的机构和个人。包括中国人民银行、政策性银行，商业银行、保险公司、证券公司、基金（含社保基金）、信托、财务公司等金融机构，非金融机构等机构投资者和个人投资者；也包含部分境外投资机构和个人。

中介机构是指为债券发行提供承销、审计、法律、担保、评级等服务的机构，主要包括承销商、受托管理人、评级机构、担保公司、会计师事务所、律师事务所等。

# 三、中国债券产品体系

在中国债券市场投资实践中，通常将债券分为利率债和信用债两大类。

利率债由中央和地方政府、三大政策性银行等具有国家背景的机构发行，几乎不存在信用风险。这类债券的价格对市场利率变动敏感性高，通常来说，市场利率上

升，债券价格下降。

而信用债的发行人没有政府信用做背书，除了受市场利率影响，还会面临信用风险。当发债企业资质下降，还本付息可能遇到困难，信用债的价格就会受到冲击。信用债和利率债收益率之间存在“信用利差”。利率债的价格波动来源于影响利率的相关因素，如利率的期限结构、通货膨胀、流动性、经济周期等；而信用债除了利率因素，还需要考虑影响信用风险的因素，如企业经营状况、还款意愿等。

在我国经济转型和财政体制改革过程中，还诞生了具有中国特色的“准市政债”，即城投债。其规模庞大，偿还责任本质上在于债务属性的认定，纳入地方政府债务范畴的，属于政府隐性债务；而不纳入政府性债务或退出地方政府融资平台名单的则属于普通公司债券。

# （一）利率债

我国利率债主要包括政府债券（国债和地方债）、中央银行票据、政策性金融债券以及政府支持机构债券。

# 1. 政府债券

我国政府债券包括国债和地方政府债。

国债是财政部代表中央政府发行的债券。国债具有安全性高、流动性强、收益稳定、享受免税待遇特点，可分为记账式国债和储蓄国债。其中，记账式国债通过中央结算公司招标发行，可进一步按附息方式分为记账式贴现国债和记账式附息国债，可在银行间市场、交易所交易。储蓄国债是通过商业银行柜台主要面向个人投资者发行的，不可流通转让，分为凭证式和电子式。

地方政府债券，是指省、自治区、直辖市和经省级人民政府批准自办债券发行的计划单列市人民政府发行的、约定一定期限内还本付息的政府债券。我国地方政府债券发行经历中央财政部代发代还（2009年），试点地区自行发债、中央代还（2011年），试点地区债券自发自还（2014年），限额内自发自还（2015年新《预算法》后）四个阶段。地方政府债按预算管理模式分为一般债券和专项债券。一般债券是为没有收益的公益性项目发行，主要以一般公共预算收入作为还本付息资金来源的政府债券；专项债券是为有一定收益的公益性项目发行，以公益性项目对应的政府性基金收入或专项收入作为还本付息资金来源的政府债券。地方政府债券也可按资金用途分为新增债券、置换债券和再融资债券。

# 2. 中央银行票据

发行主体为中国人民银行，是为调节货币供应量主要面向商业银行（一级交易商）发行的短期债务凭证。期限一般不超过1年，但也有长至3年的品种。央行票据通过央行公开市场操作系统发行，在中央结算公司托管。

# 3. 政策性金融债

由国家开发银行、中国进出口银行和中国农业发展银行三家政策性银行发行的政策性金融债主要用于国家重大基础设施建设、促进经济发展和调节金融市场等政策目标。

# 4. 政府支持机构债券

这类债券由政府支持的机构发行，例如中国铁路总公司发行的铁道债和汇金公司发行的中央汇金债。虽然这些债券不直接由政府发行，但由于有政府背景，其信用风险较低。

# 图 [案例5-1] 中国地方政府债的发展历程

2009年，国务院开始允许地方政府委托财政部代理发行地方债，债券到期后由财政部代办还本付息，然后地方政府再向财政偿还相关款项。2011年底开始允许部分省市的地方政府进行自主发债试点，这些债券依然受到中央政府的支持，财政部继续代为还本付息，中央财政实际上充当了“最终偿债人”的角色。

《2014年地方政府债券自发自还试点办法》（财库〔2014〕57号）规定，试点地区承担债券还本付息责任，并且试点地区发行政府债券实行年度发行额管理以及按照有关规定开展债券信用评级。2015年，地方政府债券开始全面“自发自还”，地方政府债券作为“银边债券”全面登上中国债券市场舞台。2020年末，财政部发布《地方政府债券发行管理办法》（财库〔2020〕43号），对债务发行额度和期限、信用评级和信息披露、债券发行与托管、相关机构职责等进行规定，明确地方财政部门应当在国务院批准的分地区限额内发行地方政府债券。在信用评级方面，该办法明确，信用评级机构应当在评级结果有效期内每年开展一次跟踪评级，在债券存续期内发生可能影响偿债能力和偿债意愿的重大事项时，及时进行不定期跟踪评级，并公布跟踪评级结果。2022年2月25日，财政部正式发布“财政部—中国地方政府债券收益率曲线”取代了原有的中债地方债估值曲线，为地方政府债券一级发行提供有效参考，有助于提高地方政府债券市场的流动性和透明度。

# （二）信用债

我国信用债主要包括商业银行债券、非银行金融机构债券、特种金融债、公司债券（含企业债）、非金融企业融资工具（短期融资券、中期票据等）、资产支持证券、熊猫债券和城投债等。

# 1. 商业银行债券

商业银行债券由境内设立的商业银行法人发行，包括商业银行发行的普通金融债和为满足巴塞尔协议发行的次级债和混合资本债等。商业银行债券可分为一般金融债券、小微企业贷款专项债、“三农”专项金融债、次级债券、二级资本债券、无固定期限资本债券等品种。自2024年起，中国工商银行、中国银行、中国建设银行、中国农业银行、交通银行总损失吸收能力（TLAC）非资本债券开始发行。

# 2. 非银行金融机构债券

非银行金融机构债券发行主体为境内设立的非银行金融机构法人。其主要有证券公司债（普通债、永续债、次级债、短期融资券）、保险公司债（普通债、永续债、资本补充债）、财务公司债、租赁公司债等。

# 3.特种金融债

特种金融债券，是指经中国人民银行批准，由部分金融机构发行的，所筹集的资金专门用于偿还不规范证券回购债务的有价证券。

# 4. 公司债券（含企业债券）

公司债，是指公司依照法定程序发行、约定在一定期限还本付息的有价证券。企业债是由中央政府部门所属机构、国有独资企业或国有控股企业发行的债券，发债主体的信用级别较高。在企业债发行职责划转之前，其发行由国家发展改革委审批和注册。2023年10月23日，中国证监会正式接管企业债券的发行审核工作，标志着公司债和企业债的审核职责统一。

# 延伸阅读

我国公司债发行主体和批准方式经历多轮变迁。2007—2012年，公司债券的起步阶段，主要是上市公司发行、中国证监会审核的初步尝试阶段。2012—2015年，为了解决中小非上市企业融资难、融资贵的问题，中国证监会推出中小企业私募债债券，在原有公司债的基础上扩充了发行主体，简化了审核流程。2015年修订的《公司债券发行与交易管理办法》（证监会令第15号）颁布和实施，公司债发行主体扩容，发行主体由上市公司拓展至非上市公司，并区分了“大公募”（面向公众投资者公开发行）、“小公募”（面向合格投资者公开发行）、“私募”（非公开发行）三种情况，公司债发行呈“井喷”之势，中小企业私募债被取代。2020年3月1日，新的《证券法》规定公司债公开发行全面实施注册制，原先“大公募”的核准制和“小公募”的简化核准制均改成注册制，即由交易所审核通过后报送中国证监会履行发行注册程序，而非公开发行公司债仍采取事后备案制度，发行人在每次发行完成后5个工作日内向中国证券业协会备案。2023年6月，中国证监会发布《关于深化债券注册制改革的指导意见》（证监会公告〔2023〕46号）以及《关于注册制下提高中介机构债券业务执业质量的指导意见》（证监会公告〔2023〕47号），标志着我国公司债券（含企业债券）注册制改革全面落地。

企业债券在我国债券历史上，也扮演重要角色。在企业债职责划转前，其发行由国家发改委审批和注册，发行主体为境内具有法人资格的企业，主要包括两大类：一类是地方政府融资平台公司，即各地城投公司；另一类是产业类公司。2020年，债券发行注册制落地，根据《关于企业债券发行实施注册制有关事项的通知》（发改财金〔2020〕298号），国家发改委将具体的企业债审核工作下放给中央国债登记结算有限责任公司和中国银行间市场交易商协会，二者分别为国家发展改革委指定的企业债券审核机构负责企业债券审核工作。国家发改委是企业债的注册机构。2023年3月，中共中央、国务院印发《党和国家机构改革方案》，明确提出“强化资本市场监管职责，划入国家发展和改革委员会的企业债券发行审核职责，由中国证券监督管理委员会统一负责公司（企业）债券发行审核工作”。2023年4月21日，中国证监会、国家发展改革委发布关于企业债券发行审核职责划转过渡期工作安排的公告，6个月过渡期开始，并至2023年10月20日结束。为贯彻落实党中央、国务院关于机构改革的决策部署，稳妥有序做好企业债券过渡期后转常规相关工作，过渡期结束当日，中国证监会发布实施新的《公司债券发行与交易管理办法》（证监会令第222号），以及《公开发行证券的公司信息披露内容与格式准则第24号——公开发行公司债券申请文件》（简称《24号准则》）。自2023年10月23日9时起，中国证监会统一负责公司（企业）债券发行审核工作。上海证券交易所、深圳证券交易所、北京证券交易所负责企业债券受理、审核工作，并报中国证监会履行注册程序；同时，取消企业债券原预约申报环节。中央国债登记结算有限责任公司自2023年10月20日17时起，不再受理企业债券项目。公开发行企业债券的发行条件、申请文件、审核注册程序等，按照公司债券（含企业债券）相关制度规则执行。

# 5. 非金融企业债务融资工具

非金融企业债务融资工具是中国银行间交易商协会主导的一些企业债务融资工具，主要包括中期票据（MTN）、短期融资券（CP）、超短期融资券（SCP）、定向工具（PPN）、中小企业集合票据、资产支持票据（ABN）、定向工具以及项目收益票据（PRN）等。这些工具的发行主体为具有法人资格的非金融企业，在中国银行间市场交易商协会注册发行，并在上海清算所登记托管。

# 6. 资产支持证券（Asset-Backed Security，ABS）

资产支持证券是通过将基础资产（如信贷资产、企业应收账款等）证券化，从而获取融资的工具。我国的资产支持证券主要包括信贷资产支持证券、企业资产支持证券、资产支持票据和不动产信托资产支持票据等。

# 延伸阅读

我国资产支持证券则从2005年开始试点实践。2005年4月，中国人民银行等联合发布《信贷资产证券化试点管理办法》，同年12月，国家开发银行和中国建设银行分别发行了我国首只信贷资产支持证券和个人住房抵押贷款资产支持证券产品。2007年进入扩大试点阶段。2008年美国次贷危机后，我国监管部门出于审慎原则对资产证券化发行速度进行了延缓。2012年5月，中国人民银行、中国银监会、财政部联合发布《关于进一步扩大信贷资产证券化试点有关事项的通知》。2014年底，资产证券化业务相关业务规则修订后，进入快速发展阶段。根据入池资产和交易结构设计不同，我国资产证券化主要包括主要信贷资产支持证券、企业资产支持证券、资产支持票据（Asset-Backed Medium-term Notes，ABN）和不动产信托支持票据（类REITs）等。相关资料见图5-3。

信贷资产支持证券（信贷ABS）。银行业金融机构将信贷资产信托给特定目的信托受托机构（SPV），由受托机构以因承诺信托而取得的银行业金融机构信贷资产（信托资产）为限，以该信托资产所产生的现金支付资产支持证券收益的结构性融资活动。信贷ABS中，个人汽车抵押贷款ABS取代个人住房抵押贷款资产支持证券（Residential Mortgage Backed Security, RMBS），成为发行规模最大的品种。

企业资产支持证券（企业ABS），是指符合要求的证券公司、基金管理公司子公司等相关主体作为管理人通过设立资产支持专项计划或者中国证监会认可的其他特殊目的载体，以企业基础资产所产生的现金流为偿付支持，通过交易结构设计等方式进行信用增级，在此基础上所发行的证券。以券商集合理财计划形式出现，基础资产为信贷资产以外的其他资产、收费权等。企业ABS中，应收账款ABS和租赁资产ABS为发行规模最大的两个品种。

资产支持票据（ABN），指非金融企业为实现融资目的，采用结构化方式，通过发行载体发行的，由基础资产（应收账款、融资租赁债权、不动产、微小企业贷款等）所产生的现金流作为收益支持的，按约定以还本付息等方式支付收益的证券化融资工具。

不动产信托资产支持票据（类REITs），指非金融企业以不动产项目公司股权和债权（如有）作为底层基础资产发行的资产证券化产品。

# 7. 熊猫债券

熊猫债是指境外机构在我国境内发行的人民币债券，包括主权类机构、国外开发机构、金融机构和非金融企业等。我国熊猫债的发展史可追溯至2005年，是外资机构

在境内募资的一项重要制度突破。

# 8. 城投债

城投债是指地方政府融资平台或政府控制的企业发行的债券，通常用于地方基础设施和公用事业建设。城投债在中国具有独特的地位，长期以来被视为具有中国特色的“准市政债”。尽管其性质和管理方式随着政策的变化不断演进，但在地方经济发展中仍然发挥着重要作用。

# 城投债的规范与管理

自1992年7月21日起，我国第一家真正意义上的城投公司——上海市城市建设投资开发总公司成立，并于1993年4月15日成功发行第一只城投债以来，城投债市场已经走过了三十多年的发展历程。

2008年“四万亿”投资计划实施后，城投债市场进入快速发展阶段。随着市场规模的扩大，地方政府债务风险日益引起关注。为规范城投债市场，财政部和审计署多次对地方政府债务进行审计和排查，并逐步明确了偿还责任的界定。2010年，《国务院关于加强地方政府融资平台公司管理有关问题的通知》（国发〔2010〕19号）明确了地方政府融资平台公司的定义，即由地方政府及其部门和机构等通过财政拨款或注入资产设立，承担政府投资项目融资功能，并拥有独立法人资格的经济实体。随后，财政部发布的《关于贯彻国务院加强地方政府融资平台公司管理通知》（财预〔2010〕412号），进一步明确了地方政府融资平台公司的范围，包括各类综合性投资公司以及行业性投资公司。

2013年，中央政府实施了全国性政府债务审计，将地方政府债务划分为负有偿还责任的债务、负有担保责任的债务、可能承担一定救助责任的债务三部分，并采取了新老划断的债务处置方式。其中，地方政府负偿还责任的债务属于地方政府的“直接显性债务”，地方政府负有担保责任的债务属于地方政府的“直接隐性债务”，地方政府可能承担一定救助责任的债务属于地方政府的“或有隐性债务”。

2014年8月，全国人大决议通过了修订后的《预算法》，规定地方政府可以通过发行地方政府债券来融资，但必须在国务院批准的限额内进行。2014年10月，国务院颁布《关于加强地方政府性债务管理的意见》（国发〔2014〕43号），要求地方政府剥离融资平台公司政府融资职能，禁止融资平台公司新增政府债务，并将地方政府债务纳入全口径预算管理。这一系列措施明确了地方性债务“开前门、堵后门”的管理思路，在赋予地方政府合法举债权的同时，禁止其通过其他渠道举债。

从2015年1月1日新《预算法》实施至2023年底，我国共开启多轮化债工作。2015—2018年为第一轮化债，主要是地方债务置换，共发行12.2万亿元置换债，用于置换一类和二类债务。新《预算法》实施后，地方政府仍通过融资平台变相举债或在化债过程中，以各种形式新增隐性债务。2017年7月14日，第五次全国金融工作会议强调“各级地方党委和政府要树立正确政绩观，严控地方政府债务增量，终身问责，倒查责任”，进一步明确地方政府在债务及其管理等方面的责任；2017年7月24日，中央政治局会议强调“要积极稳妥化解累积的地方政府债务风险，有效规范地方政府举债融资，坚决遏制隐性债务增量”，第一次正式公开提出“隐性债务”这个概念。

2018年7月中央相继下发中发〔2018〕27号文、中办发〔2018〕46号文等多个文件，开启城投平台的隐债甄别认定，确定了新的隐性债务范围。2018年8月，财政部全口径债务监测平台系统上线。该系统负责统计各级党政机关、事业单位、国有企业的举债融资、资产情况及政府中长期支出事项情况，致力于摸清地方政府隐性债务的具体规模。根据2018年8月财政部印发的《财政部地方全口径债务清查统计填报说明》，隐性债务统计主体包括两大类：（1）机关事业单位，包括各级党委、政府所属部门、事业单位和社会团体；（2）国企，以融资平台为主。随后，我国政府确定十年化债方案，2018年，财政部《地方全口径债务清查统计填报说明》中列举了六种债务化解的方式：（1）安排年度预算资金、盘活财政存量结余资金偿还；（2）出让政府股权以及经营性国有资产权益偿还；（3）利用项目结转资金、经营收入偿还；（4）将具有稳定现金流的债务转化为企业经营性债务；（5）由企事业单位协商金融机构通过借新还旧、展期偿还；（6）破产重整或清算。

2019年11月，第一轮全国建制县（区）隐性债务化解试点开始，选取了6个省份，依然用置换债券化解试点县的隐性债务，通过财政资金偿还、银行贷款置换等方式逐步化解。2020年12月，我国开启第二轮全国范围特殊再融资债置换隐债，试点范围和规模扩大，并开始用特殊再融资债券化解隐性债务，推出6128亿元额度用于建制县区隐性债务风险化解试点，其中以重庆、天津、贵州为代表的29省市获得再融资债用于置换隐债。2021年10月9日，广东省宣布启动全域无隐债试点工作，并在10—11月共发行960亿元再融资债置换隐性债务，这意味着新一轮隐债置换进程开始。2022年6月特殊再融资债主要在北京、上海、广东发行，累计发行5042亿元，助力实现“全域无隐债”试点目标，广东和北京分别于2021年和2022年实现全域清零，上海6区也在2022年实现隐债清零。

2023年7月中央政治局会议召开以来，“有效防范化解地方债务风险，制定实施一揽子化债方案”。自2023年9月募集资金用途为“偿还存量债务”的地方政府特殊再融资债重启发行，截至2023年底，大约27个省份密集发行了大约1.39万亿元特殊再融资债券，用以降低地方政府隐性债务。

2024年7月21日，《中共中央关于进一步全面深化改革 推进中国式现代化的决定》全文发布，在地方债务和融资平台规范方面，指出将“完善政府债务管理制度，建立全口径地方债务监测监管体系和防范化解隐性债务风险长效机制，加快地方融资平台改革转型”，对地方债务监测和平台转型提出新的发展要求。

# 四、中国债券市场体系

我国债券市场形成了统一分层的市场体系，主要包括银行间市场、交易所市场、商业银行柜台市场等三个子市场。

# 1. 银行间市场

银行间市场属于大宗交易市场（批发市场），主要交易渠道是同业拆借中心本币交易系统，主要进行同业拆借、质押式回购、买断式回购、同业存单发行和交易、现券买卖以及债券借贷等业务。参与者是各类机构投资者，实行双边谈判成交，主要实行“实时、全额、逐笔”的结算方式。中央结算公司和上清所为投资者开立债券账户，实行一级托管，并提供交易结算服务。

# 2. 交易所市场

交易所市场由各类社会投资者参与，属于集中撮合交易的零售市场，典型的结算方式是净额结算。交易所债券市场有两种交易方式：第一种是自由竞价、撮合成交即按照“价格优先、时间优先”的原则竞价成交；第二种是大宗交易方式：对于在上交所进行的单笔买卖申报数量不低于1 000手，或交易金额不低于100万元的现券及回购交易，以及在深交所进行的单笔交易数量不低于500手，或交易金额不低于50万元的现券及质押式回购交易，认定为大宗交易。交易所债券实行两级托管体制，其中中央结算公司为总托管人，负责为交易所开立代理总户，中证登为债券分托管人，记录交易所投资者明细账户，中央结算公司与交易所投资者没有直接的权责关系。交易所债券交易结算由中证登负责。目前，我国交易所债券市场主要包括上交所、深交所、北交所三大市场。

# 3. 柜台市场

柜台市场是银行间市场的延伸，主要是满足无法直接参与银行间债券市场的机构和个人，也属于零售市场。过去柜台债券市场只有商业银行可以开展。2024年2月29日，中国人民银行发布《关于银行间债券市场柜台业务有关事项的通知》，该通知规定自2024年5月1日起，在柜台债券市场开办机构侧允许非商业银行机构与外汇交易中心、中债登、上清所的系统联测和功能验收，具有银行间做市商资格的证券公司，在完成系统验收后，可申请成为银行间债券柜台的开办机构，服务参与债券交易的各类投资者。中央结算公司为柜台市场一级托管机构，负责为开办银行开立债券自营账户和代理总账户，开办银行为二级托管机构，负责为投资者开立二级托管账户，中央结算公司与柜台投资者没有直接的权责关系。与交易所不同的是，开办银行需及时将柜台投资者账户变动数据传给中央结算公司，同时中央结算公司为柜台投资人提供债券复核查询服务，成为保护投资者权益的重要途径。

三个子市场中，银行间市场是我国债券市场的主体，债券存量接近全市场的90%。根据中国人民银行《2023年金融市场运行情况》，截至2023年末，债券市场托管余额157.9万亿元，同比增长9.1%，其中银行间债券市场托管余额137.0万亿元，占比86.76%；交易所市场托管余额20.9万亿元，占比13.24%；商业银行柜台债券托管余额577.5亿元，占比0.037%。

2023年，银行间债券市场现券成交307.3万亿元，日均成交12341.6亿元；单笔成交量主要分布在500万\~5000万元和9000万元以上，单笔平均成交量4702.1万元。交易所债券市场现券成交46.4万亿元，日均成交1919.3亿元（见图5-4）。柜台债券市场累计成交105.1万笔，成交金额1961.4亿元。2023年末，开办柜台债券业务的商业银行共30家，较2022年末增加2家。
