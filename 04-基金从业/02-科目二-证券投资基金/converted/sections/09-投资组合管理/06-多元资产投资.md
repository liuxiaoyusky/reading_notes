# 一、多元资产投资概述

# （一）多元资产投资的定义

多元资产投资是一种通过在不同资产类别之间进行分散投资，以实现风险分散和收益优化的投资策略。根据现代投资组合理论，通过合理的分散化，投资者可以在不显著降低潜在收益的情况下有效降低整体风险。

理想的多元资产组合应当涵盖广泛的资产类别，包括：

股票：作为资本增值的主要来源，股票通常是投资组合中的增长引擎。

债券：提供稳定的收益，尤其在市场波动时为投资组合提供保护。

现金及现金等价物：确保投资组合的流动性，满足短期资金需求。

另类投资：包括私募资本、房地产、大宗商品等，具有独特的风险收益特征，有助于进一步分散投资组合风险，提供额外的回报来源。

不同资产类别之间的低相关性是多元资产配置有效性的基础。通过合理配置这些资产类别，投资者可以在优化收益的同时有效降低风险。此外，衍生品工具如期权、期货和互换等，可用于调整资产配置、管理风险敞口和实现特定投资策略，为多元资产投资提供了更大的灵活性和效率。

# （二）多元资产投资的目标与业绩比较基准

多元资产投资的主要目标是通过优化资产配置，实现长期稳健的投资回报，并穿越市场周期。个人投资者通常会将资金分散投资于房产、储蓄、理财产品、基金等，满足其多样化的理财需求。机构投资者，如保险公司、银行、养老金计划、慈善基金等，也会采用多元资产投资策略，以应对当期和未来的需求。这种策略不仅能够满足个人和机构的多样化投资目标，还能帮助他们在不同的市场环境中保持投资组合的稳定性。

在多元资产投资中，投资者的业绩比较基准通常是多个指数的复合，例如，一个典型的复合基准可能是“40%沪深300指数+20%标普500指数+10%富时100指数+20%彭博全球综合债券指数+10%标普高盛大宗商品指数”这样的形式。需要注意的是，这种基准的具体构成应根据投资者自身的投资目标、风险偏好和投资约束进行定制，而非一成不变。这种复合基准能够更准确地反映多元资产组合的表现，并为投资者提供一个衡量投资策略有效性的参考标准。业绩比较基准的选择应当与投资者的具体目标、风险偏好和投资约束相匹配。

# （三）多元资产投资的管理与挑战

多元资产投资的管理包括投资者需求分析、投资政策说明书制定或产品设计、资产配置、证券选择、组合构建、交易执行、风险管理、业绩评估以及投资组合再平衡等多个环节。与单一资产投资相比，多元资产投资的管理更为复杂，尤其是在跨国界和跨货币的投资中，需考虑汇率风险、各市场的交易时间差异，以及不同国家的监管环境和税务政策。这种复杂性要求多元资产投资通常需要依赖专业团队的合作，以有效管理投资组合并实现投资目标。

多元资产投资经理的目标是通过投资于多个资产类别分散风险，增强组合的稳定性，并达成特定的投资目标。通常，多元资产投资经理负责资产配置，而具体的证券选择则交由单一资产类别的专业投资经理处理。这种分工合作的模式有助于充分利用各个领域的专业知识。在此过程中，投资经理需要深刻理解每一类资产的风险和收益特征，以及这些资产在投资组合中所扮演的不同角色。

多元资产投资还面临着一些独特的挑战：

应对这些挑战需要强大的研究能力、先进的风险管理工具、高效的组织结构以及持续的专业发展。成功的多元资产投资管理不仅需要深入了解各个资产类别的专业知识，还需要具备从整体角度优化投资组合的能力，以实现投资者的长期目标。这要求投资团队具备跨资产类别的综合能力，以及对全球经济、市场动向和风险因素的深刻理解。最终，成功的多元资产管理在于平衡收益与风险，确保投资组合在各种市场条件下都能稳健运行。

# 二、资产配置

资产配置是根据投资者的需求将资金在不同资产类别和策略之间进行合理分配。资产配置是多元资产投资的核心步骤。通过资产配置，投资者可以在可接受的风险水平内，力求实现最高的预期收益。

资产配置不仅是一个简单的资金分配问题，更是一个系统性的决策过程，涉及多个层面的思考与规划。以下将详细介绍战略资产配置、战术资产配置、资产配置再平衡的具体内容。

# （一）战略资产配置

从一般意义上讲，战略资产配置（Strategic Asset Allocation，SAA）是为了满足投资者风险与收益目标所做的长期资产的配比。战略资产配置根据投资者的风险承受能力，对资产作出事前的、整体性的、最能满足投资者需求的规划和安排。战略资产配置确定了各主要大类资产的投资比例，体现了适合投资者长期投资目标的最佳长期资产组合结构。

战略资产配置是投资组合构建的起点，也是整个投资管理过程中的核心环节。无论是机构投资者还是个人投资者，通常都会将战略资产配置视为投资管理的基石，因为在这一过程中，投资者可以充分融入和体现自身的投资需求、偏好和长期目标。通过战略资产配置，投资者能够在较长的投资期限内，追求稳定的长期回报。

这种资产配置方式强调长期性，因此通常不考虑资产的短期波动。其投资期限往往较长，通常为5年以上。投资经理在确定可投资的资产类别后，基于长期投资目标制订战略资产配置计划。在这一过程中，投资经理需要对各类资产的长期预期收益率、风险水平以及资产间的相关性进行全面分析，并运用均值方差模型等优化方法来构建一个最优的资产组合。通过这些分析，投资经理可以确定各资产类别在投资组合中的权重，最终形成战略资产配置。一旦战略资产配置确定下来，它在整个投资期限内通常会保持相对稳定。

例如，某个投资组合的长期投资目标是战胜通货膨胀，并获得一定的相对收益，其投资范围仅限于债券和股票，且不可投资于投资级别以下的债券，如垃圾债券等。如果通货膨胀率是 $2\%$ ，每年预计获取的真实收益率是 $3\%$ ，则该投资组合每年的预期收益为真实收益率 $3\%$ 加上通货膨胀率 $2\%$ ，为年化 $5\%$ 。在战略资产配置层面，该组合将选择可以抵消或战胜通货膨胀率的资产，比如通胀保护债券，并配置部分在长期能够带来净值增长的资产类别，如股票。

# （二）战术资产配置

战略资产配置专注于长期目标的实现，但在此基础上，若能有效捕捉各资产类别的短期回报率波动，也可以显著增强投资组合的整体回报率。战术资产配置（Tactical Asset Allocation，TAA）便是在遵循战略资产配置所确定的大类资产比例基础上，根据短期内各特定资产类别的表现，对投资组合中这些资产类别的权重进行调整，从而实现这一目的。

战术资产配置是一种基于对短期资本市场环境及经济条件的预测，主动对资产配置状态进行动态调整的投资策略。其核心在于通过对市场短期波动的敏锐把握，灵活调整各资产类别的配置比例，以期在短期内增加投资组合的价值。与战略资产配置不同的是，战术资产配置更注重市场的短期表现，强调通过市场择时（Market Timing）等手段，利用金融工具在各大类资产之间灵活调配资金，从而在短期内优化投资收益和风险管理。

战术资产配置的周期通常较短，一般在1年以内。这种策略的特点是高度灵活，要求投资管理人在市场变化时迅速作出反应，并根据市场状况的变化对资产类别的预期收益进行调整。然而，战术资产配置并不涉及对投资者长期目标或风险偏好的重新评估，更多的是基于当前市场机会的短期操作。

运用战术资产配置的前提条件是基金管理人具备较高的市场洞察力和预测能力，能够准确把握市场的短期波动并有效实施动态调整。为了支持这一策略的实施，投资管理人通常使用一系列工具和方法，例如分析政治经济状况、把握市场动态、观察估值水平的变化等。这些分析工具帮助管理人预测市场趋势，并根据预测结果调整投资组合，力求在短期内获得超额收益。

然而，战术资产配置的有效性在投资界仍存在较大争议。虽然理论上，战术资产配置可以通过市场择时来获取超额收益，但实践证明，只有少数基金管理人能够持续性地通过这种策略战胜市场。因此，为了控制风险，战术资产配置对战略资产配置的偏离通常被限制在一定范围内，以避免由于过度的短期调整而导致投资组合偏离长期目标。

# （三）资产配置再平衡

在投资组合的运作过程中，随着时间的推移，各类资产的市场表现往往会出现差异。一些资产的价格上涨，导致其在投资组合中的占比上升；而另一些资产的价格下跌，其在投资组合中的占比则相应下降。因此，随着资产价格的不断变化，投资组合中各类资产的实际比例会逐渐偏离最初设定的战略资产配置基准。当这种偏离超过一定程度时，投资经理需要通过调整投资组合的资产权重，使投资组合的结构尽可能恢复到与战略资产配置设定一致的状态。这个过程被称为“资产配置再平衡”。

资产配置再平衡的主要目的是保持投资组合的风险收益特征与最初设定的一致性。再平衡并不涉及对市场状况的主动预测或分析，而是基于既定的目标进行被动操作。通常，再平衡特指由于资产价格变化导致的资产配置权重偏离战略资产配置基准，从而进行的资产权重调整。这与因投资者财务状况变化或因投资经理对市场预期调整而产生的重新配置需求不同，后者并不属于传统意义上的再平衡。

资产配置再平衡的实施可以采取多种方式，主要包括定期再平衡、基于偏离程度

的再平衡以及两者结合的再平衡策略。

定期再平衡是一种最为简单直接的方式，即在预定的时间间隔内（如每月、每季度或每年），将投资组合中的资产权重调整回目标权重。例如，假设某投资组合的目标配置是 $40\%$ 股票和 $60\%$ 债券，投资经理可能会在每季度末检查组合的实际资产比例，并将其调整回 $40\%$ 股票和 $60\%$ 债券的初始配置。这种方法的优点在于执行透明且易于管理，无须复杂的市场预测或分析。

基于偏离幅度的再平衡则更为灵活，依赖于设定的偏离度阈值。当实际资产比例偏离初始配置超过预定的阈值时，才会触发再平衡。例如，基金经理可能设定了一个最大偏离度阈值为10%的再平衡策略。如果初始设定的资产配置为40%的股票和60%的债券，那么当债券的权重上升到70%或下降到50%时，就会触发再平衡，促使基金经理将投资组合重新调整为股票40%和债券60%的初始配置。然而，如果偏离幅度在阈值内（如债券权重在50%\~70%浮动），则不会进行再平衡。这种方法的优点在于减少不必要的交易，降低交易成本，同时保持资产配置的灵活性。

再平衡也可以采取 “定期再平衡” 与 “基于偏离幅度再平衡” 相结合的方式。这种方法允许投资组合在一定的时间周期内进行检查，并且只有在偏离超过一定阈值时才进行调整。这种结合方式可以在一定程度上优化再平衡的频率，既避免了过度交易导致的成本增加，又能够有效控制资产配置的偏离度。

再平衡是一个复杂的过程，受到多种因素的影响。例如：

投资者可以通过回测历史数据，比较不同时间频率和偏离阈值下的组合表现，确定最优的再平衡时间周期和偏离阈值。通过这些方式，投资者能够在维持投资组合长期目标一致性的同时，优化再平衡的成本和效果。

总的来说，资产配置再平衡是一项至关重要的操作，它不仅帮助投资者维持投资组合的初始风险收益特征，还能在一定程度上通过纪律性操作，提升长期投资的稳定性。然而，再平衡的执行需要在成本、效益和风险控制之间找到平衡点，以确保投资组合能够在长期内保持健康的增长。

# 三、各类资产在投资组合中的作用

在构建投资组合时，各类资产的作用各有侧重，能够满足不同的投资需求。以下内容详细讨论了股票、债券和另类资产在投资组合中的作用。

# （一）股票资产在投资组合中的作用

股票资产在投资组合中的主要作用包括实现资产增值、提供股息收入、分散组合风险以及在一定条件下对抗通货膨胀。

# 1. 资产增值

在经济高速增长期，股票往往表现优于其他资产类别；而在经济疲软时期，股票表现可能会逊色于债券或其他固定收益资产。竞争格局的改善、业绩成长性好等因素都可能带来股票资产增值。

# 2. 股息收入

股息收入是股票投资的重要收益来源之一。通常成熟型公司更倾向于将盈利以股息形式分配，而成长型公司则倾向于保留盈利进行再投资。这意味着，投资者可以通过持有成熟型公司的股票，获得相对稳定的现金流，从而增强投资组合的收益稳定性。

# 3. 分散组合风险

虽然单一股票的风险较高，但通过持有多只股票，投资者可以在一定程度上分散个股风险。然而，股票市场的系统性风险（即市场整体下跌的风险）无法通过个股的分散来消除。因此，将股票投资与其他低相关性的资产，如债券或房地产结合，可以进一步降低整个投资组合的风险。

# 4. 对抗通货膨胀

股票在长期内通常能够提供一定的通货膨胀保护，尤其是那些拥有较强定价能力、能够将成本上涨有效转嫁给消费者的企业股票。然而短期内，特别是在通胀急剧上升或经济滞胀时，股票整体的表现可能并不理想。因此，股票并非在所有情境下都能有效对冲通胀，投资者需谨慎评估具体经济环境。

# （二）债券在投资组合中的作用

债券在投资组合中扮演着多重角色，包括分散风险、提供规律性现金流和对冲潜在的通货膨胀。

# 1. 分散化优势

在投资组合中加入债券能够显著提高分散化效果，尤其是在与股票或其他高风险资产组合时。通常，债券与股票的相关性较低，特别是在市场波动较大时，债券能够通过降低整体组合的波动性来分散风险。然而，资产类别之间的相关性并非恒定，可能随市场条件的变化而波动。例如，在熊市中，投资者倾向于从风险资产如股票和高收益债券，转向安全资产如政府债券。这些行为可能会降低政府债券与股票之间，以及政府债券与高收益债券之间的相关性；同时，股票和高收益债券等高风险资产之间的相关性可能会增加。

# 2. 规律性现金流优势

债券投资通常会产生有规律的现金流，投资者可以通过投资债券来为未来的支出提供资金，如学费、保险、赡养费等。此类负债驱动的投资组合所选取的债券现金流的时间和规模必须与预计未来负债的时间和规模相匹配。有的投资者会将组合中债券的到期日在投资期限内分散错开，构建阶梯式债券组合。这种方法有助于平衡债券价格波动风险和再投资风险。

# 3. 对冲潜在的通货膨胀

某些债券有对冲通货膨胀的作用。例如，通胀挂钩债券（Inflation-linked Bond）的本金与票息支付直接与消费者价格指数（CPI）等通胀指标挂钩，有效提供通胀保护。浮动利率债券（Floating Rate Bonds）的票息与市场基准利率挂钩。当通货膨胀导致市场利率上升时，其票息随之调高，从而提供一定的通胀保护，但其抗通胀作用机制与直接挂钩通胀指数的债券不同，效果通常也较通胀挂钩债券弱。

# （三）另类资产在投资组合中的作用

在多元资产投资中，另类资产日益成为关键组成部分。它们不仅能够提升投资组合的潜在收益，还能通过其独特的风险特征，实现有效的风险分散。

# 1. 私募资本

私募资本作为投资组合的一部分，主要通过非公开市场的独特机会和长期投资策略，提升整体收益。其独特的风险—收益特性使其在不同市场环境下能够提供一定的稳定性。此外，私募资本通常与传统资产的相关性较低，有助于降低组合的整体波动性。然而，投资者需权衡其流动性较低和估值复杂等挑战。

# 2. 实物资产

实物资产涵盖不动产和大宗商品等多种类别，作为多元化工具在投资组合中发挥关键作用。不动产通过稳定的租金收入和资产增值，提供稳健的现金流和长期资本增值，且其价值通常随通货膨胀上升，具有良好的通胀对冲能力。大宗商品则因其与通货膨胀高度相关，在通胀上升时期表现较好，同时其价格走势与传统金融市场不同，进一步分散投资风险。这些特性使实物资产在提升组合稳定性和抗风险能力方面具有重要作用。

# 3. 对冲基金

对冲基金通过多样化的投资策略，如多空股票策略、套利和事件驱动策略等，追求在不同市场环境下的超额收益。其策略的多样性和较低相关性能够提升组合整体的风险分散效果。然而，对冲基金的策略差异显著，投资者需谨慎评估具体策略的风险特征，以及其对组合整体风险贡献的影响。

# 四、多元资产投资的策略和产品

进行多元资产投资策略时，投资者根据不同的目标，可以采用多种策略或策略组合。这里介绍几种常见的多元资产投资策略，包括核心—卫星策略、风险平价策略和全天候策略，以及几种典型的多元资产基金。这些策略和产品各有特点，适合不同的投资需求和市场环境。

# （一）核心—卫星策略

核心—卫星策略是一种广受认可的资产配置方法，其核心思想是将投资组合分为两个主要部分：一个较大的核心部分和一个较小的卫星部分。核心部分一般采用被动管理方式，在投资组合中通常占比60%\~80%，通过低成本的指数基金或ETF来实现，旨在提供稳定的市场回报。卫星部门占比20%\~40%，主要采用主动管理方式，通过投资于特定机会或另类资产来力求获取超额收益。

实施核心—卫星策略时，投资者首先需要根据自身风险承受能力、投资目标和市场观点确定核心与卫星的配置比例，然后选择匹配的投资工具。在运作过程中需要定期再平衡，以保持预定的配置比例。

核心—卫星策略的优势在于平衡风险与收益核心部分提供稳定性和市场敞口，卫星部分则增加获取超额收益的机会，同时保持低成本。然而，该策略管理上较为复杂，需具备一定的专业知识和管理能力。频繁的再平衡可能增加交易成本，并影响整体收益。

核心—卫星策略适合那些希望在控制风险的同时追求一定程度超额收益的投资者。这些投资者通常具有一定的投资知识和经验，能够理解和管理相对复杂的投资策略。同时，由于有效实施分散化投资需要一定的资金规模，这种策略也更适合资金较为充裕的投资者。

# （二）风险平价策略

风险平价策略是一种根据不同资产类别的风险贡献度来确定其在投资组合中的权重的策略，以实现风险均衡配置。与传统的资产配置方法不同，风险平价策略关注的是每种资产对整体投资组合风险的贡献，而不是单纯依据预期收益或市值比例来分配资产。

一般情况下，高波动性的资产（如股票）在传统的投资组合中占比较大。但在风险平价策略中，这些资产的配置比例会被适当降低，以确保其对整体组合的风险贡献

与其他资产类别相当。

风险平价策略通常涉及多种资产类别，通过分散投资，能够在不同市场环境下保持相对稳定的表现。由于每种资产的风险贡献相对均衡，该策略在市场波动时更能保护投资组合，同时捕捉不同资产类别的上涨机会。

风险平价策略的核心理念是通过均衡配置风险实现长期稳健的投资回报，而非单纯追求高回报。这种策略适合希望通过分散投资来减少投资组合波动性的投资者。

# （三）全天候策略

全天候策略（All-Weather Strategy）是由桥水基金（Bridgewater Associates）创始人雷·达利欧（Ray Dalio）在1996年提出并发展的投资方法。这一策略的设计目标是在不同市场环境下都能获得稳定收益并有效控制风险。其核心理念是通过广泛分散投资，降低投资组合对单一经济环境的依赖，从而在任何市场条件下都能获得合理回报。

全天候策略考虑了经济增长、通货膨胀、通货紧缩和经济衰退等不同经济环境，通过配置适应不同经济环境的资产类别（如股票、债券、大宗商品、通胀保护证券等），确保投资组合能够在不同经济条件下表现良好。例如，在经济增长和通胀上升时期，股票和大宗商品可能表现出色；而在经济衰退和通货紧缩期间，债券和现金可能成为更好的防御性资产。

全天候策略通过在多种资产类别之间广泛分散投资来降低组合的波动性。这种策略强调资产之间的低相关性，这样在某些资产下跌时，其他资产能够提供支撑，从而平滑整体投资组合的表现。

值得注意的是，全天候策略在强劲牛市中可能表现落后于更激进的策略，且其有效性依赖于历史资产相关性的持续性。此外，频繁的再平衡可能带来额外的交易成本。

该策略适合那些希望长期稳健投资的投资者。自达利欧提出以来，全天候策略因其在不同市场环境下的稳定表现而受到广泛关注，并被许多投资者和机构采用和改进。

# （四）多元资产基金

资产规模较大的投资者可以单独购买不同的资产类别进行多元资产投资。对于资产规模较小的投资者，考虑到多元资产投资的复杂性和某些资产较高的投资门槛，投资于专门的多元资产基金更为可行。多元资产基金将多种资产类别组合在一个投资组合中，既包括传统的股票和债券、指数基金、金融衍生品，也包括另类投资，如不动产投资信托（REITs）和商品。基金经理通过对各类型资产、因子、风格和管理人的广泛和深入的研究，精心设计风险敞口，进行动态管理。养老目标基金就是多元资产基金的一种。

# 1. 基金概况

挪威政府养老金全球基金（GPFG）成立于20世纪90年代，是全球规模最大的主权财富基金之一。该基金旨在通过投资石油收入盈余，为挪威未来几代人提供财务保障，帮助应对石油资源枯竭和人口老龄化所带来的经济挑战。截至2023年底，GPFG的资产规模达到15.765万亿挪威克朗（约合1.5万亿美元），在全球金融市场中占据重要地位，其投资策略和业绩表现受到关注。

# 2. 投资目标和资产配置

GPFG的核心目标是在可接受的风险范围内，通过实现长期实际回报最大化，维持和增强其国际购买力。GPFG采用由挪威财政部设定的自定义基准指数。该基准指数由权益和固定收益两个组成部分构成：权益部分基于富时全球全市值指数（FTSE Global All Cap Index），占比70%；固定收益部分基于彭博全球综合债券指数。截至2023年底，该指数包括来自2398家发行人的17565只债券，占比30%。需要注意的是，该基准指数并未包含未上市房地产和未上市可再生能源基础设施投资，这些投资需要通过低配基准指数中的股票或债券的配置来实现。这种结构性差异增加了GPFG相对基准的超额回报和风险管理的复杂性。

根据该基金2023年年度报告，截至2023年12月31日，GPFG的资产配置为：权益占70.9%，固定收益占27.1%，非上市房地产占1.9%，未上市可再生能源基础设施占0.1%。这一配置反映了基金对长期增长资产的倾向，同时通过固定收益和实物资产来平衡风险，从而在追求高回报的同时维持资产组合的稳定性。

GPFG的投资高度多元化，涵盖72个国家和43种货币，确保了投资组合的广泛分散。主要投资地区包括美国（ $48.8\%$ ）、日本（ $7.2\%$ ）、英国（ $6.1\%$ ）等。固定收益投资以美元（ $51.2\%$ ）、欧元（ $28.2\%$ ）、日元（ $6.9\%$ ）为主，房地产投资主要分布在美国、英国、法国和德国。

# 3. 投资管理特点

GPFG结合了主动管理与被动管理策略，以在遵循战略资产配置的基础上，获取超额回报。尽管2023年基金表现略低于基准（-0.18个百分点），但长期（1998—2023年）年化超额回报0.28个百分点，表明其主动管理策略在提升整体回报方面起到了积极作用。

GPFG在股票投资中倾向于高波动性和成长型股票，同时在固定收益投资中减少对公司债券的敞口，增加了新兴市场债券的配置。这些策略反映了基金对特定风险因子的策略性暴露，以优化风险调整后的回报。

GPFG 将环境、社会和公司治理（ESG）因素纳入投资决策过程。基金积极与被投资公司就气候风险等问题进行沟通，并发布关于消费者权益等主题的投资期望，体现了其作为负责任投资者的角色。

GPFG采用全面的风险管理框架，包括预期波动率、最大预期损失（VaR）和压力测试等多种指标。2023年底，基金的预期波动率为10.3%，表明其年度资产价值可能波动约1.62万亿挪威克朗。通过这些风险管理工具，GPFG能够有效控制投资风险，确保基金的稳健运营。

2023年，GPFG基金管理成本占资产管理规模的0.045%。
