# 一、主动投资概述

与被动投资旨在复制市场基准不同，主动投资的核心目标是通过积极的投资决策，力求获得超越特定业绩比较基准的超额收益，这种超额收益通常被称为“阿尔法”（Alpha）。在现代投资组合理论中，Alpha通常指投资组合的实际收益率，在扣除其因承担系统性风险（由Beta衡量）而应获得的预期收益之后，所剩余的部分。简而言之，Alpha是衡量投资经理在扣除市场整体波动因素后，通过其主动管理能力所创造的超额回报。

Alpha 的来源可以归因于多个方面。首先，投资管理人通过独到的证券选择、有效的市场择时或行业配置，展现出优异的投资技能。其次，信息优势也是获取 Alpha的重要来源，即投资者能够获取或准确解读那些尚未被市场充分反映的信息。此外，主动投资者还可能通过识别和利用市场无效性，把握由其他投资者行为偏差引发的价格错位，从而实现超额收益。进一步地，通过对不同风险因子（如价值、成长或动量等）进行有效的暴露与择时，并把握这些因子的周期表现，也有助于提升 Alpha 水平。然而，需要强调的是，观察到的超额收益（亦称名义 Alpha）并不一定全部源自可持续的投资技能，其中可能包含了运气成分，或因承担传统风险模型未能捕捉到的隐性风险而获得的风险溢价（或风险补偿）。

所有的基金都需要选定一个业绩比较基准，它不仅是考核基金业绩的工具，也是投资经理进行组合构建的出发点和参照系。在主动管理中，基金经理有意识地对基准组合进行配置上的调整，以追求超额收益，这里的“偏离”是中性的专业术语，指的是有意识地与基准指数构成差异化配置，而非“错误”或“背离”，这种偏离必须在基金合同允许的范围内进行。主动型基金在选定业绩比较基准时，需要充分考虑其投资目标和风格。投资目标决定了基金可投资产的类别（如股票与债券的比例），而投资风格则决定了证券选择的范围。在选择业绩比较基准时要尽可能地体现这些特征，否则业绩比较基准就失去了其参考价值。

在被动投资中，我们讨论过投资组合表现与基准之间的“跟踪偏离度”和“跟踪误差”，而在主动管理中也存在类似的概念。通常将投资组合的实际收益与基准收益之差定义为主动收益（Active Return），该指标反映了基金经理通过主动管理实现的超越或落后于基准的表现，因此主动收益既可能为正，也可能为负。

主动风险（Active Risk），实际上就是前述的跟踪误差，两者计算方法一致，均用于衡量主动收益的波动性。主动风险表明，基金经理在追求主动收益过程中，投资组合的业绩与基准之间可能出现多大程度的偏离。较高的主动风险意味着投资组合收益可能大幅超越或落后于基准，主动收益的波动性较大；而较低的主动风险则说明组合收益更紧密地跟随基准，主动收益的波动性较小。因此，主动收益衡量了“偏离”的结果，而主动风险则衡量了这种“偏离”的幅度和稳定性。这两者的比值便构成了衡量主动管理能力的关键指标——信息比率（Information Ratio）。越高的信息比率表明单位主动风险所能获得的超额收益越多，这通常被视为衡量投资经理在承担主动风险的前提下，获取超额收益能力的有效指标，即主动管理能力的体现。

主动投资的业绩主要取决于投资者使用信息的能力和掌握的投资机会的数量，即信息深度和信息广度。首先，在投资机会不变的情况下，投资技能的上升会提高信息比率。经验丰富的投资者通常能实现更高的风险调整后收益。其次，在同等的投资技能下，掌握更多投资机会的投资经理往往能提高投资组合的信息比率。因此，较高投资能力的投资经理如果掌握的投资机会较少，其业绩可能与投资能力一般但掌握机会较多的经理相当。需要注意的是，投资机会的数量和使用这些机会的效率之间可能存在一种权衡关系；例如，过度寻求和扩展投资机会有时可能导致单一机会分析深度的不足或整体管理效率的下降。

# 二、主动股票投资组合管理

主动股票投资组合管理旨在通过积极的选股、行业配置和风格调整等策略，获取超越股票市场基准的收益。

研究表明，根据公司规模、所在地区、行业、业绩表现、股价表现等特征对股票进行分类，不同类别的股票在收益上存在显著差异。通常，同类股票之间具有较高的相关性，而不同类别的股票之间相关性较低。因此，投资者在实践中常从区域、行业、规模和风格等角度划分股票市场。例如，全球市场可以划分为发达市场、新兴市场和前沿市场；上市公司根据市值大小可以分为大盘股、中盘股和小盘股。

主动投资策略多种多样，其核心思想主要包括证券选择、市场择时以及行业或主题配置。证券选择旨在通过识别并投资于价值被低估的证券，或卖出价值被高估的证券，以期获取超额回报。市场择时策略则试图通过预测市场的整体走向，在不同资产类别之间或同一资产类别内部的不同风格之间进行动态配置，但持续准确地预测市场极具挑战性。中观层面的策略，如行业轮动与主题投资，则介于宏观的市场择时和微观的证券选择之间。行业轮动是根据对经济周期或特定行业前景的判断，主动调整不同行业的配置权重，例如在经济复苏期超配周期性行业。主题投资则是围绕具有长期增长潜力的特定投资主题（如人工智能、新能源等）来构建组合。

投资风格的划分也十分重要，常见的风格包括价值型、成长型和平衡型，这些风格通常通过市盈率、市净率、盈利增长等指标来界定。偏好成长风格的基金经理会挑选预期未来盈利增长较快的股票，期望获得未来业绩实现后带来的价格上涨收益；偏好价值风格的基金经理则试图寻找相对便宜的股票，期望其估值恢复到合理水平。有的基金经理既追求价值风格，又追求成长效应，这种策略被称为“合理价格下的成长策略”（Growth At Reasonable Price, GARP），即寻找盈利增长高于平均水平且价格合理的股票。此外，投资者也可能试图通过风格切换来获取更高的收益。

在组合构建方面，常用的策略包括“自上而下”与“自下而上”两种。自上而下策略从宏观经济形势及行业、板块特征入手，先确定大类资产、国家、行业的配置，然后再挑选相应的股票作为投资标的，实现配置目标。自下而上策略侧重个股表现，强调通过深入分析筛选优质股票，而不依赖于经济或市场的整体趋势。很多基金经理会结合两种策略，以兼顾宏观与微观因素。

自下而上策略主要聚焦于个股选择，这种方法没有固定的模式，而是灵活运用多种分析工具来识别和选择有潜力的股票。在实践中，投资者可以综合运用基本面分析、技术分析和量化分析等多种方法。基本面分析可以帮助投资者深入研究公司的财务状况、管理团队、行业地位和增长前景，从而评估其长期投资价值。技术分析则通过研究股票价格走势和交易量等市场数据，帮助投资者把握交易时机。量化分析利用数学模型和统计方法，系统地寻找被市场低估或高估的股票。此外，投资者还可能考虑公司的竞争优势、市场份额、公司治理等因素，以全面评估投资标的。自下而上的选股理念特别适用于市场存在广泛定价无效的情况。在这种环境下，投资者可以通过深入研究和分析，发现被市场忽视的投资机会。

自上而下策略是一种宏观视角的投资方法，其核心在于通过分析和预测影响整体经济形势的关键变量来指导投资决策。这种策略首先关注诸如消费者信心、商品价格、利率、通货膨胀率和国内生产总值等宏观经济指标，通过对这些因素的深入研究和预测，在不同类型的股票之间进行合理分配。自上而下策略还可以通过积极的投资风格调整来追求额外收益。例如，根据市场环境的变化，投资者可以灵活调整价值股与成长股的投资比例，以适应不同市场周期下的投资机会。此外，这种策略还可以运用于板块轮换，通过在周期非敏感型行业和周期敏感型行业之间进行适时切换，捕捉不同经济周期下各行业板块的表现差异，从而获得超额收益。

然而，需要注意的是，无论是采用自上而下还是自下而上的投资策略，基金的投资组合构建过程都受到多方面因素的制约。这些因素包括但不限于基金合同的规定、公司的投资政策、基金经理的个人能力和经验等。这些约束会在大类资产配置、行业选择、投资风格以及个股筛选等多个层面影响投资决策的制定和执行。因此，在实际操作中，投资者需要在遵守各项规定和约束的前提下，灵活运用策略，以实现投资目标并控制风险。

当前我国公募基金投资的大类资产以股票与固定收益证券为主。基金类型基本上决定了大类资产配置的范围。例如，股票型基金通常要求在股票资产上的配置比例不低于基金资产的80%，债券型基金在债券资产上的配置比例一般不低于基金资的80%，混合型基金选择的范围比较广，介于股票型和债券型之间。在不超出基金合同所允许的范围内，信奉自上而下理念的投资经理需要结合自己对宏观经济形势的预测来选择合适的股票投资比例，而信奉自下而上理念的投资经理在股票上的投资比例则主要取决于对其掌握的可投资股票的理解深度和广度。

在行业、风格层面上，有的基金契约已经规定投资的具体行业或风格，如行业基金、大盘/小盘基金、价值/成长基金等。这些基金的投资范围受到较为严格的限制。有的基金没有明确的行业或风格限制，投资经理可通过对当前市场形势的研究和判断，自主决定行业和风格的配置。

此外，个股的选择与权重受到基金契约和法规中投资比例等方面的限制。例如，个股投资权重的“双十限制”：一只基金持有一家公司发行的证券，其市值不得超过基金资产净值的 $10\%$ ；同一基金管理人管理的全部基金持有一家公司发行的证券，不得超过该证券的 $10\%$ 。

# 三、主动债券投资组合管理

与股票相比，债券的收益特征，尤其是票息部分，具有较高的可预测性，但其价格同样受到宏观经济、市场利率、信用环境、供需关系等多种因素的影响而波动。债券分析方法也不同于股票，主要分析指标有到期收益率、利率期限结构、久期、凸性、信用利差等。全球债券投资管理策略在过去几十年中经历了多次演变。20世纪60年代以前，大多数债券组合管理者采用买入并持有策略。到了70年代初期，随着布雷顿森林体系的解体，利率和汇率波动加剧，投资者对积极债券组合管理策略的兴趣逐渐提高。70年代末和80年代初，随着通货膨胀率和利率创历史新高，债券市场收益率波动剧烈，催生了许多新型金融工具和更为复杂的主动管理策略。

从投资目标出发，债券投资组合的策略可大致划分为以满足负债为主要目的的投资策略和以追求投资收益为主要目的的投资策略。

以满足负债为主要目的的投资策略旨在确保资产未来的现金流收入能够覆盖未来偿付负债所需的现金流支出。该策略追求的目标是偿还负债，最小化无法满足负债支出的风险。所得免疫策略和价格免疫策略都属于此类策略。

以追求投资收益为主要目的的策略则侧重于投资收益最大化，通常该类策略会选定业绩比较基准并追求超额收益。主动型债券基金经理通过对宏观、行业和个券研究，对利率和信用等要素进行预测，并调整组合的利率和信用风险水平以获取超额收益。例如，擅长利率预测的基金经理可以选择调整投资组合与基准在久期上的错配来获取超额收益。当基金经理认为当前市场的远期利率偏高而未来利率不太可能达到这个水平时，可以通过提高投资组合的久期，以从收益率曲线的下行中获利。此外，基金经理还可以通过识别被低估与被高估的债券，相对基准进行品种上的错配，低买高卖获取收益。基金经理还可以依据对收益率曲线上不同点的相对价值的判断，采用哑铃或者子弹型策略配置组合。

同股票型基金类似，债券型基金需要在招募说明书中说明基金的投资目标、投资理念、投资策略、投资范围、业绩比较基准、风险收益特征等关键要素，这些要素决定了基金投资组合的构建理念和流程。自上而下的债券配置从宏观层面开始，分析利率风险、流动性风险和信用风险，进而决定在不同的信用等级和行业类别上的配置比例，通过大类资产配置、类属资产配置和个券选择三个层次自上而下地决策，最终实现基金的投资目标。
