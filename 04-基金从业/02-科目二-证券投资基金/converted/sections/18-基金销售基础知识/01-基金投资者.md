基金产品是用来满足投资者需求的工具。基金公司与基金销售机构是连接投资者和基金产品的纽带，其根据潜在投资者、自身定位、业务发展方向制定不同的产品销售策略来满足不同投资者的需求。

# 一、投资者分类

基金投资者即基金份额的持有人，是基金资产所有者和基金投资盈亏的承担者。根据投资主体的法律地位，可把投资者分为个人投资者与机构投资者两种类型，前者为自然人，后者为法人及非法人主体。在投资者适当性管理中，常常根据风险承受能力、资产状况以及投资知识和经验的不同，把投资者分为专业投资者和普通投资者。

# （一）个人投资者与机构投资者

# 1. 个人投资者

个人投资者以自然人身份进行投资，具有以下特征：

个人投资者有各种各样的投资需求。例如，个人投资者的短期目标可能是购买房子或汽车；中期目标可能是为孩子教育准备资金，或者是创业；而长期目标则可能是通过投资为将来退休后的生活提供收入。

影响个人投资者投资需求的基本因素是他们在生命周期中所处的阶段。通常，个人投资者的风险承受能力将随着年龄的增长逐渐下降。中青年人往往是“初生牛犊不怕虎”，对证券市场波动带来的投资亏损尚未体会或体会不深，更具有冒险的精神，而且其有较长的时间来积累财富，更能承担高风险的投资后果。而老年人往往经历了证券市场多轮牛熊更替，对风险控制有更深切的体会，而且其一般因退休而失去了工资收入，增量资金有限，所以更偏向于保守的投资。

个人投资者不同的财务状况在很大程度上也会影响其投资需求。比如个人投资者的收入水平及负债水平将直接影响其投资意愿和投资金额。

个人投资者的其他个人状况，如就业状态和家庭状况，也会对其投资需求产生多方面的影响。拥有稳定工作的年轻个人投资者，其风险承受能力较强，更青睐高风险高收益的产品；子女的数量越多、需赡养老人的数量越多，家庭负担越重，则可投资的资金越少，投资者越偏向于稳健的投资策略和产品。

# 2. 机构投资者

机构投资者是指用自有资金或者筹集投资者的资金进行投资的法人或非法人主体。机构投资者有许多不同的类型，例如养老基金、大学基金会、银行、银行理财子公司、证券公司、期货公司、保险公司、FOF、私募基金、主权财富基金等。

机构投资者在资产管理策略上通常采用内部管理或外部委托管理两种模式。选择内部管理的机构往往组建专业的投资团队，直接参与金融市场的投资操作，包括股票、债券、基金和其他金融工具买卖。而选择外部委托管理的机构则将资金交由一家或多家专业的资产管理公司，投资范围可能涉及信托计划、资产管理计划等金融产品。

管理模式的选择主要受两大因素影响：资产规模和内部专业能力。通常，资产规模越大的机构越倾向于内部管理，因为规模效应能够显著降低管理成本。与此同时，机构是否具备专业的投资团队也至关重要。若机构拥有强大的内部投资管理能力，往往更愿意采取内部管理模式以充分发挥自身优势。

在实际操作中，许多机构采用混合管理模式，将内部管理与外部委托相结合。这种模式在我国资产管理行业中尤为常见。机构根据自身的管理能力和资源，将部分资产交由内部团队管理，而将超出其专业领域或管理能力的资产委托给外部管理公司。通过这种灵活的方式，机构既能发挥自身核心投资能力，又能充分利用外部专业资源。

即便采取外部委托管理，机构投资者依然需要承担一系列复杂的决策，包括选择合适的资产管理机构、评估具体的投资经理、制定投资策略和业绩基准，并持续监督外部管理人的表现。这一过程涉及详尽的尽职调查、量化分析和定性评估，要求机构具备较高的专业素养和判断力。

这种策略使机构投资者能够在利用外部专业资源的同时，保持对整体资产配置战略的控制，追求风险与收益的最优平衡。多元化的管理方式不仅提升了资产管理的效率和专业性，还增强了机构应对市场复杂性和波动性的能力。

# （二）专业投资者与普通投资者

《证券期货投资者适当性管理办法》将投资者分为专业投资者与普通投资者两大类。这种分类基于投资者的专业知识、投资经验、风险承受能力和财务状况等因素，旨在为不同类型的投资者提供适当的保护和服务。

专业投资者具备专业的投资知识和经验，能够自行判断投资品种和期限是否符合投资需求，能够理解金融产品和金融服务的风险，在财务上能够承担相应的投资风险，因此基金公司及基金销售机构在面对这类投资者时可适当豁免部分适当性义务。

相较于专业投资者，普通投资者往往处于信息不对称的相对弱势地位，需要更多保护和指导。金融机构在服务普通投资者时，必须严格履行信息披露、风险提示和适当性匹配等方面义务。

值得注意的是，个人投资者和机构投资者并不与普通投资者和专业投资者简单对应。尽管大部分个人投资者在投资知识和经验方面比较欠缺，但也有一些个人投资者由于受过相关教育或长期从事投资相关业务，有着丰富的投资经验，投资能力较强，可被认定为专业投资者；而机构投资者中，也存在资产较少、投资经历较短的机构，这些机构可能被归为普通投资者。这种灵活的分类方法更能反映投资者的实际情况和投资能力。

经营机构可以根据专业投资者的业务资格、投资实力、投资经历等因素，对专业投资者进行细化分类和管理。

# 2. 普通投资者

专业投资者之外的，符合法律、法规要求，可以从事基金交易活动的投资者均为普通投资者。基金销售机构一方面需要对投资者进行风险承受能力评估，按照普通投资者风险承受能力由低到高，基金销售机构应将普通投资者分为至少C1（含风险承受能力最低类别）、C2、C3、C4、C5五种类型；另一方面，需要对基金产品或者服务的风险等级进行划分，根据投资者的风险承受能力评估结果，向投资者建议合适的、符合其风险承受能力的基金产品和服务。投资者适当性内容将在本节第三部分详细介绍。

# 3. 普通投资者和专业投资者的转化

普通投资者和专业投资者在符合一定条件下，可以相互转化。根据《证券期货投资者适当性管理办法》的要求，专业投资者可以书面告知经营机构选择成为普通投资者，经营机构应当对其履行相应的适当性义务。

符合下列条件之一的普通投资者可以申请转化成为专业投资者，但经营机构有权自主决定是否同意其转化。

普通投资者申请成为专业投资者应当以书面形式向经营机构提出申请并确认自主承担可能产生的风险和后果，提供相关证明材料。

经营机构应当通过追加了解信息、投资知识测试或者模拟交易等方式对投资者进行谨慎评估，确认其符合上述要求，说明对不同类别投资者履行适当性义务的差别，警示可能承担的投资风险，告知申请的审查结果及其理由。

# （三）合格投资者与不特定社会公众

合格投资者是一种投资门槛，即准入要求，目的是规定某些特定的产品或特定的服务只能是由某些投资者进行投资，也就是说，合格投资者只针对特定市场、产品或服务。专业投资者、普通投资者并不与合格投资者、不特定社会公众有对应关系，普通投资者也可以是合格投资者。

不同类型的产品，合格投资者的标准会有所不同，根据《关于规范金融机构资产管理业务的指导意见》（简称《资管新规》）相关规定，资产管理产品的投资者分为不特定社会公众和合格投资者两大类。非公开发行的基金产品，如私募资产管理计划，应当向符合相关资格的合格投资者进行募集。

# 1. 合格投资者

合格投资者是指具备相应风险识别能力和风险承担能力，投资于单只资产管理产品不低于一定金额且符合下列条件的自然人和法人或者其他组织。

合格投资者投资于单只固定收益类产品的金额不低于30万元，投资于单只混合类产品的金额不低于40万元，投资于单只权益类产品、单只商品及金融衍生品类产品的金额不低于100万元。

# 2. 不特定社会公众

根据《资管新规》，合格投资者之外的，即为不特定社会公众。

# （四）我国机构投资者的主要类别

机构投资者是指用自有资金或者筹集投资者的资金进行投资的法人或非法人主体。机构投资者是金融市场重要的参与者，我国机构投资者在银行间、交易所债券市场占据统治地位，在股市、基金的占比也逐年提升。以下详细介绍我国除基金公司外的主要的机构投资者。

# 1. 商业银行及银行理财子公司

传统商业银行的主要业务是吸纳存款和发放贷款，银行也会将表内资金用于债券、基金投资。商业银行自有资金是银行间债券市场最主要的参与者，其投资受金融监管总局监管，2023年10月公布的《商业银行资本管理办法》中对商业银行表内资金投资有详细的规定。

理财产品的销售和管理也曾是银行的重要业务，2018年，《关于规范金融机构资产管理业务的指导意见》、《商业银行理财业务监督管理办法》、《商业银行理财子公司管理办法》相继发布，大型商业银行纷纷设立理财子公司，理财产品管理业务由原商业银行资产管理相关职能部门转移到理财子公司。截至2024年6月，共有32家银行公告设立理财子公司。

银行理财子公司通过商业银行代理销售理财产品、募集理财资金。理财子公司可以独立进行投资管理，也可以委托基金公司等其他金融机构进行投资管理。其风险容忍度与相应产品的投资目标和约束有关。截至2023年末，银行理财子公司管理规模超过22万亿元。

# 2. 保险公司及保险资管公司

保险公司通过销售保单募集保费，对保费进行适当的投资，如股票、债券、基金、贷款等，并将投资收益用于未来可能需要支付的理赔款或其他保单规定的支付项目。保险公司对待风险的态度通常比较谨慎。

按照保险标的的不同，保险公司可分为两种类型：财险公司与寿险公司。财险公司针对如因火灾、盗窃、自然灾害等意外事件导致的财产损失提供保险赔偿服务。财险公司赔偿额度具有很大的不确定性，其吸纳的保费投资期限较短。寿险公司开展人寿保险、人身意外险、健康险等险种业务。寿险公司通过人寿保险业务吸纳的保费具有较长的投资期限，可以部分投资于风险较高的资产。

根据《保险资产管理公司管理规定》，保险资产管理公司是由保险集团（控股）公司或保险公司发起，通过接受保险集团（控股）公司和保险公司等合格投资者委托、发行保险资产管理产品等方式，开展资产管理业务。大型保险公司的保费收入逐渐交由保险资管公司管理。截至2023年末，保险公司总资产规模超过29万亿元。保险公司及保险资管公司的监管单位为金融监管总局。

# 3. 证券公司及其资管子公司

获准开展自营业务的证券公司也是重要的机构投资者。不同证券公司根据各自自营资金的规模大小、投资期限安排、流动性要求，投资于各类金融资产，如股票、债券、基金等。有些券商具有资管牌照，有些还会设立资管子公司，可以通过发行资产管理计划来募集资金进行投资。部分券商资管具有公募牌照，可以发行公募基金。截至2023年末，券商资管私募管理规模超过5万亿元，公募管理规模超过1万亿元。证券公司及券商资管子公司监管单位为中国证监会。

# 4. 财务公司

一些大型企业集团设有财务公司。财务公司是指以加强企业集团资金集中管理和提高企业集团资金使用效率为目的，依托企业集团、服务企业集团，为企业集团成员单位（以下简称成员单位）提供金融服务的非银行金融机构。财务公司可以吸收成员单位3个月以上定期存款，并对成员单位办理贷款，还可以投资有价证券。通常情况下，财务公司会投资于银行存款、理财产品或货币市场基金，也可以投资于其他流动性较好的短期资产。财务公司根据《企业集团财务公司管理办法》进行资金管理，其监管单位为金融监管总局。

# 5. 全国社会保障基金理事会

2000年8月，党中央、国务院决定建立“全国社会保障基金”，同时设立“全国社会保障基金理事会”（简称社保基金会），负责管理运营全国社会保障基金。全国社会保障基金是国家社会保障储备基金，由中央财政预算拨款、国有资本划转、基金投资收益和国务院批准的其他方式筹集的资金构成，专门用于人口老龄化高峰时期的养老保险等社会保障支出的补充、调剂。社会保障资金的投资运作受到严格的制度约束，长期以来奉行价值投资、长期投资和责任投资的理念。

社保基金会是财政部管理的事业单位，还受托管理基本养老保险基金投资运营。基本养老保险基金，是各省（自治区、直辖市）人民政府和新疆生产建设兵团根据2015年8月17日国务院印发施行的《基本养老保险基金投资管理办法》，委托社保基金会管理的基本养老保险部分结余基金及其投资收益。根据《基本养老保险基金投资管理办法》和社保基金会与各委托省（自治区、直辖市）人民政府和新疆生产建设兵团签署的委托投资管理合同，社保基金会对受托管理的基本养老保险基金实行单独管理、集中运营、独立核算。截至2024年6月，社保基金会受托管理的基本养老保险基金规模超过1.9万亿元。

# 6. 中国投资有限责任公司

中国投资有限责任公司（简称中投公司）是中国的主权财富基金，成立于2007年。中投公司主要负责管理部分外汇储备资产，以及其他国有金融资产。作为长期投资者，中投公司在全球范围内进行多元化投资，包括公开市场的股票、债券投资，以及另类投资如私募股权、对冲基金等。中央汇金投资有限责任公司（简称中央汇金）是中投公司的全资子公司。

# 7. 企业年金和职业年金

企业年金基金属于我国社会保障体系之下的另一类机构投资者。所谓企业年金，是指企业及其职工在依法参加基本养老保险的基础上，自愿建立的补充养老保险制度。企业年金基金财产的投资范围较广，包含银行存款、国债、中央银行票据、债券回购、证券投资基金、股票、信托产品、基础设施债权投资计划、股指期货以及信用等级在投资级以上的金融债、企业（公司）债、可转换债（含分离交易可转换债）、短期融资券和中期票据等金融产品。企业年金基金在投资过程中需要严格遵循有关法规确定的投资比例限制，遵循谨慎、分散风险的原则，充分考虑企业年金基金财产的安全性、收益性和流动性，实行专业化管理。截至2024年一季度，我国企业年金规模超过3.2万亿元。

职业年金是指机关事业单位及其工作人员在参加机关事业单位基本养老保险的基础上，建立的补充养老保险制度，其投资范围与企业年金类似。

# 8. 合格境外投资者

合格境外投资者也是一类重要的机构投资者。合格境外投资者制度是指允许符合一定条件的境外机构投资者，通过在境内开立资金和证券账户，从境外汇入外币或本币，开展证券期货投资的制度。该制度是一国在货币未完全可自由兑换、资本项目尚未完全对外开放情况下有限度地引进外资、开放资本市场的一项过渡性的制度安排。2020年，经国务院批准，中国证监会、中国人民银行、国家外汇管理局发布《合格境外机构投资者和人民币合格境外机构投资者境内证券期货投资管理办法》，并由中国证监会发布配套规则，降低准入门槛，扩大投资范围，便利投资运作；中国人民银行、国家外汇管理局发布实施新的资金规定，大幅便利资金汇兑，取消额度限制。

# 二、投资者需求

投资者需求多种多样，例如：个人投资者可能会关注预期收益率、最大回撤指标、基金经理投资风格等，而机构投资者还会关注自身的资产负债结构、负债成本、基金规模等。不同的需求，对应不同的产品和策略。基金销售人员对投资者需求的深入了解与准确把握，有助于销售人员提出更具实操性的投资建议，并推荐更有可能实现投资目标的产品或产品组合。本部分旨在探讨基金销售人员如何有效发掘投资者需求，在遵循投资者适当性原则的前提下，开展基金产品的销售工作。

投资者需求分为投资目标和投资限制。投资目标是对收益和风险要求的结合体，投资限制对投资目标做了进一步框定，二者相互作用，共同影响最终的投资方案。

图 [案例18-1] 规模为 10 亿元的 A 财险账户，投资需求为在未来 5 年内确保车险及时赔付的前提下，税后取得年化超过 4% 的投资收益，且最大回撤不超过 3%。

该账户的投资目标：

风险容忍度——最大回撤不超过3%。

投资期限——5年。

相同的投资收益结果，不同的实现路径，投资者的体验完全不同。

投资目标由风险和收益两个相互依存的要素构成，不能孤立地考虑其中任何一项。收益目标反映了投资者对投资收益的合理期望，风险容忍度则界定了可接受的收益目标变动区间。通常，投资者无法找到高预期收益且不用承担高风险的投资标的，高风险资产需要提供更高的预期收益率来补偿投资者承担的额外风险。

# 1. 风险容忍度（Risk Tolerance）

风险容忍度取决于投资者的风险承受能力（Risk Capacity）和风险承受意愿（Risk Willingness），前者是投资者客观的抵御风险能力，后者是投资者对投资风险的主观偏好。银行有较高的风险承受能力，但并不意味着其有高风险承受意愿；某些个人投资者虽然风险承受能力弱，但有非常高的风险承受意愿。因此，风险容忍度是投资者对投资风险主观和客观的综合考量。风险容忍度的确定采取“孰低原则”，在风险承受能力和风险承受意愿间就低不就高。这一原则旨在保护投资者利益，确保投资决策不会超出投资者的客观承受能力及主观意愿。

风险承受意愿是投资者主观上对风险的偏好。可以通过多种量化指标来衡量风险承受意愿，如波动率容忍度、最大可承受亏损比率等。

通常，机构投资者对风险的认识和理解远高于个人投资者，能够精准的定义风险，并确定自己的风险承受意愿，最大回撤、波动率、VaR、投资范围和投资比例均可以展示其风险承受意愿。

相比之下，普通投资者中的个人投资者对风险承受意愿表述往往不够明确，基金销售人员需要通过风险教育、问卷调查和面对面交流等方式，帮助个人投资者明确并量化其风险承受意愿。例如，在与投资者交流时，可以提问“当投资组合下跌30%，是否会心神不宁、严重影响生活”。影响个人投资者风险承受意愿的因素非常多，包括但不限于历史投资经历和业绩、风险认知、财务状况、个人性格等。

整体来看，机构投资者的风险承受意愿较为稳定，个人投资者的风险承受意愿可能随时间和环境变化而改变。因此，基金销售人员应当与投资者保持定期沟通，及时更新对投资者风险容忍度的评估。

# 2. 收益目标

收益目标是投资者对投资收益的期望，可分为绝对收益目标和相对收益目标。

绝对收益目标以具体的收益率表示，如年化收益率6%；相对收益目标则是相对于某个基准的超额收益，如沪深300指数收益率+3%。这与基金的业绩比较基准有相似之处。

无论绝对收益目标还是相对收益目标，都必须与投资者风险容忍度相匹配。投资者大都希望在获得较高收益的同时承担较低风险，但通常情况下，要想获得高预期收益，就必须承担高风险。当投资者提出不切实际的收益要求时，基金管理人或基金销售机构应当为其提供顾问服务，并做好投资者教育，让投资者了解在其自身的风险容忍度和当前的市场环境下可以合理期待的收益目标。

年化收益率是最常用的衡量收益的指标。在讨论收益率时，需要区分名义收益率与实际收益率。

名义收益率是产品获取的资产名义数值增长率，常见的基金过往收益率、存款利率均指的是名义收益率。实际收益率是在名义收益率的基础上扣除了通货膨胀率的影响。对于长期投资者，关注名义收益率的同时，还应该关注实际收益率，因为实际收益率能够反映资产实际购买能力的增长率。如果投资的名义收益率与通货膨胀率相等，那么资产的实际购买能力将没有任何增长。

在评估跨境投资的收益时，应当将汇率变动纳入考虑范围，计算本币计价的实际收益率。

# （二）投资限制

投资限制是由投资者内、外部因素所产生的，是投资决策的约束条件。投资限制因素通常包括投资期限、流动性要求、税收政策、监管规定以及特殊需求等。由于投资限制的差异，相同风险容忍度和收益期望的投资者，也可能选择不同的投资产品。因此，在设定投资目标和确定投资方案时，必须考虑投资限制的影响。

举例来说，如果将例18-1的投资者改为规模10亿元的B寿险账户和规模30亿元的银行理财子公司C开放式理财产品，在同样的投资需求下，前者的投资期限可以超过30年甚至更长，可以选择流动性较低但长期收益可能更高的REITs，而后者可能更倾向于直接持有债券或者费率更低的债券ETF。这个例子清楚地说明了相同的投资目标下，不同的投资约束如何导致截然不同的投资方案。

# 1. 流动性要求

流动性要求通常源于负债端的需求，会影响投资机会的选择。通常情况下，投资期限越短，投资者对流动性的要求越高。例如，一个流动性较差的私募股权投资可能在10年以后才能变现，这样的投资机会并不适合于投资期限为5年的投资者。

流动性与收益之间常常存在反向关系。对于同类产品，流动性更差的往往需要更高的预期收益率来补偿。如果没有预期的变现需求，投资者可以适当降低流动性要求，以提高投资的预期收益率。

投资者需要为潜在的流动性需求预留充足准备。这不仅包括为可预见的资金需求作准备，也要为突发情况预留应急资金。因此，投资组合中应当配置适当比例的高流动性资产。以开放式基金为例，监管规定要求基金资产中至少5%须为现金或剩余期限不超过1年的政府债券（特殊基金品种除外），以确保有足够资金应对投资者赎回。

# 2. 投资期限

投资期限是指投资者从购买金融资产到计划兑现之间的时间长度。一些投资者可能在短期内就需要变现自己的投资资产，以获得资金满足资金使用需求，例如，某个人投资者持有货币基金，随时准备赎回用于支付商品房的首付款；一些投资者则可能在多年内都没有变现投资资产的需求，例如，某国家主权投资基金长期持有政策扶植行业上市公司的股票。

机构投资者的投资期限差异明显。例如，财险公司可能预计在几年内经常需要大笔资金用于保险理赔的偿付，并且理赔数量具有很强的随机性，它只能将资金进行短期投资，以保证流动性；而寿险公司能够对未来多年内的寿险给付作相对准确的估计，它可以对保费收入的投资作一个长期的规划；投资款来源于石油收入的海外财富基金，为了下一代的福利而投资，它的投资期限则会达到数十年。

投资期限的长短影响着投资者的风险容忍度以及对流动性的要求。投资期限越长，往往投资者能够承担的风险越大。历史经验表明，在较长的时间内，市场行情总体向好的概率要大于走低的概率，投资期限较长的投资者更可能获得预期的投资目标，即使在短期内遭受投资损失，其有更多的时间等待市场恢复。

需要注意，无论是机构投资者还是个人投资者，其资金需求常常不是单一的，这决定了投资期限多为长期和短期的结合。

# 3. 税收政策

税收政策是影响投资决策的重要考量因素。投资策略的业绩好坏是以税后收益率来衡量。对面临高税率的个人和机构投资者来说，避税和税收递延将对投资决策起到很重要的作用。相比没有税收优惠的投资产品，免税或者具有优惠税率的投资产品对投资者具有更大的吸引力。

例如，对于较高收入个人投资者，个人养老账户每年1.2万元的税收减免额度具有很强的吸引力，其省下的个税比例最高可达42%；对于机构自有资金，其投资国债免税，投资信用债需要缴纳企业所得税，税收因素会对投资标的选择产生巨大影响。

# 4. 监管规定

法律法规要求是限制投资者投资决策的外部因素。监管规定可能是限制性的，例如，目前我国个人养老账户可投资的公募基金优先纳入了符合条件的养老目标基金、指数基金，后续会适时逐步扩展；又如，我国银行自有资金不允许投资于上市公司股票，无法申购ETF等含权益资产的基金。监管规定也可能是鼓励性的，例如，我国政府支持金融机构持有绿色债券等。

# 5. 特殊要求

个体投资者自身的特殊需求均有可能限制其投资组合的选择。例如，某个人投资者偏好于自身所在行业；某基金会注重环境保护，偏好投资ESG评分高的公司，禁止投资于煤炭、钢铁等他们认为有损环境的公司。这些特殊要求虽然可能会限制投资选择，但也可能带来独特的投资机会或风险管理策略。

# 三、投资者适当性管理

根据中国证监会《证券期货投资者适当性管理办法》，投资者适当性管理要求基金销售机构在销售产品或者提供服务时，必须勤勉尽责，审慎履职，全面了解投资者情况，深入调查分析产品或者服务信息，科学有效评估，充分揭示风险，基于投资者的不同风险承受能力 $^{①}$ 以及产品或者服务的不同风险等级等因素，提出明确的适当性匹配意见，将适当的产品或者服务销售或者提供给适合的投资者，并对违法违规行为

承担法律责任。

适当性匹配是基金销售过程中了解投资者的重要环节。基金销售机构一方面需要对投资者进行风险承受能力评估，并划分风险等级；另一方面需要对基金产品或者服务的风险等级进行划分，根据投资者的风险承受能力评估结果，向投资者建议合适、符合其风险承受能力的基金产品和服务。

# （一）普通投资者风险等级的划分

根据《证券期货投资者适当性管理办法》，投资者分为专业投资者与普通投资者。普通投资者在信息告知、风险警示、适当性匹配等方面享有特别保护。专业投资者可以购买或接受所有风险等级的产品或服务；普通投资者只能购买或接受与其风险承受能力相匹配的产品或服务。

根据《基金募集机构投资者适当性管理实施指引（试行）》的要求，基金销售机构应当综合考虑普通投资者的收入来源、资产状况、债务、投资知识和经验、风险偏好、诚信状况等因素，通过风险承受能力问卷测评，确定普通投资者的风险承受能力，对其进行细化分类和管理。基金销售机构应将普通投资者按照风险承受能力由低到高分为至少C1（含风险承受能力最低类别）、C2、C3、C4、C5五种类型。

基金募集机构可以将C1中符合下列情形之一的自然人，作为风险承受能力最低类别投资者：不具有完全民事行为能力；没有风险容忍度或者不愿承受任何投资损失；法律、行政法规规定的其他情形。

# 1. 风险承受能力评估问卷

根据《基金募集机构投资者适当性管理实施指引（试行）》的要求，投资者在选择投资任何一种基金产品前，必须先完成风险承受能力评估问卷，问卷是了解投资者真实投资需求、明确投资目标、管理投资预期最重要、最常用的沟通方式。基金投资者风险测评问卷通常会涵盖以下问题：（1）主要收入来源；（2）家庭可支配年收入；（3）每年的家庭可支配收入中，可用于金融投资（储蓄存款除外）的比例；（4）未清偿的数额较大的债务情况；（5）投资知识情况；（6）投资经验；（7）投资期限；（8）对风险和收益的态度；（9）可承受的最大投资损失。

# 2. 风险承受能力的评估逻辑

问卷主要从投资者个人的客观投资实力、过往投资经历和主观投资意愿等三个方面出发：

（1）客观投资实力。客观投资实力主要是通过衡量投资者的收入和支出情况，来评估投资者的风险承受能力。

收入主要考虑收入来源和家庭收入金额，收入来源越稳定并且收入金额越高的投资者，对风险的承受能力也会越强。假设有甲乙两个人，其中甲的月收入1万元，收入全部来自工资，而乙的月收入1.5万元，一半来自工资，一半来自房租收入，那么后者承受风险的能力更强。因为乙除了工资收入，还有其他的非工资收入来源，收入来源的稳定性更高，同时乙的月收入的金额也更高。

支出主要考虑家庭可用于金融投资的资产比例和是否有较大的未清偿债务，支出和负债越低，投资者追求风险投资的倾向会更强。支出、负债和家庭的生命周期也有一定关系，单身时负债压力最小，这个时候风险承受能力相对更强。而当进入家庭成长期，由于置业升级、子女教育、赡养父母等，支出和负债压力较大，能够承受投资失败的能力就越弱，所以可用于金融投资的资产比例越低。

(2) 过往投资经历。过往的投资经历包括专业水平、过往投资品种和投资年限。

专业能力强、过往投资经验丰富的投资者，对于金融知识和金融产品的认知水平往往更高，所以风险承受能力相对更高。

在过往投资知识和投资产品经验中，除存款外基本没有其他产品投资经验的投资者，不了解股票、基金等风险投资品的基础知识，甚至不了解基本的交易规则，自然无法承受这类风险产品的高波动。

投资基金、股票、信托、私募证券等风险投资品的年限越长的投资者，对于资本市场和风险投资产品的风险收益特征越了解，甚至会总结出一套应对资本市场波动的长期有效的投资方法，当市场短期出现较大的波动时，其也会从容应对，风险承受能力相对更高。

（3）主观投资意愿。主观投资意愿由投资期限和对风险收益的态度两部分构成。如果计划投资期限较长，可以降低投资中的非理性操作风险和市场短期的系统性风险带来的影响，投资者的抗风险能力会更强。

对风险收益的态度主要考虑投资者对风险收益之间的权衡、愿意承受的最大损失。通常情况下，风险和收益是相关的，投资者想要获取更高的收益，需要承担的风险也随之增大。所以如果投资者想要获取高收益，同时愿意承担相对应的可能出现的损失，则投资者的主观风险承受能力就更高。

# （二）基金产品或者服务风险等级的划分

基金销售机构不仅要评估投资者的风险承受能力，还需履行对其所销售的基金产品或服务进行风险等级划分的义务，并根据投资者的风险承受能力评估结果，向投资者推介合适、符合其风险承受能力的基金产品和服务。

基金产品或者服务的风险等级需按照风险由低到高顺序，至少划分为R1、R2、R3、R4、R5五个等级（低风险、中低风险、中风险、中高风险、高风险），这看起来与普通投资者风险承受能力评级类似。基金销售机构可以根据实际情况在前款所列等级的基础上进行风险细分。

基金销售机构对基金产品或者服务进行风险等级划分，要从基金管理人和基金产品或服务两个维度，考虑以下因素：

①基金管理人的诚信状况，经营管理能力，投资管理能力，内部控制情况，合法合规情况；基金管理人成立时间，治理结构，资本金规模，管理基金规模，投研团队稳定性，资产配置能力，内部控制制度健全性及执行度，风险控制完备性，是否有风险准备金制度安排，从业人员合规性，股东、高级管理人员及基金经理的稳定性等。

②基金产品或者服务的合法合规情况，发行方式，类型及组织形式，托管情况，投资范围、投资策略和投资限制概况，业绩比较基准，收益与风险的匹配情况，投资者承担的主要费用及费率；基金产品或者服务的结构，投资方向、投资范围和投资比例，募集方式及最低认缴金额，运作方式，存续期限，过往业绩及净值的历史波动程度，成立以来有无违规行为发生，基金估值政策、程序和定价模式，申购和赎回安排，杠杆运用情况等。

实践中，基金销售机构一般通过官网，向投资者披露所使用的基金产品风险等级划分方法及其说明。由于各销售机构制定的规则不同，对产品风险等级划分的方式和结果有一定的差异。

就划分方法看，虽各机构风险等级评定细则不同，但通常采用定量和定性相结合的方式，从基金管理人和产品本身两个角度出发，基于基金类型和实际运作情况对基金风险进行评级。定量指标设有不同的权重及对应的分值，定性指标主要是对管理人和产品的风险进行综合考虑。两者相结合得出产品的风险等级得分，确定产品风险等级。在大部分情况下，基金所投向的资产以及资产组合决定大部分的风险来源，因而基金产品本身的因素权重较高，管理人因素权重较低。

以某机构风险等级划分为例，定量方面中，基金管理人因素主要考虑基金管理人的成立时间、注册资本金、管理产品总规模、基金经理离职率和平均管理期限等；产品因素主要考虑细分的二级基金类型、投资标的的流动性（如信用债比例、停牌股票及港股比例等）、组合集中度、产品收益标准差或最大回撤等。

在定性方面，基金管理人层面需要考虑的是公司风控和风险准备金制度、公司重大违法违规情况。基金产品层面主要考虑基金产品投资比例的遵守情况、信息披露差错情况、各类资产仓位、基金规模、持有人结构等因素。

就划分结果看，同一类型产品，由于运作情况、销售机构评价方式不同，在风险等级划分上结果有一定的差异。以基金管理人对偏股混合型基金的评价为例，绝大部分基金的风险等级为R3，但也有部分落在R4，极少量出现在R2和R5。基金风险等级评价与基金产品类型并不直接相关，因此基金销售人员需要审慎查阅所属机构对该产品的风险等级评价结果，做好投资者适当性管理工作。

⑤基金销售机构履行特别警示义务后，普通投资者仍坚持购买该产品或者服务的，基金销售机构可以向其销售相关产品或者提供相关服务。

4.需要注意的是，最低风险承受能力类别的普通投资者不得购买高于其风险承受能力的基金产品或者服务。普通投资者不得购买高于其风险承受能力的私募基金和资产管理计划。

# 投资者适当性纠纷裁判相关知识

2019年11月8日，最高人民法院公布了《全国法院民商事审判工作会议纪要》（简称《九民纪要》），其中，第五部分“关于金融消费者权益保护纠纷案件的审理”对基金募集机构等卖方机构在销售高风险金融产品前履行适当性告知说明的先合同义务提出了要求，对有关卖方机构应承担的投资者适当性义务纠纷案件的裁判思路作出规定，具体见表18-4。《九民纪要》虽然不是司法解释，不能直接作为裁判依据，但人民法院在裁判文书中具体分析法律适用的理由时可根据该会议纪要的相关规定进行说理。
