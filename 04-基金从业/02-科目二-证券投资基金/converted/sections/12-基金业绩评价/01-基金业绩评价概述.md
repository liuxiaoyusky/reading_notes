# 一、基金业绩评价的目的

基金业绩评价是指通过一系列科学、系统的量化和定性分析方法，对基金的业绩表现进行全面、客观的衡量、分析和评估的过程。系统的基金业绩评价不仅有助于提升基金管理人的运作效率和决策质量，还能提高市场透明度，为基金投资者提供决策参考，进而推动整个基金业的健康发展。

对基金管理人而言，基金业绩评价是一种重要的管理工具。基金管理人通过基金业绩评价审视基金产品的投资目标、风格和策略之间的一致性和匹配度，及时发现潜在问题，优化投资策略和产品结构。同时，基金业绩评价还能客观、准确地评价基金经理的投资管理能力，为内部绩效考核提供重要依据。

从基金经理视角来看，业绩评价是一个重要的自我反思和提升工具。通过深入的归因分析，基金经理可以厘清基金的收益与亏损来源，检验投资逻辑的有效性，并据此调整投资策略，优化投资组合，提升投资业绩。

对基金投资者而言，专业的业绩评价结果是选择基金的重要参考。它帮助投资者理解基金产品的风险收益特征，更好地选择符合自身投资目标的产品。基金业绩评价也使投资者能够更全面地认识基金管理人的能力，评估基金管理人是否致力于为其创造长期且可持续的投资回报，更加理性地选择基金管理人和基金产品。

从整个基金行业的角度看，基金评价机构作为行业中的重要参与者，通过专业且系统的业绩评价，一方面督促基金管理人遵循基金合同，践行“以投资者为本”的理念，提升其为投资者创造长期、可持续回报的投资管理能力，并引导整个行业更为关注投资者长期回报与实际盈利体验；另一方面，帮助投资者更好地理解基金产品，选择与其风险收益特征相匹配的投资工具。这有利于维护基金行业秩序，促进基金行业持续健康发展。

# 二、基金业绩评价的理论发展与演进

基金业绩评价的发展是金融学理论进步、市场复杂化和投资者需求变化的共同结果。从早期单纯依赖收益率的衡量，到现代多维度、多因子的分析方法，基金业绩评价经历了显著的演进。

# （一）早期阶段（20世纪60年代以前）

20世纪60年代以前，基金业绩评价主要依赖于两个简单指标——单位净值和投资收益率。这一时期的评价方法虽然直观，但缺乏对基金风险的系统性分析，难以反映其综合绩效，也无法为投资者提供准确的风险调整后回报衡量工具。

# （二）现代投资组合理论与风险调整收益（20世纪60年代至70年代）

随着现代投资组合理论（MPT）的提出，基金业绩评价进入了新的阶段。马科维茨的均值—方差模型为投资决策引入了量化的风险管理工具，并强调通过分散化投资来降低非系统性风险。MPT的核心思想为基金业绩评价提供了理论基础，使得投资者在衡量基金表现时，能够同时考虑风险与回报。

夏普比率（Sharpe Ratio）和詹森阿尔法（Jensen's Alpha）是这一时期的重要创新，它们为基金业绩评价引入了“风险调整后回报”的概念。夏普比率衡量基金在单位风险下的超额回报，而詹森阿尔法则用于评估基金是否跑赢其基于市场风险的预期回报。这些指标帮助投资者更全面地理解基金在不同风险水平下的表现。

# （三）主动与被动管理的分野与业绩归因分析（20世纪70年代至80年代）

20世纪70年代起，随着有效市场假说（EMH）的提出，基金业绩评价面临新的挑战。有效市场假说认为，市场价格已经反映了所有公开信息，因此很难通过主动管理持续战胜市场。然而，在半强有效市场和弱有效市场的假设下，主动管理仍然有可能通过信息不对称或市场无效性获取超额收益。

此时，基金业绩评价不仅关注基金的绝对收益，还开始评估基金经理的主动管理能力。为此，业绩归因分析（Performance Attribution）成为重要工具，帮助投资者分解基金的回报来源，区分基金经理的决策能力与市场整体走势。通过业绩归因分析，投资者能够了解基金的超额回报究竟来自于资产配置、证券选择，还是时机选择，从而更好地评估基金经理的能力。此外，投资者开始认识到，基金业绩的持续性是评价基金表现的重要维度。研究者们开发了诸如或然表和击中率等方法，用以衡量基金在不同时期内能否保持相对稳定的业绩表现。这些方法帮助投资者判断基金表现的可持续性，而不仅仅依赖于某一时期的优秀表现。

# （四）多因子模型与基金风格分析（20世纪90年代）

随着金融市场的进一步复杂化，20世纪90年代引入了多因子模型，如Fama-French三因子模型。这一模型扩展了资本资产定价模型（CAPM），表明市场之外的其他因素（如规模效应和价值效应）也会影响基金表现。多因子模型的引入推动了基金评价从单一市场基准走向多维度的分析，使得投资者能够更加全面地理解基金的风险调整后表现。

与此同时，基金业绩评价方法中引入了风格分析。不同风格的基金在同一市场环境下表现各异，因此，基于收益数据和持仓数据的风格分析方法越来越受到重视。这些方法帮助投资者将基金与合适的基准进行比较，从而更准确地评估基金经理在特定市场条件下的表现。特别是对于主动管理型基金，风格分析有助于揭示基金经理的投资偏好和策略一致性，并帮助投资者进行合理的资产配置。

# （五）技术进步与新趋势（2000年以来）

进入21世纪，技术进步显著提升了数据采集和处理能力，基金业绩评价得以实时处理海量数据、计算复杂指标，快速评估大量基金表现。技术进步提高了基金业绩评价的精度和效率，能更及时地反映市场变化和基金经理的决策效果。

随着投资者对可持续发展因素（如环境、社会和治理）的关注不断增加，基金业绩评价开始纳入ESG指标。这一趋势推动了基金业绩评价从单纯的财务回报向更加全面的可持续性评价转变。ESG因素的整合不仅关注基金的投资回报，还评估其对社会和环境的影响，反映投资者日益注重社会责任和长期可持续发展。

风险管理因素在现代基金业绩评价中变得越来越重要。投资者不仅关注基金的回报，更加重视基金在市场波动中的风险表现。下行风险、最大回撤等风险指标已成为基金业绩评价的标准工具，帮助投资者在追求收益的同时，更好地管理潜在的风险。

此外，机器学习和自然语言处理（NLP）技术也开始在基金评价中得到应用。机器学习能够通过分析历史数据发现投资模式和潜在风险，帮助识别基金表现中的复杂规律。自然语言处理技术则可以高效地分析基金经理的报告、市场评论以及相关新闻，提取相关信息。作为基金业绩评价的辅助工具，这些技术为更深层次的基金分析提供了数据支持，帮助投资者更好地理解基金经理的决策能力与市场应对策略。

随着金融市场的不断演进，基金业绩评价将继续发展，以应对日益复杂的投资环境。未来的基金业绩评价将更加注重透明度和责任性，并进一步整合新兴的技术手段和风险管理方法。动态基准和多维度风险评估将成为基金业绩评价的重要趋势，帮助投资者在复杂的市场环境中作出更明智的决策。

# 三、基金业绩评价应考虑的因素

为了客观、公正地对基金进行业绩评价，除了业绩本身之外，以下因素也不可忽视：

# （一）基金的管理规模

基金管理规模对其投资运作效率有着显著影响。规模较大的基金单位份额的固定费用较低，并且可以通过分散投资更有效地应对非系统性风险。然而，基金规模过大也可能带来问题。规模过大的基金在调仓时可能会对市场产生流动性冲击，导致交易成本上升。因此，在评价基金业绩时，需要考虑管理规模带来的成本效益和投资交易上的局限性。

# （二）业绩的时间区间与市场环境

基金的表现既受到时间区间的影响，也与市场环境和经济周期密切相关。在不同的时间段内，市场可能经历牛市、熊市或震荡市等不同的阶段，这些市场环境会显著影响基金的业绩表现。因此，评价基金业绩时，必须明确分析时间区间，并结合当时的市场环境进行解读。

短期表现可能更多地反映市场的短期波动，而长期表现则能够更好地反映基金经理的投资能力和策略的持续性。尤其是主动管理型基金，其业绩不仅依赖于市场的整体走势，还与基金经理的主动决策密切相关。因此，基金在不同市场周期中的表现，尤其是在市场下行期的抗风险能力，能为投资者提供更为全面的业绩表现分析。

另外，同一基金在不同时间区间内的业绩表现可能有很大差异，不同基金在不同时间区间内的收益、风险度量不能直接比较，因此，进行基金业绩评价时，需要将同一类型基金的业绩在同一时段内比较。

# （三）风险调整后收益

基金业绩评价的核心在于衡量其风险调整后的收益能力。投资管理的本质是风险管理，投资者期望在承担合理风险的基础上获得超额收益。所以，基金业绩评价重在评价基金产生风险调整后的超额收益的能力，基金产生正的风险调整后超额收益的能力是反映基金投资管理能力的最重要的指标，正的风险调整后的超额收益是主动管理型基金为投资者创造经济效益的重要体现。

# （四）幸存者偏差（Survivorship Bias）

幸存者偏差指的是在评估基金业绩时，只考虑当前仍然存续的基金，而忽略了那些由于表现不佳或其他原因而终止运作的基金。这种偏差会导致对整体基金业绩的过高估计，因为表现不佳的基金往往已经退出市场，而幸存的基金可能表现相对较好。为了避免幸存者偏差，基金评价应包括已终止运作或合并的基金，以确保评价结果的全面性和准确性。尤其是在私募基金领域，由于其淘汰率较高，幸存者偏差的影响会更加显著，因此必须特别加以防范。

为便于分析费用对基金收益的实际影响，可以采用以下两个指标：

费前收益率 (Gross-of-Fees Return)，指扣除基金交易成本，但未扣除管理人报酬及其他运营费用前的收益率。该指标能够反映基金投资活动本身的表现。

费后收益率 (Net-of-Fees Return)，指扣除基金交易成本，并进一步扣除所有管理人报酬及其他运营费用后的收益率。该指标反映基金在承担所有费用后的实际净回报。

需要注意的是，费前收益率和费后收益率并非严格定义的法定披露术语，在跨基金或跨管理人进行业绩比较时，应仔细核对各项指标的具体计算方法和费用扣除标准，确保分析时采用的是一致、可比的口径。

# （六）投资风格一致性

基金的投资风格和策略在很大程度上决定了其业绩表现，而基金的表现通常需要与一个适当的基准进行比较。基金的表现只有在与恰当的基准对比时，才能准确反映其真实的超额回报（即阿尔法）。如果基准选择不当，可能会导致对基金业绩的误导性解读。基准必须与基金的投资风格、资产配置及风险水平相匹配，才能为业绩评价提供客观依据。

在评价基金业绩时，还应重点关注基金实际投资行为与其声明的投资策略之间的一致性。当基金的实际持仓结构、行业分布或风险特征显著偏离其公开承诺的投资策略时，可能导致投资者面临与预期不符的风险收益特征。这种情况下，即使基金取得了短期的良好业绩，也难以对其进行有效的归因分析和长期评价。

因此，业绩评价应综合考察基金的业绩表现与其投资策略的匹配度，检验其是否始终如一地执行既定策略，并确保所用基准能准确反映基金的投资风格。只有当基金保持风格一致性时，才能有效评估基金经理的主动管理能力和基金的相对表现，也才能为投资者提供可靠的资产配置决策依据。

收益率计算是基金业绩评价的第一步。绝对收益指的是证券或投资组合在一定时间区间内所获得的回报，反映了资产的增值或贬值，常用百分比形式表示。绝对收益衡量的是投资标的的绝对表现，而不考虑与其他基准或市场的相对比较。

对于银行存款、票据和债券等金融产品，通常采用360天（少数情况下可能使用365天），这反映了这类产品的标准计息方式。

对于房地产、普通商业和实业等投资，由于它们每天都可能产生收益，不受交易日限制，因此采用365天作为计算基础更为合适。

股票、期货等在公开交易市场上交易的产品，应根据市场的实际交易日数量进行计算。实践中按实际交易日数量或根据近年的历史平均值进行计算（见表12-1）。中国A股市场年度交易天数随着节假日的安排略有变动，从2012年到2023年，平均值在243天。

# 二、相对收益

基金的绝对收益水平不足以完整评价基金业绩的优劣。在牛市环境中获得30%的收益并不一定意味着投资组合业绩突出；相反，在熊市环境中取得-5%的收益也并不一定意味着基金业绩不佳。因此，在衡量基金业绩时，除了绝对收益，还需要和同期的业绩比较基准和市场同类产品的收益率作比较，才能得出更加公正客观的结论。

相对收益（Relative Return），也被称为超额收益（Excess Return），指在一定时间区间内，基金收益超出业绩比较基准收益的部分。广义而言，相对收益的概念涵盖主动收益（Active Return）、阿尔法收益（Alpha Return）等。业绩比较基准不同，超额收益亦不相同。因此，选择适当的业绩比较基准对评价基金业绩至关重要。

# 三、捕获率

在评估基金业绩时，除了考察其绝对收益和相对收益，分析基金在基准上涨和下跌等不同市场阶段的相对表现也具有重要意义。捕获率（Capture Ratios）为此提供了有效的衡量工具，它通过上行捕获率（Upside Capture Ratio，UCR）和下行捕获率（Downside Capture Ratio，DCR）的区分，揭示基金经理在多变市场环境下的适应能力及投资策略的有效性。

计算捕获率需基于基金及其业绩比较基准的历史回报数据。在实际应用中，数据频率的选择对结果解读有直接影响，理想情况下应与基金投资策略的周期相匹配。月度数据是计算捕获率的行业惯例，因为它能较好地平滑市场短期噪音，更清晰地反映多数主动管理型基金的中长期选股和风险控制能力，而且月度数据的易得性也便于进行跨越牛熊周期的长期评估。对于某些特定策略，可能需要采用其他频率的数据。例如，对于周度判断的策略选用周度数据更具相关性；而对于更加短期的日频策略，采用日度数据计算捕获率能更精确地捕捉基金在短期市场波动中的表现。

上行与下行阶段的界定，通常依据业绩比较基准在每个数据周期（如月度）内回报率的正负进行客观划分，此为计算捕获率的常用标准方法。作为补充，分析师有时亦会依据宏观经济周期或重大市场事件，人为划定更长期的市场阶段以计算捕获率，旨在评估基金对市场大趋势的适应性，例如股市牛市阶段及熊市阶段、债市收益率上行阶段及下行阶段、通胀上行及下行阶段等等。尽管如此，此类人为划分因其主观性强、易引入后见之明偏误、且缺乏统一标准进而影响可比性，在常规业绩评价中，基于数据周期的客观划分仍是主流。若确需采用人为划分，分析师必须清晰阐述其逻辑与依据。

捕获率能够为投资者提供关于基金经理在不同市场周期（如牛市和熊市）中相对于基准的表现。理想的情况是，一只基金能够展现出较高的上行捕获率（例如大于100%）和较低的下行捕获率（例如小于100%）。这样的组合表明基金不仅能在市场上涨时争取到超越基准的更高回报，还能在市场下跌时有效地控制风险，使损失小于基准。

在实际运用中，捕获率应结合基金的投资目标、策略以及考察区间的长度和市场特征进行综合评估。常见的考察区间长度包括1年、3年、5年等，更长的周期有助于平滑短期市场波动的影响，从而更可靠地评估基金的长期表现。

此外，还可以计算整体捕获率（Overall Capture Ratio），定义为上行捕获率与下行捕获率之比（UCR/DCR）。该比率越高，通常意味着基金每承受一单位的下行风险（或相对市场下行表现），能捕获更多的上行回报（或相对市场上行表现），即具有更优的非对称收益特征。

理解不同基金的捕获率特征，有助于投资者根据自身的风险偏好、投资目标以及对市场前景的判断，选择更合适的基金产品进行配置。

最后，需要特别指出的是，当业绩比较基准在特定上行或下行阶段的平均回报率接近零时，即使基金的绝对回报并不突出，计算得到的捕获率数值也可能变得极大。这是因为分母趋近于零会导致比率的绝对值放大。在此类情形下，捕获率指标的解释力会显著下降，可能无法准确反映基金的真实表现。因此，投资者在遇到此类极端数值时，可以调整数据频率或者人为划定市场阶段，也可以结合基金的绝对回报水平、市场环境以及其他相关业绩指标进行综合审慎评估，避免过度依赖单一时期的捕获率数据。

# 四、风险调整收益指标

基金投资组合获取收益的同时也承担着风险。因此，评价基金业绩既需考虑收益水平，还需兼顾所承担的风险。风险调整收益指标的计算尤为重要，因为这类指标通过计算单位风险所对应的收益水平，实现将不同风险水平的投资组合在同一风险基准下进行比较。

衡量风险的指标很多，包含总风险、系统风险、下行风险、主动风险等，由此也产生了多种风险调整收益指标。进行基金评价时，使用不同指标，分析结果可能会存在显著差异。

值得注意的是，数据频率和时间跨度对风险调整收益的计算结果有显著影响。使用日频和月频数据计算会得出不同的结果，而不同历史时期的基金表现也可能存在显著差异。因此，在比较不同基金的风险调整收益指标时，需保持数据口径一致。

通常，较长的观察期能够提供更有价值的信息；太短的观察期可能受到随机因素的严重干扰，导致计算结果失真。例如，短期内较高的信息比率可能仅仅反映了暂时的好运，而非真正的主动投资能力。此外，投资策略的调整和基金经理变动等因素也会影响数据的参考价值，在解释结果时需要谨慎考虑这些因素。

风险调整收益指标值从不同角度对基金收益进行风险补偿，使评价结果兼顾风险和收益两个维度。然而，这些指标的计算通常基于一些假设，如投资组合的风险与收益之间存在线性相关，且这种相关性在整个观察期内保持不变。这些假设在实际市场中可能不总是成立，因此在解释结果时需要注意这一局限性。

上述模型从不同角度对基金经理的选股能力和择时能力进行了评估，从最早的詹森阿尔法到后来更复杂的多因子模型，这些方法为投资者提供了衡量基金表现的有效工具。需要注意的是，虽然这些模型在理论上假设了风险与收益之间的线性关系，但在实际应用中，市场波动性、基金经理的策略变化等因素都可能影响模型的准确性。因此，在使用这些模型时，应结合实际情况进行综合分析。
