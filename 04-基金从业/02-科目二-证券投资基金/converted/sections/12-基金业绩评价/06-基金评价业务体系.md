# 一、基金评价业务概述

随着基金行业的发展，基金产品数量不断增多，产品种类和投资策略不断丰富，基金组合投资策略不断丰富；同时，基金因其低成本、高效率的投资运作优势，使得基金成为越来越多投资者的投资选择。基金业绩评价和研究业务，在帮助投资者选择基金、鞭策基金管理人遵照契约、主动提升投资管理能力、促进基金行业健康发展方面发挥着重要作用。

基金业绩评价业务涉及基金分类、评价指标计算、评价结果发布等多个环节，经过多年的发展和实践，国内外基金评价机构已经形成各具特色、各有侧重的基金业绩评价方法体系。

2009年底、2010年初，中国证监会和中国证券业协会相继发布《证券投资基金评价业务管理暂行办法》和《证券投资基金评价业务自律管理规则（试行）》。依照规定，基金评价机构对证券投资基金进行评价并通过公开形式发布基金评价结果的，要有相关的基金从业人员并有一定的研究经历、基金数据对接及科学的评价体系与内控机制，通过相关严格审核等，从而取得相应的资质。2010年5月，经过评审，首批10家机构获得基金评价业务资质，包括中国银河证券股份有限公司、海通证券股份有限公司、招商证券股份有限公司、上海证券有限责任公司4家证券公司，晨星资讯（深圳）有限公司、北京济安金信科技有限公司2家独立基金评价机构，天相投资顾问有限公司1家证券投资咨询机构，以及中国证券报、上海证券报、证券时报3家媒体。

2019年，10家基金评价机构共同签署了《坚持长期评价，发挥专业价值》倡议书，提出了“坚持长期评价，树立长期投资理念”“提升专业价值，优化基金评价机制”“宣传长期投资，引导投资者关注长期收益”等三大方面的倡议，以强化长期评价导向，促进权益类基金发展，培育基金业长期发展的良好环境。

# 三、基金评价业务的主要环节

# (一) 基金分类

基金分类是基金业绩评价的基础和核心环节，对整个评价过程和结果都具有重大影响。其重要性主要体现在以下几个方面：

# 1. 确保评价的公平性和可比性

不同类别的基金具有不同的风险收益特征、投资策略和业绩基准。通过合理的分类，可以确保在同类基金间进行比较，避免“苹果对比橘子”的情况出现。例如，将高风险的股票型基金与低风险的货币市场基金进行直接比较是没有意义的，甚至可能产生误导性结果。

# 2. 提高评价的精确度和专业性

细致的分类可以更好地反映各类基金的特点和表现。例如，在混合型基金中，可以根据股票投资比例进一步细分为偏股型、平衡型和偏债型等，这样可以更准确地评估基金经理在不同资产配置策略下的管理能力。

# 3. 满足投资者的差异化需求

不同投资者有不同的风险偏好和投资目标。通过明确的基金分类，投资者可以更容易地找到符合自身需求的基金产品，评价机构也可以为不同类型的投资者提供更有针对性的评价结果。

# 4. 促进行业的规范发展

清晰的基金分类体系有助于规范基金产品的设计和运作，减少“风格漂移”等问题的发生。同时，它也为监管机构提供了更好的监督基础，有利于维护市场的公平性和透明度。

# 5. 提升评价结果的实用性

基于科学的分类体系，评价机构可以开发更多维度的评价指标，如同类排名、风险调整后收益等，这些指标能为投资者和市场参与者提供更多有价值的信息。

# 6. 适应市场发展的需要

随着基金行业的不断创新和发展，新的基金类型不断涌现。分类体系应允许评价机构及时调整和更新分类标准，以适应市场的变化，确保评价体系的持续有效性。

# （三）评价结果发布

评价结果发布是向市场传递评价信息的重要环节。主要包括以下几个方面：

发布形式：评级结果通常以评级或单一指标排名的形式发布。例如，多数评价机构会发布基于长期业绩的综合星级评级。

发布渠道：结果可通过评价机构官网、专业金融终端、合作媒体等多种渠道发布。

发布频率：根据评价对象和市场需求，可能采用日频、周频、月频或季频等不同的发布频率。

信息展示：除了评级结果，通常还会提供评价方法说明、数据来源等辅助信息，以增加透明度。

合规性审查：在发布前，需确保评价结果符合监管要求和行业规范。

持续更新：定期更新评价结果，反映最新的市场变化和基金表现。

投资者教育：在发布评价结果时，同时提供必要的解读和风险提示，帮助投资者正确理解和使用评价信息。

评价结果的发布不仅是向市场传递信息，也是评价机构树立公信力和影响力的重要途径。因此，评价机构需要在及时性、准确性和公正性等方面严格把关，以确保评

价结果的权威性和参考价值。
