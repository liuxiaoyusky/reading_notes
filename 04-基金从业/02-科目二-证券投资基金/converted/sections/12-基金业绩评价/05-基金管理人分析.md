# 第五节 基金管理人分析

<table><tr><td>学习内容</td><td>知识点</td></tr><tr><td>基金管理人分析</td><td>公司和人员的合规性、治理结构、投资管理和研究能力、内部控制和风险管理能力、服务投资者能力、可持续发展实践情况</td></tr></table>

近年来，全球基金行业稳步发展，呈现产品创新加速和投资策略多样化的特点。随着资本市场的逐步开放和监管体系的不断完善，中国基金行业也显示出强劲的增长势头。各类基金管理公司快速崛起，为投资者提供了丰富的投资选择。

与此同时，个人投资者的理财意识不断增强，投资者根据不同的风险偏好和收益目标，积极寻找适合的基金产品。养老金、保险、银行等机构投资者，出于管理成本、法律法规约束、提升自身专业能力等方面的考虑，逐步将部分资产委托给包括基金管理公司在内的外部资产管理机构进行管理。选择合适的基金管理人是个人和机构投资者面临的共同问题。

学术界和业界普遍认为，历史业绩对于预测未来业绩的参考价值有限，投资能力和投资业绩在短期可能出现背离。优秀的业绩需要稳定的公司发展框架和长期投资策略才能延续。历史经验表明，投资能力强的基金管理人更有可能在长期取得相对稳定的业绩表现。因此，评价基金管理人需要识别那些决定投资业绩的长期因素，将视角从单纯的历史业绩扩展到公司治理、投资管理、风险管理和合规性等方面，通过定性和定量指标综合评判其价值。

在基金管理人评价方面，不同投资者或评价机构有各自的分析框架，但普遍关注基金管理人在合规、治理、经营、投研、内控等方面的能力和表现。评价机构通常会针对每一项能力制定细化的评估指标，借助公开信息、问卷调查及访谈等方式收集数据，计算指标，最终通过综合分析给出评定结果。

随着基金行业的快速发展，监管机构对行业提出了更高的要求。这些要求强调基金管理人应树立正确的经营理念，平衡功能性和盈利性的关系，积极培育良好的行业文化和投资文化。此外，新的监管导向还要求完善行业考核评价制度，全面强化长周期考核与激励约束机制，建立健全从业人员执业声誉管理机制，并坚决纠正行业中的不良风气。这些因素也逐渐成为评估基金管理人时不可忽视的重要维度。

# 一、公司和人员的合规性

作为受托理财的持牌机构，基金管理人受到严格的监管约束。投资者和基金评价机构可以通过公开渠道，如中国证监会和中国证券投资基金业协会的处罚和自律管理决定、交易所发布的相关公告、基金产品定期报告、媒体曝光等，密切关注基金管理人在合规方面的表现，持续跟踪其是否涉及“老鼠仓”、市场操纵、利益输送、不公平交易、违规销售和宣传等违法违规行为。对于存在严重损害基金份额持有人利益的违法违规行为，一些投资者和基金评价机构会采用黑名单制度，将相关基金管理人排除在待选或待评范围之外。

# 二、治理结构

公司治理是确保公司高效运作的关键机制，旨在协调并约束内外部各利益相关方的行为。公司治理领域的核心问题主要包括股东与管理层之间的关系，以及股东之间的关系。

基金管理是以人力资本为主要资本形态的行业，管理运作的是投资者的受托资产，因此必须坚持投资者利益优先原则。一个治理良好的基金管理公司应具备能够有效统一持有人、员工和股东三方利益的治理结构。基金评价机构通常从以下几个方面对基金管理人的治理情况进行评估：

# 1. 治理架构与制衡机制

评估重点在于公司是否建立了清晰的治理架构，明确界定股东会、董事会、监事会/审计委员会和管理层的职责边界，并确保各方之间的有效制衡。特别关注独立董事、监事和督察长是否能够切实履行监督职能，强化高管人员的责任意识。同时，评估公司是否具备防止大股东或实际控制人滥用控制权干预正常经营的机制，以及是否能有效防范股东缺位或内部人控制的风险。

# 2. 股东结构的稳定性与股权准入管理

稳定的股东结构是公司长期健康发展的基石。评估关注点包括股东变动频率、股权准入管理的严格程度，以及是否有效防范股权代持、变相套取或倒卖牌照等违规行为。基金管理公司应当切实落实主体责任，确保股权结构的健康性与透明度。

# 3. 独立董事制度的实施与效能

根据监管规定，基金管理公司的独立董事人数不得少于3人，且不得少于董事会人数的1/3；基金管理公司第一大股东为自然人的，独立董事人数不得少于董事会人数的1/2。评估重点在于独立董事制度的实际运作情况，包括独立董事的选聘程序、履职能力和实际发挥的作用，以确保其能有效平衡大股东影响，切实保护基金投资者的合法权益，提升公司治理的公正性与透明度。

# 4. 从业人员的绩效考核和薪酬管理

合理的薪酬体系是保持核心人才稳定性和确保员工与公司长期利益一致的关键。评估重点包括：

（1）以基金投资收益为核心的长周期考核机制：是否建立了以基金投资收益为核心的考核体系，对基金公司高管和基金经理的考核中，基金投资收益相关指标的权重分别不低于50%和80%；是否全面实施长周期考核，3年以上中长期收益考核权重不低于80%。

# 5. 内部监督与控制机制的健全性

评估公司是否设立了独立的监察稽核和风险管理部门，是否建立了架构清晰、控制有效的内部控制机制，以及是否制定了系统全面、切实可行的内部控制流程。这些因素是确保公司合规经营和有效风险防控的重要保障。

# 6. 行业文化的践行

良好的公司治理应积极践行行业文化建设责任。基金行业深入践行以“合规、诚信、专业、稳健”为核心的行业文化理念，并通过2023年4月中国证券投资基金业协会发布的《公募基金行业文化建设自律公约》予以明确。同时，坚持“五要五不要”原则，践行中国特色金融文化，推动行业高质量发展。基金公司应以此为基础提升软实力和核心竞争力，增强从业人员的职业认同感与使命感，始终坚持持有人利益优先原则，构建具有行业特色的经营理念和价值体系，同时妥善处理功能性与盈利性的关系。

基金评价机构通常会针对以上各个维度设置细化的评估指标，并根据不同指标的权重进行综合评分，以全面衡量基金管理公司在公司治理方面的表现。

# 三、经营能力

经营能力是基金公司生存和发展的基石，主要体现在管理规模、产品结构、创新能力以及客户构成等方面。深入了解基金公司的发展历史，有助于评估其发展策略和未来潜力。投资者和基金评价机构通常从以下几个方面进行分析：

（1）管理规模；考察基金公司的资产管理规模，既要观察当前的总量，也要分析近年来的规模增长情况，包括新基金发行和存量基金持续营销带来的规模增长，以更好地判断公司的可持续发展能力、市场竞争力以及其在行业中的地位。同时，也需要考察基金规模是否与基金公司的投资管理能力、运营能力、风险控制能力和营销服务能力相匹配，避免盲目扩张规模，影响投资业绩。在评估时，需要综合考虑市场容量，交易活跃度及流动性等因素，确保基金规模与实际运作能力相适应，从而实现长期稳健的经营。

（2）产品结构：关注公司产品的数量、类型覆盖及各类产品的规模分布等。通过公司的产品布局与行业其他公司的比较，分析公司在各类产品上的竞争力。评估不同类别基金的设立时间、管理经验以及公司在各类产品上的竞争优势。产品线的广度和深度不仅反映了公司适应市场需求的能力，也体现了其在不同市场周期中的抗风险能力。

（3）创新能力：评估基金公司在产品和业务创新方面的表现，尤其是其是否能够在风险可控的前提下推出创新型产品以满足不同投资者的需求。创新不仅体现在产品线的拓展与优化，还体现在公司应对市场变化的灵活性和前瞻性。创新能力是公司在激烈市场竞争中脱颖而出的关键。

（4）客户结构：考察公司客户结构，包括机构投资者和个人投资者占比、渠道及机构客户集中度、长短期资金的比例等。多元化的资金来源和较高的中长期资金占比，有助于公司保持稳健的经营，减少因短期资金流动导致的风险，并增强公司应对市场波动的能力。

# 四、投资管理与研究能力

投研能力是基金管理人的核心竞争力。投资管理和研究能力评价包含对历史业绩、投研团队和投资流程的评价等。

（1）历史业绩：即对基金管理人旗下不同类别基金产品基于不同指标进行定量分析。这些指标包括绝对收益、相对收益、风险调整收益、主动管理能力以及业绩归因等。在评估基金管理人旗下产品的总体历史业绩时，可以通过规模加权或者算术平均等方式衡量其整体的风险收益表现。值得注意的是，任何业绩指标都只能从一个维度反映基金表现，因此必须结合多种评价指标才能较为全面地衡量基金管理人的业绩水平和收益来源。同时，结合定性分析可以判断基金管理人的历史业绩是否能够代表其当前的投资管理能力，并根据不同资产类别（如股票和债券）对管理人的投资能力进行分类评估。

（2）投研团队：投研团队是基金业绩的核心驱动力。投资决策过程中的每个环节——从研究、决策、组合构建、交易、风险管理到再平衡，都依赖于团队的协作和专业能力。对投研团队的评价是投资管理能力评估中的重要组成部分。可以通过问卷调查、现场调研以及访谈等方式，深入了解投研团队的构成、协作情况以及其研究覆盖能力。具体的评价内容包括：投研团队的资质、背景和从业经验；投资人员在投资过程中的实际参与度和协作情况；团队在宏观经济、投资策略、行业分析以及公司研究方面的覆盖能力和成果转化能力；薪酬和激励机制的合理性；投研梯队建设是否支持投研团队的长期发展和能力传承；核心人员稳定性；以及基金经理的投资理念和实际投资行为是否保持一致。

（3）投资管理流程：投资管理流程是基金管理人投资活动的制度规范和操作程序的综合。良好的投资流程能够确保投资过程的可重复性，减少主观随意性带来的风险。可以评估基金管理人的投资流程是否有制度化的规范，并且是否能够严格执行。优秀的基金公司通常采用自上而下的投研体系管理，而不是依赖单一投资经理主导基金产品的投资风格，考核机制注重中长期业绩表现。这一制度设计不仅保证了投资风格的稳定性和投研产出的持续性，还能有效减缓因投资经理变更而引发的风格和业绩波动。因此，良好的投资管理流程能够帮助基金管理人更有效地接受长期资金的委托。

# 五、内部控制和风险管理能力

基金管理人的内部控制是指公司为防范和化解风险，保证经营运作符合公司发展规划，保护投资者利益，通过建立组织机制、运用管理方法、实施操作程序和控制措施而形成的系统。

可以从以下几个方面评估基金管理人的内部控制和风险管理能力：

# 六、投资者服务能力

基金管理人的投资者服务能力体现在其依托专业的投资及研究能力，通过一系列高质量的服务和措施，与销售机构协同合作，为投资者提供全方位支持。这不仅可以帮助投资者深入了解基金产品，还可以引导其合理进行资产配置，贯彻长期投资和价值投资理念，并实现良好的投资回报。具体表现包括逆周期布局和持续营销的效果、信息披露的透明度与质量、投资者教育的广度和深度以及政策宣传和舆论引导的有效性。

# 七、可持续投资实践情况

随着可持续发展理念的普及，环境、社会和公司治理（ESG）因素在投资决策中的重要性日益凸显，越来越多的投资者开始关注基金管理人在这方面的承诺和表现。评估基金管理人的可持续发展实践，应从投资实践和自身运营两个维度展开。

# （一）投资实践层面

首先，考察基金管理人是否系统性地将 ESG 因素融入投资决策和风险管理，包括明确的可持续投资政策、专业团队及资源配备，在投资分析、决策及组合管理中全面体现 ESG 考量。

其次，关注基金管理人的信息披露质量。基金管理人应定期向投资者及利益相关方披露其可持续发展政策、实施情况和投资组合的ESG表现，确保透明度与及时性。

第三，评估基金管理人在积极所有权方面的表现。基金管理人应制定清晰的参与策略，主动参与被投资企业的重大决策过程，促进企业提升ESG绩效与长期价值。这包括系统性关注企业的环境责任、社会贡献及公司治理状况，设定明确的改善目标与路线；通过独立判断表决股东大会中涉及ESG的议案，并与企业管理层开展建设性对话，推动企业实现实质性改善。

# （二）自身运营层面

基金管理人还应在自身运营中贯彻可持续发展承诺，包括建立健全的公司治理结构、承担环境责任、保障员工公平待遇以及积极履行社会责任等。同时，在商业道德、反腐败措施、数据安全与隐私保护方面设立高标准，以自身行为体现对可持续发展的坚定承诺。

此外，基金管理人能否将国际ESG标准与本土市场实际情况有效结合，也是评估的重要方面。尤其在中国市场特殊的政策环境与发展阶段下，基金管理人应根据本土需求灵活调整可持续发展策略，例如在绿色金融领域积极支持国家碳中和目标、推动低碳经济转型，在科技金融领域优先投资能够推动产业升级与技术创新的企业，在普惠金融领域通过金融手段促进社会公平与共同富裕。这些做法体现了基金管理人对本土市场的深刻理解与实践创新能力。
