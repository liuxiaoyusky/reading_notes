# 一、另类投资的概念和类型

# (一) 概念

另类投资是相对于传统投资的一类投资形式。传统投资通常指在公开市场交易的股票、债券、期货和现金等资产，而另类投资则涵盖了除传统投资之外的投资类别，也称“替代投资”或“非主流投资”。这里的“另类”一词并无贬义，仅表示此类投资有别于股票和债券等传统资产。另类投资通常包括私募股权、私募债、房地产、基础设施、自然资源、对冲基金和收藏品等。

# （二）主要类别

# 1. 私募资本

私募资本是指主要通过非公开方式募集，向企业提供股权或债权融资的资本。其投资可涵盖企业发展的不同阶段，包括初创期、成长期、成熟期及特殊情况（如并购重组、困境企业救助等），投资形式多样，通常具有较长的投资期限。私募资本主要包括私募股权和私募债。

# 2. 实物资产

实物资产通常指具有有形物理形态、能产生经济回报的经济资源（人力资本除外），其价值与物理属性和用途直接相关，以此区别于主要代表索取权的金融资产。投资实践中，实物资产常被划分为几个主要类别，以便更好地反映其独特的投资驱动因素和风险收益特征，常见的核心领域包括不动产(含基础设施)和自然资源。

不动产投资主要聚焦于土地及其上的永久性建筑物，如商业、工业或住宅物业。

其价值核心在于地理位置、租金收入、资产增值潜力及开发活动，投资者可通过直接持有物业、投资房地产投资信托基金（REITs）或相关债权工具等方式参与。

广义的不动产投资包含基础设施投资。基础设施涵盖支持社会运行的核心物理系统与设施，例如交通、能源和公用事业网络。因其常涉及特许经营权、具公共事业属性、拥有独特（通常长期稳定）的现金流模式且受较强监管，在投资界常被视为独立于传统房地产的资产类别，可通过直接投资、参与项目融资或投资相关公司与基金进行配置。

自然资源投资则围绕能源、金属、农产品等大宗商品以及与这些资源勘探、开采、种植或管理相关的土地及权利展开。值得注意的是，农业用地和林地也常被归于此类，因为其投资价值更多地取决于资源（如作物、木材）的生长、收获及相关商品价格，而非传统土地增值逻辑。投资方式包括直接拥有实物商品或资源性土地/权利、投资于相关产业链的公司股票或基金，以及运用商品期货等金融衍生品来管理或获取价格风险敞口。需要注意的是，衍生品本身是金融工具，而非实物资产本身。

# 3. 对冲基金

对冲基金是使用多种投资策略以获取高回报的私人投资工具，具有较大的灵活性，可以利用各种策略管理证券和衍生品组合，并常使用较高的杠杆，旨在提供独立于市场的回报。对冲基金往往采用私募形式发行，不公开上市。策略包括股票对冲、事件驱动、相对价值和宏观/商品交易顾问策略等。

# 4. 收藏品投资

收藏品投资也是另类投资的重要组成部分。收藏品的投资价值通常建立在艺术家声望和销售纪录的基础上。由于这些资产的特征和质量差异较大，使得对其投资价值的评估较为复杂，并带有一定的主观性和不确定性。收藏品市场主要以拍卖为主，其独特的风险与回报特性为投资者提供了多样化选择。

此外，黄金投资虽可视为大宗商品投资的一种，但它也具有货币特性。黄金不仅作为大宗商品交易，还具备价值储存功能，通常与货币相挂钩。

这些不同类型的另类投资方式体现了另类投资的“另类”之处，既包括投资标的与策略，也包括组织形式。另类投资是一个尚未形成共识而且在快速发展变化中的领域，不同机构对另类投资的定义和分类并不完全相同。“另类”也并不意味着都是创新，例如不动产和大宗商品投资都有着悠久的历史。

# 二、另类投资的发展

# （一）全球发展情况

另类投资的概念可以追溯到数百年前，当时富有的个人和机构已经开始投资于房地产、商品和艺术品等实物资产。然而，另类投资作为一个独立的资产类别和概念，直到20世纪才逐渐确立和制度化。

私募股权的现代形式出现在20世纪中叶。1946年，美国研究与发展公司（American Research and Development Corporation，ARDC）的成立标志着专业风险投资和私募股权投资的开端。

房地产长期以来一直是财富保值和增值的重要手段。然而，作为一种投资类别，房地产的广泛认可和普及始于20世纪60年代房地产投资信托基金的创建。这一创新使得投资者不仅可以通过直接购买物业进行投资，还可以通过金融市场更便捷地参与房地产市场。

1949年，阿尔弗雷德·温斯洛·琼斯（Alfred Winslow Jones）创建了第一个对冲基金，结合多头和空头头寸以对冲市场风险。该策略旨在无论市场状况如何都能产生回报。

自20世纪80年代以来，全球另类投资的发展受到多个因素的驱动，包括机构投资者对多样化的需求、金融市场的全球化、监管环境的变化以及技术进步。这些因素共同推动了另类投资的蓬勃发展。例如，橡树资本专注于困境债务投资，通过在经济周期低谷期收购陷入困境的企业债务，并通过债务重组和资产管理获得超额回报。黑石集团则通过全球范围内的大规模私募地产投资和基础设施项目，成功实现了资产的增值和稳定的现金流。

随着另类投资的发展和成熟，大型机构投资者越来越多地将其纳入投资组合。耶鲁大学捐赠基金就是一个典型的例子。作为全球最成功的大学捐赠基金之一，耶鲁大学捐赠基金长期以来在资产配置策略上以另类投资为主。表7-1是2022和2023财年耶鲁大学捐赠基金的目标配置比例。其中，美国国内股票、海外股票和债券投资，占比并不高。大部分投资于绝对回报、杠杆收购、实物资产（不动产）、对冲基金、风险资本等另类资产投资中。

随着经济全球化的发展，另类投资也呈现出国际化的趋势。私募股权投资最早在欧美地区兴起，并逐步发展成熟。近年来，随着新兴市场的崛起，越来越多的私募股权投资者将目光转向这些新兴市场，特别是在私募股权、基础设施和房地产领域。这推动了更多国际资本进入以中国为代表的新兴市场。

根据Preqin（睿勤）发布的另类投资报告 $^{①}$ ，2023年底，全球另类资产估计规模为16.3万亿美元，预计2028年将达到24.5万亿美元，其中私募股权预计将从2022年底的4.8万亿美元增长至8.5万亿美元，复合年增长率（CAGR）约为10%；全球私募市场的房地产投资则预计将从2022年底的1.6万亿美元增长至2.2万亿美元，CAGR约为6%。

# （二）国内发展情况

在我国，另类投资于21世纪初开始起步。在经济高速增长的背景下，私募股权、不动产和基础设施等另类投资，不但为经济发展和产业转型提供资金支持，而且为未来不断增长的财富管理的需求提供了新的解决方案。随着资本市场的逐步成熟，另类投资逐渐成为重要的资产类别。

公募基金行业在2011年首次通过QDII（合格境内机构投资者）形式开始尝试另类投资业务。涵盖黄金、不动产投资信托（REITs）和商品基金。黄金QDII产品投资于海外上市交易的黄金ETF产品，部分还配置黄金类股票。早期的REITs产品投资于海外REITs，大部分投资于美国不动产市场。商品QDII投资涉及石油、农产品等多类商品。修订后的《证券投资基金法》在2013年实施后，境内公募另类投资基金开始出现。国内黄金ETF在2013年密集上市，主要是投资于上海黄金交易所的黄金产品，间接投资于实物黄金。2014年，嘉实基金管理公司发行了首只以投资于非上市公司股权的形式参与国企混合所有制改革的公募基金“嘉实元和直投封闭式混合型发起式证券投资基金”。

基础设施领域的另类投资也在中国取得了显著进展。2021年6月，沪、深证券交易所首批9只公募基础设施REITs正式上市，涵盖仓储物流、生态环保、高速公路、清洁能源等多个领域，为投资者提供了一个参与长期稳定收益投资的渠道。截至2023年末，国内已上市的公募REITs总数已达29只，总发行规模近千亿元。这标志着中国在基础设施领域的另类投资迈出了重要一步。这些REITs不仅为企业提供了新的融资渠道，也为广大投资者带来了多元化的投资选择。

另类投资业务也成为近年券商布局“投行+”业务的重点之一。随着注册制全面落地，特别是2019年科创板的推出及另类子跟投制度，券商以“投行、投资、投研”三投联动为主的“投行+”模式推动券商另类子公司的大力发展。多家券商开始密集投入资源设立另类投资子公司，以参与科创板项目的跟投。截至2023年末，证券行业共有84家券商设立了另类投资子公司，还有部分券商未具备另类投资业务展业资格。券商另类投资子公司的经营业务以一级股权投资以及科创板跟投为主，一方面，券商可以通过对潜在投行项目前期的股权投资，在增加投行项目储备的同时，打造投行生态圈，从而提升客户黏性、助力获取更加多元化的业务机会。另一方面，券商可以通过另类投资子公司参与科创板企业等项目跟投，积极支持“专精特新”等新质生产力企业发展。2023年至2024年1月底，科创板共有68家企业上市，共有20家券商的另类投资子公司参与了科创板新股跟投。

国内私募股权投资起步晚于欧美等发达地区，但发展较快。1986年，由原国家科委和财政部联合几家股东于1986年共同投资设立了中国创业风险投资公司，成为我国第一家专营风险投资的股份制公司，创立之初的目的是扶植各地高科技企业的发展。1992年，外资风险投资机构开始进入中国。2006年《合伙企业法》的颁布实施使得国际PE基金普遍采用的有限合伙组织形式得以实现，大力推动了PE行业的发展。2009年10月，创业板成立，随着多层次资本市场建设逐步完善，国内私募股权发展也迈上新台阶。2015年后，受政府主导的“大众创业、万众创新”的鼓舞，资金面流动性充裕，国内私募股权市场进入爆发式发展阶段。截至2022年底，私募股权和创投基金规模超14万亿元，占私募基金总规模的 $69\%$ ，位居世界第二。2023年以来，证券行业首部行政法规《私募投资基金监督管理条例》，以及《私募投资基金监督管理办法（征求意见稿）》《私募证券投资基金运作指引》等一系列法规接连出台，以“法律法规—部门规章—自律规则”为框架的私募监管制度体系初步完备。中国私募股权行业经过三十余年的发展，已经成长为支持实体经济不可或缺的重要金融力量。

碳排放权交易属于一种特定的商品类投资。在1997年《京都协议书》（Kyoto Protocol）签署后，各国政府把二氧化碳排放量作为一种可交易的大宗商品，形成市场机制，对碳排放权进行交易，通常合同一方通过支付货币或者其他资产来获得合同相对方的温室气体减排额。其主要类型包括配额型交易和项目型交易。近年来，我国也开始进行碳排放交易市场基础设施建设。2021年7月16日，全国碳排放权交易市场启动上线交易，交易中心设在上海，登记中心设在武汉，首批纳入全国碳市场的2162家发电企业上线交易，年覆盖温室气体排放量约45亿吨二氧化碳，覆盖全国碳排放总量约 $40\%$ 。截至2023年底，碳市场已纳入2257家发电企业，累计成交量约4.4亿吨，成交额约249亿元，覆盖年二氧化碳排放量约51亿吨。2023年，全国碳市场碳排放配额（CEA）年度成交量达到2.12亿吨，较2022年增长3倍，年度成交额为144.44亿元，日均成交量达到87.58万吨。

随着中国资本市场的进一步开放和政策支持力度的加大，另类投资在中国的发展前景广阔。未来，随着更多创新型金融产品的推出和政策的持续支持，另类投资有望继续在中国资本市场中发挥重要作用，推动经济的高质量发展。

# 三、另类投资的优势与局限

由于另类投资类别繁多且不断创新，因此以下对其优势与局限的讨论主要基于总

体趋势或某些主要类型，并不涵盖所有另类投资的特性。

# （一）另类投资的优势

# 1. 潜在的高收益

另类投资的主要吸引力之一在于其潜在的高收益。相较于传统投资，另类投资在某些情况下可能产生更高的回报。例如，Cambridge Associates的研究数据 $^{①}$ 显示，截至2023年底，美国私募股权投资过去25年的年化收益率约为13.1%，而同期标准普尔500指数的年化收益率约为7.6%，纳斯达克综合指数年化收益率约为8.8%。这种较高的收益潜力主要源于另类投资在小众市场的布局或采用传统市场难以实施的复杂投资策略。需要注意的是，历史业绩并不预示未来表现，且不同时期、不同策略的私募股权投资回报差异巨大。该数据仅为特定市场和时间段的参考。

# 2. 投资组合多元化效应

另类投资可以为投资组合带来显著的多元化效应。由于另类投资与传统资产类别（如股票和债券）的相关性通常较低，有时甚至呈现负相关，将其纳入投资组合可能有助于降低整体风险和波动性。例如，在股票市场下行期间，不动产或大宗商品等另类资产可能表现出不同的价格走势，从而在一定程度上平衡投资组合的整体表现。值得注意的是，多元化效应在极端市场条件下可能失效，例如在全球金融危机期间，许多另类投资与传统资产的相关性突然增加，导致预期的分散风险效果大幅减弱。此外，某些另类投资（如特定类型的对冲基金）本身与股票市场高度相关，无法提供有效的多元化保护。

# 3. 通货膨胀对冲

部分另类投资，特别是如实物资产（不动产）和某些大宗商品，具有潜在的通货膨胀对冲能力。在通货膨胀加剧时期，这类资产的价格随之上升，为投资者提供一定程度的保护。以房地产为例，不仅资产本身可能随时间升值，租金收入也可能随通货膨胀而增加，从而在理论上提供双重收益。然而，这种对冲效果并非绝对，仍需考虑市场供需、政策变化等多方面因素。

# 4. 独特的市场机会

另类投资为投资者提供了传统投资难以涉足的市场和机会。例如，投资者可以通过风险投资参与初创企业的融资，或投资于稀有艺术品和收藏品等领域。这些投资机会不仅可能带来可观的回报，还能满足特定投资者的专业兴趣。对于那些在某些细分领域拥有专业知识或独特见解的投资者而言，这类机会尤其具有吸引力。

# （二）另类投资的局限

# 1. 监管环境的差异性与信息透明度挑战

另类投资涵盖范围广，发展速度快。相较于高度标准化的公开市场（如股票、债券），另类投资面临的监管环境要复杂得多。这种复杂性体现在多个层面：首先，私募股权、对冲基金、房地产、基础设施等不同类型的另类资产特性迥异，适用的监管规则往往具有很强的特殊性；其次，不同国家和地区的监管框架、准入标准、运作要求差异显著；再者，许多领域的监管体系仍在不断发展和演变中，使得市场参与者需要适应动态变化的合规要求。

在信息披露方面，部分源于这种复杂且差异化的监管环境以及产品自身的特性，投资经理通常不会像公募产品那样进行广泛、标准化的公开信息披露。投资者能够获取的详细产品信息相对有限。加之另类投资产品普遍流动性较差、投资周期较长，管理人提供投资报告的频率通常较低（如月度或季度）。这种信息披露的不充分和不及时性，加剧了市场参与者之间的信息不对称，使得个人投资者相比机构投资者在获取和理解关键信息方面可能面临更大挑战，这也部分解释了为何另类投资市场目前仍以机构投资者为主导。

# 2. 流动性较差，杠杆率偏高

大多数另类投资的流动性明显低于传统金融资产。与在二级市场出售股票相比，出售不动产或私募股权投资通常需要更长时间，且可能因急于出售而承受较大价格折扣。由于交易频率低，资产价格难以准确反映其真实价值，容易受到少数参与者交易行为的显著影响。此外，某些另类投资策略（如杠杆收购）或涉及金融衍生品（如商品期货）的投资可能采用高杠杆运作，这在带来高回报潜力的同时也大幅提高了风险。

# 3. 估值难度大

另类投资的估值过程通常比传统资产更为复杂和主观。由于交易不活跃，缺乏足够的历史数据和可比价格，难以准确评估资产价值。估值过程需要更专业的知识和经验，尤其是对于非标准化资产。估值结果高度依赖于所采用的假设，如果这些假设与实际情况偏离，可能导致严重的估值误差。例如，在不动产市场下行时期，基于历史数据的估值可能过于乐观。

# 4. 产品结构复杂

操作风险和复杂性也是另类投资面临的重要挑战。许多另类投资策略涉及复杂的金融工具和交易结构，增加了操作风险。投资表现高度依赖于管理团队的专业能力和决策，增加了人为风险。此外，另类投资可能涉及复杂的法律结构和税务安排，增加了合规成本和风险。

总体来看，另类投资拓展了投资范围，在成熟的市场体系能够实现较高的收益和较低的波动性，但由于其固有的复杂性、透明度低、流动性差等特点，并不适合大多数普通投资者。它主要面向具备丰富金融知识和风险承受能力的专业投资者。投资者在考虑另类投资时，应充分认识这些局限性，并根据自身情况谨慎决策。
