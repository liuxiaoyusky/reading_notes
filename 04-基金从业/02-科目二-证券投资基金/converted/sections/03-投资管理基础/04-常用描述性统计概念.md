# 一、随机变量与描述性统计量

金融市场的核心特征之一是随机性。公司是否发生债务违约，投资项目的到期收益率，未来的资产价格等都是难以预测的。为了研究这些不确定事件，我们将它们和数值变量联系起来，并运用统计量来描述它们的特征。

# (一) 随机变量

# 1. 随机变量的定义

随机变量是一个能取得多个可能值的数值变量，是统计学中的核心概念，用于描述不确定性。例如，对某公司发行的债券，可以定义一个违约变量：

在这个例子中，违约变量Default是一个随机变量，Default=1表示债券违约，Default=0表示债券不违约。同样，某公司发行的普通股股价在未来某一天的收盘价也可以是一个随机变量。

随机变量可以分为两类:

离散型随机变量：如果随机变量X只能取有限个或可数无限多个不同的值，则X为离散型随机变量。其特点为取值是跳跃的，中间可能存在间隔。例如，抛硬币的结果（正面或反面）、骰子的点数（1到6的整数）、家庭的子女数量，以及债券的违约状态（0表示未违约，1表示违约）都属于离散型随机变量。

连续型随机变量：如果随机变量X可以取某个区间内的任意实数，则称为连续型随机变量。其特征是取值是连续的，任意两个不同的取值之间总存在其他取值。人的身高或体重、某地区的年降雨量、制造过程中产品的重量误差，以及股票在交易时间内的价格都是连续型随机变量的典型例子。

# 2. 随机变量的分布

随机变量的分布描述了它取不同值的概率。如果X是离散型随机变量，其最多可能取n个值 $x_{1}, x_{2}, \cdots, x_{n}$ ，并且记 $p_{i}=P\{X=x_{i}\}$ 是X取 $x_{i}$ 的概率，所有概率的总和 $\sum_{i=1}^{n}p_{i}=1$ 。

如果 X 是一个连续型随机变量，由于无法列出 X 取每个特定值的概率，我们使用概率密度函数来刻画 X 的分布。概率密度函数衡量随机变量 X 在特定范围内取值的可能性，其图像称为概率密度函数曲线。

图3-5中画出某连续型随机变量的概率密度函数曲线，其中的阴影部分面积就是该变量取值在（0，10]的概率 $P(0<X\leqslant10)$ 。

# （二）随机变量的数字特征与描述性统计量

在了解随机变量的分布后，我们通常需要进一步研究其特征，如取值的平均水平和离散程度。这些特征可以通过几个关键的统计量来衡量，如期望、方差、标准差、分位数和中位数等。在实际应用中，随机变量的分布往往是未知的，因此我们通过抽样并计算对应的描述性统计量来估计这些特征。

# 4. 中位数

中位数，又称中值，指按顺序排列的一组数据中居于中间位置的数。对于一组数据，有一半的数据大于或等于中位数，有一半的数据小于或等于中位数。当数据个数为奇数时，中位数是中间的那个数；当数据个数为偶数时，中位数是中间两个数的平均值。

例如，对于X的一组容量为5的样本，从小到大排列为 $X_{1},\cdots,X_{5}$ ，这组样本的中位数就是 $X_{3}$ 。如果是容量为10的样本 $X_{1},\cdots,X_{10}$ ，中位数则是 $\frac{1}{2}\left(X_{5}+X_{6}\right)$ 。

图[案例3-14]选取净值年增长率这个指标来考察基金的业绩，我们把某年度国内336只股票型基金的净值增长率按从高到低排列，其中排名第168位、第169位的某两只基金年度净值增长率分别为 $13.69\%$ 和 $13.64\%$ 。这组数据的中位数为 $(13.69\% + 13.64\%) / 2 = 13.665\%$ 。于是，我们将 $13.665\%$ 作为评价国内股票型基金当年度业绩的基准，净值增长率高于 $13.665\%$ 的基金表现优于行业一般水平，而净值增长率低于 $13.665\%$ 的基金表现劣于行业一般水平。

与另一个经常用来反映数据一般水平的统计量——均值相比，中位数的评价结果往往更为合理和贴近实际。

[案例3-15] 某债券投资者近年的年收益率由低到高分别为 $-16\%$ 、 $4\%$ 、 $5\%$ 、 $5\%$ 、 $6\%$ 、 $8\%$ ，则该投资者收益率的中位数为 $5\%$ ，均值却只有 $2\%$ 。进一步考察可知，-16%的收益率其实是受到金融危机的影响而发生的小概率极端事件，剔除掉这一异常值后，该投资者的投资策略可以取得平均5.6%的收益率。

在这种情况下，中位数不易受极端值影响，能较好地反映投资策略的真实水平；平均数（或均值）则很容易受到极端值的冲击，使其对数据的判别效果产生较大的误差。

# 二、正态分布

正态分布是最重要的一类连续型随机变量分布。当一个随机变量的取值受到众多微小且独立因素的共同影响时，该变量就服从或近似服从正态分布。在金融市场中，以股票为例，根据有效市场假说的弱式有效性，股票价格变动通常被视为随机漫步过程，而随机漫步假设股价的波动接近服从正态分布。

特别地，当 $\mu = 0$ ， $\sigma = 1$ ，称 $X$ 服从标准正态分布，记作 $X\sim N(0,1)$ 。

正态分布的概率密度曲线呈现中间高、两边低的钟形，以均值 $\mu$ 为中心向两侧对称递减。分布的两个显著特征是：

一是集中性：数据在均值附近最为集中，距离均值越远，则出现的概率越低。这意味着极端值出现的概率较小，而接近均值的值出现的概率较大。

二是波动性：正态分布的形状由标准差 $\sigma$ 决定，标准差越小，分布越“窄”，数据越集中于均值附近；标准差越大，分布越“宽”，数据的离散程度越大（见图3-6）。

正态分布有一个重要的经验法则，成为“68-95-99.7法则”：约 $68\%$ 的数据落在 $\mu \pm \sigma$ 范围内；约 $95\%$ 的数据落在 $\mu \pm 2\sigma$ 范围内；约 $99.7\%$ 的数据落在 $\mu \pm 3\sigma$ 范围内。更精确的数字是 $68.27\%$ 、 $95.45\%$ 及 $99.73\%$ 。这个特性在金融分析中经常用于评估风险和设定置信区间。

检验一个随机变量是否服从正态分布，可以绘制它的样本频率直方图，如果频率直方图呈现出“钟形”特征，可认为该变量大致服从正态分布。对于更严格的检验，可以使用统计方法如Shapiro-Wilk检验或Kolmogorov-Smirnov检验。

# 三、随机变量的相关关系——协方差、相关系数

以上讨论的都是单个随机变量的问题。但在金融市场中，多个不同随机变量之间的联系同样重要。投资者希望了解不同资产之间的相关性，例如通过期货与现货价格的相关性实现套期保值；又如，分析持有的投资组合内各项证券的价格联动性，以及组合整体表现与市场组合收益的关系。为此，我们可以适应协方差和相关系数来衡量随机变量的相关性。

为了消除协方差的单位影响，统计学家引入了相关系数的概念，用于衡量两个变量相关性的强度和方向。证券 $i$ 和证券 $j$ 的收益率相关系数 $\rho_{ij}$ 定义为协方差与各自标准差的比值：

其中， $\sigma_{i}$ 和 $\sigma_{j}$ 分别是 $r_{i}$ 和 $r_{j}$ 的标准差。

相关系数的取值范围为 $-1 \leqslant \rho_{ij} \leqslant 1$ :

\- 当 $\rho_{ij} = 1$ 时，表示 $r_i$ 和 $r_j$ 完全正相关，即它们总是同向变化。

\- 当 $\rho_{ij} = -1$ 时，表示 $r_i$ 和 $r_j$ 完全负相关，即它们总是反向变化。

\- 当 $\rho_{ij} = 0$ 时，表示 $r_i$ 和 $r_j$ 之间没有线性关系，即零相关。

相关系数反映了两个变量线性相关性的强弱，且不受原始数据单位的影响。因此，它可以用于比较不同单位或尺度的变量之间的关系。

在实际市场中，完全正相关或完全负相关的情况极为少见。大多数情况下，相关系数在 $(-1,1)$ 之间。若 $0<\rho_{ij}<1$ ，则 $r_{i}$ 与 $r_{j}$ 呈正相关，即一个变量的增加通常伴随着另一个变量的增加；若 $-1<\rho_{ij}<0$ ，则 $r_{i}$ 与 $r_{j}$ 呈负相关，即一个变量的增加通常伴随着另一个变量的减少。
