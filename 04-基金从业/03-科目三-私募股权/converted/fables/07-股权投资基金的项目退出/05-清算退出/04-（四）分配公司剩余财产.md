# （四）分配公司剩余财产

## ⚖️ 寓言故事 —— 《老吴的最后一笔账》

老吴在县城里开了一家布庄，三十年下来，几间门面变成了染坊、织机、仓库，外加南来北往的老客。股东原本只有他一人，五年前拉了两个老搭档入伙——一个做丝绸生意的钱老板，一个管账的孙先生。三人凑了一笔银子，把生意做到了府城去。

入秋时节，老吴病了。医生说他不能再操劳，要把布庄的账目和家当理一理。三个股东坐在后院，老吴从怀里掏出一本厚账册，长叹一声："我这身子，怕是扛不动了。咱们布庄的账，今天得算清楚，剩多少，分多少，按规矩来。"

钱老板第一个跳起来："老吴，咱们投得多、担得重，自然该分大头！"

孙先生按住了账册："别急，得先看看布庄还欠着谁。账上写得明白——还欠着绸缎庄陈老板三百两库银，欠着织工刘师傅等八人半年的工钱，欠着县衙的税银四十两。这些不还完，咱们谁也别想动布庄的银子和染缸。"

老吴点点头："孙先生说得对。布庄关门，账目先结清。"

孙先生翻开账册，一笔一笔算：先付清县衙的税银四十两，再清点仓库里能变卖的绸缎和棉布，折了现银，付清刘师傅他们半年的工钱。剩下的现银还了陈老板的库银之后，账册上只余下三百二十两现银和几台染缸、织机。

钱老板看着那笔结余，眼睛亮了起来："这下该咱们分了吧？"

孙先生把账册摊开："按当初入伙的约定——老吴占五成，我和钱老板各占两成五。但老吴病了，往后这布庄的招牌、门脸都靠我二人继续打理。我想跟两位商量一件事：这三百二十两现银，咱们三家先按约定的份额分。老吴那五成，一百六十两现银，归老吴养病。我那两成半八十两里，分五十两给钱老板；钱老板那两成半八十两，再分三十两给老吴。也就是从我和钱老板的份额里，各让出一部分补偿给老吴。这是我愿意的，钱老板你看呢？"

钱老板愣了愣，转头看老吴。老吴摆手："你们有这份心就够了。按账上来，该多少就是多少，多了我受不起。"

孙先生笑了："老吴，咱们这样做，并不违当初立下的字据。账面上三家按约定分，老吴那一份实打实拿到手；至于分完之后，我二人愿意再补给老吴多少，那是我们之间的情分，是另一笔账。"

钱老板沉默片刻，点了点头："成。按账来分。"

孙先生合上账册，提笔在"剩余财产"那一栏写下：剩余现银三百二十两，按老吴、钱老板、孙先生实缴出资比例五比二点五比二点五分配——老吴一百六十两，钱老板八十两，孙先生八十两。染缸、织机、门脸等实物，议定由孙先生与钱老板接手，老吴不再过问。

夕阳落进后院，老吴把账册合上，抱在怀里，朝两个老搭档深深一揖。

---

**📖 原文定义**

> 公司清偿全部公司债务后，若有剩余财产，清算组方能将公司剩余财产分配给包括股权投资基金在内的股东。对于公司清算后的"剩余财产分配"而言，《公司法》仅规定按照股东的出资比例（或持有的股份比例）分配。实践中，在满足《公司法》要求按股东实缴的出资比例分配后，公司股东之间可自行约定由部分股东将其分配所得的剩余财产补偿给股权投资基金，该等约定并不违反《公司法》相关规定。

**💡 对应点**

| 故事元素 | 概念对应 |
|---------|---------|
| 老吴病重、布庄要清算 | 清算退出的场景 |
| 孙先生先清税款、工钱、库银 | 清偿公司全部债务后才有剩余财产 |
| 账册上结余的三百二十两现银 | 剩余财产 |
| 老吴、钱老板、孙先生按 5:2.5:2.5 实缴比例分配 | 按股东实缴的出资比例分配剩余财产 |
| 孙、钱二人提议先按账分、再私下补给老吴 | 股东间自行约定部分股东将分配所得补偿给某一股东（不违反《公司法》） |
| 老吴摆手"按账上来" | 法定分配优先，约定补偿不替代法定分配 |
