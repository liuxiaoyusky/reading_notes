# （三）了结公司债权、债务，处理公司未了结的业务

## 🧵 寓言故事 —— 《陈掌柜的旧账》

陈掌柜在清河镇开染坊三十年，专染青布蓝布。前年他大病一场，把染坊交给徒弟小周打理，自己回乡下养着。这月他回到铺子一瞧——外头压着三桩没收尾的买卖，心里沉甸甸的。

头一桩，是北边赵家布庄三年前订的一千匹青布，契约上写"秋后交货，分三年付银"。布早已交了，赵家还欠着四百两尾款没给。第二桩，是城里钱粮行付了定金、订了五百匹蓝布，原说今春提货，结果钱粮行半道出事，货没人要，定金也没了下文。第三桩最琐碎——县衙去年定下二十匹青布作官服，还差五匹没交；镇上王木匠帮染坊修房梁，工钱三十两也一直拖着。

小周急得直搓手："师父，染坊可还开灶？"

陈掌柜把账本合上："不开了。可这三桩，都是染坊生前欠下的事，得一件件理清。"

他先说赵家那一千匹青布——四百两尾款，三年期限早满，该到咱们手里。可染坊眼下落幕，没功夫跟赵家打官司。他让小周带上契约去找赵家商量：能一次补齐四百两便罢；若手头紧，就把"赵家欠染坊四百两"这张字据，转给城西当铺，让当铺去收这银子。当铺吃的是这门饭，自有他的法子。

再说钱粮行那五百匹蓝布。他付了定金却没提货，按规矩定金归染坊。可钱粮行如今自顾不暇，硬扣这五十两传出去对名声不利。陈掌柜拍板：定金退一半，原料未染，转手卖给南边来的行商，落个现钱回来。

最后是县衙那五匹青布和王木匠的工钱。两桩虽小，却不能拖——县衙的布是官差，拖一日惹一日的麻烦；王木匠是街坊，欠着工钱过年不像话。小周次日就把三十两工钱从柜上支给王木匠，又从存货里挑出最好的五匹青布，亲手送到县衙销了单。

"染坊从今日起，"陈掌柜站起身，望一眼院子里那口大染锅，"只办这三桩结案的事——除这以外，不染一匹新布，不接一张新单。等这三桩都了了，再议关灶。"

三日后，王木匠工钱结清，五匹青布送入县衙。半月后，赵家果然手紧，以三百六十两把欠款字据折给了城西当铺，当铺当日兑了银子。钱粮行那头也谈妥：定金退一半，布料折价卖出，染坊落回一百二十两。

陈掌柜翻完账本，长舒一口气："该收的银子收回来了，该还的人情还上了，剩下的事——是关灶之后的话了。"

---

**📖 原文定义**

> 清算期间，公司不得开展与清算无关的经营活动，但是公司清算组为了清算的目的，有权处理公司尚未了结的业务。收取公司债权，清算组应当及时向公司债务人要求清偿已经到期的公司债权。对于未到期的公司债权，应当尽可能要求债务人提前清偿，如果债务人不同意提前清偿的，清算组可以通过转让债权等方法实现债权清收。公司清算组通过清理公司财产、编制资产负债表和财产清单，确认公司现有的财产和债权大于所欠债务，并且足以偿还公司全部债务时，应当按照法定的顺序向债权人清偿债务。

**💡 对应点**

| 故事元素 | 概念对应 |
|---------|---------|
| 染坊不再接新活、不染新布 | 清算期间不得开展与清算无关的经营活动 |
| 陈掌柜回到染坊理清四桩未结买卖 | 清算组为了清算的目的，有权处理公司尚未了结的业务 |
| 小周上门向赵家催讨到期的 400 两尾款 | 及时向债务人要求清偿已经到期的公司债权 |
| 把赵家的欠款字据折给城西当铺 | 债务人不同意提前清偿时，通过转让债权等方法实现债权清收 |
| 钱粮行未提货——退一半定金、原料折价转卖 | 处理公司未了结的业务（已付定金的订单） |
| 县衙那五匹官差布亲手送去销单、王木匠工钱当场结清 | 处理公司未了结的小额业务 / 偿付小额债务 |
| 算清"现银+应收"大于所欠外债后，再议关灶 | 确认财产和债权足以偿还全部债务时，按法定顺序清偿 |
