# 3. 剩余价值倍数

## 🏺 寓言故事 —— 《秤上的活物》

民国十二年，河北沧州运河边的小镇上，三个合伙人凑了一笔本钱做皮货生意。说好等份出资、共担盈亏，按股一分。牵头的是孙掌柜，他在运河边租了铺面，专收羊皮牛皮转手卖到天津卫的洋行。第二位是布商老郑。第三位是跑船的何七，三十出头，水性好，每年开春自己驾船往山东收皮子。

民国十三年开春，三人围坐在桐油灯下。何七掏出算盘："咱们当年一共凑了一千二百两。这几年买卖有赚有赔，到今年开春为止，账上能分到咱们自己兜里的钱一共是七百两。"

老郑端着茶碗皱眉："那剩下的本钱呢？"孙掌柜从柜下抽出账册翻开："剩下的是铺子里的货。库房还存着牛皮羊皮，加上铺面租约、跟天津洋行定好的明年单子，拢在一处算算，大概还值九百两上下。"老郑哼了一声："值九百两——又没变成银子。"孙掌柜笑了："可不是，账上写的是'值多少'，兜里揣的才是'有多少'。"

年底北风呜呜。三人围坐在炭火边，何七拨算盘，孙掌柜念账，老郑听着。

"先算总账。"何七的声音很稳，"十年里三人从铺子里一共拿回了七百两，这是'到手'。"他在纸上记下 700。"再看'还没到手'的部分——铺子里还剩着皮子和租约，拢共值九百两，这是'账上挂着'。"

"郑叔当年一共出了一千二百两。"何七接着说，"到手的七百、挂着的九百，总共一千六百两。"老郑眼睛瞪圆了："一千六百两？"孙掌柜敲了敲烟袋锅："一千六百两比一千二百两，一倍多。"何七摇头："先别说赚不赚。光看这会儿账上的家底：'到手'和'没到手'加起来，是当初本钱的一又三分之一。"

老郑追着问："那分到手的有多少？"何七说："到手的就是七百两，七百两比一千二百两，**还没到一半**。"孙掌柜插嘴："那九百两呢？"何七指了指库房方向："那九百两是皮子和租约，**还没卖出去**，还'挂'在账上。"

何七在纸上画了条线，左边写"已到手 700"，右边写"未到手 900"，下面写"本钱 1200"。"左边这七百，叫'已经收回来'；右边这九百，叫'账面还剩'。那九百虽然还没换成银子，可它还在铺子里头，还值这个数。"

老郑慢慢点头："那要是明年皮子大跌，这九百两就可能缩水。"何七说："对。右边那九百两，是个**活的数**。它不是银子，是**装在柜子里的皮子**。皮子在一天，它就值一天；皮子烂了、价跌了，它就缩水。"

老郑端起茶碗又放下："这么说，'账面还剩'是**还没兑现**的——什么时候皮子真卖了、租约真转了手，它才变成真金白银。"孙掌柜把炭火拨了拨："那今年这桩买卖就一句话：'到手'是七百，'挂账'是九百，'本钱'是一千二。前头那七百**已经收回来了**，后头那九百**还挂在账上**。两边都要看。"

老郑没急着接话，盯着那两行字看了好一会儿："只要皮子还在、租约还在，这一笔就**没消失**。"何七点头："只要皮子还在、租约还在，这一笔就**还在那**。"

---

**📖 原文定义**

> 剩余价值倍数（Residual Value to Paid-in，RVPI）衡量了基金剩余未分配资产的价值与投资者已支付实缴资本的比率。RVPI反映了尚未实现的账面回报，其计算公式如下：
>
> RVPI = NAV / (PI_0 + PI_1 + ... + PI_n) = NAV / Σ(t=0 to n) PI_t
>
> 其中，NAV为基金的资产净值，PI_t为投资者在第t年向基金支付的实缴出资额。
>
> RVPI反映了关于基金未来潜在回报的估计。一般来说，RVPI在基金成立初期趋近于1倍，当投资项目出现账面增值时呈现上升趋势。在基金生命的中后期随着项目退出及基金分配而逐渐降低，因此更适用于评估在基金生命周期的早期、大部分资产还没有进行现金分配时的基金业绩。

**💡 对应点**

| 故事元素 | 概念对应 |
|---------|---------|
| 三人凑的本钱一千二百两 | 投资者已支付实缴资本（PI） |
| 库房里的皮子和租约、值九百两 | 基金剩余未分配资产的价值（NAV） |
| 九百两比一千二百两的比率 | 剩余价值倍数 RVPI |
| 老郑说"还没变成银子" | 尚未实现的账面回报 |
| 何七把"到手"和"挂账"分两边算 | RVPI 仅看未分配部分 |
| 皮子价涨了租约值钱了，账面跟着涨 | NAV 随市面波动，RVPI 反映潜在回报的估计 |
| 皮子大跌时九百两可能变成六百 | 资产尚未退出，账面价值有波动风险 |
| "只要皮子还在、租约还在，这一笔就没消失" | RVPI 衡量"剩余未分配"的部分 |
| "皮子真卖了、租约真转了手，才变成真金白银" | 未实现账面回报须待退出分配后才兑现 |
| 生意才到第十年，大部分货还没出手 | 适用于基金生命周期早期、大部分资产未进行现金分配时的业绩评估 |
