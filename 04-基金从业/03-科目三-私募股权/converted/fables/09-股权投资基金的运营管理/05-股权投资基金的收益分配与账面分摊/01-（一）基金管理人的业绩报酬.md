# （一）基金管理人的业绩报酬

## 🏺 寓言故事 —— 《两掌柜的分账》

临河镇上有家绸缎庄，名叫"瑞丰号"，掌柜姓林，人称林掌柜。林掌柜做了三十年绸缎生意，门道精熟，可惜这两年染坊翻了两次船，资金周转不开，眼看就要关张。

那年开春，林掌柜的远房侄子沈清找上门来。

沈清在江南几家大商号里做过学徒，也替人跑过买卖，眼界宽。林掌柜看着侄子长大，知他是个能成事的人，便把话挑明："瑞丰号要重开张，至少要再筹八百两银子。我出铺面、存货、老主顾；你出银子、点子、人手。赚了怎么分，你先说说。"

沈清心里明白，叔叔这是在试他。

他没急着应承，回家想了三天。三天后他登门，从袖子里取出一张纸，纸上只写了一行字："赚了，先把八百两本钱全数还我；剩下的钱，二八劈——叔拿八份，我拿二份。"

林掌柜皱起眉。

"二八？你跑前跑后、担风险、出主意，只拿二份？"

"对。"沈清点头，"叔的本钱不回来，我分文不取。本钱回来了，叔又凭什么分我赚的钱呢？只有赚出来的那一截，才是咱们共担风险、共享的那一份。我多操心、多出力，多分一些；叔出钱、出铺面、按规矩拿大头。"

林掌柜听完，沉默半晌，把那张纸按在桌上，敲了三下："成。就照这个办。"

绸缎庄开张。

第一年行情稳，瑞丰号只赚回了本钱，叔侄俩相安无事。第二年市面依旧平淡，到了年底结账，沈清一分没拿。第三年开春，江南忽起一阵绸缎风，镇上大户人家争着做衣裳，瑞丰号的存货被一抢而空。

林掌柜坐在账房里，看着沈清算出来的数字，半晌没说话。

八百两本钱，三年前沈清投进去；三年下来，连本带利，瑞丰号共赚回了一千二百两。其中八百两是还给沈清的本钱，二百两是两人共担风险下赚出来的"多出来的那一截"。

按约定，沈清从二百两里拿走二份——四十两；林掌柜拿八份——一百六十两。

林掌柜把一百六十两推回去一些，说："行情好，也多亏你这一年跑得勤。多的二十两，你也收着。"

沈清摇头："当初说好的二八，就是二八。规矩立了，不能今天嫌少、明天嫌多。叔叔守规矩，我才能在外面立规矩。"

林掌柜看着他，长长地"嗯"了一声。

他忽然明白过来：沈清要的不是这四十两的多少，是这个"先还本、再分超出来的钱"的路数。这条路数摆在那里，沈清往后无论替谁家管事、无论赚多赚少，都按这把尺子说话。今天的四十两只是小头，沈清赚的是往后每一桩买卖、每一个主顾的信任。

瑞丰号从这一年起，年年按这条二八的路子分账。十年下来，沈清的名字在临河镇越叫越响。林掌柜逢人便说："我那侄子，赚的是规矩。"

---

**📖 原文定义**

> 业绩报酬是指基金管理人为基金创造超额收益后，参与到基金的收益分配中来，按照约定的比例提取已经实现的基金收益，作为对基金管理人创造超额收益的奖励。比较常见的业绩报酬分配模式为"二八模式"，即基金收益或超额收益的20%作为业绩报酬分配至基金管理人，80%分配至基金投资者。

**💡 对应点**

| 故事元素 | 概念对应 |
|---------|---------|
| 沈清投入的八百两本钱 | 基金投资者的实缴出资 |
| "先全数还本，再二八分多出来的那一截" | 业绩报酬的提取前提——先实现超额收益（基金收益分配中投资者优先） |
| 二八劈账——沈清二份、林掌柜八份 | "二八模式"业绩报酬分配比例：管理人 20%、投资者 80% |
| 沈清在淡季三年分文不取 | 基金管理人未创造超额收益时不参与收益分配 |
| 沈清"本钱不回来，分文不取" | 业绩报酬的奖励性质——必须先有"超额"才有"报酬" |
| 林掌柜最终接受并常年按此规矩分账 | 业绩报酬作为长期激励机制对管理人的约束与驱动 |
| 沈清拒绝多拿二十两，坚持原数 | 业绩报酬的契约性——按合同约定比例执行，不因单期表现随意调整 |
| 沈清赚的是"往后每一桩买卖的信任" | 业绩报酬机制的核心目的——激励管理人最大化创造投资收益 |
