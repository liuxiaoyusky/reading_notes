# 一、股权投资基金的基本架构

## 🌳 寓言故事 —— 《老槐树下的四家人》

清河镇东头有一棵三百年的老槐树。槐树下住着四家人。

老周是镇上有名的掌柜，在江南做了二十年绸缎生意，攒下一份厚实的家底。年景好的时候，他一个人能拿出几百两银子周转；年景差的时候，他也不慌——他知道钱放在手里会发霉，得让它动起来。

老周有个外甥，叫李娜。李娜二十岁出头，在京城的织造局做过三年学徒，眼界宽，手也巧。她对绸缎的成色、产地的差异、各路客人的喜好，门儿清。每年回镇探亲，她都跟老周说："舅舅，您一个人挑货、跑码头、谈价钱，太累了。"

老周摆摆手："累是累，可我也乐在其中。"

老陈是镇上的教书先生，手头没几个闲钱，但他媳妇过门时带了一份嫁妆——三十两压箱银。教书先生家里平日不愁吃穿，这笔银子就一直压在床底下。媳妇偶尔念叨："这钱在床底下躺了七八年了，都没生过利息。"

老陈笑笑："生利息的事，咱们不懂。别折腾它。"

王志远是镇上的木匠，靠一手好手艺吃饭。手艺人有一个特点——手里有活儿的时候从不缺钱，手里没活儿的时候连买米都要赊账。所以王志远平日里不太敢把钱攥在手里，也不愿把好不容易攒下的几两银子借给谁。他见过太多"借出去就回不来"的事。

阿秀是王志远的媳妇，在镇上开着一家小茶馆。她嘴甜人勤，茶馆里人来人往。有一回她给王志远算了一笔账："咱家一年能攒下十二两。如果这十二两借给老周那样的行家，让老周转手出去做买卖，年底分咱们几成，咱们不是白赚吗？"

王志远摇头："那不叫借，那叫合伙。合伙的账最难算。"

这一年清河镇遭了一场大水。灾后百废待兴。老周心里盘算：灾后重建，土布、草药、木料，价格一定往上走。他想做一笔大生意——把江南的绸缎压一压，转头去收灾区周边的土布和药材，等价高了再出手。可是他手里的本钱不够。

他想到了李娜的话，也想到了镇上几家人的光景。

清明那天，老周把老陈、王志远、阿秀请到老槐树下喝茶。他开门见山：

"我有个想法。我做买卖，你们出钱。赚了，按事先说好的分；亏了，亏的是你们出的那一份。买卖怎么做，码头怎么跑，货怎么挑，全听我的。你们不掺和，我也不让你们掺和——掺和了反而乱。"

老陈第一个问："我出多少合适？"

老周说："量力而行。一两不嫌少，十两不嫌多。"

王志远问："亏了真就全亏我们出的那份？"

老周点头："亏的是你们出本钱的那一份。我出力、出人、出脑子，但不掏本钱——我掏的是手艺和工夫。"

阿秀又问："那我们怎么知道你没把我们的钱拿去乱花？"

这一问，问到了点子上。

老周想了想，说："咱们找一个镇上都信得过的人，把所有收来的银子，全交到他手里。他不动用一分一厘，只管记账、付款、收款。我要用钱，从他那里支；货卖出去了，钱回到他那里。他再按咱们说好的比例，把钱分到各家。"

阿秀当场就拍了一下腿："我大伯在镇上开钱庄半辈子，人人都信他。"

于是这件事就这么定了。

四家人凑在一起，拟了一份字据，字据上写明：

第一，老陈、王志远、阿秀他们三家是"出钱的"，出钱多寡各凭自愿，按出钱的多少分利润，但平时不参与买卖的具体事情；

第二，老周是"管事的"，买卖怎么做、货怎么挑、什么时候出手，全由他说了算，老周自己也掏一份本钱出来——掏出来的是"手艺钱"——把自己的利害跟大伙捆在一起；

第三，镇上钱庄的老掌柜是"管账的"，所有的钱从他那里进，也从他那里出，他只管钱，不掺和买卖；

第四，老周除了年底分到一份利润外，平时从总账里按月拿一份"操心钱"——他得养家、跑码头、雇伙计，这些花销要从生意里出；此外，等所有买卖都收尾、钱都收回来、大家先拿回本金、再按事先说好的比例分到一定数目的利润之后，剩下的部分老周还能再分一份——这是对他这一行手艺的额外奖赏。

老陈回去跟媳妇商量了三天，媳妇终于松了口：把那三十两压箱银，从床底下翻出来，凑了进去。

王志远犹豫了一阵，也咬了咬牙：手艺人不攒钱不行，但错过这一回，往后未必还有。他把十二两攒了一年的银子递了过去。

阿秀把茶馆这一季的流水结余，挤了八两出来。

老周自己也掏了二十两——他说，"出钱的才真心疼这桩买卖"。

字据画了押，钱庄老掌柜的账本上，多了一笔总账。

灾后的生意比预想的还要好。老周跑了三趟码头，每一趟都踩准了节拍。土布从灾区收上来，两三个月后价格翻了一番；药材囤了半年，赶上一场时疫，价格涨了三倍。年底一结账，三家出钱的人先拿回各自的本金，再按事先说好的比例分了一笔利润——老陈分了十五两，老陈媳妇的压箱银一年翻了一番；王志远分了六两；阿秀分了四两。

老周呢？除了月月的"操心钱"之外，等所有人分到利润之后，剩下的部分，他再拿一份。一年下来，老周在镇上盖了新房，给李娜置办了一份体面的嫁妆。

第二年春天，老槐树下的茶又开喝。老周笑着跟大伙说："这桩事能成，靠的是三样：出钱的人放心，不管闲事；管事的人上心，把买卖当自家事；管账的人公正，一分一厘都过明路。三样凑齐了，才是这门营生的样子。"

老陈点头："我以后每年都把闲钱凑进去。"

王志远也说："我从前最怕合伙分账。现在明白了：分账分得清，靠的是人，更靠的是那套安排。"

老槐树在风里哗哗响。三百年的树看着镇上来来去去的人。它见过太多散伙的反目，太少这样收场的圆满。

但老槐树也见过另一面——王志远说得对：分账分得清，靠的是人，更靠的是事先讲清楚的那套安排。如果字据上没写清楚老周事后能分多少，老周未必肯把全部心思扑上去；如果没有钱庄的老掌柜，钱到了老周手里，谁也说不清是赚了还是亏了。

那棵老槐树下的四家人，靠的不是信任——信任是会变的——靠的是四份角色：出钱的人、管事的人、管账的人，加上把大家捆在一起的那份字据。

这个道理，老槐树看了三百年。

**📖 原文定义**

> 股权投资基金是开展股权投资的载体，在管理人的运作和管理下，将从投资者募集的资金投向底层投资项目，通过被投资企业的业绩增长和发展获得资本增值，在投资项目实现投资退出后，再将相应的收益向投资者进行分配，从而实现为投资者获取投资收益的目标。

> 以合伙型基金为例，股权投资基金基本架构通常如图1-1所示。

> 在合伙型基金中，基金的投资者通常被作为有限合伙人（Limited Partner，LP）。常见的投资者类型包括机构投资者和高净值个人（详见第四章第二节）。投资者提供资金，一般不参与日常管理，通过筛选优质的基金管理人，委托管理人进行基金投资，以获取相应的回报。由于有限合伙人以出资为限承担有限责任，投资者的投资损失风险也通常限于其投资的金额。

> 基金管理人通常由拥有较好的投资能力和项目执行能力的机构担任。基金的普通合伙人（General Partner，GP）可以与基金的管理人为同一主体，也可以与管理人为不同的主体。基金管理人通常负责投资项目开发、尽职调查、投资决策和投后管理，以及项目退出工作。为了实现与投资者利益的捆绑，管理人通常同时作为基金的普通合伙人向基金出资。管理人的报酬通常包含向基金收取的管理费和从基金的收益中提取的业绩报酬，在同时作为普通合伙人向基金出资时，管理人还可以取得出资部分的资本利得。

**💡 对应点**

| 故事元素 | 概念对应 |
|---------|---------|
| 老周出谋划策、跑码头、谈价钱、做买卖 | 管理人：拥有投资能力和项目执行能力，负责投资项目的开发与执行 |
| 老陈、王志远、阿秀出资、不参与具体买卖 | 投资者：提供资金，不参与日常管理，委托管理人进行投资 |
| 三家出钱的人"亏了亏的是出本钱的那一份" | 有限合伙人以出资为限承担有限责任，投资损失风险通常限于投资金额 |
| 老周自己也掏二十两本钱 | 管理人同时作为普通合伙人向基金出资，实现与投资者利益的捆绑 |
| 字据上写明老周按月拿"操心钱" | 管理人向基金收取管理费 |
| 字据上写明老周在大家分到利润之后还能再分一份"额外奖赏" | 管理人从基金收益中提取业绩报酬 |
| 老周除了操心钱和额外奖赏，自己那份本钱也跟着赚了 | 管理人作为出资人取得的资本利得 |
| 钱庄老掌柜管账、只管钱不掺和买卖 | 托管人角色：保管资金、记录账目，与管理人的投资决策相分离 |
| 四家人画押的字据 | 基金合同：明确各方权利义务与分配机制 |
| 灾后土布、药材的生意，老周三趟码头踩准节拍 | 投资项目开发、投资决策、投后管理、项目退出 |
| 资金先从老陈等流入老周账上，再去收土布药材，最后回款按字据分配 | "从投资者募集 → 投向底层项目 → 实现退出 → 向投资者分配收益"的完整载体逻辑 |
| 老槐树最后说"靠的不是信任，是事先讲清楚的那套安排" | 基金架构的核心：通过合同安排明确角色与分配，而非仅依赖信任 |
