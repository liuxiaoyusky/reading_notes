# 一、股权投资基金支持科技创新

## 寓言故事 —— 《磨铜镜的师傅》

江南有一条老街，街尾有一间打铁铺。铺子的招牌是「周记铜器」，掌柜姓周，村里人都喊他老周。老周四十出头，手掌厚实，手背上烫着几道旧疤——是年轻时打铁留下的。

老周打了一辈子铜。打铜壶，打铜锁，打铜盆。打铜这件事，最难的是「入水」那一刻——铜件烧红了，师傅要把它按进冷水里，水声「嗞啦」一响，铜的性子才定下来，定下来的铜才硬，才亮，才不会走形。

老周有两个儿子。大儿子叫周明远，二十二岁，在城里念完工科，回了村。二儿子叫周明澈，十九岁，还在城里的学堂里念书。明远回来那天，老周正在铺子里敲一只铜壶。明远站在门口，背着一个旧帆布包。

「爹，」明远说，「我不想考功名了。我要回村里做事。」

老周没有抬头，锤子又落下两下。

「做什么事？」

「磨镜子。」

老周这才停手。锤子搁在砧子上，砧子上的铜壶「嗡」地响了一声。

「磨镜子？」

「不是普通的镜子，」明远说，「是一种新的镜子。不是用铜磨的，是用一种我还没完全想明白的料做的。比铜镜亮十倍。我和城里的同学试过一小块，夜里能照出月亮上的影子。」

老周看着明远。他知道大儿子在城里跟人捣鼓东西，但他没想到儿子会「回村」来捣鼓。村里能有什么？村里只有打铁铺、染坊、豆腐坊。

「这种东西，城里不能做？」老周问。

「城里太贵，」明远说，「一间屋子，租金够我吃半年。城里人也不愿意借我他们的炉子。我回村，是想借咱家的炉子。」

老周沉默了半晌。

「你要借多久？」

「三年。」

「三年里吃什么？」

「这个——」明远从帆布包里摸出一张纸，展开给老周看。纸上画着一只新镜子，旁边写着几行字：「三年做出能照人的镜子一只。三年里不向爹要一文钱。」

老周没有说好，也没有说不好。他只是把那张纸折起来，搁在砧子边。

「先吃饭，」他说。

明远就这样住下了。他把铺子后院那间堆杂物的小屋收拾出来，铺了一张床，把从城里带回来的几个瓶子、几块铁片、几卷铜线码在桌上。那天晚上，他在灯下一直坐到子时，老周起来给炉子封火的时候，还看见后院那间屋亮着。

这间铺子此后三年，再没有一寸闲。

明远每天的工作分三段。白天他在炉子上烧东西。烧的是从镇上买的粗铜、粗铁、还有从山里挖出来的石头。石头要先磨成粉，铜要先化成水。下午他在桌上拼东西。把各种料按不同的比例合在一起，看哪一份在夜里能发出光。晚上他坐在后院的屋檐下，看天上的星星。他要琢磨的，是怎么让手里那一小块亮光「稳下来」——不是闪一下就灭，是能亮一整夜。

这件事的难处，他后来对弟弟明澈说：「不是难在'做出来'。我第一年就做出来了。难的是'做稳'。稳不下来，就不能交给人用。」

明远第一年烧坏了十七只炉子。烧坏的炉子要修，要换，要重新砌。砌一只新炉子的工钱，是周记铜器三个月的进账。老周没有说什么，他只是在账本上把一笔一笔的支出记下来，记到第十二只炉子的时候，账本已经换到第三本了。

「爹，」明远有一天晚饭时说，「我不能再烧了。再烧，咱家铺子要塌。」

「你说怎么办。」

「我得有一笔本钱。这笔本钱不用还，但三年后如果做成了，我要分一份利给这出钱的人。」

老周停下筷子。他知道儿子在说什么。

「你这是要把咱家铺子——」

「不是卖铺子，」明远说，「是把这一份'东西'许给愿意出钱的人。我做出来的东西归我，但三年里烧坏的本钱、走村串巷买料的脚力、雇人看炉子的工钱，都从这笔钱里出。三年后东西做出，这笔钱要收回去——还要再多收一份，做成后赚的钱里分出来的那一份。」

「你不向人借钱？」

「不借。借的钱要按月还，利上加利。我做的事，前三年根本没有进账，借了还不起。我出的是'东西'换'钱'，人出的是'钱'换'东西'。这是一桩买卖，不是一笔债。」

老周想了想，点了点头。

「你去找谁？」

明远列出三个人。一个是镇上染坊的张老板，张老板每年秋天收布，手里有一笔闲钱。第二个是村里豆腐坊的李婶，李婶攒了十年，准备给儿子娶媳妇。第三个是县城里开药铺的老王，老王前年刚把铺子的债还清，账上还有余银。

明远没有先去找张老板。他知道张老板精明，会问「这事儿能不能赚」。他先去找了李婶。

李婶在豆腐坊里听明远说完，叹了一口长气。

「明远，」她说，「婶子不懂你那些什么料什么粉。婶子就问你一句——你要是烧到第二年就撂挑子，婶子的钱怎么办？」

「婶子的钱我立字据，三年内不挪用。三年后东西做出，婶子的本钱原数还，再加一份利。若做不出，本钱由我用别的活路慢慢还，不赖账。」

李婶又叹了一口长气。她从房梁下的坛子里摸出一只布包，打开，里面是她攒的五十两银子。她把布包推到明远手边。

「婶子信你爹，」她说，「信你爹的儿子。」

明远又去县城找老王。老王在药铺里听完，把算盘拨了一通。

「你这一年要烧多少料？」

「粗算二十两。」

「三年？」

「六十两打底，可能上不封顶。」

「我出八十两，」老王说，「四十两算我的本钱，四十两算我借给你周转的——这笔不算利息，但你三年后得让我在你做出来的东西里，挑一只要我铺子用得上的。」

「成交。」

最后明远才去找张老板。张老板听明远说完，没有立刻答应。

「你那玩意儿，」张老板说，「做出来卖给谁？」

「卖给夜里需要光的人。夜里读书的，夜里走路的，夜里看病的。」

「我出二十两，」张老板说，「但我有一个条件——做出来后，第一批货要给我二十只，我拿去送人。」

明远想了一夜，答应了。

三份钱凑在一起——李婶五十两、老王八十两、张老板二十两——一共一百五十两。这笔钱，明远立了三份字据，字据上写明：「本钱到日子原数奉还，外加利润一成。若做不成，本钱由明远以其他营生慢慢归还，十年为期。」字据没有「按月还利」四个字，也没有「抵押铺子」这四个字。

老周看着这三份字据，对明远说：「你这是把你这条命押在里头了。」

「不是押命，爹，」明远说，「是押我这一桩买卖。这桩买卖成了，我赚到的不只是钱，是我这辈子要做的事。买卖不成，我再去别的买卖上把这笔钱挣回来。」

「那三位出钱的人呢？」

「他们信的不是我，爹。他们信的是这桩买卖能成。这桩买卖要是真能成，他们拿回本钱，再拿一份利，皆大欢喜。这桩买卖要是不成，他们拿不回本钱，十年里慢慢拿。我不赖账。」

明远用这一百五十两，过了三年。

三年里他烧坏的东西比第一年少了一半。炉子的砌法他改了，料的比例他也改了。第二年的春天，他做出了一只能在夜里亮一整晚的东西。第三年的秋天，他做出了一只能照出人脸的东西——不是模糊的影子，是清清楚楚的脸。

第三年冬天，明远把那三份字据摊在桌上。桌上还有三样东西：一只他自己磨的镜子，一只他自己改的炉子模型，一只他这三年记下的所有账。

他请李婶、老王、张老板来铺子里。

李婶先到。她进后院，看了一眼桌上那只能照出人脸的镜子，又看了一眼明远。

「这是你做的？」

「是。」

「我那五十两——」

「原数还您，」明远说，「再加一成利。五十两加五两，一共五十五两。」他把钱袋推到李婶面前。

李婶摸了摸钱袋，笑了。她没数，把钱袋揣进怀里。

「你爹的儿子，」她说，「没让我白攒十年。」

老王到的时候，明远把八十两还了，外加八两利，一共八十八两。老王接了钱，从怀里掏出一张纸。

「我那四十两，」老王说，「按字据，我要从你做出来的东西里挑一只要我铺子用得上的。」

明远把一只改过的、能在夜里照清药方字迹的镜子递到老王手里。老王把它翻来覆去看了半天，点了一下头。

「行。」

张老板最后到。他要的不是钱，他要的是二十只货。明远从后屋搬出二十只用油纸包好的镜子，一一码在桌上。

「我能不能问一句？」张老板看完货，说。

「您问。」

「这三份字据上，」张老板指指桌上的三份字据，「为什么没有写'按月付息'？为什么没有写'抵押周记铺子'？你就不怕这三年里你跑了？你就不怕我们仨来追债，把你家铺子砸了？」

明远笑了笑。

「张叔，您看，」他说，「这三份字据里写的是'本钱原数奉还，外加利润一成'。不是'借'，是'投'。您出二十两，是投这一桩买卖。我做出来，您拿二十只货去送人。我做不出来，您拿不回这二十两——但您拿不回这二十两，也不是因为您'借'给我了，是因为您'投'的这桩买卖折了。」

张老板愣了一下。

「那这三年里你要是跑了呢？」

「我跑不了，」明远说，「我跑的代价，比我留下来做成的代价，要大得多。」

张老板又愣了一会儿，然后点头。

「我明白了，」他说，「你这不是借钱。你这是——」

「对，」明远说，「我不是'借'钱的人。您三位也不是'放'钱的人。我们是一起在做这一桩买卖。买卖成了，大家分。买卖不成，大家认。」

张老板拿起一只镜子，端详了半天，把它揣进怀里。

「明远，」张老板说，「明年你要是还要做下一桩，叔再给你二十两。」

明远谢过三位，把他们送到村口。回来的时候，老周还坐在铺子里的砧子边，锤子搁在砧子上，砧子上的铜壶已经凉透。

「爹，」明远说。

「嗯。」

「您听见了吗？」

「听见了。」

「我刚才说的那几句话，您听明白了吗？」

「听明白了，」老周说，「你不是借钱。你是叫人家一起做事。」

「对，」明远说，「这三个人出了钱，但他们出的不是'债'，他们出的是'本钱'。我做出来的东西，不是我一个人的，是我和他们三个人一起做的。我赚的那一份是我该赚的，他们赚的那一份是他们该赚的。买卖折了，我认栽——我用别的活路慢慢还他们十年。买卖赚了，大家分。」

老周点了点头。

「你二弟明澈，」老周说，「他在城里念书，念的是算学。」

「嗯。」

「等他念完，让他回村。」

「让他回村做什么？」

「让他也来磨镜子，」老周说，「你一个人磨，太慢。」

明远笑了。他回后院继续磨他的镜子。后院的屋檐下，那只新磨出的镜子在桌上亮着，把桌面照得清清楚楚。

老周坐在铺子里，把砧子上那只凉透的铜壶又烧起来。炉子里的火苗跳着，映在墙上。

他没有再问明远「什么时候能赚回本钱」。他知道，这件事不是「赚」不「赚」的事。这件事是「做」不「做」的事。明远在做，就一直在做。明远一停，这件事就完了。

一只镜子是这样。一间铺子是这样。一个村子是这样。

他年轻时打铜，铜件入水那一刻，「嗞啦」一响，铜的性子才定下来。明远磨镜子也是这样——磨到那一晚，整只镜子亮了一整夜，明远的性子才定下来。

父子俩都没有再说话。铺子外头，江南的雪下了起来。

**📖 原文定义**

> 应当说，中国的科技创新能力受到多方面因素的共同作用：一是支撑创新的长期资本投入，这是中小企业实现科技创新的金融基础；二是人才红利，中国拥有大量科学家、工程师和理工科人才，构成创新的智力基础；三是资本和科学家结合的方式，决定了科研成果转化和创新培育的效率；四是中国拥有全球最大的超级市场，产业和消费升级为科技创新提供了广阔的应用场景。只有促进上述创新要素相互驱动、共同作用，推动创新链、产业链、资金链、人才链深度融合，才能更好地助力科技自立自强，催生更多新技术新产业，在日益激烈的国际竞争中形成独特优势，实现科技、产业和金融高水平循环。

> 股权投资基金的特点决定了其能够有效撬动大量社会资本，直接形成科技创新型企业的资本金，为科创企业提供覆盖全生命周期的资本支持。一方面，中小微企业尤其是科创型中小企业的成熟往往需要较长的周期，在整个过程中，中小微企业对资金量的需求又较大，在不提升企业财务杠杆的条件下，股权投资基金能够为科创企业提供长期资本，捕捉企业成长的机会。另一方面，股权投资基金也能通过产业整合、企业经营改造等方式推动存量经济企业的转型与调整，积极助力战略性新兴产业整合提效和传统经济改造升级，是我国直接融资体系中的重要有生力量。

> 股权投资基金已成为增加社会直接融资、加速促进创新资本形成、全面支持科技创新和产业结构调整的中流砥柱。注册制改革以来，近乎全部的北交所上市公司、近九成的科创板上市公司和六成的创业板上市公司获得过股权投资基金支持，股权投资基金已成为推动科技创新的重要金融支撑。分行业来看，股权投资基金渗透率较高的行业大多为医疗健康、电子信息、先进制造等硬科技行业。从股权投资基金的发展历史来看，许多著名的科技企业，如微软、英特尔、谷歌、特斯拉、百度、阿里、腾讯等，在发展初期背后都有股权投资基金的支持。

| 故事元素 | 概念对应 |
|---------|---------|
| 明远要「借三年」做新料镜子，铜器铺前两年没有进账 | 中小微科创企业成熟周期长，前阶段没有收入 |
| 父老周本不看好，但允许明远用自家炉子 | 科技创新的智力基础——人才、科学家、工程师的实验场所 |
| 明远烧坏十七只炉子，账本换到第三本 | 创新过程中对长期资本的消耗 |
| 明远没有「向人借钱」，而是「立字据许以分成」——不按月还利、不抵押铺子 | 股权投资基金「不增加企业财务杠杆」——不形成债务，而是形成资本金 |
| 三份字据写明「本钱原数奉还，外加利润一成」，做不成由明远以其他营生慢慢还 | 投资者与企业共担风险、共享收益，是「直接融资」而非「间接融资」 |
| 李婶五十两、老王八十两、张老板二十两，三方出钱 | 「有效撬动大量社会资本」——民间资本被引导进科技创新 |
| 老王除本钱外另出四十两周转，并要求「做出来的东西里挑一只要铺子用得上」 | 资本与产业结合——「资本和科学家结合的方式」 |
| 张老板不要钱要「二十只货去送人」 | 股权投资的多样化回报形式——可以分现金、可以分产品、可以分股权 |
| 明远说「我跑不了，我跑的代价比我留下来做成的代价大得多」 | 投资者通过字据、契约、参与决策等机制绑定创业者长期承诺 |
| 明远做出来的镜子先给老王药铺用、给张老板送人 | 「科技成果转化」——从实验室产品到具体应用场景 |
| 明远父子铺子既打铜器又磨镜子 | 创新链、产业链、资金链、人才链在同一场景中融合 |
| 老周最后说「明远一个人磨太慢，让明澈也回村」 | 科技创新不是一个人能做完的事——需要持续的人才接力 |
