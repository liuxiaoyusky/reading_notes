1. **不要用 `TaskOutput` 收 subagent 全量结果** — 它会把整个 subagent transcript 拉回主 context,
   3 个 fab × 几 KB 就爆。换法:
   - 改用 `Read` 读 `agent-*.jsonl` 最后 50 行(只看 subagent 末尾回报)
   - 或者 subagent 完成后**让它自己负责 `record` + `git commit`**,主 loop 不收任何东西,
     只等 `task-notification` 拿 status 即可

2. **派 subagent 时不要把整段 prompt 都塞在 main loop 里** — prompt 模板已经写在
   `.orchard/prompts/` 下,新 session 只发一个 "Read prompt file X, dispatch subagent, await notification"
   的最小指令。

3. **每 30 个 fab 主动 /compact** — 哪怕感觉还够用,因为每次派 + 收 都会
   隐性增加主 context(系统 prompt 重复出现)。
