# 第一节 股权投资基金的概念和特点

## 🏺 寓言故事 —— 《老周的船队》

海边镇上，老周是出了名的懂船人。年轻时他跑过南洋，闻过香料，也见过风暴。到了五十岁，他有了一个念头：造一支大船队，去更远的海外做生意。

可一支船队需要十艘大船，老周算来算去，自己的积蓄只够造两艘。他坐在码头边，看着海面上的帆影，对老友阿福叹气："我懂船、懂航线、懂货，可我没那么多钱。"

阿福是个布商，手里有些积蓄，但对大海一窍不通："老周，我出钱，你出力，赚了怎么分？"

老周眼睛一亮："咱们不公开招揽镇上所有人，只找几个信得过、赔得起、也愿意等的人。钱凑在一起，船归船队，账归我管。出海一次，少说三五年才能回来，中间谁也撤不走。"

这话传出去，镇上来问的人不少。老周却一一摇头："你家底子薄，孩子还小，这钱要是五年回不来，你怎么办？"最后，只有阿福、老李、钱掌柜和两位退休的官员入了伙。他们每人出的钱都不是小数目，而且都明白一件事：船没回来之前，这钱动不了。

船队出海那天，码头上挤满了人。老周站在船头，对五个合伙人说："海上的事，我替你们盯着。但大海不讲交情，有的船可能满载而归，有的船可能沉在半路。我能保证的只有一点——我会用一辈子跑船的本事，替大家挑好航线、选好货物、管好水手。"

头两年，只偶尔有快船带回几封信。信上说，三艘船在异域港口卸了货，赚了一倍；一艘船遇上飓风，桅杆断了，正在修。阿福急得团团转，想把钱要回来，老周却摇头："当初说好的，五年为期，船在海上，账不能乱动。"

到了第四年，消息渐渐多了。有人传说老周的船队在锡兰换到了整船的宝石，也有人说其中两艘船已经沉了。合伙人们心里七上八下，却也只能等着。老李私下对阿福说："咱们隔着一片大海，船上到底怎样，只有老周最清楚。这叫什么？这叫咱们信他这个人。"

第五年冬天，船队终于回来了。七艘船进港，甲板上堆着香料、宝石和稀罕货。清点之后，有人大赚，有人小赚，但总的来说，远比把钱埋在床底下强得多。也有两艘船永远留在了海底，成了账上的亏损。

老周把账目摊在桌上，一笔一笔算清楚。他拿出自己应得的那份，说："我管船队，要拿一份辛苦钱；船队赚了，我也按规矩分一份。但船沉了，我也跟着承担。这就是咱们当初的约定。"

阿福看着满屋子的货，忽然明白了：这笔钱，从一开始就不是普通的买卖。它要等专业的人、要愿意等五年、要能承受船沉的风险、还不能随便退出。它像一艘远洋的船，看不见、摸不着，但只要选对了船长，耐心等下去，就能带回意想不到的财富。

---

**📖 原文定义**

> 国内所称"股权投资基金"，是指主要投资于非公开交易企业股权的基金。这里的"非公开交易企业股权"，包括未上市企业的股权和上市企业非公开交易的普通股、可转换为普通股的优先股和可转换债。

> 作为一种重要的资产配置工具，股权投资基金具有以下特点：专业性较强；投资期限长、流动性较低；投后管理投入资源较多；公允估值较为困难；项目间回报分布不均；信息不对称较为严重；投资者门槛较高。

**💡 对应点**

| 故事元素 | 概念对应 |
|---------|---------|
| 老周造的船队，去海外做生意 | 股权投资基金 |
| 投资的是船队的股权份额，而非公开买卖的货物 | 投资于非公开交易企业股权 |
| 只找阿福、老李等少数人私下入伙，不公开招揽 | 非公开方式募集 |
| 老周懂船、懂航线、懂管理 | 专业性较强 |
| 出海一次需要三五年，中途不能撤资 | 投资期限长、流动性较低（耐心资本） |
| 老周每年送信、管水手、修船 | 投后管理投入资源较多 |
| 船在海上，真实价值难以准确估算 | 公允估值较为困难 |
| 有的船满载而归，有的船沉没 | 项目间回报分布不均 |
| 合伙人隔着大海，只能信老周的报告 | 信息不对称较为严重 |
| 只有有钱、赔得起、愿等待的人才能入伙 | 投资者门槛较高 |
| 老周按规矩分一份收益，也承担亏损 | 基金管理人参与收益分配、承担风险 |
