# 第三节 股权投资基金市场参与主体

## 🎯 寓言故事 —— 《粮仓里的分工》

老周在镇上经营一座大粮仓，冬天收粮、春天卖粮，赚取差价。起初只有他自己和几个出钱的朋友，日子久了，粮仓越来越大，镇上的人都说："这已经不是你老周一个人的买卖了。"

那一夜，粮仓偏房突然起火。火很快被扑灭，但合伙人们慌了神。阿福第一个冲到老周面前，脸涨得通红："老周，你是不是动过粮仓里的钱？我怎么听说账目对不上？"

老周皱着眉，还没来得及开口，一旁的钱掌柜已经把一个檀木箱子抱到桌上："阿福，你先别急着吵。钱箱一直由我单独保管，钥匙在我这儿，老周动不了。箱子里的进出，每一笔都在册。"

阿福将信将疑。这时，账房王先生翻开一本厚厚的册子："阿福，你入了多少份、该分多少粮，这里记得清清楚楚。咱们这叫份额登记，谁有多少，白纸黑字，跑不了。"

李讼师也站了出来，手里抖着一叠契约："当初入伙时，条款怎么写、规矩怎么定，都是我拟的。老周有没有越权，一对照就知道。"

张算盘是镇上出了名的细心人，他打开带来的算盘："我替你们审过账了。钱掌柜的箱子、账房先生的册子、老周的进出单据，三处一对，数目清楚。老周没私吞。"

阿福的火气消了一半，但仍不依不饶："就算老周没动钱，这火怎么起的？以后要是再出事呢？"

老周叹口气，从袖中取出一份文书："这是县衙派人来查验后出具的火因单子，说是老鼠咬断了蜡烛绳，不是人为。县衙还叮嘱咱们，粮仓大了，得按规矩办。"

一旁商会会长也开了口："咱们镇上几家大粮仓，已经商议过了，要立个行规。钱怎么管、账怎么记、火怎么防，都写在行会章程里。这叫自律，自己管自己，比外人硬管强。"

阿福坐下来，看着满屋子的人：钱掌柜管钱箱，王先生管份额，李讼师管契约，张算盘管审计，县衙管监管，商会管自律。每个人都在粮仓这件事里有一席之地，少了谁，心里都不踏实。

他挠挠头，对老周说："看来我这股东当得轻松，是因为有这么多人在背后盯着。"

老周笑了："粮仓越大，越不能只靠一个人。咱们这伙人，各管一摊，才能让出钱的人放心。"

从那以后，镇上再有人想入伙，老周都会把人带到粮仓里，一一介绍："这是出钱的人，这是管事的，这是管钱的，这是记账的，这是写契的，这是查账的，这是县衙的监管，这是商会的规矩。"每一个角色，都是这座粮仓能稳稳运转下去的根基。

---

**📖 原文定义**

> 股权投资基金当事人，通常是基金合同的签署方。从本质上看，股权投资基金是资产管理产品，基金投资者将资金委托给基金管理人管理，因此，基金投资者和基金管理人必然是基金当事人。另外，如果基金财产交由托管人托管，则基金托管人也是基金当事人之一。

> 股权投资基金市场服务机构主要包括基金销售机构、基金份额登记机构、律师事务所、会计师事务所、估值核算服务机构、信息技术系统服务机构等。

> 中国证监会及其派出机构是我国股权投资基金的监管机构。中国证券投资基金业协会是我国股权投资基金行业的全国性自律组织。

**💡 对应点**

| 故事元素 | 概念对应 |
|---------|---------|
| 阿福等出钱入伙的人 | 基金投资者（基金份额持有人/LP） |
| 老周经营管理粮仓 | 基金管理人（GP） |
| 钱掌柜单独保管钱箱 | 基金托管人 |
| 王先生的份额册子 | 基金份额登记机构 |
| 李讼师拟契约 | 律师事务所 |
| 张算盘核对账目 | 会计师事务所 / 估值核算服务机构 |
| 县衙查验、出火因单子 | 政府监管机构（中国证监会） |
| 商会立行规、自我管理 | 行业自律组织（中国证券投资基金业协会） |
| 老周向新人介绍各方角色 | 股权投资基金市场参与主体 |
